모두 3D 모델에서 베이크한 평면 스프라이트입니다. 태양과 불이 실시간으로 비춥니다.

Sun Forge는 Unity 6 및 URP에서 3D를 2D로 바꾸는 스프라이트 베이커이자 실시간 2D 조명입니다. 둘은 함께 써도 되고, 하나만 따로 써도 됩니다.

3D 모델을 2D 캐릭터로 베이크

방향과 애니메이션을 고르세요. Sun Forge가 모든 프레임을 스프라이트로 렌더링하고, 그 스프라이트를 재생하는 프리팹을 만듭니다.

직접 그린 스프라이트용

기존 스프라이트에 조명 적용

픽셀 아트를 포함한 스프라이트에서 Set Up for Lighting 메뉴를 선택하세요. 노멀 맵을 가져와 쓰면 스프라이트에 입체감이 생깁니다. 금속으로 쓸 색과 발광할 색을 고르면 Sun Forge가 금속 텍스처와 발광 텍스처를 만듭니다.

플랫포머용

플랫포머용 사이드 뷰 베이크

Elevation Angle 필드가 0이면 모델을 사이드 뷰 스프라이트로 베이크합니다. 태양을 움직이고, 광원을 배치하고, 스타일을 조정해 레벨을 비추세요.

픽셀 아트로 만들려면 Pixels Per Unit 필드 값을 낮게 설정하고 점 필터링으로 베이크하세요.

캐릭터, 식물, 상자, 횃불 부품은 쇼케이스 샘플에서 가져왔습니다.

프리셋과 배치 베이크

프리셋은 모델 하나를 베이크하는 방식을 저장합니다. Batch 탭은 선택한 프리셋을 한 번에 베이크합니다.

다시 베이크해도 같은 프리팹에 베이크되며, 직접 추가한 자식 오브젝트와 컴포넌트, 플랫폼 오버라이드도 그대로 남습니다.

질문

구매 전 확인 사항

광원을 움직이면 다시 베이크해야 합니까?

아닙니다. 태양, 광원, 스타일은 실시간으로 바뀝니다. 그림자는 스프라이트와 함께 움직이며, 베이크할 때의 방향을 그대로 유지합니다.

스프라이트는 Sun Forge에서만 쓸 수 있습니까?

아닙니다. 베이크는 표준 Unity 스프라이트, 아틀라스, 애니메이션 클립, 애니메이터 컨트롤러, 프리팹을 만듭니다.

3D 모델이 게임에 포함됩니까?

아닙니다. 3D 모델, 메시, 리그는 빌드에 포함되지 않습니다.

3D 게임에도 쓸 수 있습니까?

카메라 각도가 하나로 고정된 3D 게임이라면, 모델을 스프라이트로 베이크해 게임을 2D로 만드세요.

직접 그린 스프라이트에도 조명을 적용할 수 있습니까?

네. 스프라이트를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 Sun Forge > Set Up for Lighting 메뉴를 선택하세요. 직접 만든 노멀 맵으로 스프라이트에 입체감을 줄 수 있습니다.

어떤 플랫폼에서 실행됩니까?

URP가 지원하는 모든 플랫폼을 대상으로 만들었습니다. 게임 빌드는 Direct3D 12를 쓰는 Windows, Vulkan 또는 OpenGL ES 3을 쓰는 ARM64 Android, WebGL 2를 쓰는 웹에서 실행됩니다. Unity 6.6에서는 웹 빌드가 WebGPU로도 실행됩니다.

질문

추가 질문

스프라이트 베이커 없이 2D 조명만 쓸 수 있습니까?

네. 둘은 각각 따로 작동합니다. 조명은 어떤 2D 또는 2.5D 씬에서든 직접 그린 스프라이트를 비추며, 베이크는 Unity의 기본 스프라이트 머티리얼에 쓸 일반 스프라이트만 만들 수도 있습니다.

Unity의 Light 2D와 함께 작동합니까?

네. Light 2D 컴포넌트로 Sun Forge의 Light Source 컴포넌트를 제어할 수 있으며, Light 2D는 Sun Forge의 Unity Lights 머티리얼도 계속 비춥니다.

베이크하는 데 시간이 얼마나 걸립니까?

Ryzen 9 7900X와 RTX 4060 기준으로 나무 하나를 16방향으로 베이크하는 데 약 25초, 애니메이션 4개가 있는 캐릭터(스프라이트 968개)는 약 1분이 걸립니다.

베이크된 스프라이트는 텍스처 메모리를 얼마나 차지합니까?

데스크톱에서는 쇼케이스의 너도밤나무를 16방향으로 베이크하면 9.5MiB, 쇼케이스 기사의 스프라이트 968개는 81MiB를 차지합니다. 방향 수나 조명 텍스처 수를 줄이거나 해상도를 낮추면 메모리를 덜 차지합니다.

무엇을 베이크할 수 있습니까?

애니메이션 클립과 Particle System 컴포넌트가 있는 모델이나 프리팹을 원래의 머티리얼과 셰이더 그래프 그대로 베이크할 수 있습니다. 프롭, 파티클 이펙트, 지면 타일도 베이크할 수 있습니다.

코드로 베이크하거나 Addressables에 등록할 수 있습니까?

네. 에디터 코드에서 베이크하고 직접 만든 C# 단계로 베이크를 확장할 수 있으며, 베이크할 때 프리팹과 아틀라스를 Addressables에 등록할 수도 있습니다.
