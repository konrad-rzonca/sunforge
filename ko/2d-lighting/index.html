모든 기능 2D 조명

Unity URP용 실시간 2D 조명(2D 라이팅)

Sun Forge 2D Lighting 패키지는 낮부터 밤까지 이어지는 태양, 달, 하늘과 광원, 드리운 그림자, 네 가지 스타일로 2D 또는 2.5D 씬에 3D 같은 조명을 더합니다. 베이크된 스프라이트도, 직접 그린 스프라이트도 비춥니다.

별을 드래그해 홀의 조명을 끄고, 텍스처를 골라 조명이 무엇을 읽는지 확인해 보세요.

디퓨즈인게임

dark_igorek의 The Forgotten Knight, LasquetiSpice의 스켈레톤(CC BY 4.0)을 수정해 사용했습니다.

낮부터 밤까지 이어지는 실시간 태양

태양, 달, 하늘이 낮에도 밤에도 씬을 비춥니다. 시간대를 직접 바꾸거나 스크립트나 애니메이션으로 바꾸면, 아무것도 다시 베이크하지 않아도 스프라이트가 새 조명을 받습니다.

밤에는 달빛을 받은 표면이 푸르게 바뀌고, 불빛과 발광은 제 색을 유지합니다.

dark_igorek의 The Forgotten Knight, LasquetiSpice의 스켈레톤(CC BY 4.0)을 수정해 사용했습니다.

불처럼 깜박이는 동적 2D 광원

Light Source 컴포넌트는 점, 스폿, 선, 사각형 광원이 될 수 있으며, 불처럼 깜박일 수도 있습니다. 씬 뷰에서는 핸들로 각 광원의 높이, 도달 범위, 스폿 각도를 조정합니다.

Unity의 Light 2D 컴포넌트로 Light Source 컴포넌트를 제어할 수 있으며, Light 2D는 Sun Forge의 Unity Lights 머티리얼도 계속 비춥니다.

dark_igorek의 The Forgotten Knight, LasquetiSpice의 스켈레톤(CC BY 4.0)을 수정해 사용했습니다.

다른 스프라이트에도 드리우는 2D 그림자

그림자는 스프라이트와 함께 움직이고, 지면과 다른 스프라이트에 드리우며, 해가 지면 옅어집니다. 드리운 그림자는 그림자를 드리운 물체의 높이만큼, 그 안에 선 스프라이트를 타고 올라갑니다. 별을 드래그해 비교해 보세요.

그림자는 베이크하거나 그릴 때 정한 태양 방향으로 드리우며, 태양이 움직여도 돌아가지 않습니다.

지면만스프라이트에도

지면 안개와 구름 그림자

하늘은 떠다니는 구름 그림자와 지면 안개를 더합니다. 베이크된 스프라이트는 각각 높이를 저장하므로, 안개가 스프라이트를 발부터 위로 덮습니다. 모든 Light Source 컴포넌트는 안개도 비춥니다.

dark_igorek의 The Forgotten Knight, LasquetiSpice의 스켈레톤(CC BY 4.0)을 수정해 사용했습니다.

시작점이 되는 네 가지 조명 스타일

Regular, Cinematic, Flat, Realistic 스타일은 같은 스프라이트를 비추며, 플레이 모드에서도 스타일이 실시간으로 바뀝니다. 스타일을 조정해 새 스타일로 저장할 수도 있습니다.

스타일마다 고유한 설정이 있습니다. 예를 들어 Regular 스타일과 Cinematic 스타일에는 픽셀 외곽선, Cinematic 스타일에는 그린 듯한 빛, Flat 스타일에는 해 질 녘에 금빛으로 바뀌는 색이 있습니다. Flat 스타일은 외곽선과 주름 선을 그립니다.

dark_igorek의 The Forgotten Knight, LasquetiSpice의 스켈레톤(CC BY 4.0)을 수정해 사용했습니다.

직접 그린 스프라이트의 조명, 픽셀 아트까지

스프라이트를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 Sun Forge > Set Up for Lighting 메뉴를 선택하세요. 직접 만든 노멀 맵이 스프라이트에 입체감을 주며, 노멀 맵이 없으면 스프라이트는 평평한 표면으로 조명을 받습니다. 발광할 색과 금속처럼 빛날 색을 고르면 Sun Forge가 발광 텍스처와 금속 텍스처를 만듭니다.

Sun Forge 2D Lighting

그 밖에 조명이 하는 일

URP의 2D 렌더러와 유니버설 렌더러

조명은 두 렌더러에서 모두 작동하며, 조명 머티리얼에는 셰이더 작업이 필요 없습니다.

메뉴 항목 하나로 설정

메뉴 항목 하나와 Fix All 버튼으로 씬의 조명을 설정합니다.

에디터와 플레이어에서 실시간으로

조명은 편집 모드, 플레이 모드, 플레이어에서 실시간으로 표시되므로, 스크립트나 애니메이션으로 태양이나 광원을 바꾸면 스프라이트에 새 조명이 적용됩니다.

금속, 평활도, 앰비언트 오클루전

조명은 각 스프라이트의 노멀, 마스크, 지오메트리 텍스처를 읽습니다. 마스크의 빨간색에는 금속, 초록색에는 평활도, 파란색에는 앰비언트 오클루전이 담깁니다.

플랫폼

Sun Forge는 URP가 지원하는 모든 플랫폼을 대상으로 만들었습니다. 게임 빌드는 Direct3D 12를 쓰는 Windows, Vulkan 또는 OpenGL ES 3을 쓰는 ARM64 Android, WebGL 2를 쓰는 웹에서 실행되며, Unity 6.6에서는 WebGPU로도 실행됩니다.

스프라이트 베이커 없이

두 도구는 각각 따로 작동합니다. 조명은 탑다운, 아이소메트릭, 사이드 뷰 등 어떤 2D 또는 2.5D 씬에서든 직접 그린 스프라이트를 비춥니다. 이때 카메라는 스프라이트를 정면으로 바라봅니다.

조명을 받을 스프라이트 베이크

한 번 구매하면 Sun Forge 2D Lighting 패키지와, 조명이 읽는 텍스처를 만드는 스프라이트 베이커를 함께 받습니다. 모든 기능을 보거나 조명 가이드를 읽어 보세요.

Unity 에셋 스토어 출시 예정

Sun Forge를 사용하려면 Unity 6.3 LTS(6000.3.29f1 이상)부터 Unity 6.6까지의 버전과 URP(2D 렌더러 또는 유니버설 렌더러)가 필요합니다.
