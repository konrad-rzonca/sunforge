유니티 노멀 맵으로 2D 스프라이트에 입체감 주기

스프라이트는 평평한 그림이므로 빛이 비출 입체가 없습니다. 노멀 맵은 픽셀마다 그 부분의 표면이 향하는 방향을 담아 스프라이트에 입체감을 줍니다. 노멀 맵이 있으면 캐릭터 왼쪽의 횃불이 캐릭터의 왼쪽 면을 비추고, 횃불이 움직이면 음영도 움직입니다.

Sprite Lit 머티리얼과 Light 2D: Unity가 스프라이트를 비추는 방식

Unity의 2D 광원은 유니버설 렌더 파이프라인(URP)에 속하며, 프로젝트가 URP의 2D 렌더러를 쓸 때 작동합니다. 이때 씬 뷰로 드래그한 스프라이트에는 2D 광원이 비추는 Sprite-Lit-Default 머티리얼이 지정됩니다. Sprite-Unlit-Default 머티리얼을 쓰는 스프라이트는 2D 광원을 무시합니다.

광원을 추가하려면 계층 구조 창에서 마우스 오른쪽 버튼을 클릭하고 Light(광원) 메뉴를 선택한 다음, 2D 광원인 Spot, Freeform, Sprite, Global 중 하나를 고르세요. 전역 광원은 모든 스프라이트를 고르게 비춥니다. 노멀 맵이 없으면 나머지 광원은 종이를 오려 낸 그림 위의 램프처럼 스프라이트를 비춥니다. 광원의 모양 안쪽이 밝아질 뿐, 그림 자체에는 음영이 생기지 않습니다.

스프라이트 노멀 맵에 담기는 정보

노멀 맵은 스프라이트의 텍스처와 위치가 맞는 텍스처입니다. 빨간색에는 각 픽셀의 표면이 오른쪽으로 기운 정도, 초록색에는 위쪽으로 기운 정도, 파란색에는 보는 사람을 향한 정도가 담깁니다. 보는 사람을 정면으로 향한 픽셀은 연한 파란색 #8080FF입니다.

Unity에서 스프라이트에 노멀 맵 적용하기

  1. 노멀 맵을 임포트하고, 인스펙터에서 Texture Type(텍스처 타입) 필드를 Normal map(노멀 맵) 옵션으로 설정합니다.
  2. 스프라이트의 텍스처를 선택하고 Sprite Editor(스프라이트 에디터) 창을 연 다음, 드롭다운에서 Secondary Textures(보조 텍스처) 옵션을 고릅니다.
  3. + 버튼을 클릭하고 Name(이름) 필드의 드롭다운에서 _NormalMap 옵션을 고른 다음, 노멀 맵을 할당하고 Apply(적용) 버튼을 클릭합니다.
  4. 스프라이트의 Sprite Renderer 컴포넌트가 Sprite-Lit-Default 머티리얼이나 노멀 맵을 읽는 다른 머티리얼을 쓰는지 확인합니다.
  5. Light 2D 광원을 선택합니다. Normal Maps(노멀 맵) 섹션에서 Quality(품질) 필드를 Fast(빠름) 옵션이나 Accurate 옵션으로 설정합니다.

5단계를 마치기 전까지 광원은 노멀 맵을 무시합니다. 전역 광원에는 이 설정이 없으므로, 음영을 보여 주려면 씬에 Spot, Freeform, Sprite 중 하나가 필요합니다. 같은 섹션의 Distance(거리) 필드 값을 낮추면 광원이 스프라이트에 더 가까워지므로 디테일이 더 잘 드러납니다.

직접 만드는 셰이더는 Assets > Create > Shader Graph > URP > Sprite Lit Shader Graph(에셋 > 생성 > 셰이더 그래프 > URP > 스프라이트 릿 셰이더 그래프) 메뉴에서 시작할 수 있으며, 이 그래프에는 Normal (Tangent Space) 블록이 있습니다.

마스크 텍스처, _MaskTex

스프라이트에는 두 번째 보조 텍스처인 _MaskTex 텍스처를 둘 수 있습니다. Texture Type(텍스처 타입) 필드를 Default(기본) 옵션으로 두고 sRGB (Color Texture)(sRGB(컬러 텍스처)) 체크박스를 끈 상태로 임포트하세요.

마스크는 빛이 닿을 수 있는 곳을 정합니다. Blend Style(블렌드 스타일) 필드가 Multiply with Mask (R) 옵션이나 Additive with Mask (R) 옵션인 광원은 마스크의 빨간색 채널이 0보다 큰 픽셀만 비춥니다. 2D 렌더러 에셋에서는 블렌드 스타일마다 빨간색 대신 초록색, 파란색, 알파를 읽게 할 수 있습니다. 림 조명이나, 갑옷에만 생기는 반짝임에 쓰세요.

노멀 맵을 구하는 방법

  • 직접 그린 맵. 노멀 맵 팔레트의 방향 색으로 스프라이트 위에 칠합니다. Krita에는 이를 위한 브러시가 있습니다. 애니메이션이 있는 캐릭터에는 프레임마다 맵이 필요합니다.
  • 스프라이트에서 생성한 맵. 표면이 높을수록 흰색인 그레이스케일 하이트 맵을 그리고, Texture Type(텍스처 타입) 필드를 Normal map(노멀 맵) 옵션으로 설정하고 Create from Grayscale(그레이스케일에서 생성) 체크박스를 켠 상태로 임포트합니다. 그림만으로 작업하는 도구는 주로 외곽선을 둥글게 만드는 방식으로 입체를 추측합니다.
  • 3D 모델에서 렌더한 맵. 스프라이트가 3D 모델을 렌더한 것이라면 같은 카메라로 모델의 노멀을 렌더합니다. 그러면 모든 프레임에 꼭 맞는 맵이 생깁니다. 블렌더의 Normal 패스는 방향을 월드 공간으로 담으므로, 저장하기 전에 카메라 뷰 기준으로 변환합니다.

노멀 맵만으로는 할 수 없는 일

  • 금속과 평활도. Unity 매뉴얼에 따르면 Unity의 2D 조명은 물리 기반이 아닙니다. Sprite-Lit-Default 머티리얼은 색 텍스처, 마스크, 노멀 맵을 읽지만, 어느 것도 픽셀이 얼마나 반짝이는지 담지 않으므로 강철과 천이 빛을 똑같이 받습니다. 손으로 배치한 마스크 광원으로 반짝임을 흉내 낼 수는 있습니다.
  • 서로 그림자를 드리우는 스프라이트. Shadow Caster 2D 컴포넌트는 스프라이트의 Custom Outline, 콜라이더, 직접 그린 모양 중 하나의 외곽선에서 모양을 가져옵니다. 이 모양에는 스프라이트의 가장자리만 있을 뿐, 각 부분의 높이는 없습니다. Unity의 Happy Harvest 샘플은 그 대신 나무 아래 그림자를 늘인 스프라이트로 그립니다. 각 방법은 2D와 탑다운 스프라이트의 그림자에서 볼 수 있습니다.

둘 다 픽셀마다 더 많은 데이터, 즉 표면의 메탈릭 값과 평활도, 그리고 높이가 필요합니다.

Unity 스프라이트 노멀 맵이 작동하지 않는 이유

광원이 아무것도 바꾸지 않으면 2D 광원이 적용되지 않을 때 확인할 사항부터 살펴보세요. 다음은 맵 자체의 함정입니다:

  • 텍스처 타입. Sprite (2D and UI)(스프라이트(2D 및 UI)) 옵션으로 둔 노멀 맵은 음영이 잘못 나옵니다. 광원이 움직여도 어두운 면이 그대로입니다. Texture Type(텍스처 타입) 필드를 Normal map(노멀 맵) 옵션으로 설정하고, 파일이 하이트 맵이 아니라면 Create from Grayscale(그레이스케일에서 생성) 체크박스는 끄세요.
  • 뒤집힌 초록색 채널. Unity는 초록색이 위쪽을 뜻한다고 가정하며, 이를 Y+ 또는 OpenGL 방식이라고 합니다. 반대 방식으로 만든 맵은 광원이 위에 있을 때 아래에서 비추는 것처럼 보입니다. 텍스처의 임포트 설정에서 Flip Green Channel(녹색 채널 플립) 체크박스를 켜세요.
  • 뒤집힌 스프라이트. Sprite Renderer 컴포넌트에 있는 Flip(플립) 필드의 X 체크박스는 그려지는 모습만 뒤집습니다. Y축을 중심으로 180도 회전한 스프라이트는 조명이 잘못 적용되며, Unity는 이를 의도된 동작으로 봅니다. 음수 Scale X 필드 값으로 뒤집는다면 스프라이트 위에 광원을 두고 위쪽 가장자리가 밝게 비치는지 확인하세요.
  • 스프라이트 아틀라스. 스프라이트 아틀라스는 스프라이트의 보조 텍스처를 별도의 텍스처로 합칩니다. 아틀라스 안의 모든 스프라이트에 같은 수의 보조 텍스처를 주세요. 그러지 않으면 합쳐진 텍스처에 빈 공간이 많이 생길 수 있습니다. 다른 도구로 시트를 패킹한다면 노멀 맵도 같은 레이아웃으로 패킹해야 합니다. Unity는 두 텍스처를 같은 UV로 읽기 때문입니다.

Sun Forge: 스프라이트마다 노멀, 마스크, 지오메트리, 이미션 텍스처

Unity 에디터 툴인 Sun Forge는 세 번째 방법을 Unity 안에서 씁니다. 베이크는 3D 모델이나 프리팹을 방향마다 스프라이트 시트가 있는 2D 스프라이트 프리팹으로 바꿉니다. 각 시트에는 색 텍스처 외에 노멀, 마스크, 지오메트리 텍스처가 있으며, 베이크에서 Emission 섹션을 켜면 이미션 텍스처도 생깁니다.

  • 마스크의 빨간색에는 금속, 초록색에는 평활도, 파란색에는 앰비언트 오클루전이 담깁니다.
  • 지오메트리 텍스처에는 스프라이트의 피벗에서 잰 각 텍셀의 높이가 담기며, 이 높이로 스프라이트끼리 서로 그림자를 드리울 수 있습니다.

Sun Forge의 조명 패키지인 Sun Forge 2D Lighting 패키지가 이 텍스처를 읽습니다. 드리운 그림자는 그림자를 드리운 물체의 높이만큼, 그 안에 선 스프라이트를 타고 올라갑니다.

조명은 직접 그린 스프라이트도 비춥니다. 스프라이트를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 Sun Forge > Set Up for Lighting 메뉴를 선택하세요. 직접 만든 노멀 맵이 스프라이트에 입체감을 주며, 노멀 맵이 없으면 스프라이트는 평평한 표면으로 조명을 받습니다. 발광할 색과 금속처럼 빛날 색을 고르면 Sun Forge가 발광 텍스처와 금속 텍스처를 만듭니다.

Sun Forge를 사용하려면 Unity 6.3 LTS(6000.3.29f1 이상)부터 Unity 6.6까지의 버전과 URP(2D 렌더러 또는 유니버설 렌더러)가 필요합니다. 베이커와 조명은 각각 따로 작동합니다. 스프라이트 베이커와 조명 페이지를 참조하세요.
