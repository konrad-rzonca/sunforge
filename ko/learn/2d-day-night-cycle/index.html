유니티 2D 낮과 밤 사이클, 구름 그림자 구현

2D URP 씬에서는 시간대에 맞춰 그레디언트를 따라 색이 바뀌는 Global Light 2D로 낮과 밤 사이클을 만듭니다. 밤에는 Volume 컴포넌트가 화면에 컬러 그레이딩을 적용하고, 해가 지면 램프가 서서히 켜지며, 스크롤되는 구름 텍스처가 지면에 그늘을 드리웁니다. 아래 단계는 Unity 6.3 기준입니다.

Global Light 2D로 구현하는 Unity 2D 낮과 밤 사이클

Light Type(광원 타입) 필드를 Global(전역) 옵션으로 설정한 Light 2D 컴포넌트는 모든 2D 게임 오브젝트를 고르게 비춥니다. 그 색을 바꾸면 조명을 받는 모든 스프라이트가 함께 바뀝니다.

  1. 스프라이트는 새 스프라이트에 기본으로 지정되는 Sprite-Lit-Default 머티리얼로 둡니다. 2D 광원은 Sprite-Unlit-Default 머티리얼에 영향을 주지 않습니다.
  2. 계층 구조 창에서 마우스 오른쪽 버튼을 클릭하고 Light(광원) 메뉴를 선택한 다음 Global Light 2D를 고릅니다. 아무 2D 광원이나 골라 Light Type 필드를 Global 옵션으로 설정해도 됩니다. Unity에서는 블렌드 스타일과 정렬 레이어마다 전역 광원을 하나만 둘 수 있습니다.
  3. 아래 스크립트를 아무 게임 오브젝트에 추가하고 광원을 할당합니다. 스크립트의 Light Color 필드에 있는 그레디언트에서 양 끝에는 자정의 색을, 가운데에는 정오의 색을 둡니다.
  4. 카메라에서 Post Processing(포스트 프로세싱) 체크박스를 켭니다. GameObject > Volume > Global Volume(게임 오브젝트 > 볼륨 > 전역 볼륨) 메뉴를 선택하고, New(신규) 버튼을 클릭해 프로파일을 만든 다음, Add Override(오버라이드 추가) 버튼을 클릭해 Color Adjustments 옵션을 고릅니다. 이 오버라이드를 밤의 모습에 맞게 설정합니다. 예를 들어 Saturation 필드 값을 낮춥니다. Volume 컴포넌트를 스크립트에 할당하면 스크립트가 그 Weight(가중치) 필드를 설정합니다.
  5. 램프나 불마다 Spot Light 2D를 추가하고, 스크립트의 목록에 넣습니다. 이전 Unity 버전을 다룬 튜토리얼에서는 이 광원을 Point Light 2D라고 부릅니다.
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class DayCycle : MonoBehaviour
{
    public Light2D globalLight;
    public Gradient lightColor;   // the same color at both ends
    public AnimationCurve night;  // 1 at time 0 and at 1, 0 by day
    public Volume nightVolume;
    public Light2D[] lamps;
    public float lampIntensity = 1f;
    public float dayLengthSeconds = 600f;
    public float time;            // 0 and 1 are midnight, 0.5 is noon

    void Update()
    {
        time = Mathf.Repeat(time + Time.deltaTime / dayLengthSeconds, 1f);
        float n = night.Evaluate(time);

        globalLight.color = lightColor.Evaluate(time);
        nightVolume.weight = n;
        foreach (Light2D lamp in lamps)
            lamp.intensity = lampIntensity * n;
    }
}

2D 낮과 밤 사이클의 함정

  • 자정의 순환. Gradient.Evaluate 메서드는 0~1의 시간을 받으며, 스크립트는 자정에 시간을 다시 0으로 되돌립니다. 그레디언트의 첫 색과 마지막 색이 다르면 그 순간 씬이 갑자기 바뀝니다. 양 끝에 같은 색을 주고, 밤 커브의 양 끝에도 같은 값을 주세요. 그레디언트에는 컬러 키를 최대 8개까지 넣을 수 있으므로, 어느 시각에 키를 둘지 고르세요.
  • 갑자기 켜지는 광원. 정해진 시각에 켜는 램프는 한 프레임 만에 나타납니다. 그래서 스크립트는 대신 밤 커브로 각 램프의 intensity 값을 정하며, 커브가 올라가면서 램프가 서서히 밝아집니다.
  • 어두워지는 발광체. 전역 광원은 창문이나 불꽃을 포함해 조명을 받는 모든 스프라이트를 어둡게 합니다. 발광하는 부분은 Sprite-Unlit-Default 머티리얼을 쓰는 별도의 스프라이트로 그리세요. Volume 컴포넌트의 Color Filter(컬러 필터) 필드와 Post Exposure 필드는 발광하는 부분까지 포함해 화면 전체를 바꿉니다. 밤의 어두움과 색조는 광원의 색으로 주고, Volume 컴포넌트는 채도와 대비에 쓰세요.
  • 블룸 임계값. 블룸은 Intensity(강도) 필드가 0보다 커야 켜집니다. 켜진 뒤에도 Threshold(임계값) 필드 값(기본값 0.9)보다 밝은 픽셀에만 적용됩니다. 조명을 받는 스프라이트의 발광은 밤에 임계값 아래로 떨어집니다. 이 점도 발광을 언릿으로 그려야 하는 이유입니다. Light 2D 컴포넌트의 Intensity(강도) 필드 값이 1을 넘으면 스프라이트가 본래 색보다 밝아지므로, 정오에는 옅은 색 벽이 임계값을 넘어 블룸이 생길 수 있습니다.

Unity 2D 햇빛: Global Light 2D로 보여 줄 수 없는 것

전역 광원에는 방향이 없습니다. 모든 것을 고르게 비추며, 인스펙터에 Normal Maps(노멀 맵) 섹션도 Shadows(그림자) 섹션도 없습니다. 그래서 정오와 해 질 녘은 색만 다릅니다. 스프라이트의 어느 면도 다른 면보다 밝지 않고, 아무것도 그림자를 드리우지 않습니다.

태양의 위치를 보여 주려면 다음 두 가지가 모두 필요합니다:

  1. 각 스프라이트의 노멀 맵. 스프라이트 에디터에서 Secondary Textures(보조 텍스처) 옵션으로 전환해 _NormalMap 이름으로 추가합니다(단계 참조).
  2. 위치가 있는 광원. 큰 Spot Light 2D를 추가하고, Normal Maps 섹션에서 Quality(품질) 필드를 Fast(빠름) 옵션이나 Accurate 옵션으로 설정한 다음, 하루 동안 스크립트로 광원을 옮기거나 돌립니다.

Unity의 Happy Harvest 샘플은 스크립트로 돌리는 큰 스폿 광원으로 이렇게 낮을 비춥니다. Unity가 밝힌 비용은 두 가지입니다. 노멀 맵은 레이어 배치마다 전체 크기의 렌더 패스를 하나씩 더하며, 큰 광원 하나가 작은 광원 여러 개보다 비용이 더 들 수 있습니다.

Shadow Caster 2D 그림자는 이런 광원에서만 생기며, 전역 광원에서는 생기지 않습니다. Happy Harvest 샘플은 태양의 그림자에 늘인 블롭 스프라이트를 쓰고, 스크립트로 하루 동안 이 스프라이트를 돌리고 늘입니다. 2D와 탑다운 스프라이트의 그림자에서 각 방법을 비교합니다.

Unity 2D 구름 그림자

Unity 자체 도구만 쓰는 방법은 두 가지입니다:

  • 스크롤되는 오버레이. 어둡고 부드러운 구름 텍스처를 지면보다 위에 정렬되는 Sprite Renderer 컴포넌트에 넣으세요. 텍스처가 화면 전체에 반복되도록 Draw Mode(드로우 모드) 필드를 Tiled(타일됨) 옵션으로 설정하고, Sprite-Unlit-Default 머티리얼을 지정하세요. 오버레이를 매 프레임 움직이고, 타일 하나만큼 움직이면 위치를 되돌리세요. 그 아래에 그려지는 모든 것이 어두워지며, 램프 빛과 발광하는 스프라이트도 마찬가지입니다.
  • 빛을 빼는 광원. 2D 렌더러 에셋의 Light Blend Styles(광원 블렌드 스타일) 섹션에서 스타일 하나의 Blend Mode(블렌드 모드) 필드를 Subtractive(감산) 옵션으로 설정하세요. Light Type(광원 타입) 필드를 Sprite(스프라이트) 옵션으로 설정한 Light 2D 컴포넌트를 추가하고, 구름 텍스처를 스프라이트로 지정한 다음, 그 블렌드 스타일을 골라 같은 방식으로 움직이세요. 이 광원은 Target Sorting Layers(타겟 정렬 레이어) 필드에 있는 레이어에서 조명을 받는 스프라이트의 빛만 빼므로, 언릿 발광은 밝기를 유지합니다.

어느 방법이든 오버레이의 색이나 광원의 강도로 구름도 밤 커브에 따라 옅어지게 하세요. 그러지 않으면 자정에도 그림자가 정오만큼 어둡습니다.

Sun Forge 2D Lighting의 방식

Sun Forge 2D Lighting 패키지는 2D 렌더러나 유니버설 렌더러를 쓰는 URP용 조명 패키지입니다. 낮부터 밤까지 이어지는 태양, 달, 하늘, 날씨가 있습니다. 직접 그린 스프라이트를 비추려면 스프라이트를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 Sun Forge > Set Up for Lighting 메뉴를 선택하세요. 직접 만든 노멀 맵이 스프라이트에 입체감을 줍니다. 노멀 맵이 없으면 스프라이트는 평평한 표면으로 조명을 받습니다.

Lighting Setup 컴포넌트의 Time Of Day 필드는 0~24의 시각을 정하고, 조명 스타일은 시각마다 빛을 정합니다. 스크립트로 하루를 진행하려면 Update 메서드에서 SunForgeLightingSetup.TimeOfDay 값을 설정하세요. 조명은 편집 모드, 플레이 모드, 플레이어에서 실시간으로 표시되므로, 시각이 바뀌면 스프라이트에 새 조명이 적용됩니다.

  • 밤에는 달빛을 받은 표면이 푸르게 바뀌고, 불빛과 발광은 제 색을 유지합니다.
  • 광원은 점, 스폿, 선, 사각형 광원이 될 수 있으며, 불처럼 깜박일 수도 있습니다. Unity의 Light 2D 컴포넌트로 Sun Forge의 Light Source 컴포넌트를 제어할 수 있으며, Light 2D는 Sun Forge의 Unity Lights 머티리얼도 계속 비춥니다.
  • 하늘은 떠다니는 구름 그림자와 지면 안개를 더합니다. 사이드 뷰에는 둘이 놓일 지면이 보이지 않으므로 둘 다 나타나지 않습니다.

그림자는 베이크하거나 그릴 때 정한 태양 방향으로 드리우며, 태양이 움직여도 돌아가지 않습니다. 해가 지면 그림자가 옅어집니다.

Sun Forge를 사용하려면 Unity 6.3 LTS(6000.3.29f1 이상)부터 Unity 6.6까지의 버전과 URP가 필요합니다.
