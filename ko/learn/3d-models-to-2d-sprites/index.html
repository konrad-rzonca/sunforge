학습

유니티에서 3D 모델을 2D 스프라이트로 변환하기

3D 모델로 만든 2D 스프라이트는 고정된 카메라로 모델을 렌더해 배경을 투명하게 저장한 이미지입니다. 애니메이션이 있는 캐릭터는 이런 이미지 여러 장으로 이루어지며, 프레임마다, 애니메이션마다, 방향마다 한 장씩 필요합니다. 프레임을 렌더해 스프라이트로 분할하고, 애니메이션 클립을 만든 다음 텍스처를 패킹합니다.

블렌더에서 3D 모델로 2D 스프라이트를 만드는 방법

  1. 카메라 타입을 Orthographic 옵션으로 설정합니다. 그러면 모델은 거리와 관계없이 같은 크기로 보입니다. 이미지 속 모델의 크기는 Orthographic Scale 값으로 정합니다.
  2. 렌더 설정의 Film 섹션에서 Transparent 체크박스를 켭니다.
  3. 알파 채널이 남도록 PNG 같은 포맷을 쓰고, 출력 색을 RGBA 옵션으로 설정합니다.
  4. 애니메이션을 이미지 시퀀스로 렌더합니다. 다른 방향은 모델이나 카메라를 돌려 다시 렌더합니다.

PNG 파일을 그대로 임포트해 파일마다 스프라이트 하나로 쓰거나, 먼저 시트 하나로 합치세요.

Unity에서 3D 모델을 스프라이트로 렌더하기

  1. 카메라를 추가하고 Projection(투사) 필드를 Orthographic(직교) 옵션으로 설정합니다. Size(크기) 필드 값은 월드 단위로 잰 뷰 높이의 절반입니다.
  2. Background Type(배경 타입) 필드를 Solid Color(단색) 옵션으로 설정하고, Background(배경) 필드에서 색의 알파를 0으로 설정합니다.
  3. Assets > Create > Rendering > Render Texture(에셋 > 생성 > 렌더링 > 렌더 텍스처) 메뉴로 렌더 텍스처를 만들고, 컬러 형식은 알파 채널이 있는 것으로 고릅니다. 이 텍스처를 카메라의 Output Texture(출력 텍스처) 필드에 할당합니다.
  4. URP에서는 카메라의 Post Processing(포스트 프로세싱) 체크박스를 끄거나 URP 에셋의 Alpha Processing 체크박스를 켭니다. 그러지 않으면 포스트 프로세싱이 알파를 1로 바꿉니다.
  5. 에디터 스크립트에서 프레임마다 clip.SampleAnimation(model, time) 메서드로 모델의 자세를 잡고 이미지를 저장합니다:
static void SaveFrame(Camera camera, RenderTexture target, string path)
{
    camera.targetTexture = target;
    camera.Render();

    RenderTexture previous = RenderTexture.active;
    RenderTexture.active = target;
    var frame = new Texture2D(target.width, target.height, TextureFormat.RGBA32, false);
    frame.ReadPixels(new Rect(0, 0, target.width, target.height), 0, 0);
    frame.Apply();
    RenderTexture.active = previous;

    System.IO.File.WriteAllBytes(path, ImageConversion.EncodeToPNG(frame));
    Object.DestroyImmediate(frame);
}

렌더 텍스처와 Texture2D의 포맷은 같아야 합니다. 선형 색 공간을 쓰는 프로젝트에서는 이름 끝이 _SRGB인 렌더 텍스처 포맷을 고르세요. 그러지 않으면 저장한 색이 어둡게 나옵니다.

스프라이트 에디터에서 스프라이트 시트 분할하기

  1. 2D Sprite 패키지가 설치되어 있는지 확인합니다.
  2. 이미지를 선택하고 Texture Type(텍스처 타입) 필드를 Sprite (2D and UI)(스프라이트(2D 및 UI)) 옵션으로, Sprite Mode(스프라이트 모드) 필드를 Multiple(다중) 옵션으로 설정한 다음 Apply(적용) 버튼을 클릭합니다.
  3. 스프라이트 에디터를 열고 Slice(분할) 메뉴를 엽니다. 크기가 같은 프레임에는 Grid By Cell Size 옵션을, 행과 열의 수가 정해져 있으면 Grid By Cell Count 옵션을 고릅니다.
  4. Pivot(피벗) 필드를 설정하고 Slice 버튼을 클릭한 다음 Apply 버튼을 클릭합니다.

프레임으로 만드는 애니메이션 클립과 애니메이터 컨트롤러

  1. 첫 스프라이트를 씬으로 드래그합니다. 그러면 Sprite Renderer 컴포넌트가 있는 게임 오브젝트가 생깁니다.
  2. 그 게임 오브젝트를 선택한 상태로 애니메이션 창에서 Create(생성) 버튼을 클릭하고 클립을 저장합니다. Unity가 이 클립을 기본 상태로 하는 애니메이터 컨트롤러를 만들고, 게임 오브젝트에 Animator 컴포넌트를 추가합니다.
  3. 프레임마다 스프라이트 하나씩, Sprite Renderer 컴포넌트의 스프라이트에 키를 추가합니다.
  4. 애니메이션을 더 만들 때마다 애니메이션 창의 클립 메뉴에서 Create New Clip(새 클립 생성) 옵션을 고르고, 애니메이터 컨트롤러에서 클립 사이에 전환을 추가합니다.

클립이 많다면 이 단계를 스크립트로 처리하세요. Unity의 AnimationClip 스크립트 레퍼런스에는 프로젝트 창에서 선택한 스프라이트로 클립을 만드는 예제가 있습니다.

함정

단위당 픽셀(Pixels Per Unit)

Pixels Per Unit 값은 스프라이트 이미지에서 월드 공간 1단위에 해당하는 픽셀 수입니다. 임포트할 때 쓸 값을 정하고, 렌더 텍스처의 높이를 2 x Size x Pixels Per Unit 픽셀로 만드세요. Size 값이 1.5이고 Pixels Per Unit 값이 64라면 192픽셀입니다. 그러면 2D 씬의 스프라이트가 모델과 같은 높이가 됩니다. 모든 스프라이트에 같은 값을 쓰세요. 그러지 않으면 일부 스프라이트가 다른 스프라이트보다 선명해 보입니다.

피벗과 구도

피벗은 이미지에서 스프라이트의 로컬 좌표가 시작되는 점입니다. 캐릭터라면 피벗을 발에, 모든 프레임에서 같은 픽셀에 두세요. 그러려면 모든 애니메이션의 모든 프레임을 같은 카메라 위치에서, 같은 Size 값과 같은 해상도로, 가장 넓은 자세가 들어갈 만큼 넓게 렌더하세요. 그런 다음 그리드로 분할하고 모든 스프라이트에 같은 피벗을 지정하세요. Automatic(자동) 옵션으로 분할하면 투명 픽셀을 기준으로 자르므로 프레임마다 다른 사각형이 생깁니다. 그러면 Bottom 같은 피벗이 프레임마다 몸의 다른 지점에 놓여 캐릭터가 떨립니다.

프리멀티플라이드 알파와 가장자리 헤일로

투명한 지오메트리를 렌더 텍스처에 블렌딩하면 텍스처는 각 색에 알파를 미리 곱해 저장합니다. 일반적인 투명도(Blend SrcAlpha OneMinusSrcAlpha)를 쓰는 머티리얼은 알파를 한 번 더 곱하므로 반투명 픽셀이 어두워집니다. PNG를 저장하기 전에 색을 알파로 나누거나, 프리멀티플라이드 색을 블렌딩하는 셰이더(Blend One OneMinusSrcAlpha)를 쓰세요.

텍스처 필터링은 가장자리 픽셀을 옆의 투명 픽셀과 섞습니다. 텍스처의 임포트 설정에서 Alpha Is Transparency(알파값을 투명으로 사용) 체크박스를 켜세요. 그러면 Unity가 색 채널을 바깥으로 확장해 가장자리의 필터링 아티팩트를 막습니다.

텍스처 크기와 아틀라스 패킹

방향 8개, 256 x 256픽셀 프레임 16개로 된 애니메이션 3개면 프레임 384개, 약 2,500만 픽셀이며, 압축하지 않으면 96MiB입니다. Pixels Per Unit 값을 절반으로 하면 그 4분의 1만 차지합니다.

Unity는 임포트할 때 Max Size(최대 크기) 필드 값보다 큰 텍스처를 그 크기로 줄입니다. 큰 시트는 Max Size 값을 높이거나 애니메이션별로 나누세요. 그런 다음 Assets > Create > 2D > Sprite Atlas(에셋 > 생성 > 2D > 스프라이트 아틀라스) 메뉴로 스프라이트 아틀라스를 만들어 스프라이트를 패킹하세요. 스프라이트 아틀라스는 텍스처를 하나로 합치므로, Unity가 그 안의 모든 스프라이트를 드로우 콜 하나로 그릴 수 있습니다.

색에 베이크된 조명, 또는 노멀 맵

렌더에 들어간 빛은 스프라이트 색의 일부가 됩니다. 왼쪽에서 빛을 받은 기사는 오른쪽에 횃불이 있어도 계속 왼쪽에서 빛을 받습니다. 게임 중에 바뀌는 빛을 쓰려면 색은 균일한 빛 아래에서 렌더하고, 같은 프레임의 노멀 맵을 같은 카메라로 렌더하세요. 스프라이트 에디터에서 노멀 맵을 _NormalMap 이름의 보조 텍스처로 추가하고, Sprite-Lit-Default 같은 머티리얼을 쓰고, 2D 광원의 Normal Maps(노멀 맵) 섹션에서 Quality(품질) 필드를 Fast(빠름) 옵션이나 Accurate 옵션으로 설정하세요. Unity는 두 텍스처를 같은 UV 좌표로 샘플링하므로, 노멀 맵은 스프라이트 텍스처와 위치가 맞아야 합니다. 단계와 함정은 Unity의 스프라이트 노멀 맵에서 볼 수 있습니다.

Unity 안에서 3D를 2D 스프라이트로 변환하는 툴: Sun Forge

Sun Forge는 이 사이트가 소개하는 스프라이트 베이커입니다. Unity 에디터 안에서 Bake Window 또는 에디터 코드로 베이크합니다. 모델이나 프리팹을 애니메이션 클립, Particle System 컴포넌트와 함께, 셰이더 그래프를 포함한 원래의 머티리얼 그대로 베이크할 수 있습니다.

베이크가 만드는 2D 스프라이트 프리팹에는 방향마다 스프라이트 시트, 애니메이션과 애니메이터 컨트롤러, 조명 텍스처, 그림자, 콜라이더, 게임플레이 컴포넌트가 있습니다.

  • 카메라. 베이크 카메라의 각도는 0~90도 사이에서 정할 수 있습니다. 사이드 뷰부터 바로 위에서 내려다보는 각도까지, 아이소메트릭을 포함한 그 사이의 모든 각도를 쓸 수 있습니다. 베이크는 1~64방향을 만들며, 게임에 필요한 방향 수는 별도의 글에서 다룹니다.
  • 해상도와 메모리. 새 베이크의 Pixels Per Unit 값은 96입니다. 베이크할 때마다 Bake 탭에 출력이 차지하는 텍스처 메모리가 표시됩니다.
  • 조명. 각 시트에는 색 텍스처 외에 노멀, 마스크, 지오메트리 텍스처가 있으며, Sun Forge 2D Lighting 패키지가 이 텍스처를 읽으므로 태양과 광원을 실시간으로 바꿀 수 있습니다. 베이크는 켠 텍스처만 만들며, 프리팹에 Unity의 기본 스프라이트 머티리얼을 지정하도록 설정할 수도 있습니다.

Sun Forge를 사용하려면 Unity 6.3 LTS(6000.3.28f1 이상) 또는 Unity 6.6, URP(2D 렌더러 또는 유니버설 렌더러)가 필요합니다. 빌트인 렌더 파이프라인이나 HDRP에서는 위의 단계를 따르세요. 스프라이트 베이커 페이지에서 베이크의 각 부분을 볼 수 있습니다.
