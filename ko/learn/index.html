학습

유니티 2D 스프라이트와 조명을 다루는 글

각 글은 Unity 자체 도구로 질문 하나에 답하고, 주의할 함정을 짚은 뒤, Sun Forge로 해결하는 방법으로 마무리합니다.

  • 유니티에서 3D 모델을 2D 스프라이트로 변환하기

    블렌더나 Unity에서 프레임을 렌더하고, 분할하고, 클립을 만들고, 텍스처를 패킹하는 방법을 다룹니다.

  • 유니티 8방향 스프라이트: 4, 8, 16방향 중 어느 쪽?

    방향 수마다 드는 비용, 각 뷰를 만드는 카메라 각도, 스프라이트를 고르는 코드를 다룹니다.

  • 유니티 노멀 맵으로 2D 스프라이트에 입체감 주기

    스프라이트에 노멀 맵과 마스크를 추가하는 방법, 구하는 곳, 둘만으로는 할 수 없는 일을 다룹니다.

  • 유니티 2D와 탑다운 스프라이트의 그림자

    Shadow Caster 2D, 블롭, 기울인 사본, 3D 모델 렌더와 각 방법이 어울리는 월드를 다룹니다.

  • 유니티 2D 낮과 밤 사이클, 구름 그림자 구현

    그레디언트를 따르는 Global Light 2D, 밤 화면을 보정하는 Volume, 서서히 켜지는 램프, 지면에 그늘을 드리우는 구름을 다룹니다.

  • 유니티 2D 씬의 안개 효과와 지면 안개

    Unity의 안개가 스프라이트에 적용되지 않는 이유와, 스프라이트, 파티클, 전체 화면 패스로 안개를 만드는 네 가지 방법을 다룹니다.

  • 유니티 2D 광원이 적용되지 않을 때: 확인할 사항

    회색으로 비활성화되거나, 스프라이트를 비추지 않거나, 노멀 맵을 무시하거나, 빌드에서 사라지는 Light 2D를 다룹니다.
