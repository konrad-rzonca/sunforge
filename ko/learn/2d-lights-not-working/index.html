유니티 2D 광원이 적용되지 않을 때: 확인할 사항

Unity의 2D 광원은 유니버설 렌더 파이프라인(URP)에 속하며, URP의 2D 렌더러에서만 작동합니다. 광원을 추가해도 아무 변화가 없으면 아래 설정을 순서대로 확인하세요. 메뉴 이름은 Unity 6.3 기준입니다.

메뉴에서 회색으로 비활성화된 Unity 2D 광원

증상: GameObject > Light(게임 오브젝트 > 광원) 메뉴의 2D 광원을 클릭할 수 없거나, Light 2D 컴포넌트의 인스펙터에 "2D renderer data must be assigned to your universal render pipeline asset or camera."만 표시됩니다.

원인: 프로젝트에 URP 에셋이 없어 빌트인 렌더 파이프라인으로 실행되거나, URP 에셋의 기본 렌더러가 유니버설 렌더러입니다.

  1. 프로젝트 창에서 Create > Rendering > URP Asset (with 2D Renderer)(생성 > 렌더링 > URP 에셋(2D 렌더러 포함)) 메뉴를 선택합니다. Unity가 URP 에셋과 2D 렌더러 에셋을 만듭니다.
  2. Edit > Project Settings > Graphics(편집 > 프로젝트 설정 > 그래픽스) 창을 열고 Default Render Pipeline 필드를 새 URP 에셋으로 설정합니다.

기존 URP 에셋을 계속 쓰려면 Create > Rendering > URP 2D Renderer(생성 > 렌더링 > URP 2D 렌더러) 메뉴로 렌더러를 만들어 에셋의 Renderer List(렌더러 목록) 필드에 추가하고, 그 렌더러의 Set Default(기본값 설정) 버튼을 클릭하세요.

다른 URP 에셋을 지정한 품질 레벨

증상: 그래픽스 설정은 올바른데도 광원이 여전히 비활성화되어 있거나 아무 효과가 없습니다.

원인: 품질 레벨마다 Render Pipeline Asset(렌더 파이프라인 에셋) 필드가 있습니다. 이 필드가 설정되어 있으면 Unity는 그 레벨에서 그래픽스 설정의 에셋 대신 이 에셋을 사용합니다.

  1. Edit > Project Settings > Quality(편집 > 프로젝트 설정 > 품질) 창을 엽니다.
  2. 각 레벨을 차례로 선택해 Render Pipeline Asset 필드를 확인합니다.
  3. 필드를 비우거나, 2D 렌더러를 쓰는 URP 에셋으로 설정합니다.

스프라이트에 적용되지 않는 Unity 2D 광원

증상: 광원을 어떻게 바꿔도 일부 스프라이트가 원래 밝기 그대로입니다. 프로젝트를 URP로 옮기기 전에 만든 스프라이트인 경우가 많습니다.

원인: 2D 광원은 2D 광원용으로 만든 머티리얼에만 영향을 줍니다. Sprite-Lit-Default 머티리얼이 그중 하나입니다. Sprites-Default 같은 빌트인 렌더 파이프라인의 머티리얼과 Sprite-Unlit-Default 머티리얼은 반응하지 않습니다.

  1. 스프라이트를 선택합니다.
  2. 그 스프라이트의 Sprite Renderer 컴포넌트에서 Material(머티리얼) 필드를 Sprite-Lit-Default 머티리얼로 설정합니다.

프로젝트 전체를 변환하려면 먼저 백업한 뒤 Window > Rendering > Render Pipeline Converter(Window > 렌더링 > 렌더 파이프라인 컨버터) 창을 열고, 2D Converters > Built-in to 2D URP Material Upgrader 옵션을 고른 다음 Material and Material Reference Upgrade 체크박스를 켜고 변환을 실행하세요. 직접 셰이더를 만들려면 Create > Shader Graph > URP > Sprite Lit Shader Graph(생성 > 셰이더 그래프 > URP > 스프라이트 릿 셰이더 그래프) 메뉴에서 시작하세요.

광원의 Target Sorting Layers에서 빠진 스프라이트

증상: 광원이 범위 안의 스프라이트 중 일부만 비추고 나머지는 비추지 않습니다.

원인: Light 2D 컴포넌트는 Target Sorting Layers(타겟 정렬 레이어) 필드에 있는 정렬 레이어만 비춥니다. 새 광원은 모든 정렬 레이어를 대상으로 합니다. 정렬 레이어를 추가할 때 열려 있지 않던 씬이나 프리팹의 광원에는 새 레이어가 들어 있지 않습니다.

  1. 스프라이트를 선택하고 Sprite Renderer 컴포넌트의 Sorting Layer(정렬 레이어) 필드를 확인합니다.
  2. 광원을 선택하고 그 레이어를 Target Sorting Layers 필드에 추가합니다.

광원의 Z 위치는 상관없습니다. 2D 광원은 스프라이트가 광원 앞에 있든 뒤에 있든, 거리와 관계없이 비춥니다.

광원 밖이 모두 검은색

증상: 광원을 추가하기 전에는 씬이 정상으로 보였는데, 이제 그 광원이 비추는 영역만 보입니다.

원인: 씬에 Light 2D 컴포넌트가 없는 동안 Unity는 스프라이트를 본래 색으로 그립니다. 첫 광원을 추가한 뒤로는 스프라이트에 닿는 빛만 보입니다. Global Light 2D 컴포넌트는 타겟 레이어의 모든 스프라이트를 고르게 비춥니다.

  1. GameObject > Light > Global Light 2D(게임 오브젝트 > 광원 > 전역 광원 2D) 메뉴를 선택합니다.
  2. 다른 광원이 닿지 않는 곳에서 씬이 보여야 할 모습에 맞춰 Color(컬러) 필드와 Intensity(강도) 필드를 설정합니다.

Unity에서는 블렌드 스타일과 정렬 레이어의 조합마다 전역 광원을 하나만 둘 수 있습니다. 두 개가 있으면 콘솔에 "More than one global light on layer" 메시지가 표시됩니다. 하나를 삭제하거나, 각 광원에 서로 다른 Target Sorting Layers(타겟 정렬 레이어) 값을 지정하세요.

Unity Light 2D가 보이지 않을 때: 블렌드 스타일과 강도

증상: 위의 설정이 모두 올바른데도 광원이 여전히 아무 효과를 내지 않습니다.

원인: 겹친 광원의 값은 합산됩니다. Multiply 블렌드 스타일에서는 합계가 1이면 스프라이트가 본래 색으로 보이고, 1을 넘으면 본래 색보다 밝아집니다. 강도 1의 흰색 전역 광원이 있으면 다른 광원이 더할 밝기가 거의 남지 않습니다.

  1. 전역 광원의 Intensity(강도) 필드를 0.3 정도로 낮춥니다.
  2. 다른 광원의 Blend Style(블렌드 스타일) 필드를 확인합니다. Multiply with Mask (R) 옵션과 Additive with Mask (R) 옵션은 스프라이트의 마스크 맵에서 빨간색 채널이 0보다 큰 부분만 비춥니다.

적용되지 않는 Unity 2D 노멀 맵

증상: 스프라이트는 빛을 받는데 노멀 맵을 적용해도 달라지는 것이 없습니다. 다음 항목을 순서대로 확인하고, 전체 단계는 Unity의 스프라이트 노멀 맵을 참조하세요:

  1. 광원. Normal Maps(노멀 맵) 섹션에서 Quality(품질) 필드를 Fast(빠름) 옵션이나 Accurate 옵션으로 설정합니다. 새 광원은 Disabled(사용 안 함) 옵션으로 되어 있습니다. Global Light 2D 컴포넌트에는 이 설정이 없으므로 Spot, Freeform, Sprite 중 하나를 추가합니다.
  2. 이름. 스프라이트의 텍스처를 선택하고 Open Sprite Editor(스프라이트 에디터 열기) 버튼을 클릭한 다음, Secondary Textures(보조 텍스처) 옵션으로 전환해 노멀 맵이 _NormalMap 이름으로 등록되어 있는지 확인합니다.
  3. 임포트. 노멀 맵을 선택하고 Texture Type(텍스처 타입) 필드를 Normal map(노멀 맵) 옵션으로 설정합니다.
  4. 레이아웃. Unity는 스프라이트 텍스처의 UV 좌표로 노멀 맵을 읽으므로, 각 프레임은 두 텍스처에서 같은 위치에 있어야 합니다.
  5. 머티리얼. Sprite-Lit-Default 머티리얼은 노멀 맵을 읽습니다. 직접 만든 셰이더 그래프에서는 노멀 맵을 Normal (Tangent Space) 블록에 연결합니다.
  6. 거리. Normal Maps 섹션의 Distance(거리) 필드 값을 낮춥니다. 그러면 광원이 더 가까이 있는 것처럼 작용해, 더 낮고 비스듬한 각도에서 디테일을 비춥니다.
  7. 아틀라스. 스프라이트 아틀라스를 선택하고 미리보기 오른쪽 위의 드롭다운에서 패킹된 보조 텍스처를 표시합니다. 함께 패킹되는 스프라이트는 보조 텍스처 수가 같아야 합니다.

게임 뷰에서는 보이지만 씬 뷰에서는 보이지 않는 광원

씬 뷰에는 자체 조명 스위치인 툴바의 전구 버튼이 있습니다. 이 버튼이 꺼져 있으면 씬 뷰는 2D 광원 없이 스프라이트를 그립니다. 버튼을 켜세요. 게임 뷰와 빌드는 이 스위치를 쓰지 않습니다.

빌드에서 보이지 않는 Unity Light 2D

증상: 광원이 에디터에서는 작동하지만 플레이어에서는 작동하지 않습니다.

원인: 에디터는 Project Settings > Quality(프로젝트 설정 > 품질) 창에서 강조 표시된 품질 레벨을 사용합니다. 빌드는 해당 플랫폼의 기본 레벨, 즉 그 플랫폼 열에 초록색 체크박스가 표시된 레벨로 시작하며, 이 레벨이 다른 URP 에셋을 지정할 수도 있습니다. 또한 빌드에는 그래픽스 설정의 URP 에셋과, 해당 플랫폼에서 활성화된 레벨의 URP 에셋만 포함됩니다. 이 중 어디에도 2D 렌더러가 없으면 Unity는 빌드의 셰이더에서 2D 조명 패스를 제거합니다.

  1. Project Settings > Quality 창에서 대상 플랫폼의 체크박스가 켜진 모든 레벨의 Render Pipeline Asset(렌더 파이프라인 에셋) 필드를 확인합니다.
  2. 빌드 프로파일을 사용한다면 프로파일도 확인합니다. 프로파일은 해당 플랫폼의 그래픽스 설정을 오버라이드할 수 있습니다.
  3. Project Settings > Player > Other Settings(프로젝트 설정 > Player > 기타 설정) 섹션에서 Strict shader variant matching(엄격한 셰이더 배리언트 매칭) 체크박스를 켜고 다시 빌드합니다. 그러면 Unity가 누락된 셰이더 배리언트를 에러 셰이더로 표시하고, 로그에 그 이름을 남깁니다.

유니버설 렌더러에서 쓰는 2D 조명

Sun Forge 2D Lighting 패키지는 2D 렌더러와 유니버설 렌더러에서 모두 작동하는 별도의 조명 패키지입니다. 메뉴 항목 하나와 Fix All 버튼으로 씬의 조명을 설정할 수 있으며, Unity의 Light 2D 컴포넌트로 Sun Forge의 Light Source 컴포넌트를 제어할 수도 있습니다.
