すべての機能 スプライトベイカー

Unity 向けの 3D から 2D へのスプライトベイカー

Sun Forge は、3D モデルとそのアニメーションを 2D スプライトシートにベイクし、ライティング用のテクスチャ、影、再生用のプレハブも書き出します。

方向

モデルを回すには、スプライトにポインターを合わせるかタップするか、スライダーをドラッグしてください。モデルが向いている方向のスプライトが一緒に再生されます。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

8 方向のスプライト、または 1 から 64 の任意の方向数

ベイクでは 4、8、16 方向など 1 から 64 方向を書き出し、不要な方向はオフにできます。カメラは 0 から 90 度の範囲で 0.25 度刻みの任意の角度から撮影します。サイドビューにも真上からの見下ろしにも、アイソメトリックを含むその間のどの角度にもできます。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

3D アニメーションを 2D スプライトシートに変換

ベイクするアニメーションクリップを選んでください。ベイクでは、方向ごとのスプライトシート、アニメーションクリップ、アニメーターコントローラー、それらを再生するプレハブが書き出されます。どれも Unity 標準のアセットで、3D モデル、メッシュ、リグはビルドに含まれません。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

法線マップとライティング用のテクスチャ

各シートには、色のほかに法線、マスク、ジオメトリテクスチャがあり、ベイクで Emission をオンにした場合はエミッションテクスチャもあります。ベイクで書き出されるのは、オンにしたテクスチャだけです。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

シーンを照らすエミッションテクスチャ

ベイクでは、発光部分がエミッションテクスチャに書き出されます。Glow Light をオンにすると発光部分にライトも追加され、近くの地面とスプライトを照らします。星をドラッグして比較してください。

発光オフ発光オン

The Forgotten Knight は dark_igorek、スケルトンは LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

コライダーとヒットボックス付きのプレハブ

ベイクしたプレハブには、コライダー、ヒットボックス、HP バー、VFX ボックス、頭上のアンカーなど、アーキタイプが与えるパーツが付き、それぞれシーンビューでドラッグできます。

Hero、Enemy、Wildlife のアーキタイプはビヘイビアを追加します。Hero は歩いて撃ち、Enemy は近接攻撃し、Wildlife は歩き回ります。C# で自作のビヘイビアを書き、アーキタイプに追加できます。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

ベイクを実行前にプレビュー

Bake Window では、3D モデル、ベイクカメラ、ベイクで書き出されるスプライトが視点を回せるプレビューに表示され、マーカーはドラッグして配置できます。

ベイクはエディター上で、Bake Window またはエディタースクリプトから実行します。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

プリセット、アーキタイプ、バッチベイク

プリセットには 1 つのモデルのベイク方法が保存され、アーキタイプには出力フォルダー、カメラ、影など、同じ種類のベイクすべてに共通する設定が保持されます。Batch タブには保存したすべてのプリセットが一覧表示され、選択したものを一度にベイクします。

ショーケースのモデルを使用しています。

スプライトベイカー

ベイクでできるほかのこと

キャラクター、小道具、パーティクル、タイル

モデルやプレハブは、アニメーションクリップと Particle System ごと、元のマテリアル (Shader Graph を含む) のままベイクされます。小道具、焚き火の炎などのパーティクルエフェクト、地面タイルもベイクできます。

スプライト向けの柔らかい影

ベイクでは、地面に投影した柔らかい影または丸影、パーティクルのフリップブック、スプライトアトラスも書き出します。影はベイクしたときの太陽の方向を保ちます。

再ベイクしてもプレハブはそのまま

再ベイクしても、プレハブの GUID、追加した子オブジェクトとコンポーネント、プラットフォームオーバーライド、シーンビューで調整したコライダー、ヒットボックス、HP バーはそのまま残ります。

ベイク時間とテクスチャメモリ

ショーケースの 16 方向のブナの木は、RTX 4060 を搭載した Ryzen 9 7900X で約 25 秒でベイクでき、Windows、Mac、Linux 向けにパックした状態で 9.5 MiB のテクスチャメモリを使います。騎士はアニメーション 4 つ分の 968 枚のスプライトで、ベイクは約 1 分、テクスチャメモリは 81 MiB です。

Addressables とエディタースクリプト

ベイクには、書き出したプレハブとアトラスを Addressables に登録する機能があります。エディタースクリプトからベイクでき、自作の C# の処理でベイクを拡張できます。

ライティングなしのスプライト

ベイクは、ライティング用のテクスチャを持たないスプライトと、Unity のデフォルトのスプライトマテリアルを使うプレハブを書き出せるので、Sun Forge のライティングなしでもベイカーを使えます。

ベイクしたスプライトをライティング

1 回の購入で、スプライトベイカーと、ベイクで書き出したテクスチャを読み込む Sun Forge 2D Lighting の両方が手に入ります。すべての機能を確認するか、ガイドを読んでください。

Unity Asset Store で近日公開

Sun Forge には、Unity 6.3 LTS (6000.3.29f1 以降) から Unity 6.6 までのバージョンと、2D レンダラーまたはユニバーサルレンダラーを使う URP が必要です。
