Unity 2D の昼夜サイクルと雲の影

URP の 2D シーンでは、時刻に合わせて Global Light 2D の色を Gradient に沿って変えることで昼夜サイクルを作ります。夜には Volume で画面をカラーグレーディングし、日が暮れるとランプが徐々に灯り、スクロールする雲のテクスチャが地面に影を落とします。以下の手順は Unity 6.3 向けです。

Global Light 2D で作る Unity 2D の昼夜サイクル

Light Type を Global にした Light 2D は、すべての 2D ゲームオブジェクトを均等に照らします。その色を変えると、照らされるスプライトはすべてそれに合わせて色が変わります。

  1. スプライトのマテリアルは、新しいスプライトにデフォルトで設定される Sprite-Lit-Default のままにします。2D ライトは Sprite-Unlit-Default には影響しません。
  2. Hierarchy ウィンドウで右クリックし、Light を選択してグローバルの 2D ライトを選びます。または任意の 2D ライトを選び、その Light Type を Global に設定します。Unity では、グローバルライトはブレンドスタイルとソートレイヤーごとに 1 つまでです。
  3. 下のスクリプトを任意のゲームオブジェクトに追加し、ライトを割り当てます。その Light Color のグラデーションでは、両端を真夜中、中央を正午にします。
  4. カメラの Post Processing をオンにします。GameObject > Volume > Global Volume を選択し、New (新規) をクリックしてプロファイルを作り、続けて Add Override (オーバーライドを追加) をクリックして Color Adjustments を選びます。Saturation を下げるなど、夜の見た目に設定します。Volume をスクリプトに割り当てると、スクリプトがその Weight を設定します。
  5. ランプや火ごとに 2D スポットライトを追加し、スクリプトのリストに入れます。古いバージョン向けのチュートリアルでは、このライトをポイントライトと呼んでいます。
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class DayCycle : MonoBehaviour
{
    public Light2D globalLight;
    public Gradient lightColor;   // the same color at both ends
    public AnimationCurve night;  // 1 at time 0 and at 1, 0 by day
    public Volume nightVolume;
    public Light2D[] lamps;
    public float lampIntensity = 1f;
    public float dayLengthSeconds = 600f;
    public float time;            // 0 and 1 are midnight, 0.5 is noon

    void Update()
    {
        time = Mathf.Repeat(time + Time.deltaTime / dayLengthSeconds, 1f);
        float n = night.Evaluate(time);

        globalLight.color = lightColor.Evaluate(time);
        nightVolume.weight = n;
        foreach (Light2D lamp in lamps)
            lamp.intensity = lampIntensity * n;
    }
}

2D の昼夜サイクルの落とし穴

  • 真夜中のループ。 Gradient.Evaluate は 0 から 1 の時間を受け取り、スクリプトは真夜中に時間を 0 に戻します。Gradient の最初と最後の色が違うと、そこでシーンが急に切り替わります。両端を同じ色にし、夜のカーブも両端を同じ値にしてください。Gradient に置けるカラーキーは最大 8 個なので、キーを置く時刻を選んでください。
  • 急に点くライト。 決まった時刻に有効にしたランプは、1 フレームで突然現れます。そこでスクリプトは代わりに各ランプの intensity を夜のカーブから設定するため、カーブが上がるにつれてランプが明るくなります。
  • 発光するものまで暗くなる。 グローバルライトは、窓や炎も含め、照らされるスプライトをすべて暗くします。発光部分は、Sprite-Unlit-Default マテリアルを使った別のスプライトとして描いてください。Volume の Color Filter と Post Exposure は、発光部分も含めて画面全体を変えます。夜の暗さと色味はライトの色で表し、Volume は彩度とコントラストに使ってください。
  • ブルームのしきい値。 ブルームは Intensity (強さ) が 0 を超えるまでオフです。オンになると、Threshold (しきい値) より明るいピクセルにだけかかります。デフォルトは 0.9 です。照らされるスプライトの発光は夜にはしきい値を下回ります。これも発光をアンリットで描画する理由の 1 つです。Light 2D の Intensity が 1 を超えるとスプライトは元の色より明るくなるため、正午には淡い色の壁がしきい値を超えてブルームがかかることがあります。

Unity 2D の太陽光: Global Light 2D では表せないこと

グローバルライトには方向がありません。すべてを均等に照らし、その Inspector には Normal Maps (法線マップ) と Shadows (影) のセクションがありません。そのため、正午と夕暮れの違いは色だけになります。スプライトのどの面もほかの面より明るくならず、影を落とすものもありません。

太陽の位置を表すには、次の 2 つがどちらも必要です。

  1. 各スプライトの法線マップ。Sprite Editor ウィンドウで Secondary Textures (補助的テクスチャ) を開き、_NormalMap という名前で追加してください (手順)。
  2. 位置を持つライト。大きな 2D スポットライトを追加し、Normal Maps の Quality (品質) を Fast (高速) または Accurate に設定して、スクリプトで一日を通して動かすか回転させてください。

Unity の Happy Harvest サンプルは、スクリプトで回転させる大きなスポットライトを使って、この方法で昼を照らしています。Unity は 2 つの負荷を挙げています。法線マップはレイヤーバッチごとにフルサイズのレンダーパスを 1 つ追加し、大きなライト 1 つは小さなライト数個より負荷が高くなることがあります。

Shadow Caster 2D の影はこのようなライトから生まれ、グローバルライトからは生まれません。太陽の影には、Happy Harvest は引き伸ばした丸影のスプライトを使い、スクリプトで一日を通して回転させ、長さを変えています。2D と見下ろしのスプライトの影で、それぞれの方法を比較しています。

Unity 2D の雲の影

Unity 標準の機能だけを使う方法が 2 つあります。

  • スクロールするオーバーレイ。 暗く柔らかな雲のテクスチャを、地面より手前にソートされる Sprite Renderer に設定してください。テクスチャが画面全体に繰り返されるように Draw Mode (描画モード) を Tiled に設定し、Sprite-Unlit-Default マテリアルを割り当ててください。毎フレーム動かし、1 タイル分ずれたら位置を戻してください。その下に描画されるものは、ランプの光や発光するスプライトも含めてすべて暗くなります。
  • 光を減算するライト。 2D レンダラーアセットの Light Blend Styles で、いずれかのスタイルの Blend Mode を Subtractive (減法) に設定してください。Light Type を Sprite にした Light 2D を追加し、雲のテクスチャをそのスプライトに設定し、そのブレンドスタイルを選んで、同じように動かしてください。このライトは、その Target Sorting Layers にある照らされるスプライトからだけ光を差し引くため、アンリットの発光は明るさを保ちます。

どちらの方法でも、オーバーレイの色かライトの強さを使って、雲も夜のカーブに合わせてフェードさせてください。そうしないと、真夜中でも正午と同じくらい影が濃くなります。

Sun Forge 2D Lighting での実現方法

Sun Forge 2D Lighting は、2D レンダラーまたはユニバーサルレンダラーで使う URP 向けのライティングパッケージです。太陽、月、空と、昼から夜までの天候を備えています。描いたスプライトを照らすには、スプライトを選択して右クリックし、Sun Forge > Set Up for Lighting を選んでください。自作の法線マップがあれば立体感が出ます。法線マップがない場合、スプライトは平らな表面として照らされます。

Lighting Setup の Time Of Day で 0 から 24 までの時刻を設定し、ライティングスタイルで各時刻の光を設定します。スクリプトで一日を進めるには、Update で SunForgeLightingSetup.TimeOfDay を設定してください。ライティングは編集モード、再生モード、プレイヤーでリアルタイムに描画されるため、時刻が変わるとスプライトも照らし直されます。

  • 夜には、月明かりに照らされた表面は青くなり、火の光と発光は色を保ちます。
  • ライトはポイント、スポット、ライン、矩形のいずれかにでき、火のようにちらつかせることもできます。Unity の Light 2D で Sun Forge の Light Source を制御でき、その Light 2D は Unity の Lit マテリアルも引き続き照らします。
  • 空とともに、流れる雲の影と地面を這う霧が加わります。サイドビューにはそれらがかかる地面が映らないため、どちらも表示されません。

影は、ベイクしたとき、または描いたときの太陽の方向に落ち、太陽が動いても回転しません。日が沈むにつれて薄れていきます。

Unity 6.3 LTS (6000.3.28f1 以降) または Unity 6.6、URP、リニア色空間が必要です。
