Unity 2D シーンのフォグと地面を這う霧

Unity のフォグ設定はスプライトには適用されないため、URP の 2D シーンではスプライト、パーティクル、フルスクリーンパスでフォグを作ります。この記事で扱うのは天候としてのフォグです。プレイヤーが探索していないマップの部分を隠すフォグオブウォーは別のもので、ここでは扱いません。

2D シーンで Unity のフォグが効かない理由

フォグの設定は Lighting ウィンドウ (Window > Rendering > Lighting) の Environment (環境) タブ、Other Settings (その他の設定) の下にあります。設定には色とモードがあり、フォグはカメラから離れるほど濃くなります。

スプライトだけのシーンでオンにしても、何も変わりません。URP のスプライト用シェーダー Sprite-Lit-Default と Sprite-Unlit-Default はフォグを適用せず、Sprite Lit や Sprite Unlit の Shader Graph も同様です。フォグを適用するシェーダーがあっても、あまり役に立ちません。2D シーンのスプライトはどれもカメラからほぼ同じ距離にあるため、フォグはすべてのスプライトに同じだけ色味を付けるだけです。

Unity 2D のボリュメトリックフォグ

Unity のボリュメトリックフォグは HDRP の機能で、URP にはありません。2D ゲームでフォグに立体感を出しているのはレイヤーです。奥行きの異なる位置に数枚のフォグを重ね、それぞれ異なる速度で動かしています。

2D のフォグエフェクトを作る 4 つの方法

スクロールするノイズのスプライト

広い範囲を覆うフォグに向いています。

  1. タイリングできる柔らかなノイズテクスチャをインポートし、Wrap Mode を Repeat (繰り返し) に設定します。
  2. Assets > Create > Shader Graph > URP > Sprite Unlit Shader Graph (アセット > 作成 > シェーダーグラフ > URP > スプライト Unlit シェーダーグラフ) を選択します。
  3. グラフで Time ノードに小さな速度を掛け、その結果を Tiling And Offset ノードの Offset につなぎます。そのノードの出力でノイズをサンプリングします。
  4. サンプリングした値にフォグの色を掛け、スプライトの上端に向かってアルファをフェードさせて、フォグの上端がくっきり切れないようにします。
  5. グラフからマテリアルを作り、その範囲を覆う Sprite Renderer に設定します。Sorting Layer と Order in Layer (レイヤーの順序) を設定して、目的のレイヤーの間に描画されるようにします。

このようなレイヤーを 2 枚、異なる速度でスクロールさせると、1 枚の絵がずれていくようには見えにくくなります。

柔らかなスプライトの Particle System

池の上や戸口など、一部分にかかる霧に向いています。低いアルファの柔らかな雲のテクスチャで、大きくゆっくりしたパーティクルを少しだけ放出する Particle System を用意してください。マテリアルには URP の Particles Unlit シェーダーを選び、Surface Type を Transparent (透明) に設定してください。Renderer モジュールの Sorting Layer ID と Order in Layer で、スプライトとの間のソート順が決まります。

フルスクリーンパス

URP の Full Screen Pass Renderer Feature は、画面全体にマテリアルを描画します。レンダラーアセットを選択して Add Renderer Feature をクリックし、Fullscreen Shader Graph から作ったマテリアルをその Renderer Feature に設定してください。描画するタイミングは Injection Point (投入ポイント) で決まります。Before Rendering Post Processing にすると、透明なオブジェクトの後、ポストプロセスの前に描画されます。

フルスクリーンパスはそれより前に描画されたものをすべて覆うため、2 つのレイヤーの間には置けません。そのような場合のために、2D レンダラーには Camera Sorting Layer Texture があります。選んだソートレイヤーまでを描画し終えた時点の画像を保存し、それより後のレイヤーにあるフォグのシェーダーで読み取れます。

色味をフォグの色に寄せた遠くのレイヤー

この方法では描画するものが増えません。各パララックスレイヤーの Sprite Renderer の Color (色) を、奥のレイヤーほど少しずつ強くフォグの色に寄せてください。この色はアートに乗算されるため、暗くすることしかできません。暗いアートに淡いフォグをかけるには、シェーダーでフォグの色にブレンドするか、レイヤーを描き直してください。

落とし穴

フォグがキャラクターを頭から足まで覆う。 フォグのレイヤーは平らな 1 枚の板です。キャラクターの手前にソートすると全身がかすみ、奥にソートすると全身がくっきり見えます。地面を這う霧は、足元で濃く頭のあたりで薄くなるのが自然です。サイドビューでは、上に向かってフェードアウトする低い帯をキャラクターの手前に置けば、近い見た目になります。見下ろしやアイソメトリックのシーンではキャラクターがさまざまな奥行きに立つため、1 本の帯ではほとんどのキャラクターに合いません。霧を細長い帯に分けてキャラクターの間にソートすることもできますが、そのぶんレイヤーが増えます。

ソート。 Unity はスプライトを、まずソートレイヤー、次に Order in Layer (レイヤーの順序)、最後にカメラからの距離で並べます。Order in Layer は値が小さいものほど奥に描画されます。フォグには専用のソートレイヤーか専用の順序を与えてください。どちらもほかのスプライトと同じ場合、それらの間での位置はその距離で決まります。

オーバードロー。 透明なレイヤーはそれぞれ後ろにあるものの上に描画されるため、フルスクリーンのフォグを 3 枚重ねると、すべてのピクセルがさらに 3 回塗られます。これで真っ先に重くなるのはスマートフォンの GPU です。Window > Analysis > Rendering Debugger (ウィンドウ > 分析 > レンダリングデバッガー) で開く URP の Rendering Debugger ウィンドウには、ピクセルが重ねて描画されている場所を示す Overdraw ビューがあります。小さなパーティクルを多数使うのではなく大きなパーティクルを少数使い、テクスチャも小さくしてください。柔らかなノイズは低い解像度でも見た目が変わりません。

ライトを無視するフォグ。 アンリットのフォグは光に関係なく色が変わらないため、夜には火のそばでも灰色のまま、暗がりでも白っぽいままです。Light 2D のライトがフォグに届くようにするには、グラフを Sprite Lit Shader Graph で作り、各ライトの Target Sorting Layers にフォグのソートレイヤーを含めてください。すると、平らな壁に当たるときと同じように光がフォグに当たります。

バンディング。 低いアルファの柔らかなグラデーションには段差が出ます。フォグのテクスチャの Compression (圧縮) を None (なし) に設定してください。カメラの Rendering で、広いグラデーションや暗い部分のバンディングを減らす Dithering をオンにしてください。

Sun Forge 2D Lighting による地面を這う霧

Sun Forge 2D Lighting は URP 向けのライティングパッケージです。霧はこのパッケージの天候の一部で、雲の影と同じように地面の上を流れます。URP の 2D レンダラーとユニバーサルレンダラーのどちらでも動作します。対象は見下ろしまたはアイソメトリックのシーンで、カメラはスプライトを正面から映します。サイドビューには霧がかかる地面が映らないので霧は表示されず、プラットフォーマーには上記の方法のいずれかが必要です。

この霧は、スプライトの手前や奥に置くレイヤーではありません。Sun Forge が 3D モデルからベイクするスプライトにはそれぞれジオメトリテクスチャがあり、スプライトのピボットから見た各テクセルの高さを保持しています。そのため、霧は各スプライトを足元から覆います。

すべての Light Source が霧も照らします。

Sun Forge には Unity 6.3 LTS (6000.3.28f1 以降) または Unity 6.6 が必要です。
