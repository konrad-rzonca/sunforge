Unity の 2D スプライトとライティングのガイド

各ガイドは 1 つの疑問に Unity 標準の機能で答え、落とし穴を挙げ、最後に Sun Forge での方法を紹介します。

  • Unity で 3D モデルを 2D スプライトに変換する方法

    Blender または Unity でフレームをレンダリングし、スライスしてクリップを作り、テクスチャをパックします。

  • Unity の 8 方向スプライト: 4 方向か 8 方向か 16 方向か?

    方向数ごとの負荷、各ビューのカメラ角度、スプライトを選ぶコード。

  • Unity の法線マップで 2D スプライトを立体的に見せる方法

    スプライトに法線マップとマスクを追加する方法と入手先、この 2 つだけではできないこと。

  • Unity で 2D と見下ろしのスプライトに影を落とす方法

    Shadow Caster 2D、丸影、傾けたコピー、3D モデルからのレンダリングと、それぞれに向くワールド。

  • Unity 2D の昼夜サイクルと雲の影

    Gradient で色を変える Global Light 2D、夜のための Volume、徐々に灯るランプ、地面に影を落とす雲。

  • Unity 2D シーンのフォグと地面を這う霧

    Unity のフォグがスプライトに効かない理由と、スプライト、パーティクル、フルスクリーンパスでフォグを作る 4 つの方法。

  • Unity の 2D ライトが反映されないときのチェック項目

    グレーアウトする、スプライトを照らさない、法線マップが反映されない、ビルドで表示されない Light 2D。
