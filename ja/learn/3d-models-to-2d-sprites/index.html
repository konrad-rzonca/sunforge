解説記事

Unity で 3D モデルを 2D スプライトに変換する方法

3D モデルから作る 2D スプライトは、固定したカメラからモデルをレンダリングし、背景を透明にして保存したものです。アニメーションするキャラクターは、このようなレンダリングを数多く集めたもので、フレームごと、アニメーションごと、方向ごとに 1 枚ずつあります。フレームをレンダリングしてスプライトにスライスし、アニメーションクリップを作り、テクスチャをパックします。

Blender で 3D モデルから 2D スプライトを作る方法

  1. カメラのタイプを Orthographic に設定し、どの距離でもモデルの大きさが変わらないようにします。画像の中でのモデルの大きさは Orthographic Scale で決まります。
  2. レンダー設定の Film で Transparent をオンにします。
  3. アルファチャンネルを残すため、出力のカラーを RGBA にし、PNG などの形式を選びます。
  4. アニメーションを連番画像としてレンダリングします。別の方向は、モデルかカメラを回してもう一度レンダリングします。

PNG ファイルは、1 ファイルを 1 枚のスプライトとしてそのままインポートするか、先に 1 枚のシートにまとめてください。

Unity で 3D モデルをスプライトにレンダリングする方法

  1. カメラを追加し、Projection (投影方法) を Orthographic (平行投影) に設定します。Size は、ビューの高さの半分をワールド単位で表した値です。
  2. Background Type (背景タイプ) を Solid Color に設定し、Background (背景) の色のアルファを 0 にします。
  3. Assets > Create > Rendering > Render Texture (アセット > 作成 > レンダリング > レンダーテクスチャ) で、カラーフォーマットにアルファチャンネルがあるレンダーテクスチャを作成し、カメラの Output Texture (出力テクスチャ) に割り当てます。
  4. URP では、カメラの Post Processing をオフにするか、URP アセットの Alpha Processing をオンにします。そうしないと、ポストプロセスでアルファが 1 に置き換えられます。
  5. フレームごとに clip.SampleAnimation(model, time) でモデルにポーズを取らせ、エディタースクリプトから次のように画像を保存します。
static void SaveFrame(Camera camera, RenderTexture target, string path)
{
    camera.targetTexture = target;
    camera.Render();

    RenderTexture previous = RenderTexture.active;
    RenderTexture.active = target;
    var frame = new Texture2D(target.width, target.height, TextureFormat.RGBA32, false);
    frame.ReadPixels(new Rect(0, 0, target.width, target.height), 0, 0);
    frame.Apply();
    RenderTexture.active = previous;

    System.IO.File.WriteAllBytes(path, ImageConversion.EncodeToPNG(frame));
    Object.DestroyImmediate(frame);
}

レンダーテクスチャと Texture2D は同じフォーマットにしてください。リニア色空間のプロジェクトでは、名前が _SRGB で終わるレンダーテクスチャのフォーマットを選んでください。そうしないと、保存した色が暗くなります。

Sprite Editor でスプライトシートをスライスする方法

  1. 2D Sprite パッケージがインストールされていることを確認します。
  2. 画像を選択し、Texture Type を Sprite (2D and UI) に、Sprite Mode を Multiple (複数) に設定して、Apply (適用する) をクリックします。
  3. Sprite Editor ウィンドウを開き、Slice メニューを開きます。同じ大きさのフレームには Grid By Cell Size を、行と列の数がわかっている場合は Grid By Cell Count を選びます。
  4. Pivot を設定し、Slice をクリックしてから Apply をクリックします。

フレームから作るアニメーションクリップとアニメーターコントローラー

  1. 最初のスプライトをシーンにドラッグします。Sprite Renderer を持つゲームオブジェクトが作成されます。
  2. そのゲームオブジェクトを選択した状態で、Animation ウィンドウの Create (作成) をクリックし、クリップを保存します。Unity は、そのクリップをデフォルトのステートとするアニメーターコントローラーを作成し、ゲームオブジェクトに Animator を追加します。
  3. Sprite Renderer のスプライトに、1 フレームに 1 枚ずつキーを設定します。
  4. 2 つ目以降のアニメーションごとに、Animation ウィンドウのクリップメニューで Create New Clip (新しいクリップを作成) を選び、アニメーターコントローラーでクリップ間に遷移を追加します。

クリップが多い場合は、この手順をスクリプトにしてください。Unity の AnimationClip のリファレンスには、Project ウィンドウで選択したスプライトからクリップを作る例があります。

落とし穴

Pixels Per Unit

Pixels Per Unit は、ワールド空間の 1 単位をスプライト画像の何ピクセルで覆うかを表します。インポートで使う値を決め、レンダーテクスチャの高さを 2 × Size × Pixels Per Unit ピクセルにしてください。Size が 1.5、Pixels Per Unit が 64 なら 192 ピクセルです。そうすると、2D シーンでのスプライトの高さがモデルと同じになります。すべてのスプライトに同じ値を使ってください。そうしないと、一部のスプライトがほかより鮮明に見えます。

ピボットとフレーミング

ピボットは、スプライトのローカル座標の原点となる画像上の点です。キャラクターの場合は足元に置き、すべてのフレームで同じピクセルにしてください。そのためには、すべてのアニメーションのすべてのフレームを、同じカメラ位置、同じ Size、同じ解像度でレンダリングし、フレームの幅はいちばん幅の広いポーズが収まるようにします。そのうえでグリッドでスライスし、すべてに同じピボットを設定します。Automatic (自動) のスライスは透明なピクセルを境に切り分けるため、フレームごとに矩形が異なり、Bottom などのピボットがフレームごとに体の違う位置に来て、キャラクターががたついて見えます。

乗算済みアルファと縁のハロー

透明なジオメトリをレンダーテクスチャにブレンドすると、テクスチャには各色があらかじめアルファを掛けた値で保存されます。従来の透明度 (Blend SrcAlpha OneMinusSrcAlpha) を使うマテリアルはもう一度アルファを掛けるため、半透明のピクセルが暗くなります。PNG を保存する前に色をアルファで割るか、乗算済みの色をブレンドするシェーダー (Blend One OneMinusSrcAlpha) を使ってください。

テクスチャのフィルタリングは、縁の各ピクセルを隣の透明なピクセルと混ぜます。テクスチャのインポート設定で Alpha Is Transparency (アルファ値を透明度として使用) をオンにしてください。すると Unity がカラーチャンネルを外側に広げるため、縁にフィルタリングによるアーティファクトが出なくなります。

テクスチャサイズとアトラスへのパック

8 方向、各 16 フレームの 3 つのアニメーション、256 x 256 ピクセルなら 384 フレームになり、約 2,500 万ピクセル、非圧縮で 96 MiB です。Pixels Per Unit を半分にすると、その 4 分の 1 で済みます。

Unity はインポート時に、Max Size (最大サイズ) より大きいテクスチャをそのサイズまで縮小します。大きなシートでは Max Size を上げるか、アニメーションごとにシートを分けてください。そのうえで、Assets > Create > 2D > Sprite Atlas (アセット > 作成 > 2D > スプライトアトラス) で作るスプライトアトラスにスプライトをパックしてください。スプライトアトラスは複数のテクスチャを 1 枚にまとめるため、Unity はそのスプライトをすべて 1 回のドローコールで描画できます。

色にベイクしたライティングか、法線マップか

レンダリングした光は、スプライトの色の一部になります。左から照らした騎士は、右側にたいまつがあっても左から照らされたままです。ゲーム中に変わる光を使うには、均一な光の下で色をレンダリングし、同じフレームの法線マップを同じカメラでレンダリングしてください。Sprite Editor ウィンドウで、法線マップを _NormalMap という名前の補助的テクスチャとして追加し、Sprite-Lit-Default などのマテリアルを使い、2D ライトの Normal Maps (法線マップ) で Quality (品質) を Fast (高速) または Accurate に設定してください。Unity は両方を同じ UV 座標でサンプリングするため、法線マップはスプライトのテクスチャと位置が揃っている必要があります。Unity のスプライトの法線マップに、手順と落とし穴をまとめています。

Unity の中で 3D モデルを 2D スプライトに変換するツール: Sun Forge

Sun Forge は、このサイトで紹介しているスプライトベイカーです。Unity エディターの中で、Bake Window またはエディタースクリプトからベイクします。アニメーションクリップと Particle System を含むモデルまたはプレハブを、モデル自身のマテリアル (Shader Graph のマテリアルも含む) のままベイクできます。

ベイクで書き出されるのは 2D のスプライトプレハブです。方向ごとのスプライトシート、アニメーターコントローラー付きのアニメーション、ライティング用のテクスチャ、影、コライダー、ゲームプレイ用のコンポーネントが含まれます。

  • カメラ。 ベイクカメラは、サイドビューから真上からの見下ろしまで、アイソメトリックを含む 0 から 90 度のどの角度からでもモデルを写せます。ベイクで書き出す方向数は 1 から 64 で、ゲームに必要な方向の数は別の記事で解説しています。
  • 解像度とメモリ。 新しいベイクの初期値は 96 Pixels Per Unit です。ベイクのたびに、その出力が使うテクスチャメモリが Bake タブに表示されます。
  • ライティング。 各シートにはカラーテクスチャのほかに法線テクスチャ、マスクテクスチャ、ジオメトリテクスチャがあり、Sun Forge 2D Lighting がそれらを読み取るため、太陽やライトを変えるとその場で反映されます。ベイクで書き出すのはスイッチがオンのテクスチャだけで、プレハブに Unity のデフォルトのスプライトマテリアルを設定することもできます。

Sun Forge には、Unity 6.3 LTS (6000.3.29f1 以降) から Unity 6.6 までのバージョンと、2D レンダラーまたはユニバーサルレンダラーを使う URP が必要です。ビルトインレンダーパイプラインまたは HDRP では、上記の手順を使ってください。スプライトベイカーのページで、ベイクの各部分を紹介しています。
