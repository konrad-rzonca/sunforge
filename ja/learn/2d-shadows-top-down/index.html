Unity で 2D と見下ろしのスプライトに影を落とす方法

Unity の 2D スプライトに影を付ける方法は 4 つあります。URP の Shadow Caster 2D、足元に置く丸影のスプライト、スプライトを傾けた暗いコピー、スプライトの元になった 3D モデルからレンダリングした影です。どれを選ぶかは、まず影がどこに落ちるかで決めてください。画面の平面上か、キャラクターが立つ地面の上かです。

2 種類の 2D の影

横から見たプラットフォーマーは平らなワールドで、真上から見たダンジョンも同じです。壁がたいまつの光をさえぎり、壁の向こう側は暗くなります。

見下ろしや 2.5D のワールドでは、カメラは斜めに見下ろし、キャラクターは地面の上に直立しています。そこでは影はキャラクターの足元の地面に落ち、太陽と反対の方向を向きます。

Shadow Caster 2D が作るのは 1 つ目の種類です。ほかの 3 つの方法は 2 つ目の種類を作ります。

Unity の Shadow Caster 2D と Light 2D

Shadow Caster 2D は、2D ライトが影を落とすときに使う形を設定する URP のコンポーネントです。プロジェクトには 2D レンダラーを使う URP が必要で、スプライトには、デフォルトの Sprite-Lit-Default など、2D ライトで照らされるマテリアルが必要です。

  1. Hierarchy ウィンドウで右クリックし、Light を選択して、スポット、フリーフォーム、スプライトのいずれかのライトを選びます。
  2. Light 2D で Shadows (影) をオンにします。Strength (強さ) はキャスターが光をどれだけさえぎるかを 0 から 1 の範囲で設定し、Softness (ぼかし) は影の縁をぼかします。
  3. 影を落とすスプライトを選択し、Add Component (コンポーネントを追加) をクリックして Shadow Caster 2D を追加します。その形は Sprite Editor ウィンドウで設定したスプライトの Custom Outline で、シーンビューには白で描画されます。
  4. 別の形を使うには、Casting Source (投影ソース) を、Polygon Collider 2D など同じゲームオブジェクトにあるコライダーに設定するか、Shape Editor に設定して Edit Shape をクリックします。
  5. 複数のスプライトの影をまとめるには、それらを Composite Shadow Caster 2D を持つゲームオブジェクトの子にします。

Casting Option (投影オプション) は、キャスターがほかのスプライト、自分自身、またはその両方に影を落とすかを設定し、Target Sorting Layers は影が落ちるソートレイヤーを設定します。

ただし、これでは見下ろしのキャラクターに地面の影は付きません。

  • キャスターは光をさえぎるアウトラインです。スプライトの高さや影の長さを設定する項目はありません。
  • グローバルライト、つまり日光のようにすべてのスプライトを均等に照らすタイプには、Shadows の設定がありません。ほかのタイプはライトの位置から影を落とすため、影はキャスターの向こう側に落ちます。

Unity の見下ろしのサンプル Happy Harvest のガイドによると、これらの影はどこまでも伸びるため、一般的な日光には不自然に見えます。このサンプルは、ランプや火の近くでだけ、キャラクターの足元に置いたキャスターから影を落としています。木や茂みには丸影を使っています。

2D スプライトの下の丸影

丸影は柔らかく暗い楕円で、キャラクターの足元に子スプライトとして描画します。どのスプライトやアニメーションでも使え、描画するスプライトが 1 枚増える分の負荷がかかります。キャラクターが地面に触れている位置はわかりますが、キャラクターの形も太陽の方向もわかりません。Sprite Renderer の Color (色) を少し透明な黒にすると、1 枚のテクスチャをどんな地面にも使えます。

傾けたコピーによるスプライトのキャストシャドウ

キャラクターの形の影にするには、キャラクターのスプライトをもう一度描画します。黒の色味を付けて半透明にし、平らにつぶして、地面に横たわるように傾けます。

  • コピーは、ピボットが足元にある子に付けた 2 つ目の Sprite Renderer です。アニメーションするキャラクターでは、Unity がすべての Update の後に呼び出す LateUpdate で、スクリプトが本体の現在のスプライトと反転を毎フレームコピーに写します。
  • Transform には斜めにゆがめる設定がありません。不均一なスケールを持つ親の下で回転させた子は斜めにゆがんで見えることがあり、これで傾きを付けられます。もう 1 つの方法は、ピボットからの高さに応じて各頂点を横にずらす影用のシェーダーです。

コピーは、太陽から見たキャラクターではなく、カメラから見たキャラクターを表します。太陽の方向がカメラの方向から離れるほど、アウトラインは合わなくなります。

3D モデルからレンダリングした影

スプライトが 3D モデルをレンダリングしたものなら、影もモデルからレンダリングしてください。Blender の Cycles では、オブジェクトの Shadow Catcher オプション (Object Properties > Visibility) を使うと、地面の平面が影の光線だけを受けるため、平面をレンダリングすると影だけが写ります。影を本体とフレームごとに揃えた専用のシートとしてレンダリングし、キャラクターの下にある 2 つ目の Sprite Renderer で表示してください。

この影には、太陽から見たアウトラインがあります。シートの数は 2 倍になり、影の方向はレンダリングした時点で決まります。向きが複数あるキャラクターでは、モデルが回転してもワールドの太陽を固定したままにしてください。そうしないと、キャラクターが向きを変えるたびに影がぐるりと回ってしまいます。

2D スプライトの影の落とし穴

  • ソート。 見下ろしのシーンでは通常、2D レンダラーアセットで Transparency Sort Mode (透明度ソートモード) を Custom Axis (カスタム軸) にし、軸を (0, 1, 0) にして、スプライトを y でソートします。すると、キャラクターと同じソートレイヤーにある影は、持ち主の後ろに立つキャラクターの足元の上に描画されます。影には専用のソートレイヤーを用意し、Project Settings > Tags and Layers (プロジェクト設定 > タグとレイヤー) で、地面のレイヤーの後、キャラクターのレイヤーの前に並べてください。Unity はリストの順にレイヤーを描画します。
  • 重なり。 半透明の影が 2 つ重なると、そこの地面は 2 回暗くなります。直すには自作の影用シェーダーが必要です。URP が対応している ShaderLab の Stencil コマンドを使うと、最初の影が描画した各ピクセルに印を付け、後の影がそのピクセルを飛ばすようにできます。
  • 方向。 シーンのすべての影は同じ方向を向き、スプライトに描き込まれた光やレンダリングされた光と一致している必要があります。傾けたコピーはすべて 1 つの角度で制御し、モデルはすべて 1 つの太陽の下でレンダリングしてください。
  • ほかのスプライト。 丸影、コピー、レンダリングしたシートが暗くするのは地面だけです。木の影に入ったキャラクターは明るく照らされたままです。影はどのキャラクターよりも下に描画され、どちらのスプライトも高さを保持していないためです。Shadow Caster 2D の影は、その Target Sorting Layers にあるすべてのスプライトに、地面にもほかのキャラクターにも同じように落ちます。

Sun Forge での実現方法

Unity のエディターツールである Sun Forge は、4 つ目の方法を取ります。ベイクは 3D モデルを 2D のスプライトプレハブに変換し、そのスプライトの影も書き出します。地面に投影した柔らかな影か、丸影です。

影はスプライトと一緒に動き、日が沈むにつれて薄れます。ベイクしたときの太陽の方向を保ち、シーンの太陽が動いても回転しないため、一日を通して影が回転する必要があるゲームには向きません。

ベイクした各シートには、カラーテクスチャに加えてジオメトリテクスチャがあり、スプライトのピボットから見た各テクセルの高さを保持します。この高さによって、ベイクしたスプライトが互いに影を落とせます。キャストシャドウの中に立っているスプライトには、影を落とすものと同じ高さまで影がかかります。

Sun Forge には、Unity 6.3 LTS (6000.3.29f1 以降) から Unity 6.6 までのバージョンと、2D レンダラーまたはユニバーサルレンダラーを使う URP が必要です。ライティングのページでは、キャストシャドウをオフにした場合とオンにした場合の同じシーンを見られます。
