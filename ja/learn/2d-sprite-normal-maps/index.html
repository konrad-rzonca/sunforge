解説記事

Unity の法線マップで 2D スプライトを立体的に見せる方法

スプライトは平らな絵なので、光が当たる立体的な形がありません。法線マップがその形を与えます。ピクセルごとに、その部分の表面が向いている方向を保持しています。法線マップがあれば、キャラクターの左にあるたいまつはキャラクターの左側を照らし、たいまつが動くとシェーディングも動きます。

Sprite Lit と Light 2D: Unity がスプライトを照らす仕組み

Unity の 2D ライトはユニバーサルレンダーパイプライン (URP) の一部で、プロジェクトが 2D レンダラーを使っているときに機能します。その場合、シーンビューにドラッグしたスプライトには Sprite-Lit-Default マテリアルが設定され、2D ライトで照らされます。Sprite-Unlit-Default のスプライトは 2D ライトを無視します。

ライトを追加するには、Hierarchy ウィンドウで右クリックし、Light を選んで、スポット、フリーフォーム、スプライト、グローバルのいずれかの 2D ライトを選んでください。グローバルライトはすべてのスプライトを均等に照らします。法線マップがない場合、それ以外のライトは、紙の切り抜きの上にかざしたランプのようにスプライトを照らします。ライトの形の内側が明るくなるだけで、絵そのものにはシェーディングが付きません。

スプライトの法線マップ (ノーマルマップ) が保持する情報

法線マップは、スプライトのテクスチャと位置が揃ったテクスチャです。赤は各ピクセルの表面がどれだけ右に傾いているか、緑はどれだけ上に傾いているか、青はどれだけ正面を向いているかを保持します。正面をまっすぐ向いたピクセルは、明るい青の #8080FF になります。

Unity でスプライトに法線マップを追加する方法

  1. 法線マップをインポートし、Inspector で Texture Type を Normal map (法線マップ) に設定します。
  2. スプライトのテクスチャを選択し、Sprite Editor を開いて、そのドロップダウンから Secondary Textures (補助的テクスチャ) を選択します。
  3. + をクリックし、Name (名前) ドロップダウンで _NormalMap を選択します。法線マップを割り当て、Apply (適用する) をクリックします。
  4. スプライトの Sprite Renderer が Sprite-Lit-Default、または法線マップを読み取るほかのマテリアルを使っていることを確認します。
  5. Light 2D を選択します。Normal Maps (法線マップ) で Quality (品質) を Fast (高速) または Accurate に設定します。

手順 5 を済ませるまで、ライトは法線マップを無視します。グローバルライトにはこの設定がないため、シェーディングを表示するには、シーンにスポット、フリーフォーム、スプライトのいずれかのライトが必要です。同じセクションの Distance (距離) を小さくするとライトがスプライトに近づき、細部がよりはっきり見えます。

自作のシェーダーは、Assets > Create > Shader Graph > URP > Sprite Lit Shader Graph (アセット > 作成 > シェーダーグラフ > URP > スプライト Lit シェーダーグラフ) から作り始められます。このグラフには Normal (Tangent Space) 入力があります。

マスクテクスチャ _MaskTex

スプライトには、2 つ目の補助的テクスチャ _MaskTex を設定できます。Texture Type を Default にし、sRGB (Color Texture) をオフにしてインポートしてください。

マスクは、光が当たってよい場所を示します。Blend Style が Multiply with Mask (R) または Additive with Mask (R) のライトは、マスクの赤チャンネルが 0 より大きいピクセルだけを照らします。2D レンダラーアセットでは、ブレンドスタイルごとに、赤の代わりに緑、青、アルファを読み取るように設定できます。リムライトや、鎧だけに当たるきらめきに使ってください。

法線マップの入手先

  • 手描き。 法線マップ用のパレットから方向を表す色を取り、スプライトの上に塗ります。Krita には専用のブラシがあります。アニメーションするキャラクターには、フレームごとに法線マップが必要です。
  • スプライトから生成。 表面が高いほど白くなるグレースケールのハイトマップを描き、Texture Type を Normal map (法線マップ) にし、Create from Grayscale (グレースケールから作成) をオンにしてインポートしてください。絵だけから生成するツールは形を推測し、たいていはアウトラインを丸めるだけです。
  • 3D モデルからレンダリング。 スプライトが 3D モデルをレンダリングしたものなら、同じカメラからモデルの法線をレンダリングすれば、どのフレームにも一致する法線マップができます。Blender の Normal パスは方向をワールド空間で保持するため、保存する前にカメラから見た向きに変換してください。

法線マップだけではできないこと

  • 金属と滑らかさ。 Unity のマニュアルによると、Unity の 2D ライティングは物理ベースではありません。Sprite-Lit-Default が読み取るのはカラーテクスチャ、マスク、法線マップで、どれもピクセルの光沢を示さないため、鋼も布も同じように光を受けます。手動で配置したマスク付きのライトで、きらめきを擬似的に表現できます。
  • 互いに影を落とすスプライト。 Shadow Caster 2D は、スプライトの Custom Outline、コライダー、自分で描いたシェイプのいずれかのアウトラインから形を取ります。わかるのはスプライトの縁だけで、各部分がどれだけ高く立っているかはわかりません。Unity の Happy Harvest サンプルでは、代わりに木の下の影を引き伸ばしたスプライトとして描画しています。2D と見下ろしのスプライトの影で、それぞれの方法を紹介しています。

どちらにも、ピクセルごとのデータがさらに必要です。表面がどれだけメタリックで滑らかか、そしてどれだけ高く立っているかです。

Unity のスプライトの法線マップが機能しない原因

ライトを当てても何も変わらない場合は、まず Unity の 2D ライトが反映されないときのチェック項目を確認してください。ここでは法線マップそのものの落とし穴を挙げます。

  • テクスチャタイプ。 Sprite (2D and UI) のままの法線マップは正しくシェーディングされず、ライトが動いても暗い側が動きません。Texture Type を Normal map (法線マップ) に設定し、ファイルがハイトマップでない限り Create from Grayscale (グレースケールから作成) はオフにしてください。
  • 反転した緑チャンネル。 Unity は緑が上を表すことを前提としています。これは Y+ または OpenGL と呼ばれる規約です。逆の規約で作られた法線マップでは、ライトが上にあるのに下から照らされたように見えます。テクスチャのインポート設定で Flip Green Channel (緑のチャンネルを反転) をオンにしてください。
  • 反転したスプライト。 Sprite Renderer の Flip (反転) の X は、描画されるものだけを反転します。Y 軸まわりに 180 度回転させたスプライトは正しく照らされませんが、Unity はこれを仕様としています。負の Scale X で反転する場合は、スプライトの上にライトを置き、上側の縁が照らされていることを確認してください。
  • スプライトアトラス。 スプライトアトラスは、含まれるスプライトの補助的テクスチャをまとめて専用のテクスチャにします。アトラス内のすべてのスプライトに同じ数の補助的テクスチャを設定してください。そうしないと、まとめたテクスチャに大きな空き領域ができることがあります。シートを別のツールでパックする場合は、法線マップも同じレイアウトでパックする必要があります。Unity は両方を同じ UV で読み取るためです。

Sun Forge: スプライトごとの法線、マスク、ジオメトリ、エミッションの各テクスチャ

Unity のエディターツールである Sun Forge は、3 つ目の方法を Unity の中で実現します。ベイクは 3D モデルまたはプレハブを 2D のスプライトプレハブに変換し、方向ごとにスプライトシートを作ります。各シートには、カラーテクスチャに加えて法線、マスク、ジオメトリの各テクスチャが付き、ベイクで Emission がオンのときはエミッションテクスチャも付きます。

  • マスクは、赤に金属、緑に滑らかさ、青にアンビエントオクルージョンを保持します。
  • ジオメトリテクスチャは、スプライトのピボットから見た各テクセルの高さを保持します。これによって、スプライト同士が影を落とし合えます。

Sun Forge のライティングパッケージである Sun Forge 2D Lighting が、これらのテクスチャを読み取ります。キャストシャドウは、その中に立っているスプライトを、影を落とすものと同じ高さまで這い上がります。

このライティングは、描いたスプライトも照らします。スプライトを選択して右クリックし、Sun Forge > Set Up for Lighting を選んでください。自作の法線マップがあれば立体感が出ます。ない場合、スプライトは平らな表面として照らされます。発光させる色と金属のように光らせる色を選ぶと、Sun Forge がそのエミッションテクスチャと金属テクスチャを書き出します。

Sun Forge には、Unity 6.3 LTS (6000.3.28f1 以降) または Unity 6.6 と、2D レンダラーまたはユニバーサルレンダラーを使う URP が必要です。ベイカーとライティングは、それぞれ単独でも動作します。スプライトベイカーとライティングを参照してください。
