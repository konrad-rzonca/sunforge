解説記事

Unity の 2D ライトが反映されないときのチェック項目

Unity の 2D ライトはユニバーサルレンダーパイプライン (URP) の一部で、その 2D レンダラーでのみ機能します。ライトを置いても何も変わらないときは、以下の設定をこの順に確認してください。メニュー名は Unity 6.3 のものです。

Unity の 2D ライトがメニューでグレーアウトして使えない

症状: GameObject > Light にある 2D ライトをクリックできません。または、Light 2D の Inspector に "2D renderer data must be assigned to your universal render pipeline asset or camera." とだけ表示されます。

原因: プロジェクトに URP アセットがなくビルトインレンダーパイプラインで動作しているか、URP アセットのデフォルトのレンダラーがユニバーサルレンダラーになっています。

  1. Project ウィンドウで Create > Rendering > URP Asset (with 2D Renderer) (作成 > レンダリング > URP アセット (2D レンダラー含む)) を選択します。Unity が URP アセットと 2D レンダラーのアセットを作成します。
  2. Edit > Project Settings > Graphics (編集 > プロジェクト設定 > グラフィックス) を開き、Default Render Pipeline を新しい URP アセットに設定します。

今ある URP アセットを使い続けるには、Create > Rendering > URP 2D Renderer (作成 > レンダリング > URP 2D レンダラー) でレンダラーを作成し、アセットの Renderer List に追加して、そのレンダラーで Set Default (デフォルトに設定) を選択してください。

品質レベルで別の URP アセットが指定されている

症状: グラフィックス設定は正しいのに、ライトが無効のままか、何も変わりません。

原因: 各品質レベルには Render Pipeline Asset フィールドがあります。これが設定されていると、Unity はそのレベルで、グラフィックス設定のアセットではなくそのアセットを使います。

  1. Edit > Project Settings > Quality (編集 > プロジェクト設定 > 品質) を開きます。
  2. 各レベルを順に選択し、Render Pipeline Asset を確認します。
  3. このフィールドを空にするか、2D レンダラーを使う URP アセットに設定します。

Unity の 2D ライトがスプライトに反映されない

症状: ライトがどう変わっても、一部のスプライトが元の明るさのままです。多くは、プロジェクトを URP に移行する前に作ったスプライトです。

原因: 2D ライトが変えるのは、2D ライト用に作られたマテリアルだけです。Sprite-Lit-Default はその 1 つです。Sprites-Default などのビルトインレンダーパイプラインのマテリアルや、Sprite-Unlit-Default は反応しません。

  1. スプライトを選択します。
  2. その Sprite Renderer で Material を Sprite-Lit-Default に設定します。

プロジェクト全体を変換するには、バックアップを取ってから Window > Rendering > Render Pipeline Converter を開き、2D Converters > Built-in to 2D URP Material Upgrader を選んで、Material and Material Reference Upgrade を実行してください。自作のシェーダーは、Create > Shader Graph > URP > Sprite Lit Shader Graph (作成 > シェーダーグラフ > URP > スプライト Lit シェーダーグラフ) から作り始めてください。

ライトの Target Sorting Layers にスプライトが含まれていない

症状: ライトの範囲内にあるスプライトのうち、照らされるものとされないものがあります。

原因: Light 2D は、その Target Sorting Layers にあるソートレイヤーだけを照らします。新しいライトはすべてのソートレイヤーを対象にします。ソートレイヤーを追加したときに開いていなかったシーンやプレハブにあるライトには、新しいレイヤーが含まれません。

  1. スプライトを選択し、その Sprite Renderer の Sorting Layer を確認します。
  2. ライトを選択し、そのレイヤーを Target Sorting Layers に追加します。

ライトの Z 位置は関係ありません。2D ライトは、スプライトがライトの手前にあっても奥にあっても、どれだけ離れていても照らします。

ライトの外側がすべて黒くなる

症状: ライトを追加するまではシーンが普通に見えていたのに、今はそのライトの範囲しか表示されません。

原因: シーンに Light 2D がない間、Unity はスプライトを本来の色で描画します。最初のライトを置いた時点から、スプライトには届いた光だけが表示されます。Global Light 2D は、対象のレイヤーにあるすべてのスプライトを均等に照らします。

  1. GameObject > Light > Global Light 2D を選択します。
  2. ほかのライトが届かない場所でのシーンの見え方に合わせて、その Color (色) と Intensity (強さ) を設定します。

Unity では、グローバルライトはブレンドスタイルとソートレイヤーごとに 1 つまでです。2 つあると、Console ウィンドウに "More than one global light on layer" と表示されます。1 つを削除するか、それぞれに別の Target Sorting Layers を設定してください。

Unity の Light 2D が表示されない: ブレンドスタイルと強さ

症状: ここまでの設定はすべて正しいのに、ライトを置いても何も変わりません。

原因: 重なったライトは足し合わされます。Multiply ブレンドスタイルでは、合計が 1 のときスプライトは本来の色で表示され、1 を超えるとそれより明るくなります。強さ 1 の白いグローバルライトがあると、ほかのライトで明るくできる余地はほとんど残りません。

  1. グローバルライトの Intensity (強さ) を、たとえば 0.3 まで下げます。
  2. ほかのライトの Blend Style を確認します。Multiply with Mask (R) と Additive with Mask (R) は、マスクマップの赤チャンネルが 0 より大きい部分だけでスプライトを照らします。

Unity 2D で法線マップが反映されない

症状: スプライトは照らされているのに、法線マップの効果が表れません。次の項目を順に確認してください。詳しい手順は Unity のスプライトの法線マップを参照してください。

  1. ライト。 Normal Maps (法線マップ) で Quality (品質) を Fast (高速) または Accurate に設定してください。新しいライトでは Disabled (無効) になっています。Global Light 2D にはこの設定がないため、スポット、フリーフォーム、スプライトのいずれかのライトを追加してください。
  2. 名前。 スプライトのテクスチャを選択し、Open Sprite Editor (スプライトエディターを開く) をクリックして Secondary Textures (補助的テクスチャ) に切り替え、法線マップが _NormalMap という名前で登録されていることを確認してください。
  3. インポート。 法線マップを選択し、Texture Type を Normal map (法線マップ) に設定してください。
  4. レイアウト。 Unity は法線マップをスプライトのテクスチャの UV 座標で読み取るため、各フレームは両方のテクスチャで同じ位置にある必要があります。
  5. マテリアル。 Sprite-Lit-Default は法線マップを読み取ります。自作の Shader Graph では、法線マップを Normal (Tangent Space) に接続してください。
  6. 距離。 Normal Maps の Distance (距離) を小さくしてください。ライトが近くにあるときのように、より低く、表面をかすめる角度から細部を照らします。
  7. アトラス。 スプライトアトラスを選択し、そのプレビューの右上にあるドロップダウンで、パックされた補助的テクスチャを表示してください。一緒にパックするスプライトには、同じ数の補助的テクスチャが必要です。

ゲームビューではライトが表示されるのに、シーンビューでは表示されない

シーンビューには独自のライティングのスイッチとして、ツールバーに電球のボタンがあります。これがオフの間、シーンビューは 2D ライトなしでスプライトを描画します。オンにしてください。ゲームビューとビルドはこのスイッチを使いません。

ビルドで Unity の Light 2D が表示されない

症状: ライトはエディターでは機能するのに、プレイヤーでは機能しません。

原因: エディターは、Project Settings > Quality (プロジェクト設定 > 品質) でハイライトされている品質レベルを使います。ビルドは、そのプラットフォームの列で緑のチェックボックスが付いたデフォルトのレベルで始まり、そのレベルが別の URP アセットを指定していることがあります。また、ビルドに含まれるのは、グラフィックス設定の URP アセットと、そのプラットフォームで有効なレベルの URP アセットだけです。そのどれにも 2D レンダラーがなければ、Unity はビルドのシェーダーから 2D ライティングのパスを取り除きます。

  1. Project Settings > Quality で、プラットフォームのチェックボックスがオンになっているすべてのレベルの Render Pipeline Asset を確認します。
  2. ビルドプロファイルを使っている場合は、プロファイルも確認します。プロファイルは、そのプラットフォームのグラフィックス設定をオーバーライドできます。
  3. Project Settings > Player > Other Settings (プロジェクト設定 > プレイヤー > その他の設定) で Strict shader variant matching (厳密なシェーダーバリアント整合) をオンにし、もう一度ビルドします。足りないシェーダーバリアントはエラーシェーダーで描画され、ログに名前が表示されます。

ユニバーサルレンダラーでの 2D ライティング

Sun Forge 2D Lighting は、2D レンダラーとユニバーサルレンダラーのどちらでも動作する、別のライティングパッケージです。シーンのライティングは 1 つのメニュー項目と Fix All でセットアップでき、Unity の Light 2D で Sun Forge の Light Source を制御できます。
