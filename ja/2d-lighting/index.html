すべての機能 2D ライティング

Unity URP 向けのリアルタイム 2D ライティング

Sun Forge 2D Lighting は、2D や 2.5D のシーンを 3D のように照らします。昼から夜までの太陽、月、空に加えて、ライト、キャストシャドウ、4 つのスタイルを備えています。ベイクしたスプライトも、描いたスプライトも照らします。

星をドラッグして広間のライティングを外し、テクスチャを選んで、ライティングが読み取るものを確認してください。

ディフューズゲーム内

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

太陽と空

リアルタイムの太陽で昼から夜まで

太陽、月、空が昼も夜もシーンを照らします。時間帯を手動、スクリプト、アニメーションのいずれかで変えると、何も再ベイクせずにスプライトが照らし直されます。

夜には、月明かりに照らされた表面は青くなり、火の光と発光は色を保ちます。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

ライト

火のようにちらつく動的な 2D ライト

Light Source は、ポイント、スポット、ライン、矩形のいずれかにでき、火のようにちらつかせることもできます。シーンビューでは、ハンドルで各ライトの高さ、届く範囲、スポットの角度を設定します。

Unity の Light 2D で Light Source を制御でき、その Light 2D は Unity の Lit マテリアルも引き続き照らします。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

影

ほかのスプライトにも落ちる 2D の影

影はスプライトと一緒に動き、地面とほかのスプライトに落ち、日が沈むにつれて薄れます。キャストシャドウの中に立っているスプライトには、影を落とすものと同じ高さまで影がかかります。星をドラッグして比較してください。

影の向きは、ベイクしたとき、または描いたときの太陽の方向で決まり、太陽が動いても変わりません。

天候

地面を這う霧と雲の影

空とともに、流れる雲の影と地面を這う霧が加わります。ベイクしたスプライトはそれぞれ高さを保持しているため、霧は各スプライトを足元から覆います。どの Light Source も霧を照らします。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

スタイル

出発点になる 4 つのライティングスタイル

Regular、Cinematic、Flat、Realistic は同じスプライトを照らし、スタイルは再生モード中でもリアルタイムに切り替わります。スタイルを調整して、自作のスタイルとして保存できます。

各スタイルには独自の設定があります。たとえば、Regular と Cinematic のピクセルアウトライン、Cinematic の絵画のような光、Flat の日没に金色に変わる色です。Flat はアウトラインとくぼみの線を描画します。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

描いたスプライト

ドット絵も含む描いたスプライトのライティング

スプライトを選択して右クリックし、Sun Forge > Set Up for Lighting を選んでください。自作の法線マップがあれば立体感が出ます。ない場合、スプライトは平らな表面として照らされます。発光させる色と金属のように光らせる色を選ぶと、Sun Forge がそのエミッションテクスチャと金属テクスチャを書き出します。

Sun Forge 2D Lighting

ライティングの詳細

URP の 2D レンダラーとユニバーサルレンダラー

ライティングはどちらでも動作し、マテリアルのシェーダーに手を加える必要はありません。

1 つのメニュー項目でセットアップ

シーンのライティングは、1 つのメニュー項目と Fix All でセットアップできます。

エディターでもプレイヤーでもリアルタイム

ライティングは編集モード、再生モード、プレイヤーでリアルタイムに描画されるため、スクリプトやアニメーションで太陽やライトを変えると、スプライトが照らし直されます。

金属、滑らかさ、アンビエントオクルージョン

ライティングは、各スプライトの法線テクスチャ、マスクテクスチャ、ジオメトリテクスチャを読み取ります。マスクは、赤に金属、緑に滑らかさ、青にアンビエントオクルージョンを保持します。

プラットフォーム

Sun Forge は、URP が対応するすべてのプラットフォーム向けに作られています。プレイヤーは、Direct3D 12 の Windows、Vulkan と OpenGL ES 3 の Android (ARM64)、WebGL 2、Unity 6.6 での WebGPU で動作します。

スプライトベイカーなしで

どちらのツールも単独で使えます。ライティングは、スプライトを正面から映すカメラで見た 2D や 2.5D のシーンであれば、見下ろし、アイソメトリック、サイドビューのどれでも、描いたスプライトを照らします。

ライティングが照らすスプライトをベイク

1 回の購入に、Sun Forge 2D Lighting と、ライティングが読み取るテクスチャを書き出すスプライトベイカーが含まれます。すべての機能を確認するか、ライティングのガイドを読んでください。

Unity Asset Store で近日公開

Sun Forge には、Unity 6.3 LTS (6000.3.28f1 以降) または Unity 6.6、2D レンダラーまたはユニバーサルレンダラーを使う URP、リニア色空間が必要です。
