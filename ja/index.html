ゲームの中で

ここにあるキャラクターと小道具はすべて 2D スプライト

どれも 3D モデルからベイクした平らなスプライトです。太陽と火がリアルタイムで照らしています。

Sun Forge は、Unity 6 と URP 向けの 3D から 2D へのスプライトベイカーと、リアルタイムの 2D ライティングです。2 つを組み合わせても、どちらか一方だけでも使えます。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

スプライトベイカー

3D モデルを 2D キャラクターにベイク

方向とアニメーションを選んでください。Sun Forge がすべてのフレームをスプライトとしてレンダリングし、それらを再生するプレハブを作成します。

方向

モデルを回すには、スプライトにポインターを合わせるかタップするか、スライダーをドラッグしてください。モデルが向いている方向のスプライトが一緒に再生されます。

The Forgotten Knight は dark_igorek の作品で、CC BY 4.0 のもとで改変しています。

2D ライティング

3D モデルのように光を受けるスプライト

金属は輝き、くぼみは暗くなり、ベイクしたスプライト同士にキャストシャドウが落ちます。ライティングに使うテクスチャはベイクで書き出されるので、手で描く必要はありません。星をドラッグして広間のライティングを外し、テクスチャを選んでそれぞれを確認してください。

手描きのスプライト向け

手持ちのスプライトもライティング

ドット絵も含め、スプライトに Set Up for Lighting コマンドを実行してください。用意した法線マップで立体感が出ます。どの色を金属にし、どの色を発光させるかを選ぶと、Sun Forge が金属テクスチャとエミッションテクスチャを書き出します。

プラットフォーマー向け

プラットフォーマー向けに横からベイク

Elevation Angle を 0 にすると、モデルはサイドビューのスプライトとしてベイクされます。太陽を動かし、ライトを配置し、スタイルを調整して、ステージを照らしてください。

ドット絵にするには、Pixels Per Unit を低くし、ポイントフィルタリングでベイクしてください。

キャラクター、植物、宝箱、たいまつのパーツはショーケースサンプルのものです。

アイソメトリックゲーム向け

アイソメトリックゲーム向けのベイク

Elevation Angle を 30 度のままにすると、正方形の地面が 2:1 のひし形で描画されます。ブロックを段ごとに積み重ねるか、ベイクしたタイルの Tilemap に 1 段分をペイントしてください。

キャラクター、小道具、植物はショーケースサンプルのものです。

ライティングスタイルを選ぶとすべてのスプライトに反映

Regular、Cinematic、Flat のどれでも、再ベイクせずに同じスプライトを照らします。いずれかを自作のスタイルとして保存し、調整してください。

The Forgotten Knight は dark_igorek、骸骨は LasquetiSpice の作品で、CC BY 4.0 のもとで改変しています。

質問

購入の前に

ライトを動かしたら再ベイクが必要ですか?

いいえ。太陽、ライト、スタイルはリアルタイムで変更できます。影はスプライトと一緒に動き、ベイクしたときの方向を保ちます。

スプライトは Sun Forge でしか使えませんか?

いいえ。ベイクで書き出されるのは、Unity 標準のスプライト、アトラス、アニメーションクリップ、アニメーターコントローラー、プレハブです。

3D モデルはゲームに含まれますか?

いいえ。3D モデル、メッシュ、リグはビルドに含まれません。

3D ゲームにも使えますか?

カメラの角度が 1 つに固定された 3D ゲームなら、モデルをスプライトにベイクして 2D で作れます。

自分で描いたスプライトも照らせますか?

はい。スプライトを選択して右クリックし、Sun Forge > Set Up for Lighting を選択してください。自作の法線マップを使うと立体感が出ます。

どのプラットフォームで動作しますか?

URP が対応するすべてのプラットフォーム向けに作られています。ゲームのビルドは、Direct3D 12 の Windows、Vulkan または OpenGL ES 3 の ARM64 Android、WebGL 2 のウェブで動作します。Unity 6.6 では、ウェブビルドは WebGPU でも動作します。

質問

その他の質問

スプライトベイカーを使わずに 2D ライティングだけを使えますか?

はい。どちらも単独で使えます。ライティングは、どんな 2D や 2.5D のシーンでも手で描いたスプライトを照らします。また、ベイクでは Unity のデフォルトのスプライトマテリアル用に、ライティング用のテクスチャを持たないスプライトも書き出せます。

Unity の Light 2D と一緒に使えますか?

はい。Light 2D で Sun Forge の Light Source を制御でき、その Light 2D は Unity の Lit マテリアルも引き続き照らします。

ベイクにはどのくらい時間がかかりますか?

RTX 4060 を搭載した Ryzen 9 7900X では、16 方向の木のベイクが約 25 秒、アニメーション 4 つのキャラクター (968 枚のスプライト) が約 1 分です。

ベイクしたスプライトはテクスチャメモリをどのくらい使いますか?

デスクトップでは、ショーケースの 16 方向のブナの木が 9.5 MiB、騎士の 968 枚のスプライトが 81 MiB です。方向を減らす、解像度を下げる、ライティング用のテクスチャを減らすと、さらに少なくなります。

何をベイクできますか?

アニメーションクリップと Particle System を含むモデルやプレハブを、そのマテリアルと Shader Graph のままベイクできます。小道具、パーティクルエフェクト、地面タイルもベイクできます。

コードからベイクしたり、Addressables を使ったりできますか?

はい。エディタースクリプトからベイクでき、自作の C# の処理でベイクを拡張できます。ベイクには、書き出したプレハブとアトラスを Addressables に登録する機能もあります。
