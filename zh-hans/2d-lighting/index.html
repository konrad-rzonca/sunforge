全部功能 2D 光照

实时 2D 光照，适用于 Unity URP

Sun Forge 2D Lighting 像 3D 一样照亮 2D 或 2.5D 场景，提供从白天到夜晚的太阳、月光和天空，以及光源、投射阴影和四种风格。烘焙出的精灵和自己绘制的精灵都能照亮。

拖拽星星可移去石厅的光照，选择纹理即可查看光照读取的内容。

实时太阳，贯穿昼夜

太阳、月光和天空在白天和夜晚照亮场景。可以手动、用脚本或用动画改变一天中的时间，精灵会随之重新受光，无需重新烘焙。

夜晚，月光照到的表面会变蓝，而火光和发光保持原有的颜色。

dark_igorek 的 The Forgotten Knight 和 LasquetiSpice 的骷髅模型，CC BY 4.0，有修改。

动态 2D 光源，像火一样闪烁

Light Source 可以是点光源、聚光灯、线光源或矩形光源，还能像火一样闪烁。在 Scene 视图中，可以用手柄设置每个光源的高度、照射范围和聚光角度。

Unity 的 Light 2D 可以驱动 Light Source，同时仍会照亮 Sun Forge 的 Unity Lights 材质。

dark_igorek 的 The Forgotten Knight 和 LasquetiSpice 的骷髅模型，CC BY 4.0，有修改。

2D 阴影，投射在其他精灵上

阴影随精灵移动，落在地面和其他精灵上，并随日落逐渐变淡。投射阴影会沿站在其中的精灵向上爬，最高与投射阴影的物体同高。拖拽星星即可对比。

阴影朝烘焙或绘制时所用的太阳方向投射，不会随太阳移动而转动。

地面薄雾与云阴影

天空会带来飘移的云阴影和地面薄雾。薄雾从脚底向上覆盖每个精灵，因为每个烘焙出的精灵都存储了自身的高度。每个 Light Source 也会照亮薄雾。

dark_igorek 的 The Forgotten Knight 和 LasquetiSpice 的骷髅模型，CC BY 4.0，有修改。

以四种光照风格为起点

Regular、Cinematic、Flat 和 Realistic 照亮同一批精灵，风格可以实时切换，在播放模式下也可以。可以调整风格，并另存为自己的风格。

每种风格都有自己的设置，例如 Regular 和 Cinematic 的像素描边、Cinematic 的手绘感光照，以及 Flat 在日落时变成金色的颜色。Flat 会绘制描边和折痕线。

dark_igorek 的 The Forgotten Knight 和 LasquetiSpice 的骷髅模型，CC BY 4.0，有修改。

为自己绘制的精灵打光，像素画也可以

选择精灵，右键单击并选择 Sun Forge > Set Up for Lighting。自己的法线贴图能让精灵有立体感；没有法线贴图时，精灵按平坦的表面受光。选择会发光的颜色和像金属一样反光的颜色后，Sun Forge 会写入相应的发光纹理和金属纹理。

关于光照的更多内容

URP 的 2D Renderer 与 Universal Renderer

光照在两者下都能工作，其材质无需编写着色器。

一个菜单项即可设置

用一个菜单项和 Fix All 即可设置场景的光照。

在编辑器和 Player 中实时生效

光照在编辑模式、播放模式和 Player 中实时绘制，因此脚本或动画改变太阳或光源时，精灵会随之重新受光。

金属、平滑度和环境光遮蔽

光照读取每个精灵的法线纹理、遮罩纹理和几何信息纹理。遮罩用红色通道表示金属，绿色通道表示平滑度，蓝色通道表示环境光遮蔽。

平台

Sun Forge 为 URP 支持的所有平台而构建。Player 可在以下平台运行：Windows（Direct3D 12）、使用 Vulkan 和 OpenGL ES 3 的 Android（ARM64）、WebGL 2，以及使用 Unity 6.6 时的 WebGPU。

不用精灵烘焙工具

两个工具都能单独使用。光照可以照亮任意 2D 或 2.5D 场景中自己绘制的精灵，无论是俯视、等距还是侧视，摄像机正对精灵即可。

烘焙供光照使用的精灵

一次购买即包含 Sun Forge 2D Lighting 和精灵烘焙工具，后者会写入光照读取的纹理。请查看全部功能，或阅读光照指南。

即将上架 Unity Asset Store

Sun Forge 需要 Unity 6.3 LTS（6000.3.29f1 或更高版本）至 Unity 6.6，以及通用渲染管线（URP）的 2D Renderer 或 Universal Renderer。
