Unity 2D 光照不生效：排查要点

Unity 的 2D 光源属于通用渲染管线（URP），只在其 2D Renderer 下工作。光源没有任何效果时，请按顺序检查下面的设置。菜单名称以 Unity 6.3 为准。

Unity 2D 光源在菜单中呈灰色

现象：GameObject > Light（游戏对象 > 灯光）下的 2D 光源无法单击，或者 Light 2D 的 Inspector 窗口只显示“2D renderer data must be assigned to your universal render pipeline asset or camera.”

原因：项目没有 URP 资产，运行的是内置渲染管线；或者项目 URP 资产的默认渲染器是 Universal Renderer。

  1. 在 Project 窗口中，选择 Create > Rendering > URP Asset (with 2D Renderer)（创建 > 渲染 > URP 配置文件（带 2D 渲染器））。Unity 会创建 URP 资产和 2D Renderer 资产。
  2. 打开 Edit > Project Settings > Graphics（编辑 > 项目设置 > 图形），将 Default Render Pipeline 设为新的 URP 资产。

如果要保留现有的 URP 资产，请用 Create > Rendering > URP 2D Renderer（创建 > 渲染 > URP 2D 渲染器）创建渲染器，将其添加到该资产的 Renderer List（渲染器列表），然后为其选择 Set Default（设置默认值）。

质量级别指定了另一个 URP 资产

现象：Graphics 设置正确，但光源仍然处于禁用状态或没有任何效果。

原因：每个质量级别都有 Render Pipeline Asset（渲染管线资产）字段。设置了该字段时，Unity 在该级别使用这个资产，而不是 Graphics 设置中的资产。

  1. 打开 Edit > Project Settings > Quality（编辑 > 项目设置 > 质量）。
  2. 依次选择每个级别，查看 Render Pipeline Asset。
  3. 清空该字段，或将其设为使用 2D Renderer 的 URP 资产。

Unity 2D 光源对精灵不生效

现象：无论光源如何变化，部分精灵始终保持完全亮度，这些精灵往往是项目迁移到 URP 之前制作的。

原因：2D 光源只作用于为其制作的材质，Sprite-Lit-Default 就是其中之一。内置渲染管线的材质（例如 Sprites-Default）以及 Sprite-Unlit-Default 不会有反应。

  1. 选择精灵。
  2. 在精灵的 Sprite Renderer 中，将 Material（材质）设为 Sprite-Lit-Default。

要转换整个项目，请先备份项目，然后打开 Window > Rendering > Render Pipeline Converter（窗口 > 渲染 > Render Pipeline Converter），选择 2D Converters > Built-in to 2D URP Material Upgrader，并运行 Material and Material Reference Upgrade。要编写自己的着色器，请从 Create > Shader Graph > URP > Sprite Lit Shader Graph（创建 > Shader Graph > URP > 精灵光照 Shader Graph）开始。

光源的 Target Sorting Layers 未包含该精灵

现象：光源能照到其覆盖范围内的部分精灵，却照不到另一些。

原因：Light 2D 只照亮其 Target Sorting Layers（目标排序层）中的排序图层。新建的光源以所有排序图层为目标。添加排序图层时未打开的场景或预制件中的光源，不会包含新图层。

  1. 选择精灵，查看其 Sprite Renderer 上的 Sorting Layer（排序图层）。
  2. 选择光源，将该图层添加到 Target Sorting Layers。

光源的 Z 位置无关紧要：2D 光源能照亮位于光源前方或后方任意距离处的精灵。

光照范围以外全是黑色

现象：添加光源之前，场景看起来正常；添加之后，只显示该光源照到的区域。

原因：场景中没有 Light 2D 时，Unity 以精灵自身的颜色绘制精灵。从第一个光源起，精灵只显示照到其上的光。Global Light 2D 会均匀照亮其目标图层上的每个精灵。

  1. 选择 GameObject > Light > Global Light 2D（游戏对象 > 灯光 > 全局光源 2D）。
  2. 设置其 Color（颜色）和 Intensity（强度），使场景在其他所有光源都照不到的地方呈现应有的样子。

Unity 在每种混合样式和每个排序图层上只允许一个全局光源。有两个时，Console 窗口会显示“More than one global light on layer”。请删除其中一个，或为每个光源设置各自的 Target Sorting Layers（目标排序层）。

Unity Light 2D 不显示：混合样式与强度

现象：以上各项都正确，但光源仍然没有任何效果。

原因：重叠的光会叠加。在 Multiply 混合样式下，总和为 1 时精灵显示自身的颜色，超过 1 时会比自身的颜色更亮。强度为 1 的白色全局光源会让其他光源几乎显示不出效果。

  1. 降低全局光源的 Intensity（强度），例如降到 0.3。
  2. 检查另一个光源的 Blend Style（混合样式）。Multiply with Mask (R) 和 Additive with Mask (R) 只在精灵遮罩贴图的红色通道大于 0 的地方照亮精灵。

Unity 2D 法线贴图不生效

现象：精灵受到光照，但其法线贴图没有任何作用。请按顺序检查以下各项，完整步骤参见 Unity 中的精灵法线贴图：

  1. 光源。在 Normal Maps（法线贴图）下，将 Quality（质量）设为 Fast（快速）或 Accurate。新建光源默认为 Disabled（已禁用）。Global Light 2D 没有此设置，因此需添加聚光、自由形式或精灵光源。
  2. 名称。选择精灵的纹理，单击 Open Sprite Editor（打开 Sprite 编辑器），切换到 Secondary Textures（辅助纹理），确认法线贴图列出的名称为 _NormalMap。
  3. 导入。选择法线贴图，将 Texture Type（纹理类型）设为 Normal map（法线贴图）。
  4. 布局。Unity 用精灵纹理的 UV 坐标读取法线贴图，因此每一帧在两张纹理中的位置必须相同。
  5. 材质。Sprite-Lit-Default 会读取法线贴图。在自己的 Shader Graph 中，将法线贴图连接到 Normal (Tangent Space)。
  6. 距离。降低 Normal Maps 下的 Distance（距离）。光源会表现得像离得更近，从更低、更贴近表面的角度照亮细节。
  7. 图集。选择精灵图集，用其预览右上角的下拉菜单显示打包后的辅助纹理。打包在一起的精灵应具有相同数量的辅助纹理。

光源在 Game 视图中显示，在 Scene 视图中不显示

Scene 视图有自己的光照开关，即其工具栏中的灯泡按钮。开关关闭时，Scene 视图绘制精灵时不带 2D 光源。请打开该开关。Game 视图和构建不使用这个开关。

Unity Light 2D 在构建中不显示

现象：光源在编辑器中正常工作，在 Player 中却不起作用。

原因：编辑器使用 Project Settings > Quality（项目设置 > 质量）中高亮的质量级别。构建从其平台的默认级别开始，即该平台一列中带绿色勾选的复选框，这个级别可能指定了另一个 URP 资产。构建也只包含 Graphics 设置中的 URP 资产，以及该平台启用的各级别的 URP 资产。如果这些资产都没有 2D Renderer，Unity 会从构建的着色器中剥离 2D 光照通道。

  1. 在 Project Settings > Quality 中，检查目标平台已勾选的每个级别的 Render Pipeline Asset（渲染管线资产）。
  2. 如果使用了构建配置文件，检查该配置文件：配置文件可以为其平台覆盖 Graphics 设置。
  3. 启用 Project Settings > Player > Other Settings（项目设置 > 玩家 > 其他设置）下的 Strict shader variant matching，然后重新构建。这样，缺失的着色器变体会以错误着色器绘制，并在日志中列出名称。

Universal Renderer 下的 2D 光照

Sun Forge 2D Lighting 是一个独立的光照包，在 2D Renderer 和 Universal Renderer 下都能工作。用一个菜单项和 Fix All 即可设置场景的光照，而且 Unity 的 Light 2D 可以驱动 Sun Forge 的 Light Source。
