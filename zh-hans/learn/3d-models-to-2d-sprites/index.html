学习

在 Unity 中把 3D 模型转为 2D 精灵

用 3D 模型制作的 2D 精灵，就是用固定摄像机渲染出的模型画面，以透明背景保存。带动画的角色由许多这样的画面组成：每个方向、每个动画的每一帧各一张。做法是渲染帧，切分成精灵，制作动画剪辑，再打包纹理。

如何在 Blender 中用 3D 模型制作 2D 精灵

  1. 将摄像机类型设为 Orthographic（正交），这样模型在任何距离下大小都不变。Orthographic Scale（正交比例）决定模型在画面中的大小。
  2. 在渲染设置的 Film（胶片）下，启用 Transparent（透明）。
  3. 将输出的颜色设为 RGBA，并选用 PNG 等格式，以保留 Alpha 通道。
  4. 将动画渲染为序列帧。要渲染另一个方向，转动模型或摄像机后再渲染一次。

可以直接导入这些 PNG 文件，每个文件一个精灵，也可以先把它们拼成精灵表。

在 Unity 中把 3D 模型渲染成精灵序列帧

  1. 添加摄像机，将 Projection（投影）设为 Orthographic（正交）。摄像机的 Size（大小）是视图高度的一半，以世界单位计。
  2. 将 Background Type（背景类型）设为 Solid Color（纯色），并将 Background（背景）颜色的 Alpha 设为 0。
  3. 通过 Assets > Create > Rendering > Render Texture（资产 > 创建 > 渲染 > 渲染器纹理）创建颜色格式带 Alpha 通道的渲染纹理，并指定给摄像机的 Output Texture（输出纹理）。
  4. 在 URP 中，禁用摄像机上的 Post Processing（后处理效果），或在 URP 资产中启用 Alpha Processing。否则后处理会把 Alpha 替换为 1。
  5. 对每一帧，用 clip.SampleAnimation(model, time) 摆好模型的姿势，然后在编辑器脚本中保存画面：
static void SaveFrame(Camera camera, RenderTexture target, string path)
{
    camera.targetTexture = target;
    camera.Render();

    RenderTexture previous = RenderTexture.active;
    RenderTexture.active = target;
    var frame = new Texture2D(target.width, target.height, TextureFormat.RGBA32, false);
    frame.ReadPixels(new Rect(0, 0, target.width, target.height), 0, 0);
    frame.Apply();
    RenderTexture.active = previous;

    System.IO.File.WriteAllBytes(path, ImageConversion.EncodeToPNG(frame));
    Object.DestroyImmediate(frame);
}

渲染纹理和 Texture2D 的格式必须相同。在使用线性颜色空间的项目中，请选择以 _SRGB 结尾的渲染纹理格式，否则保存的颜色会偏暗。

在 Sprite Editor 中切分精灵表

  1. 确认已安装 2D Sprite 包。
  2. 选择图像，将 Texture Type（纹理类型）设为 Sprite (2D and UI)（Sprite（2D 和 UI）），将 Sprite Mode（Sprite 模式）设为 Multiple（多个），然后单击 Apply（应用）。
  3. 打开 Sprite Editor 窗口及其 Slice（切片）菜单。帧大小相同时选择 Grid By Cell Size，已知行数和列数时选择 Grid By Cell Count。
  4. 设置 Pivot（轴心），单击 Slice，然后单击 Apply。

用帧制作动画剪辑和动画器控制器

  1. 将第一个精灵拖拽到场景中，这会创建一个带 Sprite Renderer 的游戏对象。
  2. 选择该游戏对象，在 Animation 窗口中单击 Create（创建）并保存动画剪辑。Unity 会创建动画器控制器，以该剪辑为默认状态，并为游戏对象添加 Animator。
  3. 为 Sprite Renderer 的 Sprite 属性设置关键帧，每帧一个精灵。
  4. 每增加一个动画，就在 Animation 窗口的剪辑菜单中选择 Create New Clip（创建新剪辑），然后在动画器控制器中添加剪辑之间的过渡。

剪辑较多时，可以用脚本完成这一步：Unity 的 AnimationClip 参考文档中有一个示例，用 Project 窗口中选中的精灵构建剪辑。

陷阱

每单位像素数

每单位像素数是精灵图像中覆盖世界空间一个单位的像素数。选定导入时要用的值，并把渲染纹理的高度设为 2 × Size × 每单位像素数（以像素计）：Size 为 1.5、每单位像素数为 64 时为 192 像素。这样，精灵在 2D 场景中就与模型一样高。所有精灵都使用同一个值，否则有的精灵会比其他精灵更清晰。

轴心与取景

轴心是图像上的一个点，精灵的局部坐标从这里开始。角色的轴心应放在脚底，并且每一帧都落在同一个像素上。为此，所有动画的每一帧都要从同一个摄像机位置、以同一个 Size 和同一分辨率渲染，画面要宽到容得下最宽的姿势。然后按网格切分，为所有帧设置同一个轴心。Automatic（自动）切分按透明像素切割，每帧会得到各自的矩形，像 Bottom（底部）这样的轴心在每帧中落在角色的不同部位，角色就会抖动。

预乘 Alpha 与边缘光晕

透明几何体混合到渲染纹理中时，纹理存储的每个颜色都已乘过自身的 Alpha。使用传统透明混合（Blend SrcAlpha OneMinusSrcAlpha）的材质会再乘一次 Alpha，半透明像素就会变暗。保存 PNG 前，请将颜色除以 Alpha，或者使用按预乘颜色混合的着色器（Blend One OneMinusSrcAlpha）。

纹理过滤会把每个边缘像素与旁边的透明像素混合。请在纹理的导入设置中启用 Alpha Is Transparency（Alpha 是透明的）：Unity 会扩充颜色通道，从而避免边缘出现过滤瑕疵。

纹理尺寸与图集打包

八个方向、三个动画、每个动画 16 帧、每帧 256 × 256 像素，共 384 帧，约 2500 万像素，未压缩时为 96 MiB。每单位像素数减半，占用就只有其四分之一。

导入时，Unity 会把大于 Max Size（最大尺寸）的纹理缩小到该尺寸，因此大型精灵表要调高 Max Size，或按动画拆分。然后通过 Assets > Create > 2D > Sprite Atlas（资产 > 创建 > 2D > Sprite 图集）把精灵打包进精灵图集。精灵图集把多张纹理合并为一张，Unity 因此能在一次绘制调用中绘制其中所有精灵。

光照烘焙进颜色，还是用法线贴图

渲染中的光会成为精灵颜色的一部分：从左侧受光的骑士，即使右侧有一支火把，也仍然是左侧受光。要让光在游戏中变化，请在均匀的光下渲染颜色，并用同一摄像机为相同的帧渲染一张法线贴图。在 Sprite Editor 窗口中把法线贴图添加为名为 _NormalMap 的辅助纹理，使用 Sprite-Lit-Default 等材质，并在 2D 光源的 Normal Maps（法线贴图）下，将 Quality（质量）设为 Fast（快速）或 Accurate。法线贴图必须与精灵纹理对齐，因为 Unity 用相同的 UV 坐标对两者采样。Unity 中的精灵法线贴图介绍了具体步骤和陷阱。

Unity 中的 3D 模型转 2D 精灵工具：Sun Forge

Sun Forge 就是本网站介绍的精灵烘焙工具。Sun Forge 在 Unity 编辑器中烘焙，可以从烘焙窗口烘焙，也可以用编辑器代码烘焙。烘焙接收模型或预制件及其动画剪辑和 Particle System，并沿用其自身的材质，Shader Graph 材质也包括在内。

烘焙会写出一个 2D 精灵预制件：每个方向一张精灵表，还有带动画器控制器的动画、光照纹理、阴影、碰撞器和玩法组件。

  • 摄像机。 烘焙摄像机可以从 0 到 90 度之间的任意角度观察：侧视、垂直俯视以及两者之间的所有角度，包括等距视角。一次烘焙可写出 1 到 64 个方向，游戏需要多少个方向另有专文介绍。
  • 分辨率与内存。 新建烘焙的每单位像素数为 96。每次烘焙后，Bake 选项卡会显示其输出占用的纹理内存。
  • 光照。 每张精灵表除颜色外，还有法线纹理、遮罩纹理和几何信息纹理，Sun Forge 2D Lighting 会读取这些纹理，因此太阳和光源的变化会实时呈现。烘焙只写出开关已启用的纹理，也可以为预制件指定 Unity 的默认精灵材质。

Sun Forge 需要 Unity 6.3 LTS（6000.3.28f1 或更高版本）或 Unity 6.6，以及使用 2D Renderer 或 Universal Renderer 的 URP。在内置渲染管线或 HDRP 上，请使用上文的步骤。精灵烘焙工具页面展示了烘焙的每个部分。
