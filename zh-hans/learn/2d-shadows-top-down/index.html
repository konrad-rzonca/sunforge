Unity 中 2D 与俯视角精灵的阴影

在 Unity 中，2D 精灵的阴影有四种做法：URP 的 Shadow Caster 2D、脚底的斑点阴影精灵、精灵的倾斜深色副本，或者从精灵所来自的 3D 模型渲染出的阴影。选择之前，先确定阴影落在哪里：是在屏幕平面内，还是在角色站立的地面上。

两类 2D 阴影

侧视的平台跳跃游戏是一个平面世界，从正上方看的地牢也是。墙会挡住火把的光，墙后的东西就处于黑暗中。

在俯视或 2.5D 世界中，摄像机以一定角度向下看，角色直立在地面上。这里的阴影落在角色脚底的地面上，指向背离太阳的方向。

Shadow Caster 2D 产生第一类阴影，其他三种方法产生第二类。

Unity 的 Shadow Caster 2D 与 Light 2D

Shadow Caster 2D 是 URP 的组件，用于设置 2D 光源投射阴影时使用的形状。项目需要使用带 2D Renderer 的 URP，精灵需要使用 2D 光源能照亮的材质，例如默认的 Sprite-Lit-Default。

  1. 在 Hierarchy 窗口中右键单击，选择 Light（灯光），然后选择 Spot（聚光）、Freeform（自由形式）或 Sprite（精灵）光源。
  2. 在 Light 2D 上启用 Shadows（阴影）。Strength（强度）设置投射器遮挡多少光，从 0 到 1；Softness（柔和度）柔化阴影的边缘。
  3. 选择要投射阴影的精灵，单击 Add Component（添加组件），然后添加 Shadow Caster 2D。其形状是 Sprite Editor 中精灵的 Custom Outline，Scene 视图用白色绘制这一形状。
  4. 要使用其他形状，将 Casting Source（投射光源）设为同一游戏对象上的碰撞器（例如 Polygon Collider 2D），或设为 Shape Editor 并单击 Edit Shape。
  5. 要合并多个精灵的阴影，将这些精灵设为某个游戏对象的子对象，该游戏对象带有 Composite Shadow Caster 2D。

Casting Option（投射选项）设置投射器的阴影落在其他精灵上、自身上还是两者上；Target Sorting Layers（目标排序层）设置阴影落在哪些排序图层上。

这种方法不能让俯视角色在地面上得到阴影：

  • 投射器是遮挡光线的轮廓，没有设置精灵高度或阴影长度的选项。
  • 全局光源（像日光一样均匀照亮每个精灵的类型）没有 Shadows 设置。其他类型从光源所在位置投射，因此阴影落在投射器背向光源的一侧。

Unity 为其俯视角示例项目 Happy Harvest 编写的指南指出，这类阴影会无限延伸，用作一般日光阴影时看起来不对。该示例只在灯和火附近投射这类阴影，投射器位于角色脚底。示例中的树木和灌木使用斑点阴影。

2D 精灵下方的斑点阴影

斑点阴影是一个柔和的深色椭圆，由子对象上的精灵绘制在角色脚底。斑点阴影适用于任何精灵和任何动画，代价是多绘制一个精灵。它能显示角色与地面接触的位置，但既不显示角色的形状，也不显示太阳的方向。将 Sprite Renderer 的 Color（颜色）设为带一定透明度的黑色，这样一张纹理就能用于任何地面。

以倾斜副本充当精灵的投射阴影

要得到角色形状的阴影，就把角色的精灵再绘制一次：染成黑色、半透明、压扁，并倾斜到平躺在地面上。

  • 副本是子对象上的第二个 Sprite Renderer，子对象的轴心位于脚底。角色有动画时，由脚本在每一帧的 LateUpdate 中把主体当前的精灵和翻转状态复制给副本，Unity 会在每次 Update 之后调用该方法。
  • Transform 没有倾斜设置。在非均匀缩放的父对象下旋转子对象，子对象会显得倾斜，从而得到倾斜效果。另一种方法是用阴影着色器，按每个顶点在轴心之上的高度将其横向移动。

副本显示的是摄像机看到的角色，而不是太阳“看到”的角色。太阳方向与摄像机方向相差越大，轮廓就越不吻合。

从 3D 模型渲染的阴影

如果精灵是 3D 模型的渲染图，阴影也从模型渲染。在 Blender 的 Cycles 中，物体的 Shadow Catcher 选项（Object Properties > Visibility）可让地面平面只接收阴影光线，这样渲染平面时得到的只有阴影。将阴影渲染成单独的精灵表，与主体逐帧对应，并在角色下方用第二个 Sprite Renderer 显示。

这种阴影具有太阳所见的轮廓。这种方法会让精灵表的数量翻倍，阴影方向在渲染时就已固定。如果角色有多个朝向，请在模型转动时让太阳在世界中保持不动，否则每次角色转身时阴影都会跟着甩动。

2D 精灵阴影的陷阱

  • 排序。俯视场景通常按 y 对精灵排序：在 2D Renderer 资产上将 Transparency Sort Mode（透明度排序模式）设为 Custom Axis（自定义轴），轴为 (0, 1, 0)。这样，位于角色排序图层上的阴影会盖住其主人身后那个角色的脚底。为阴影设置单独的排序图层，在 Project Settings > Tags and Layers（项目设置 > 标签和图层）中排在地面的图层之后、角色的图层之前。Unity 按列表顺序绘制图层。
  • 重叠。两片半透明阴影重叠处，地面会变暗两次。解决方法需要自己的阴影着色器：URP 支持 ShaderLab 的 Stencil 命令，用它可让第一片阴影标记自己绘制的每个像素，之后的阴影便跳过这些像素。
  • 方向。场景中的所有阴影都必须指向同一方向，并与绘制或渲染到精灵中的光照一致。用同一个角度驱动所有倾斜副本，在同一个太阳下渲染所有模型。
  • 其他精灵。斑点阴影、副本和渲染出的精灵表只会让地面变暗。角色走进树的阴影后仍然完全受光，因为阴影绘制在所有角色下方，而且两个精灵都不存储高度。Shadow Caster 2D 的阴影会落在其 Target Sorting Layers（目标排序层）中的每个精灵上，地面和其他角色都一样。

Sun Forge 的做法

Sun Forge 是一款 Unity 编辑器工具，采用的是第四种方法。烘焙会把 3D 模型变成 2D 精灵预制件，同时写出精灵的阴影：投射在地面上的柔和阴影，或者一个椭圆。

阴影随精灵移动，并随日落逐渐变淡。阴影保持烘焙时的太阳方向，场景中的太阳移动时不会转动，因此不适合阴影必须随一天时间转动的游戏。

除颜色外，每张烘焙出的精灵表还有一张几何信息纹理，保存每个纹素在精灵轴心之上的高度。有了这个高度，烘焙出的精灵就能相互投射阴影。投射阴影会沿站在其中的精灵向上爬，最高与投射阴影的物体同高。

Sun Forge 需要 Unity 6.3 LTS（6000.3.28f1 或更高版本）或 Unity 6.6，以及通用渲染管线（URP）的 2D Renderer 或 Universal Renderer。光照页面展示了同一场景关闭和开启投射阴影时的样子。
