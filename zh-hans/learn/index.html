Unity 2D 精灵与光照教程

每篇教程用 Unity 自带的工具回答一个问题，指出容易踩的坑，最后介绍 Sun Forge 的做法。

  • 在 Unity 中把 3D 模型转为 2D 精灵

    在 Blender 或 Unity 中渲染帧，切分成精灵，制作动画剪辑并打包纹理。

  • Unity 八方向精灵：4、8 还是 16 个方向？

    每种方向数量的代价、每种视角背后的摄像机角度，以及选择精灵的代码。

  • 用 Unity 法线贴图让 2D 精灵有立体感

    为精灵添加法线贴图和遮罩、从哪里获取，以及单靠它们做不到什么。

  • Unity 中 2D 与俯视角精灵的阴影

    Shadow Caster 2D、斑点阴影、倾斜副本或 3D 模型的渲染，以及各自适合哪类游戏世界。

  • Unity 2D 昼夜循环与云阴影

    随 Gradient 变色的 Global Light 2D、用于夜晚的 Volume、逐渐亮起的灯，以及在地面投下阴影的云。

  • Unity 2D 场景中的雾效与地面薄雾

    Unity 的雾为何对精灵无效，以及用精灵、粒子或全屏通道制作雾的四种方法。

  • Unity 2D 光照不生效：排查要点

    Light 2D 呈灰色不可用、照不亮任何精灵、忽略法线贴图或在构建中消失。
