Unity 2D 场景中的雾效与地面薄雾

Unity 的雾设置作用不到精灵，因此在 2D URP 场景中，要用精灵、粒子或全屏通道来制作雾。本文讲的是天气中的雾。战争迷雾用来隐藏玩家尚未探索的地图区域，是另一回事，本文不涉及。

为什么 Unity 的雾在 2D 场景中不起作用

雾设置位于 Lighting 窗口中 Environment（环境）选项卡的 Other Settings（其他设置）下，可通过 Window > Rendering > Lighting（窗口 > 渲染 > 光照）打开该窗口。雾有颜色和模式，离摄像机越远越浓。

在由精灵构成的场景中启用雾，什么都不会变。URP 的精灵着色器 Sprite-Lit-Default 和 Sprite-Unlit-Default 不应用雾，Sprite Lit 或 Sprite Unlit Shader Graph 也不应用。即使着色器应用了雾，作用也不大：2D 场景中的精灵与摄像机的距离都差不多，因此雾会给所有精灵染上同等程度的颜色。

Unity 2D 体积雾

Unity 的体积雾属于 HDRP，URP 没有体积雾。在 2D 游戏中，看起来有体积感的其实是分层：几层位于不同深度、以不同速度移动的雾。

制作 2D 雾效的四种方法

滚动的噪声精灵

这种方法适合大范围的雾。

  1. 导入一张可无缝平铺的柔和噪声纹理，并将其 Wrap Mode（贴图间拼接模式）设为 Repeat（重复）。
  2. 选择 Assets > Create > Shader Graph > URP > Sprite Unlit Shader Graph（资产 > 创建 > Shader Graph > URP > 精灵无光照 Shader Graph）。
  3. 在 Shader Graph 中，将 Time 节点乘以一个较小的速度，并把结果连接到 Tiling And Offset 节点的 Offset。用该节点的输出采样噪声。
  4. 将采样结果乘以雾的颜色，并让其 Alpha 朝精灵顶部逐渐减弱，使雾的上边缘不生硬。
  5. 用该 Shader Graph 创建材质，并将材质放到覆盖该区域的 Sprite Renderer 上。设置其 Sorting Layer（排序图层）和 Order in Layer（图层顺序），使其绘制在所需的图层之间。

两层以不同速度滚动的雾，看起来就不那么像一张滑动的图片了。

由柔和精灵构成的粒子系统

这种方法适合一小片薄雾，例如池塘上方或门口的薄雾。使用一个 Particle System，发射少量大而慢的粒子，粒子使用低 Alpha 的柔和云纹理。为其指定一个材质，该材质使用 URP 的 Particles Unlit 着色器，且 Surface Type（表面类型）设为 Transparent（透明的）。在 Renderer（渲染器）模块中，Sorting Layer ID 和 Order in Layer（图层顺序）决定粒子在精灵之间的排序。

全屏通道

URP 的 Full Screen Pass Renderer Feature 会在整个屏幕上绘制一个材质。选择渲染器资产，单击 Add Renderer Feature，并为该渲染器功能指定一个用全屏 Shader Graph 制作的材质。其 Injection Point（注入点）决定绘制的时机：Before Rendering Post Processing 会在透明对象之后、后处理之前绘制。

全屏通道会覆盖在其之前绘制的一切，因此无法夹在两个图层之间。为此，2D Renderer 提供了 Camera Sorting Layer Texture（摄像机排序层纹理）：该纹理会保存所选排序图层绘制完毕时的画面，之后图层上的雾着色器可以读取该画面。

让远处图层偏向雾的颜色

这种方法不增加任何绘制。将每个视差图层上 Sprite Renderer 的 Color（颜色）调向雾的颜色，越靠后的图层调得越多。该颜色与精灵原图的颜色相乘，因此只能变暗。要在深色的图上表现浅色的雾，请在着色器中向雾的颜色混合，或重新绘制这些图层。

陷阱

雾从头到脚覆盖角色。 雾层是一张平面。排在角色前面时，整个角色都会蒙上雾；排在后面时，整个角色都清晰可见。地面薄雾应在脚底处浓，在头部淡。在侧视场景中，可以在角色前方放一条向上逐渐淡出的低矮雾带，效果接近。在俯视或等距场景中，角色站在许多不同的深度上，因此一条雾带对其中大多数角色都不对。可以把薄雾切成条带，排在角色之间，代价是图层更多。

排序。 Unity 先按排序图层对精灵排序，再按 Order in Layer（图层顺序）排序，值较小的绘制在值较大的后面，最后按与摄像机的距离排序。请为雾单独指定一个排序图层或顺序值。如果雾与其他精灵的排序图层和顺序都相同，雾在这些精灵之间的位置就取决于该距离。

过度绘制。 每个透明图层都会绘制在其后方的内容之上，因此三个全屏雾层会让每个像素多填充三次。手机的 GPU 最先因此变慢。URP 的 Rendering Debugger 窗口有一个 Overdraw（过度绘制）视图，显示像素在哪里相互叠绘，可通过 Window > Analysis > Rendering Debugger（窗口 > 分析 > 渲染调试器）打开该窗口。请用少量大粒子代替大量小粒子，并使用小尺寸纹理：柔和的噪声在低分辨率下看起来一样。

不受光源影响的雾。 无光照的雾无论光如何都保持原有颜色，因此夜间在火堆旁仍是灰色，在黑暗中仍是浅色。要让 Light 2D 光源照到雾，请将 Shader Graph 创建为 Sprite Lit Shader Graph（精灵光照 Shader Graph），并把雾所在的排序图层加入每个光源的 Target Sorting Layers（目标排序层）。这样光就会像落在平坦的墙上一样落在雾上。

色带。 低 Alpha 的柔和渐变会出现台阶状的色阶。请将雾纹理的 Compression（压缩）设为 None（无）。在摄像机的 Rendering（渲染）下启用 Dithering（抖动），可以减少大面积渐变和暗部的色带。

Sun Forge 2D Lighting 如何制作地面薄雾

Sun Forge 2D Lighting 是适用于 URP 的光照包。薄雾是其天气的一部分，会像其云阴影一样在地面上飘移。薄雾适用于 URP 的 2D Renderer 和 Universal Renderer，用于摄像机正对精灵的俯视或等距场景。在侧视画面中，薄雾不会显示，因为侧视画面中没有可供薄雾落上的地面，所以平台跳跃游戏需要采用上面的某种方法。

这种薄雾不是位于精灵前方或后方的图层。Sun Forge 从 3D 模型烘焙出的每个精灵都带有一张几何信息纹理，记录每个纹素相对精灵轴心的高度。因此薄雾会从脚底开始向上覆盖每个精灵。

每个 Light Source 也会照亮薄雾。

Sun Forge 需要 Unity 6.3 LTS（6000.3.28f1 或更高版本）或 Unity 6.6。
