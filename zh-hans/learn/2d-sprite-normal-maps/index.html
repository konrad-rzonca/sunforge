学习

用 Unity 法线贴图让 2D 精灵有立体感

精灵是一张平面图片，因此光源照在上面时没有形体可依。法线贴图为精灵提供形体：每个像素都记录了该处表面朝向的方向。有了法线贴图，角色左侧的火把会照亮角色的左侧，火把移动时明暗也会随之移动。

Sprite Lit 与 Light 2D：Unity 如何照亮精灵

Unity 的 2D 光源属于通用渲染管线（URP），在项目使用其 2D Renderer 时生效。此时，拖拽到 Scene 视图中的精灵会获得 Sprite-Lit-Default 材质，2D 光源会照亮这种材质。使用 Sprite-Unlit-Default 的精灵则不受 2D 光源影响。

要添加光源，请在 Hierarchy 窗口中右键单击，选择 Light（灯光），然后选择一种 2D 光源：Spot（聚光）、Freeform（自由形式）、Sprite（精灵）或 Global（全局）。全局光源会同等地照亮每个精灵。没有法线贴图时，其他光源照亮精灵的方式就像灯照在剪纸上：光源形状内更亮，画面本身却没有明暗。

精灵法线贴图存储了什么

法线贴图是一张与精灵纹理对齐的纹理。红色记录每个像素的表面向右倾斜的程度，绿色记录向上倾斜的程度，蓝色记录朝向观察者的程度。正对观察者的像素是浅蓝色 #8080FF。

在 Unity 中为精灵添加法线贴图

  1. 导入法线贴图，并在 Inspector 窗口中将其 Texture Type（纹理类型）设为 Normal map（法线贴图）。
  2. 选择精灵的纹理，打开 Sprite Editor（Sprite 编辑器），并从其下拉菜单中选择 Secondary Textures（辅助纹理）。
  3. 单击 +，在 Name（名称）下拉菜单中选择 _NormalMap，指定法线贴图，然后单击 Apply（应用）。
  4. 确认精灵的 Sprite Renderer 使用 Sprite-Lit-Default，或其他会读取法线贴图的材质。
  5. 选择 Light 2D。在 Normal Maps（法线贴图）下，将 Quality（质量）设为 Fast（快速）或 Accurate。

完成第 5 步之前，光源会忽略法线贴图。全局光源没有这项设置，因此场景中需要一个聚光、自由形式或精灵光源才能显示明暗。同一部分中的 Distance（距离）越小，光源离精灵越近，细节就越明显。

自己的着色器可以从 Assets > Create > Shader Graph > URP > Sprite Lit Shader Graph（资产 > 创建 > Shader Graph > URP > 精灵光照 Shader Graph）开始，这种 Shader Graph 有 Normal (Tangent Space) 输入。

遮罩纹理 _MaskTex

精灵还可以有第二张辅助纹理 _MaskTex。导入时将 Texture Type（纹理类型）设为 Default（默认），并禁用 sRGB (Color Texture)（sRGB（颜色纹理））。

遮罩决定光源的光可以落在哪里：Blend Style（混合样式）为 Multiply with Mask (R) 或 Additive with Mask (R) 的光源只照亮遮罩红色通道大于 0 的像素。在 2D Renderer 资产中，每种混合样式都可以改为读取绿色、蓝色或 Alpha 通道。请用遮罩制作边缘光，或只在盔甲上制作高光。

法线贴图从哪里来

  • 手绘。 用法线贴图调色板中的方向颜色在精灵上绘制。Krita 有专门的笔刷。有动画的角色每一帧都需要一张贴图。
  • 从精灵生成。 绘制一张灰度高度贴图，表面越高处越白，然后在导入时将 Texture Type（纹理类型）设为 Normal map（法线贴图），并启用 Create from Grayscale（从“灰度”创建）。只根据画面生成的工具会猜测形体，大多是把轮廓变圆。
  • 从 3D 模型渲染。 如果精灵是 3D 模型的渲染图，就用同一个摄像机渲染模型的法线，这样每一帧都有与之匹配的贴图。Blender 的 Normal 通道以世界空间存储方向，因此保存前要把方向转换到摄像机视角。

单靠法线贴图做不到的事

  • 金属和平滑度。 Unity 手册说明其 2D 光照不是基于物理的。Sprite-Lit-Default 读取颜色纹理、遮罩和法线贴图，但这些都不表示像素有多光亮，因此钢铁和布料受光的方式相同。手动放置一个带遮罩的光源，可以模拟出高光。
  • 相互投射阴影的精灵。 Shadow Caster 2D 的形状来自轮廓：精灵的 Custom Outline、碰撞器或自己绘制的形状。Shadow Caster 2D 只有精灵的边缘，没有每个部分的高度。Unity 的 Happy Harvest 样本改为用拉长的精灵绘制树下的阴影。2D 与俯视角精灵的阴影介绍了每种做法。

两者都需要每个像素有更多数据：表面的金属度和平滑度，以及表面有多高。

Unity 精灵法线贴图为何不起作用

如果光源完全不起作用，请先查看 2D 光源不生效时的检查项。以下是法线贴图本身的陷阱：

  • 纹理类型。 保持为 Sprite (2D and UI)（Sprite（2D 和 UI））的法线贴图会产生错误的明暗：光源移动时，暗面不动。请将 Texture Type（纹理类型）设为 Normal map（法线贴图），除非文件是高度贴图，否则禁用 Create from Grayscale（从“灰度”创建）。
  • 翻转的绿色通道。 Unity 认为绿色表示向上，即 Y+ 或 OpenGL 约定。按另一种约定制作的贴图在光源位于上方时，看起来像是从下方照亮。请在纹理的导入设置中启用 Flip Green Channel（翻转绿色通道）。
  • 翻转的精灵。 Sprite Renderer 中 Flip（翻转）的 X 只翻转绘制出的画面。绕 Y 轴旋转 180 度的精灵受光会出错，Unity 认为这是预期行为。如果用负的 Scale X 翻转，请在精灵上方放一个光源，检查受光的是否是精灵的顶部边缘。
  • 精灵图集。 精灵图集会为每种辅助纹理另建一张图集纹理，把各精灵的这种辅助纹理合并进去。请让同一图集中的每个精灵拥有相同数量的辅助纹理，否则合并后的纹理可能包含大量空白。如果用其他工具打包精灵表，该工具必须以相同的布局打包法线贴图，因为 Unity 用相同的 UV 读取两者。

Sun Forge：每个精灵的法线、遮罩、几何信息和自发光纹理

Sun Forge 是一款 Unity 编辑器工具，在 Unity 内采用第三种方法。烘焙会把 3D 模型或预制件变成 2D 精灵预制件，每个方向一张精灵表。每张精灵表除了颜色外，还有法线、遮罩和几何信息纹理；烘焙启用 Emission 时，还会有自发光纹理。

  • 遮罩用红色存储金属，用绿色存储平滑度，用蓝色存储环境光遮蔽。
  • 几何信息纹理存储每个纹素相对精灵轴心的高度，使精灵能够相互投射阴影。

Sun Forge 的光照包 Sun Forge 2D Lighting 会读取这些纹理。投射阴影会爬上站在阴影中的精灵，高度与投射阴影的物体一致。

光照包也能照亮自己绘制的精灵。请选择精灵，右键单击并选择 Sun Forge > Set Up for Lighting。自己的法线贴图能让精灵有立体感；没有法线贴图时，精灵按平坦的表面受光。选择会发光的颜色和像金属一样反光的颜色后，Sun Forge 会写入相应的发光纹理和金属纹理。

Sun Forge 需要 Unity 6.3 LTS（6000.3.28f1 或更高版本）或 Unity 6.6，以及使用 2D Renderer 或 Universal Renderer 的 URP。烘焙器和光照包都可以单独使用：请参阅精灵烘焙器和光照包。
