Unity 2D 昼夜循环与云阴影

在 2D URP 场景中，昼夜循环就是一个 Global Light 2D，其颜色在一天中随 Gradient 变化。夜间由 Volume 为画面调色，黄昏后灯逐渐亮起，滚动的云纹理在地面投下阴影。以下步骤适用于 Unity 6.3。

用 Global Light 2D 制作 Unity 2D 昼夜循环

Light Type（光照类型）设为 Global（全局）的 Light 2D 会同等地照亮所有 2D 游戏对象。改变这个光源的颜色，所有受光的精灵都会随之变化。

  1. 让精灵保持使用 Sprite-Lit-Default 材质，新建的精灵默认使用该材质。2D 光源不影响 Sprite-Unlit-Default。
  2. 在 Hierarchy 窗口中右键单击，选择 Light（灯光），然后选择全局 2D 光源；也可以选择任意一种 2D 光源，再将其 Light Type 设为 Global。Unity 在每个混合样式和排序图层中只允许一个全局光源。
  3. 将下面的脚本添加到任意游戏对象上，并指定该光源。在脚本的 Light Color 渐变中，把午夜放在两端，正午放在中间。
  4. 在摄像机上启用 Post Processing（后处理效果）。选择 GameObject > Volume > Global Volume（游戏对象 > 体积 > 全局体积），单击 New（新建）创建配置文件，然后单击 Add Override（添加覆盖）并选择 Color Adjustments。将其设为夜晚的外观，例如调低 Saturation。将该 Volume 指定给脚本，由脚本设置其 Weight（权重）。
  5. 为每盏灯或每处火添加一个 Spot Light 2D，并在脚本中列出这些光源。旧版本的教程把这种光源称为点光源。
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class DayCycle : MonoBehaviour
{
    public Light2D globalLight;
    public Gradient lightColor;   // the same color at both ends
    public AnimationCurve night;  // 1 at time 0 and at 1, 0 by day
    public Volume nightVolume;
    public Light2D[] lamps;
    public float lampIntensity = 1f;
    public float dayLengthSeconds = 600f;
    public float time;            // 0 and 1 are midnight, 0.5 is noon

    void Update()
    {
        time = Mathf.Repeat(time + Time.deltaTime / dayLengthSeconds, 1f);
        float n = night.Evaluate(time);

        globalLight.color = lightColor.Evaluate(time);
        nightVolume.weight = n;
        foreach (Light2D lamp in lamps)
            lamp.intensity = lampIntensity * n;
    }
}

2D 昼夜循环中的陷阱

  • 午夜的循环衔接。 Gradient.Evaluate 接受从 0 到 1 的时间，脚本会在午夜把时间绕回 0。如果渐变的首尾颜色不同，场景会在午夜跳变。请让两端颜色相同，并让夜晚曲线两端的值相同。一个 Gradient 最多只能有 8 个颜色键，因此请选定要设颜色键的时刻。
  • 突然亮起的光源。 在固定时刻启用的灯会在一帧之内出现。因此脚本改为根据夜晚曲线设置每盏灯的 intensity，让灯随曲线上升逐渐变亮。
  • 变暗的发光物体。 全局光源会让每个受光的精灵变暗，窗户和火焰也不例外。请把发光部分画成单独的精灵，并使用 Sprite-Unlit-Default 材质。在 Volume 中，Color Filter（颜色过滤器）和 Post Exposure 会改变整个画面，发光部分也包括在内。请把夜晚的暗度和色调放在光源的颜色中，用 Volume 调整饱和度和对比度。
  • 泛光阈值。 Intensity（强度）大于 0 之前，泛光不起作用。之后泛光只作用于比 Threshold（阈值）更亮的像素，阈值默认为 0.9。受光精灵上的发光在夜间会低于阈值，这也是用无光照材质绘制发光的另一个理由。Light 2D 的 Intensity（强度）大于 1 时，精灵会比自身颜色更亮，因此正午时浅色的墙可能超过阈值而产生泛光。

Unity 2D 阳光：Global Light 2D 无法呈现的效果

全局光源没有方向。全局光源同等地照亮一切，其 Inspector 窗口中也没有 Normal Maps（法线贴图）和 Shadows（阴影）部分。因此正午和黄昏只有颜色上的区别：精灵没有哪一面比另一面更亮，也没有任何物体投下阴影。

要表现太阳的位置，需要同时具备以下两点：

  1. 每个精灵各有一张法线贴图。在 Sprite Editor 窗口中打开 Secondary Textures（辅助纹理），以 _NormalMap 为名称添加法线贴图（操作步骤）。
  2. 一个有位置的光源。添加一个大型 Spot Light 2D，在 Normal Maps 下将其 Quality（质量）设为 Fast（快速）或 Accurate，并在一天中用脚本移动或转动这个光源。

Unity 的 Happy Harvest 样本就是这样照亮白天的：用一个由脚本转动的大型聚光灯。Unity 指出了两项开销：法线贴图会为每个图层批次增加一个全尺寸的渲染通道，而一个大光源的开销可能超过几个小光源。

Shadow Caster 2D 的阴影来自这样的光源，从不来自全局光源。Happy Harvest 用拉长的斑点精灵表现太阳的阴影，脚本会在一天中转动并拉长这些精灵。2D 与俯视角精灵的阴影比较了这几种做法。

Unity 2D 云阴影

只用 Unity 自带工具的两种方法：

  • 滚动的叠加层。 把一张深色、柔和的云纹理放在一个排序在地面之上的 Sprite Renderer 上。将其 Draw Mode（绘制模式）设为 Tiled（已平铺），让纹理在视野中重复，并为其指定 Sprite-Unlit-Default 材质。每帧移动这个 Sprite Renderer，并在移满一个平铺单元后把位置移回起点。叠加层会让其下绘制的一切变暗，灯光和发光的精灵也不例外。
  • 减性光源。 在 2D Renderer 资产的 Light Blend Styles（光源混合样式）下，将其中一个混合样式的 Blend Mode（混合模式）设为 Subtractive（减性）。添加一个 Light Type（光照类型）为 Sprite（精灵）的 Light 2D，将云纹理指定为其精灵，选择该混合样式，并以同样的方式移动。这个光源只减去其 Target Sorting Layers（目标排序层）上受光精灵的光，因此无光照的发光保持原有亮度。

无论用哪种方法，都请同样按夜晚曲线让云变淡：调整叠加层的颜色或光源的强度。否则午夜的阴影会和正午一样深。

Sun Forge 2D Lighting 的做法

Sun Forge 2D Lighting 是适用于 URP 的光照包，可在 2D Renderer 或 Universal Renderer 下使用。这个包提供从白天到夜晚的太阳、月光、天空和天气。要照亮自己绘制的精灵，请选择这些精灵，右键单击并选择 Sun Forge > Set Up for Lighting。自己的法线贴图能让精灵有立体感。没有法线贴图时，精灵按平坦的表面受光。

Lighting Setup 上的 Time Of Day 设置时刻，范围从 0 到 24，光照风格则决定每个时刻的光。要用脚本推进一天，请在 Update 中设置 SunForgeLightingSetup.TimeOfDay。光照在编辑模式、播放模式和 Player 中都实时绘制，因此精灵会随时刻变化重新受光。

  • 夜晚，月光照到的表面会变蓝，而火光和发光保持原有的颜色。
  • 光源可以是点光源、聚光灯、线光源或矩形光源，还能像火一样闪烁。Unity 的 Light 2D 可以驱动 Sun Forge 的 Light Source，并继续照亮 Sun Forge 的 Unity Lights 材质。
  • 天空会带来飘移的云阴影和地面薄雾。侧视画面中看不到可承接云阴影和薄雾的地面，因此两者都不显示。

阴影沿烘焙或绘制时设定的太阳方向落下，不会随太阳移动而转动。太阳落山时，阴影会逐渐变淡。

运行需要 Unity 6.3 LTS（6000.3.29f1 或更高版本）至 Unity 6.6，以及 URP。
