每个都是用 3D 模型烘焙出的平面精灵。太阳和火光实时照亮这些精灵。

Sun Forge 是适用于 Unity 6 和 URP 的 3D 转 2D 精灵烘焙工具和实时 2D 光照。两者可以一起使用，也可以只用其中一个。

dark_igorek 的 The Forgotten Knight 和 LasquetiSpice 的骷髅模型，CC BY 4.0，有修改。

把 3D 模型烘焙成 2D 角色

选择方向和动画。Sun Forge 会把每一帧渲染成精灵，并生成播放这些精灵的预制件。

方向

将指针移到精灵上、轻点精灵或拖拽滑块，即可转动模型。与模型朝向对应的精灵会随之播放。

常见问题

购买之前

移动光源后需要重新烘焙吗？

不需要。太阳、光源和风格的改动都会实时生效。阴影随精灵移动，并保持烘焙时的方向。

精灵只能在 Sun Forge 中使用吗？

不是。烘焙生成的是标准的 Unity 精灵、图集、动画剪辑、动画器控制器和预制件。

3D 模型会进入游戏吗？

不会。构建中不包含任何 3D 模型、网格或骨架。

适合 3D 游戏吗？

如果 3D 游戏只用一个固定的摄像机角度，可以把其中的模型烘焙成精灵，改用 2D 制作。

可以给自己画的精灵打光吗？

可以。请选择精灵，右键单击，然后选择 Sun Forge > Set Up for Lighting。自备的法线贴图能让精灵呈现立体感。

可以在哪些平台上运行？

Sun Forge 面向 URP 支持的所有平台设计。游戏构建可在 Windows（Direct3D 12）、ARM64 Android（Vulkan 或 OpenGL ES 3）和网页端（WebGL 2）上运行。在 Unity 6.6 上，网页端构建还可以使用 WebGPU 运行。

常见问题

更多问题

不用精灵烘焙工具，也能使用 2D 光照吗？

可以。两者都能单独使用。光照可以照亮任意 2D 或 2.5D 场景中自己绘制的精灵，烘焙也可以生成供 Unity 默认精灵材质使用的普通精灵。

能和 Unity 的 Light 2D 一起使用吗？

可以。Light 2D 可以驱动 Sun Forge 的 Light Source，同时仍会照亮 Sun Forge 的 Unity Lights 材质。

烘焙需要多长时间？

在配备 Ryzen 9 7900X 和 RTX 4060 的电脑上，烘焙一棵 16 个方向的树约需 25 秒，烘焙带 4 个动画的角色（968 个精灵）约需一分钟。

烘焙出的精灵占用多少纹理内存？

在桌面平台上，Showcase 样本中 16 个方向的山毛榉树占用 9.5 MiB，骑士的 968 个精灵占用 81 MiB。减少方向、降低分辨率或减少光照纹理都能降低占用。

可以烘焙什么？

带动画剪辑和 Particle System 的模型或预制件，用自身的材质和 Shader Graph 烘焙。道具、粒子特效和地面瓦片也能烘焙。

能用代码烘焙或使用 Addressables 吗？

可以。能用编辑器代码烘焙，并用自己编写的 C# 步骤扩展烘焙；烘焙还可以把预制件和图集注册到 Addressables。
