Scene view

The Scene view panel of Sun Forge, and what each of its rows draws.

Sun Forge Gizmos

Shows a switch in the Scene view for each kind of thing Sun Forge draws there, and hides while the scene has nothing for it.

Point at a row to read what it draws.

Object

  • Collider

    Shortcut Manager: Sun Forge › Toggle Collider

    Each baked prefab's physics shape. Drag an edge to size it.

  • Hitbox

    Shortcut Manager: Sun Forge › Toggle Hitbox

    Where hits land on each baked prefab. Drag an edge to size it.

  • Attach Points

    Shortcut Manager: Sun Forge › Toggle Attach Points

    Where each baked prefab's health bar, VFX box and overhead anchor sit. Drag them to move them.

  • Glow Point

    Shortcut Manager: Sun Forge › Toggle Glow Point

    Where each glowing prop's light sits on the ground. Drag it to move the light over another spot.

  • Facing

    Shortcut Manager: Sun Forge › Toggle Facing

    Which way each object faces. Drag the arrow's tip to turn it.

  • Markers

    Shortcut Manager: Sun Forge › Toggle Markers

    Each baked prefab's markers. Set them in the Bake Window (Bake tab, MARKERS, Advanced view).

  • Sort Point

    Shortcut Manager: Sun Forge › Toggle Sort Point

    The point each baked prefab's sprite sorts at.

Lighting

  • Ping Lighting Setup

    Pings the Lighting Setup in effect here, in the Hierarchy.

  • Lights

    Shortcut Manager: Sun Forge › Toggle Lights

    How far each light reaches on the ground. Select a prefab to edit the lights it holds, such as a candle's flame.

  • Shadow Height

    Shortcut Manager: Sun Forge › Toggle Shadow Height

    How high each flat thing, such as a rug, casts its shadow from. Drag the top of its stem.

  • Feet Line

    Shortcut Manager: Sun Forge › Toggle Feet Line

    Where each sprite you drew stands. Drag the dashed line to its feet, then Apply in its Inspector.

  • Texture View

    Shows a texture the lighting reads from each sprite, in this Scene view only.
