光源

添加 Light Source，调整光的形状，并继续使用已有的 Light 2D 光源。

本页内容
  • 添加光源
  • 设置光源形状
  • 使用现有的 Light 2D 光源
  • 摄像机可照亮的光源数量
  • 精灵自身的发光光源

Light Source 在两种 URP 渲染器下都能照亮风格材质。光斑落在光源下方的地面上。

添加光源

  1. 选择 GameObject > Sun Forge > Light Source > Light（游戏对象 > Sun Forge > Light Source > Light）。在同一子菜单中，Spot Light、Line Light 和 Rectangle Light 分别照亮锥形、线形和矩形区域，Fire、Lamps、Magic 和 Windows and Doors 中则是现成的初始外观，例如火把、路灯或窗户。
  2. 把光源移到发光处，例如灯的火焰上。
  3. 选中光源后，在 Scene 视图中拖拽光源上方的圆点即可设置 Height Above Ground（离地高度）：光源随之升高或降低，光斑留在原处。其他手柄用于设置 Ground Radius（地面半径）、Inner Radius（内半径）、尺寸和各个聚光角度。将鼠标悬停在手柄上，即可查看其名称和数值。

要把现有对象（例如灯的预制件）变成光源，请使用 Add Component > Sun Forge > Lighting > Light Source（添加组件 > Sun Forge > Lighting > Light Source）。

3D 点光源或聚光灯不会照亮使用风格材质的精灵。要为这样的光源添加 Light Source，请选择该光源，然后单击其 Inspector 窗口顶部的 Add a Sun Forge Light Here（在此位置添加 Sun Forge 光源）。

照得更远的光斑 调高 Intensity（强度）。Ground Radius（地面半径）决定光照到哪里为止

使用现有的 Light 2D 光源

现有的 Light 2D 光源会继续照亮 Unity Lights 材质。要让这些光源也照亮使用风格材质的精灵：

  1. 选择 GameObject > Sun Forge > Set Up for Lighting（游戏对象 > Sun Forge > Set Up for Lighting），然后单击 Apply（应用）。每个以所有排序图层为目标的 Light 2D 都会获得一个由其驱动的 Light Source，因此脚本和动画对 Light 2D 所做的修改会同步到 Light Source。要只设置某一个光源，或设置之后添加的光源，选择该光源，然后单击其 Inspector 窗口顶部的 Use This Light with Sun Forge（在 Sun Forge 中使用此光源）。
  2. 如果某个 Light 2D 未以某个排序图层为目标，选择 Lighting Setup，然后在列出该光源的问题旁单击 Fix（修复）。
  3. 将每个 Light Source 的 Height Above Ground（离地高度）设为对应 Light 2D 离地面的高度。光源仍位于 Light 2D 处；在使用风格材质的精灵上，光斑落在光源下方的地面上，因此光斑看起来是压扁的，就像美术中的地面一样。在侧视美术上，改为设置较小的 Height Above Ground（参见 侧视）。

摄像机可照亮的光源数量

每个摄像机最多让 512 个光源生效，在 WebGL 2 Player 中最多 128 个。主摄像机能看到却未生效的光源，在 Scene 视图中显示为灰色灯泡。要让这样的光源继续生效，请启用其 Special Cases（特殊情况）下的 Is Prioritized（优先照亮）。

精灵自身的发光光源

发光光源是 Sun Forge 为精灵的发光部分创建的 Light Source。由 Sun Forge 写入纹理的精灵，可在其 Lighting Style Renderer 的 Glow, Surfaces and Edges（发光、表面和边缘）下单击 Glow Light（发光光源）行中的 Add（添加）来添加发光光源。Lighting Setup 上 Values（值）下的两个 Glow（发光）值决定发光光源如何照亮其所属的精灵，发光光源 Special Cases（特殊情况）下的 Light On Its Object Shift（对所属对象的光照偏移）和 Glow Parts Light Scale（发光部分光照缩放）则只为某个精灵更改这一点。

精灵材质所属的风格与场景的风格不同时（例如 Regular 场景中的 Flat 材质），由材质所属的风格决定精灵的发光光源如何照亮精灵，Lighting Setup 的两个 Glow 值不会改变这一点。在这一点上，Realistic 视为 Regular，自己的风格视为其所基于的风格。发光光源的 Light On Its Object Shift 和 Glow Parts Light Scale 仍会改变这类精灵。
