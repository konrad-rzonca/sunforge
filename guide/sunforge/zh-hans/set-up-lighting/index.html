设置场景

为场景中的精灵打光并添加第一个光源，共三步。

  1. 打开场景，然后选择 GameObject > Sun Forge > Set Up for Lighting（游戏对象 > Sun Forge > Set Up for Lighting）。窗口会列出将要更改的内容。如果美术是从侧面绘制的（例如平台跳跃游戏的美术），在窗口的 Art View（美术绘制视角）行中选择 From the Side（侧视角）。
  2. 单击 Apply（应用）。场景中会添加一个 Regular 风格的 Lighting Setup，场景中的精灵随即受光。从上方绘制的美术还会投射阴影。
  3. 要添加光源，选择 GameObject > Sun Forge > Light Source > Light（游戏对象 > Sun Forge > Light Source > Light），或同一子菜单中的某个初始外观（例如 Fire > Torch），然后把光源移到灯或火焰上。

要为游戏运行时生成的预制件设置光照，请在 Project 窗口中选择这些预制件，右键单击，然后选择 Sun Forge > Set Up for Lighting。

要使用自己的法线贴图，或让某些颜色发光或像金属一样反光，请参阅 手绘的精灵 › 精灵纹理。
