模型材质

烘焙会从模型材质中读取什么，以及每一项在精灵纹理中变成什么。

本页内容
  • 精灵和 2D 骨架
  • 使用自己着色器的模型

模型的材质按以下方式烘焙：

  • 模型的颜色纹理会烘焙成精灵的颜色，而场景会再次照亮精灵，因此画进纹理的光影会出现在每个精灵中。
  • 材质的 Occlusion Map（遮挡贴图）会烘焙进遮罩纹理。请把该贴图用于比网格更细的细节，例如树皮的沟纹。
  • 按 Alpha 渐隐的材质会在不透明度为一半处裁剪后烘焙，因此玻璃和其他透明表面烘焙后要么实心，要么镂空。
  • 无论材质的 Render Face（渲染面）如何设置，烘焙都会绘制模型表面的两面，因此从背面看时，单面的叶片面片或披风仍会出现在精灵中。
  • 网格自身的顶点颜色不会烘焙，因为 URP 的 Lit 和 Standard 会忽略顶点颜色。
  • 发光部分只在露出的地方照亮自身所在的模型：推入实体内部的部分不照亮任何内容。只渲染一面的表面是实体的外皮，因此对于位于这种表面后方的发光部分（例如用单层面建模的灯罩下的灯泡），请将灯罩材质的 Render Face 设为 Both。
  • 切换网格、精灵或线条材质的动画剪辑，或用 2D Animation 的 Sprite Swap 切换精灵的动画剪辑，每一帧都按该帧显示的内容烘焙。动画剪辑在材质上动画化的值（例如颜色、发光、纹理偏移或裁剪阈值）会按剪辑播放时的样子烘焙到每一帧。
  • 烘焙期间脚本不会运行。在场景对象上，脚本用 MaterialPropertyBlock 在其渲染器上设置的值，会按烘焙时对象显示的样子烘焙。

精灵和 2D 骨架

  • 用 2D Animation 绑定骨骼的角色，每一帧都按其骨骼和 2D IK 给出的姿势烘焙。
  • 对于使用 Sun Forge 光照材质绘制的精灵，烘焙会使用该精灵绘制时所用的法线、遮罩和自发光纹理，例如 Set Up for Lighting（设置光照）为精灵设置的纹理。
  • 在 Sprite Renderer 上，精灵的每张辅助纹理都会代替材质中同名的纹理参与烘焙。在 Shader Graph 中，该名称的纹理属性需要启用 Show In Inspector，否则烘焙找不到该属性。
  • Sprite Renderer 的 Color（颜色）和 Line Renderer 的 Color 渐变会像在场景中一样为各自的部分着色。

使用自己着色器的模型

使用自己的着色器时，烘焙读取以下属性：

烘焙采用的内容 来源
颜色 着色器标记为主纹理和主颜色的属性，否则为 _BaseMap 或 _MainTex 以及 _BaseColor 或 _Color
法线贴图 _BumpMap 或 _NormalMap，并像 URP 的 Lit 那样按 _BumpScale 缩放
发光 材质的 Emission 复选框（_EMISSION 关键字）启用时为 _EmissionColor 和 _EmissionMap；如果着色器没有该关键字，则始终采用这两项

在 Shader Graph 中，请右键单击属性并选择 Set as Main Texture 或 Set as Main Color。

对于无法编辑的着色器，烘焙扩展可以为烘焙所用的模型副本指定使用这些属性名称的材质（参见 扩展烘焙 › 扩展）。Bake（烘焙）选项卡仍会指出该材质，因为该选项卡在扩展运行之前检查模型。
