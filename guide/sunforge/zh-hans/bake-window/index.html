辅助纹理

法线烘焙法线纹理，让光源照出精灵形状的明暗。没有法线纹理时，Sun Forge 材质会把精灵当作平面照亮。
遮罩烘焙遮罩纹理：金属、光泽和环境光遮蔽。不烘焙遮罩纹理时，Sun Forge 材质使用中性值。
遮罩 › 金属和光泽金属和光泽的来源：材质自身的数值，或下方列出的颜色。不读取 HDRP 和 glTF 的遮罩贴图。
遮罩 › + 添加表面添加一种颜色，为其单独烘焙金属和光泽。
遮罩 › 环境光遮蔽Advanced使用类型模板的环境光遮蔽、禁用环境光遮蔽，或为此烘焙单独设置。
遮罩 › 强度Advanced模型形状产生的遮蔽深浅，从 0（无）到 1（完全）。材质的遮挡贴图更暗的地方显示贴图。
遮罩 › 半径Advanced精灵遮蔽的影响范围（模型“绘制高度”的比例）
遮罩 › 半径Advanced地面瓦片遮蔽的作用范围（世界单位）
自发光烘焙自发光纹理，让发光的部分在游戏中保持发光。在 Flat 风格下，发光部分显示自身的发光，不显示其“Sunlit Outline”。
自发光 › 发光发光的来源：材质的自发光贴图和颜色，或下方列出的颜色
自发光 › + 添加发光颜色添加一种发光的颜色。
自发光 › 强度上方所列颜色在游戏中的发光亮度
自发光 › 发光光源精灵在模型或其粒子发光处添加光源。该光源如何照亮模型自身由光照风格决定。要放置数以百计的道具时，请禁用此项。
自发光 › 亮度光源的亮度和照射范围。如果是火或灯，请调高到 1 左右。模型自身受到的光由光照风格决定。
自发光 › 种类设为“火焰”时，光源和预制件的发光会在播放模式下闪烁。如果是火，请同时将“亮度”设为 1 左右。
自发光 › 火焰 › 振幅火焰的光最多减弱多少。大多数时候减弱得更少。为 0 时光线保持稳定。
自发光 › 火焰 › 频率火焰跳动的速度：蜡烛约为 10，篝火约为 3。“Flutter”决定火焰的闪烁中有多少按此速度变化。为 0 时保持稳定。
自发光 › 火焰 › 颤动火焰的闪烁中，快速颤动相对于缓慢明暗起伏所占的比例。为 0 时只有缓慢的明暗起伏。
几何信息纹理精灵烘焙每个像素高出地面的高度，供光源、投射阴影、树荫和薄雾使用。关闭时，精灵按竖立的扁平面片受光。

动画

静止姿势方向数Advanced精灵静止姿势及其粒子烘焙的方向。留空时使用类型模板的方向。道具的碰撞器和发光跟随这些方向。方向越多，烘焙越慢；没有“待机”条目时，占用的纹理内存也越多。
动画播放器Advanced精灵选择播放预制件动画和粒子的组件。场景中有大量角色或大量带动画的道具时，“帧动画播放器”占用的 CPU 更少。
动画剪辑 › 复制精灵复制此条目，并使用唯一的输出名称。
动画剪辑 › 模式精灵此条目在生成的动画器控制器中的作用
动画剪辑 › 动画剪辑精灵此条目烘焙的动画，取自源的动画。选择“静止姿势”或将“动画剪辑”留空时，烘焙模型原本的样子，不带动画。
动画剪辑 › 范围精灵拖拽可只烘焙源动画剪辑的一部分。对于循环条目，请让起点和终点的姿势一致，否则精灵每次重复播放时都会跳变。
动画剪辑 › 倒放精灵从结尾到开头播放“范围”，例如把倒地动画做成起身动画。
动画剪辑 › 额外偏航角精灵仅对此条目进一步转动模型，适用于朝向与模型不一致的动画剪辑。
动画剪辑 › 速率精灵
动画剪辑 › 方向Advanced精灵此动画烘焙的方向：自有的方向数和开关。留空时使用类型模板的方向，静止姿势条目则使用“静止姿势方向数”。
动画剪辑 › + 添加姿势覆盖精灵添加骨骼，在此条目播放时保持另一个动画剪辑中的某个姿势，例如让手臂在行走时保持瞄准姿势。
动画剪辑 › + 添加条目精灵添加动画条目。条目的“模式”会根据动画剪辑的名称推测。多个条目可以烘焙同一个动画剪辑。
动画剪辑 › 大小测量依据Advanced精灵碰撞器、受击框、VFX 框和血条的“测量依据”为“动画帧”时，会贴合这些动画。无论“测量依据”如何设置，草都可能绘制在这些动画抬离地面超过 0.25 世界单位的部分之上。

遮挡组Advanced精灵同组的标记点（例如一双眼睛）在模型转动时，位于组远侧的会淡出。

Addressables 分组Advanced烘焙注册预制件和图集所用的 Addressables 分组。创建分组会保存项目。
Addressables 标签Advanced每个烘焙出的预制件和图集获得的 Addressables 标签，不存在时会创建

使用 Crunch 压缩Advanced对烘焙发布的内容使用 Crunch 压缩，以减小 Web 构建的体积。精灵会损失一些细节，静止的精灵可能闪烁。在 ASTC 构建中，或在桌面平台上“压缩”为“高质量”时，此设置不起作用。法线贴图和高度纹理不使用 Crunch 压缩。
过滤模式Advanced烘焙发布的每张纹理和每个图集的过滤方式。“点”可保持像素画清晰。如需硬边，请同时禁用“质量”部分的“超采样”。
生成 Mip 贴图Advanced为烘焙发布的每张纹理和每个图集生成 Mip 贴图，使以远小于原尺寸绘制的精灵不会闪烁。

摄像机

每单位像素数每世界单位的精灵像素数：数值越高越清晰，占用的纹理内存也越多。在 Flat 光照风格下，数值越高，折痕线越细；数值较低时，描边更宽。
俯角游戏摄像机俯视的角度（度）：0 为侧视，不烘焙地面阴影；90 为垂直俯视。如需侧视，请使用 0，而不是较小的角度。精灵按此视角绘制，每次烘焙的光照也使用此角度。
方向精灵烘焙模型所用的方向数，1 到 64。为 1 时只烘焙背面视角，为 8 时烘焙四个侧面和四个对角方向。方向越多，角色转向时越贴近瞄准或移动的方向，朝屏幕上方和下方时尤其明显。动画和静止姿势可以设置各自的方向。
方向 › 填补最宽间隙精灵

质量

超采样Advanced每像素最多渲染 16 个采样再缩小，边缘更平滑，细节在帧与帧之间保持稳定，但烘焙时间更长；边长超过 1024 像素的精灵采样数更少。禁用时每像素渲染一个采样，烘焙更快，适合像素画，但边缘可能闪烁。禁用且阴影的“柔和度”为 0 时，地面投影阴影像素级锐利。
动画帧速率Advanced精灵未设置帧速率的动画条目以及粒子所用的每秒帧数。留空则保留每个动画剪辑自身的帧速率，并以每秒 16 帧烘焙粒子。
环境光遮蔽Advanced根据模型形状将环境光遮蔽烘焙到遮罩中。如果材质有遮挡贴图，每个像素取两者中较暗的值。
AO 强度Advanced模型形状产生的遮蔽深浅，从 0（无）到 1（完全）。材质的遮挡贴图更暗的地方显示贴图。
AO 半径Advanced精灵遮蔽的影响范围（模型“绘制高度”的比例）
AO 半径Advanced地面瓦片遮蔽的作用范围（世界单位）
AO 质量Advanced“快速”使用 32 个方向，“高”使用 64 个方向。“高”的着色更平滑，但烘焙更慢。

阴影

烘焙阴影在遮罩中为模型在太阳下自身遮挡的区域着色，并烘焙下方已启用的阴影类型。
太阳仰角太阳的高度（度）。太阳越低，投下的阴影越长。
太阳方向太阳照来的方向，从屏幕顶部按顺时针计算（度）。为 180 时，太阳位于摄像机后方。
柔和度Advanced阴影边缘的柔和程度。为 0 时是硬边：禁用“超采样”时像素级锐利，启用时略有平滑。在精灵上，此值为地面投影阴影淡出的宽度（世界单位）。精灵投在自身上的阴影会同样柔化，但“柔和度”或“每单位像素数”较高时仍比地面阴影更锐利。在地面瓦片上，阴影离投射它的物体越远，淡出越宽。
色调Advanced精灵地面投影阴影和简单椭圆阴影的颜色。其 Alpha 决定阴影在 Regular 风格日光下的深浅，Sun Forge 的阴影材质还会根据光和 Lighting Setup 的“Ground Shadow Strength”将阴影绘制得更深或更浅。烘焙会将其设为预制件中阴影 Sprite Renderer 的“Color”。在那里手动设置的“Color”会保留。
材质Advanced精灵留空时使用 Sun Forge 的阴影材质，该材质随光变化，并在薄雾下淡出。Cast Shadow Field 只取用该材质的薄雾淡出。在不受薄雾影响的地面上，请选择无光照材质，例如 Unity 的 Sprites-Default，该材质按原样绘制“色调”。“游戏中”预览显示太阳和天空的效果，不含云、薄雾和 Light Source 的效果。
高度范围Advanced精灵几何信息纹理存储的高度范围（世界单位）。“自动”会贴合模型。仅当代码需要固定值时才设置此项。
地面投影精灵烘焙太阳投射在地面上的阴影。
分辨率缩放Advanced精灵阴影细节和纹理开销（“每单位像素数”的比例）。为 1 时每个阴影像素对应一个精灵像素，符合像素画的需要。
烘焙投影高度纹理Advanced精灵烘焙每个阴影像素的投射高度，使树冠在 Cast Shadow Field 中把阴影投在其下方的精灵上。禁用时，每张阴影精灵表少用一张纹理。此时如果太阳从侧面照射，阴影落到精灵上时只会爬上精灵的底部。
添加 Cast Shadow CasterAdvanced精灵为烘焙出的预制件添加 Cast Shadow Caster，使场景中的 Cast Shadow Field 将其阴影投射到周围的精灵上。
简单椭圆精灵在模型下方烘焙简单椭圆阴影。
不透明度Advanced精灵椭圆的绘制深浅。为 0 时不可见，为 1 时完全呈现“色调”。
缩放Advanced精灵相对于模型的俯视占地范围缩放椭圆阴影。

物理

可移动Advanced精灵开启：设置了“碰撞器形状”时使用动态刚体，受物理推动。关闭：静态，不受物理推动。如果没有移动预制件的行为（例如 Movement 或 Wander），会为其 Rigidbody 2D 设置“Linear Damping”，被撞后会逐渐停下。
密度Advanced精灵密度（kg/m³）。烘焙数据的“质量”等于模型体积乘以此值，预制件的 Rigidbody 2D 或 Physics Body 会获得该质量。
可离地Advanced精灵启用时，预制件在子对象“Body”上绘制主体，脚本可以抬高或降低该子对象，而碰撞器和阴影仍留在地面上，移动也仍沿地面进行。适用于会飞或会跳跃的生物。
