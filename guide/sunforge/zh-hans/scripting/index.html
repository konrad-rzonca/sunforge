脚本编程

需要引用的程序集，以及脚本如何读取烘焙写入的内容。

程序集 命名空间 内容
KonradRzonca.SunForge.Runtime KonradRzonca.SunForge 烘焙数据、适配器接口和标记点
KonradRzonca.SunForge.Lighting KonradRzonca.SunForge 光照组件，来自 Sun Forge 2D Lighting 包
KonradRzonca.SunForge.Gameplay KonradRzonca.SunForge.Gameplay 玩法行为和物理
KonradRzonca.SunForge.Editor KonradRzonca.SunForge.Editor 扩展、预设、验证，以及从代码运行烘焙
KonradRzonca.SunForge.Lighting.Editor KonradRzonca.SunForge.Editor 加载内置光照风格，以及从代码设置场景的光照，来自 Sun Forge 2D Lighting 包

请在自己的程序集定义中引用要用到的程序集。

组件的类名是 SunForge 加上组件在 Inspector 窗口中显示的名称：Light Source 的类为 SunForgeLightSource。

要让 IDE 显示 Sun Forge 各类型和成员的说明，请在 Edit > Preferences > External Tools > Generate .csproj files for（编辑 > 首选项 > 外部工具 > Generate .csproj files for）下启用 Sun Forge 的安装来源，例如 Registry packages 或 Local tarball，然后单击 Regenerate project files。

读取烘焙数据

SunForgeBakedPrefab.Of(component) 可从角色上的任意组件（包括子对象上的组件）找到烘焙数据：

using KonradRzonca.SunForge;
using UnityEngine;

public sealed class ShowBakeInfo : MonoBehaviour
{
    void Start()
    {
        SunForgeBakedPrefab baked = SunForgeBakedPrefab.Of(this);
        SunForgeBakedData data = baked.Data;
        Vector3 textPoint = baked.AnchorSpace.TransformPoint(baked.Anchors.OverheadAnchor);
        Rect hitbox = baked.WorldHitbox;
        Debug.Log($"{data.OutputName} bakes {data.Clips.Count} clips. Text goes at {textPoint}. Hits land in {hitbox}.");
    }
}
  • Anchors 中的所有矩形和点都位于 AnchorSpace 的局部空间，只有 Anchors.Collider 位于根的局部空间。baked.Anchors.HealthBar.ToWorld(baked.AnchorSpace) 返回世界空间中的矩形。
  • 烘焙时启用了 Leaves The Ground（可离地，Archetypes（类型模板）选项卡 PHYSICS（物理）部分，Advanced（高级）视图）的预制件，要在游戏运行时改变其高度，设置其 Body 子对象上 SunForgeBakedRendererBinding 的 HeightAboveGround，然后调用根上 SunForgeBakedShadowSync 的 PlaceAtHeight(Vector3.zero)，该方法会移动主体及其阴影。对于缩放过的预制件，在脚本调用 PlaceAtHeight 之前，主体所在的高度为设定高度乘以缩放值。
