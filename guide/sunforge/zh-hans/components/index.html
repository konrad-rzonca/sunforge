  • Pixel Sort Character

    检查器

    “逐像素道具排序”启用时，将角色与其所在道具的每个部分分别排序。

    道具中的角色 › 修正单个预制件

    检查器中的设置

    自动深度在角色碰撞器的前缘处拆分道具。禁用后可自行输入深度。
    深度道具围绕角色拆分的位置在角色脚底下方的距离（世界单位）。道具位于该线以下的部分绘制在角色前方。

添加组件 › Sun Forge › Animation

  • Flipbook Animator Link

    检查器

    启动烘焙出的粒子帧动画的循环，并让该帧动画随其所属的角色一同转向。

  • Flipbook Player

    检查器

    不使用 Animator 播放烘焙出的角色的动画，适用于角色众多的场景。

    检查器中的设置

    烘焙数据要播放的烘焙数据。为空时使用烘焙出的预制件的数据。
    粒子播放烘焙的粒子帧动画，而不是主体的动画。

  • 朝向

    检查器

    记录对象的朝向，并显示对应方向的精灵。

    检查器中的设置

    朝向对象在屏幕上的朝向。为零时朝向静止方向。
    角度屏幕上的方向，以从右侧起逆时针旋转的度数表示。角色会转向烘焙渲染过的最近方向。

添加组件 › Sun Forge › Baked

  • Baked Prefab

    检查器

    将烘焙出的预制件的根与其烘焙关联，重新烘焙时可保留自行添加的组件。

    检查器中的设置

    烘焙数据此预制件读取的烘焙数据。烘焙时会设置此项。在自己搭建的根对象上，请在此处设置。

  • Baked Renderer Binding

    检查器

    将渲染器与其烘焙关联，使 Sun Forge 着色器按该烘焙的设置照亮渲染器的精灵。

    检查器中的设置

    烘焙数据此渲染器的精灵所属的烘焙，渲染器的着色器从中读取值。由烘焙设置。
    精灵种类此渲染器绘制烘焙的哪种精灵，例如主体或阴影
    离地高度此精灵离地面的高度（世界单位），例如桌上的灯或飞行中的鸟。精灵受到的光照、遮蔽、投射阴影以及绘制在精灵之上的草都按此高度计算。此值不会移动精灵：请自行将精灵放到该高度。
    Split Around Characters在“Project Settings > Sun Forge”中启用“逐像素道具排序”时，围绕此道具内的每个 Pixel Sort Character 拆分此道具。自己制作的角色也需要添加该组件。

  • Baked Shadow Sync

    让烘焙出的角色的阴影与主体保持相同的朝向和动画帧。

    检查器中的设置

    主体阴影跟随的主体渲染器。为空时使用此游戏对象上的 Sprite Renderer。
    地面阴影背向太阳投下的地面阴影渲染器，或自己绘制的阴影。没有地面阴影时为空。
    椭圆阴影椭圆阴影渲染器。没有椭圆阴影时为空。
    烘焙数据提供阴影帧的烘焙数据。为空时使用烘焙出的预制件的数据。

添加组件 › Sun Forge › Gameplay

  • Camera Follow

    检查器

    使摄像机以任意帧率平滑跟随目标。

    检查器中的设置

    目标镜头对准的角色。用于主摄像机时，如果此项为空，带有 Camera Target 的角色会在播放模式下将自身填入此项。
    Target Offset摄像机居中对准的点，相对于目标根对象的偏移（世界单位）
    Smooth Time镜头跟上移动目标所需的秒数
    Teleport Distance目标跳跃距离超过此值（世界单位）时，镜头直接切到目标，而不是平滑移动。

  • Camera Target

    播放模式下使主摄像机跟随此角色；摄像机上有其他脚本（如 Cinemachine Brain）时除外。

  • Health

    检查器

    承受射击和打击造成的伤害，角色受伤期间其上方会出现血条。

    检查器中的设置

    最大生命值角色的初始生命值
    Show Bar角色受伤期间在其上方显示血条。生命值归零时血条会再次隐藏。
    生命值归零时“保持站立”会将角色留在场景中，交由自己的脚本处理。“死亡并停用”会播放 Die 条目（如果烘焙中有），然后停用角色。
    Damaged每次命中时触发，并传入伤害值和攻击的行进方向。
    Depleted在使生命值归零的那次命中时触发一次。

  • Melee Attacker

    走向最近的带有 Movement 的角色并发起打击，同时播放名为 Attack 的“播放一次”条目。

    检查器中的设置

    目标要追击的角色。为空时追击最近的带有 Movement 的角色。目标未激活、生命值耗尽或目标的 Health 已禁用时，攻击者原地待机。
    速度世界单位/秒。为 0 时使用烘焙行走动画的速度，没有烘焙行走动画时使用 1.6。按烘焙速度向左或向右行走时，脚部不会打滑。
    Reach停下并发起打击时，自身碰撞器与目标碰撞器之间的距离（世界单位）。打击可命中比此距离最多远 0.25 的目标。
    伤害每次打击从目标的 Health 中扣除的生命值
    Cooldown Seconds两次打击的间隔秒数

  • Movement

    检查器

    用 WASD 或方向键行走，并朝向行走的方向。

    检查器中的设置

    速度世界单位/秒。为 0 时使用烘焙行走动画的速度，没有烘焙行走动画时使用 3.2。按烘焙速度向左或向右行走时，脚部不会打滑。
    Reads Input用 WASD 或方向键行走。禁用后可由自己的脚本驱动角色行走。

  • Physics Body

    检查器

    播放模式下，在物理世界中模拟烘焙出的角色。

    检查器中的设置

    物理世界此角色参与物理模拟的物理世界。烘焙会根据类型模板设置此项。
    Is Static对物理永远不会移动的场景物体启用。类型模板的“可移动”（“高级”视图）禁用时，烘焙会启用此项。
    质量质量（kg），在此对象没有 Rigidbody 2D 时使用。烘焙会将其设为模型体积乘以类型模板的“密度”（“高级”视图）。
    Simulated禁用时，角色在播放模式下既不移动，也不形成阻挡。脚本也可以将其禁用和启用。

  • Projectile

    检查器

    从发射位置沿直线飞行，并对击中的第一个 Health 造成伤害。遇到 Projectile Blocker 时停止。

    检查器中的设置

    速度飞行速度（世界单位/秒）。为 0 时停在原处，直到命中为止。
    Max Range销毁前的飞行距离（世界单位）
    伤害从击中的 Health 中扣除的生命值

  • Projectile Blocker

    在此对象的受击框处拦截 Sun Forge 的投射物。此对象不会受到伤害。

  • Shooter

    检查器

    单击、触摸或按空格键时朝指针开火，并播放名为 Attack 的“播放一次”条目。如需改为继续播放行走动画，请将“While Walking”设为“保持行走”。投射物从名为 Muzzle 的标记点射出，没有该标记点时从受击框边缘射出，并穿过瞄准的点。

    检查器中的设置

    Projectile Prefab每次射击生成的预制件。为空时发射内置投射物。
    Cooldown Seconds按住开火时两次射击的间隔秒数。小于 Attack 的时长时，每次射击都会从头播放 Attack。略大于该时长时，Attack 定格在最后一帧，直到下一次射击。
    行走时角色行走时射击所播放的动画。“播放 Attack”会播放 Attack 条目来代替行走动画。“保持行走”会继续播放行走动画（角色射击方向与行走方向相反时倒着播放），并跳过 Attack 及其动画事件。“保持行走”适合本身就举着武器的行走动画。
    Recoil Pixels选择“保持行走”时，行走中射击把角色绘制位置向后推的距离（以精灵的像素为单位）。绘制位置很快复位，碰撞器保持不动。为 0 时不后推。
    Reads Input用指针或触摸瞄准，单击、触摸或按空格键开火。禁用后可由自己的脚本瞄准和开火。
    Aim Camera用指针瞄准时所用的摄像机。为空时使用标签为 MainCamera 的摄像机。

  • Wander

    检查器

    在起点附近漫游，每段行走之间会停顿。

    检查器中的设置

    速度世界单位/秒。为 0 时使用烘焙行走动画的速度，没有烘焙行走动画时使用 0.4。按烘焙速度向左或向右行走时，脚部不会打滑。
    半径角色离开起点行走的最远距离（世界单位）
    Seed相同的非零种子会重现相同的行走路线。为 0 时根据起点生成种子。

添加组件 › Sun Forge › Lighting

  • Canopy Shade

    检查器

    按自动绘制或手绘的树冠贴图，为树冠下的地面和精灵投下树荫。

    检查器中的设置

    Map树冠贴图：白色表示开阔的天空，黑色表示浓密的树冠下方。“绘制贴图”会根据“Trees”绘制此贴图。只读取红色通道，因此按“Single Channel”、“Red”导入可节省内存。
    矩形贴图覆盖的区域（世界单位），相对于此对象。区域之外天空无遮挡。
    Canopy Height精灵高于此高度（世界单位）时不在树荫中。请设为与树高大致相同的值。“绘制贴图”会将此值设为树顶的平均高度。
    树木只包含树木的对象，供“绘制贴图”使用。其下的空对象表示一组树，其余每个对象表示一棵树，“绘制贴图”将树的轴心当作树干与地面的交点。

  • Cast Shadow Caster

    检查器

    使精灵在太阳下投射自身的阴影，或投射为其绘制的阴影。

    检查器中的设置

    阴影高度为扁平物体的整个阴影指定统一的高度（世界单位）。站立的物体请保持为 0。带有投影高度纹理的阴影精灵会忽略此值。

  • Cast Shadow Field

    检查器

    将每个精灵的阴影投射到地面和站立的精灵上，重叠处只变暗一次。

    检查器中的设置

    Followed CameraCast Shadow Field 跟随的摄像机。留空则跟随标签为 MainCamera 的摄像机。
    每单位像素数阴影分辨率（每世界单位纹素数）。为 0 时与阴影精灵中最高的“Pixels Per Unit”一致。值越低，在手机上的开销越小。
    模式阴影落在何处。“地面叠加层”类模式适用于所有地面材质。“地面材质”类模式需要使用 Sun Forge 风格材质的地面，且 Lighting Setup 的“投射阴影拉伸”会拉长其阴影。名称以“和精灵”结尾的模式还会在使用风格材质的站立精灵上投下阴影。
    排序模式“最下层阴影”：与排序最靠下的阴影排在同一位置。“自定义”：使用下方的图层和顺序。排序在阴影层上方的贴花不显示阴影。
    排序图层名称阴影层绘制所在的排序图层名称。为空时使用“Default”。
    Sorting Order阴影层绘制时的排序顺序

  • Cast Shadow Pair

    将精灵与为其绘制的阴影精灵配对。

    检查器中的设置

    主体阴影跟随的主体渲染器。为空时使用此游戏对象上的 Sprite Renderer。
    地面阴影背向太阳投下的地面阴影渲染器，或自己绘制的阴影。没有地面阴影时为空。
    椭圆阴影椭圆阴影渲染器。没有椭圆阴影时为空。

  • Light Source

    检查器

    照亮一个点周围、沿一条线或一个矩形内的精灵，亮度可保持稳定，也可闪烁。

    光源 › 添加光源

    检查器中的设置

    Driving Light 2D启用时，此游戏对象上的 Light 2D 决定此光源的颜色、亮度、“Ground Radius”和聚光角度，因此凡是驱动 Light 2D 的内容也会驱动此光源。
    由 Light 2D 驱动启用时，此游戏对象上的 Light 2D 决定此光源的颜色、亮度、“Ground Radius”和聚光角度，因此凡是驱动 Light 2D 的内容也会驱动此光源。
    颜色光源的颜色。火焰变暗时会发红。在 Flat 风格下，靠近明亮或饱和色光源的图像可能比关闭光源时更暗，这种情况出现在黄昏、黎明、室内和明亮的夜晚。在明亮的夜晚，任何颜色的光都会使金属变暗。如需避免这种情况，请调低光源的“Intensity”，或将光源移到离图像更远的位置。
    亮度
    强度光源处的亮度，与太阳的强度单位相同。亮度随距离衰减，到“Ground Radius”处消失。为 0 时光源关闭，不占用摄像机可用于照明的光源名额。
    离地高度光源离地面的高度（世界单位）。光斑落在游戏对象正下方的地面上。光源越高，光斑越均匀，也越暗淡。在按俯角 0（侧视）绘制的图像上，光源越高，离图像就越远。
    地面半径光源在地面和高出地面的任何物体上照射的距离（世界单位），从光源正下方的点或光源的线、矩形向外计算。更改“Height Above Ground”不会改变此距离。为 0 时光源不照亮任何内容。在按俯角 0（侧视）绘制的图像上，光斑位于屏幕上光源的周围，止于此半径。
    Source Radius光源发光部分（如火焰）的半径（世界单位）。半径越大，角色和物体上的明暗过渡越柔和，高光范围也越宽。火焰的光会在此半径内移动。
    形状光源在地面上的形状。“Ground Radius”延伸到形状边缘之外，“Inner Radius”使形状变圆润。
    形状长度光源在地面上的长度（世界单位），沿游戏对象的向上轴。如需调整照射方向，请在“Scene”视图中拖拽照射方向手柄，或旋转游戏对象。
    宽度光源在地面上的宽度（世界单位），垂直于游戏对象的向上轴
    内半径距地面上光源的点、线或矩形此距离（世界单位）以内的地面，亮度均匀。最大可设为“Ground Radius”，此时光斑边缘为硬边。
    内聚光角度在此角度（度）以内光为全强度，角度以游戏对象的向上轴为中心计算。如需调整照射方向，请在“Scene”视图中拖拽照射方向手柄，或旋转游戏对象。
    外聚光角度光到此角度（度）为止，角度以游戏对象的向上轴为中心计算。设为 360 时照亮四周。
    种类稳定的光源，或在播放模式下闪烁的火焰
    Flicker Amplitude火焰的光最多减弱多少。大多数时候减弱得更少。为 0 时光线保持稳定。
    Flicker Frequency火焰跳动的速度：蜡烛约为 10，篝火约为 3。“Flutter”决定火焰的闪烁中有多少按此速度变化。为 0 时保持稳定。
    颤动火焰的闪烁中，快速颤动相对于缓慢明暗起伏所占的比例。为 0 时只有缓慢的明暗起伏。
    Glow Renderers用于绘制此光源发光效果的渲染器。列表中发光的粒子不受此光源照亮；光源为“火焰”时，还会让这些渲染器的发光闪烁。
    特殊情况 › Excluded Objects此光源不照亮的对象，例如携带此光源的主角。列入游戏对象时，其下所有渲染器都不受此光源照亮；列入渲染器时，只排除该渲染器本身。光源在薄雾中的发光保持不变。
    特殊情况 › Is Prioritized进入摄像机视野的光源多于摄像机能用来照明的数量时，此光源排在所有未启用此选项的光源之前。
    特殊情况 › Scaled By Scene Lights启用时，此光源随 Scene Lights 的“Intensity”缩放。禁用时，即使 Scene Lights 的“Intensity”设为 0，光源也保持自身亮度。
    特殊情况 › 随用途的 Emission Scale 缩放按场景风格中此用途材质的“Emission Scale”缩放此光源的亮度。“无”保持光源自身的亮度。
    特殊情况 › Light On Its Object Shift此光源对所属对象的照亮程度，相对于光照风格的“Glow Light On Its Object”：0 保持风格的值，1 完全照亮，-1 完全不照亮。风格已完全照亮所属对象时，大于 0 的值不起作用；风格不照亮所属对象时，小于 0 的值不起作用。
    特殊情况 › Glow Parts Light Scale对此光源所属的对象，将光照风格的“Glow Parts Light On Its Object”乘以此值。1 保持风格的值，0 不添加任何光照。风格的值为 0 时，此值不起作用。

  • Lighting Setup

    检查器

    按其光照风格，用太阳或月光、天空、云和薄雾照亮场景。

    检查器中的设置

    美术绘制视角未设置“美术绘制视角”，因此每个精灵、Tilemap 和 Sprite Shape 都按其材质设定的角度绘制。请选择“俯视角”或“侧视角”，让它们都按同一角度绘制。
    风格 › 风格此 Lighting Setup 应用的光照风格：包括其材质、后处理和光照值
