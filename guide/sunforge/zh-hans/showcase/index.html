Showcase

Showcase 场景的打开方式、要求和移除方法。

本页内容
  • 系统要求
  • 打开 Showcase
  • 移除 Showcase

可游玩的森林场景，其中的每个角色和道具都是 Sun Forge 的烘焙输出；除了草和夜间出现的光灵，每个特效也都是烘焙输出。控制面板可以逐项切换功能。样本保留了烘焙美术资源所用的 3D 模型和预设，因此可以修改预设后重新烘焙。

系统要求

  • Sun Forge 和 Sun Forge 2D Lighting（二者会随 Showcase 一起安装），以及 Sun Forge 的 README 中“系统要求”下列出的全部要求。
  • 安装 Showcase 时，还会启用 UIElements 和 Vector Graphics 这两个内置包。
  • 构建 Android 或 iOS 版本时，为该平台所用的质量级别单独指定一份 URP 资产副本，并将该副本的 Render Scale（渲染缩放）设为 0.5。在 Android 或 iOS Player 中，场景的投射阴影以每单位 16 个纹素绘制，这个值由 Features 下 Cast Shadow Field Controller 对象上的 Phone Pixels Per Unit 设置。
  • 在 Windows 上，确保项目文件夹路径不超过 110 个字符。路径更长时，样本的部分文件会超出 Windows 的路径长度限制，导致导入失败。

打开 Showcase

请选择 Tools > Sun Forge > Open Showcase（工具 > Sun Forge > Open Showcase）。首次选择时，菜单项会将样本导入 Assets/Samples/Sun Forge Showcase/<version>/Showcase/ 并打开样本的场景；如果项目中还没有 Sun Forge Showcase，会先下载。如何试玩场景、如何重新烘焙其美术资源，请参阅该文件夹中的 README.md。

移除 Showcase

请先删除导入的 Assets/Samples/Sun Forge Showcase 文件夹，再在 Package Manager 窗口中移除 Sun Forge Showcase。样本的场景和预制件使用该包的脚本，因此先移除包会导致场景和预制件中出现缺失脚本。
