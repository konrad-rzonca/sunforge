从代码设置光照

从编辑器脚本为场景打光，并设置场景中的精灵。

本页内容
  • 预览设置
  • 为精灵指定用途
  • 按下 Performance 按钮
  • 保存并调整风格

编辑器脚本可以用某个风格为场景设置光照，像 Set Up for Lighting（设置光照）那样设置精灵，并完成 Fix All（全部修复）所做的操作：

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.Rendering;

SunForgeSceneLighting.SetUp(SunForgeShippedLightingStyle.Regular);

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.SetUpSprites(art))
    Debug.Log(line);

SunForgeSceneLighting.FixAll();

// On the Universal Renderer, the sort that Fix All skips. A Custom Axis is a choice of yours, so keep it.
if (GraphicsSettings.transparencySortMode != TransparencySortMode.CustomAxis)
{
    GraphicsSettings.transparencySortMode = TransparencySortMode.CustomAxis;
    GraphicsSettings.transparencySortAxis = new Vector3(0f, 1f, 0f);
}

IReadOnlyList<string> left = SunForgeSceneLighting.Check();
foreach (string message in left)
    Debug.LogWarning(message);

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • SetUp(SunForgeShippedLightingStyle.Regular, SunForgeLightingStyleVariant.Indoor) 会用 Regular 的“室内”变体设置场景。
  • 对于从侧面绘制的美术（例如平台跳跃游戏的美术），在设置精灵之前，将 SetUp 返回的 Lighting Setup 的 ViewElevationDegrees 设为 0。
  • SetUpSprites 执行与在 Set Up for Lighting 中单击 Apply（应用）相同的操作，并返回可供显示或写入日志的各行：会更改和保存什么、每个精灵设置成什么、哪些精灵不作改动，以及移动哪些轴心。传入文件夹时包括其下的每个精灵纹理和预制件，传入游戏对象时包括其下的每个精灵，传入精灵时包括显示该精灵的每个渲染器。该方法会立即保存轴心有移动的精灵、预制件、未打开的场景，以及已放置的美术因轴心移动而得到校正的每个已打开场景，这些保存无法撤消。该方法不添加 Lighting Setup，也不设置 Art View（美术绘制视角），因此请在调用 SetUp 并设置视角之后再调用该方法：视角决定每个精灵的设置方式，侧视画面不会移动任何轴心。
  • FixAll 应用 Fix All 所应用的每项修复，并且不打开任何窗口。会打开 Set Up for Lighting 的修复则不做：请用 SetUpSprites 设置这些精灵。该方法返回剩下的问题：只能由您自己修复的问题、Fix All 因会更改您所做的选择而跳过的每项修复，以及每条需用 SetUpSprites 修复的问题。请在场景中有了精灵后调用该方法，添加更多精灵后再调用一次，以添加这些精灵所需的内容，例如为投射阴影的精灵添加 Cast Shadow Field。Check 返回剩下的问题，不做任何更改。
  • 已加载的摄像机会保持自己的排序方式，直到其所在场景重新加载；Scene 视图会保持其排序方式，直到重新打开。要立即对它们应用该排序，还需在每个已加载的摄像机以及 SceneView.GetAllSceneCameras() 返回的每个摄像机上设置 transparencySortMode 和 transparencySortAxis。
  • 其他更改存在于内存中的已打开场景和项目资产里。请像最后两行那样，在脚本结束前保存场景和资产。

预览设置

要在保存任何内容之前查看这次设置会更改哪些内容，请用与应用时相同的参数预览。PreviewSpriteSetup 返回 SetUpSprites 所返回的各行，不做任何更改：

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.PreviewSpriteSetup(art))
    Debug.Log(line);

if (EditorUtility.DisplayDialog("Set Up for Lighting", "Set up the sprites the Console lists?", "Set Up", "Cancel"))
{
    SunForgeSceneLighting.SetUpSprites(art);
    EditorSceneManager.SaveOpenScenes();
}
  • 要像 Keep these pivots（保留这些轴心）那样让轴心保持原位，在两次调用中都传入 keepPivots: true。之后的运行会保留这一选择。

为精灵指定用途

要像每个精灵旁边的下拉菜单那样为精灵指定用途，请传入用途。先设置地板，其他精灵就会以地板为准来设置：

var floor = AssetDatabase.LoadAssetAtPath<Sprite>("Assets/Art/Floor.png");
SunForgeSceneLighting.SetUpSprites(new Object[] { floor }, SunForgeSpriteRole.Ground);
SunForgeSceneLighting.SetUpSprites(new Object[] { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") });
EditorSceneManager.SaveOpenScenes();
  • 用途会应用到传入的每个 Sprite Renderer、传入的每个游戏对象上的 Sprite Renderer，以及显示传入的精灵或精灵纹理的每个渲染器；传入文件夹时，则应用到其下的每个精灵纹理，以及其下每个预制件根上的 Sprite Renderer。已放置的预制件实例在其预制件中获得该用途。窗口会就某个精灵提问时（例如可能是地面的精灵），该调用会按窗口最初为其显示的用途设置该精灵，并由返回的各行提出问题。要在保存任何内容之前作答，请先预览，再按所选用途设置该精灵，就像上面的代码对地板所做的那样。
  • 在以下情况下，该调用会抛出 InvalidOperationException，且不做任何更改：窗口会要求保存某个在预制件模式中打开的预制件，或保存没有文件的场景；Set Up for Lighting（设置光照）无法运行（例如在播放模式下）；版本控制或只读文件阻止其运行。设置开始后，如果有文件未能保存或 Unity 抛出异常，该调用会抛出 IOException，其消息会说明哪些内容未设置。

按下 Performance 按钮

脚本可以用 ApplyPerformance 按下 Performance（性能）按钮，该方法返回其更改的每项设置：

var lit = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeSceneLighting.ApplyPerformance(lit, SunForgeLightingPerformanceButton.Balanced);
EditorSceneManager.SaveOpenScenes();

保存并调整风格

脚本可以保存自己的风格，并像 Look（外观）那样调整该风格（参见 调整风格）。以下脚本保存场景的外观，并启用 Pixel Outline：

var setup = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeLightingStyle style = SunForgeSceneLighting.SaveAsNewStyle(setup, "Assets/Lighting/My Style.asset");
IReadOnlyList<Material> materials = SunForgeLightingStyleEditing.EnsureOwnMaterials(style);

SunForgeLightingStyleSetting row = SunForgeLightingStyleSettings.Find("_SFPixelOutline");
foreach (Material material in materials)
{
    if (!material.HasProperty(row.Name))
        continue;

    Undo.RecordObject(material, "Set Pixel Outline");
    material.SetFloat(row.Name, 1f);
    if (row.Keyword != null)
        material.EnableKeyword(row.Keyword);
}

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • 路径上已有文件时，SaveAsNewStyle 会抛出异常，除非传入 overwrite: true 且该文件是光照风格。要调整以前保存的风格，请改用 AssetDatabase.LoadAssetAtPath<SunForgeLightingStyle> 加载该风格。
  • 对于后处理，EnsureOwnProfile 会为风格提供其配置文件的独立副本，并返回该副本。
  • SunForgeLightingStyleSettings.MaterialProperties 列出每一行，包括其属性的 Name、Tooltip 和 Group。行在 Look 中的标签是该属性在材质着色器中的描述：shader.GetPropertyDescription(shader.FindPropertyIndex(row.Name))。
  • 滑块的上下限取自着色器，即 shader.GetPropertyRangeLimits。SetFloat 不会把值限制在该范围内。
  • 带有 Keyword 的行需要两步：设置属性，并用 EnableKeyword 启用关键字或用 DisableKeyword 禁用关键字。带有 Switch 的行只在该名称所指的行启用时显示，就像 Pixel Outline Color 只在 Pixel Outline 启用时显示一样。
  • 每次更改前调用 Undo.RecordObject，场景就会立即绘制更改。不调用时，请在 Lighting Setup 上调用 Publish。
  • BakedArt 行不在 Look 中：请在对应的材质上设置。Orientation 行请保持不变。
