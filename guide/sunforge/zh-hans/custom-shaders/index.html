自定义着色器

从 Sun Forge 模板新建 Shader Graph，或用场景的风格、光源、阴影和薄雾照亮自己的 Shader Graph 或手写的精灵着色器。

Shader Graph

要从现成的 Shader Graph 开始，请选择 Assets > Create > Shader Graph > From Template（资产 > 创建 > Shader Graph > From Template），在 Sun Forge 下选择 Sun Forge Sprite Lit 或 Sun Forge Dissolve，然后执行下面的第 5 步。如果要自己搭建：

  1. 在 Sprite Unlit Shader Graph 中添加 Sun Forge > Sun Forge Sprite Lit。
  2. 将该节点的 Color 连接到 Base Color，将其 Alpha 连接到 Alpha。
  3. 在 Graph Settings 中启用 Disable Color Tint。如果不启用，Sprite Renderer 的 Color（颜色）为黑色的精灵会失去发光、边缘光、薄雾和受击闪白。
  4. 同样在 Graph Settings 中，将 Custom Editor GUI 设为 KonradRzonca.SunForge.Editor.Inspector.SunForgeStyledMaterialEditor。这样，使用该 Shader Graph 的材质在 Inspector 窗口中会显示与 Sun Forge 材质相同的预览和工具提示。
  5. 在 Project 窗口中右键单击该 Shader Graph，然后选择 Create > Material（创建 > 材质）。在每个使用该材质的渲染器上，选择 Add Component > Sun Forge > Lighting > Lighting Style Renderer（添加组件 > Sun Forge > Lighting > Lighting Style Renderer），并将其 Material（材质）设为自己的材质。在 Mesh Renderer、Skinned Mesh Renderer、Line Renderer 或 Trail Renderer 上，将纹理设置在材质上，不要通过自己的属性块设置，否则 Shader Graph 可能什么都不绘制。

这样，材质就带有精灵的五个纹理槽位和光照读取的材质属性，与 Sun Forge 的材质一样。请将材质上的 Role 设为 Sprite、Ground 或 Ground Clutter：精灵会采用该用途的外观，Cast Shadow Field 以及该精灵的 Lighting Style Renderer 也会沿用材质上的用途。

要在受光之前更改精灵（例如溶解特效或滚动的纹理），请用 Sun Forge Sprite Textures 和 Sun Forge Lit Color 代替 Sun Forge Sprite Lit。请将 Sun Forge Sprite Textures 的每个输出连接到 Sun Forge Lit Color 的同名端口，把自己的特效接在两者之间，然后按第 2 步的方式连接 Sun Forge Lit Color。要在某个坐标处采样这些纹理，请将该坐标连接到 UV。

Sun Forge Lit Color 端口 接收 未连接时
Albedo 精灵的颜色和 Alpha 白色
Normal 精灵的法线，例如来自 Sun Forge Sample Normal Map 的法线 Role 为 Ground 且 Bake Camera Elevation (Degrees) 大于 0 时为水平的地面，否则为朝向摄像机的表面
Mask 分别位于红、绿、蓝通道的金属度、平滑度和遮蔽：请保留 Sun Forge Sprite Textures 给出的 Alpha 无金属、平滑度为一半、无遮蔽
Emission 发光颜色，Alpha 中则是精灵从自身发光中受到的光：请保留 Sun Forge Sprite Textures 给出的 Alpha，使用自己的颜色时则将 Alpha 设为 1 不发光
Geometry 几何信息纹理的采样结果（参见下文的“几何信息纹理”） 站立的精灵是一张竖直的面片

地面覆盖物、Flat 风格的描边、贴合轮廓的边缘光、Point 过滤精灵的清晰高光，以及 Regular 和 Cinematic 下近处 Light Source 的平滑光照，都会读取每个像素周围精灵自身的纹理。如果 Shader Graph 绘制的形状不是精灵自身的图像，请将 Sun Forge Lit Color 上的 Shape From 设为 This Graph，这样，这些效果就不会读取精灵的纹理。

节点 提供
Sun Forge Sample Normal Map 自己的法线贴图，以与 Sun Forge 材质相同的方式读取，用于 Normal 端口
Sun Forge Mist 叠加了场景薄雾的颜色，用于 Sun Forge 节点不照亮的特效
Sun Forge Scene Light 太阳或月亮的方向和颜色、Lighting Setup 发布的天空和地面颜色，以及 Sun Forge 材质播放动画所依据的时间（秒）
  • 如果 Shader Graph 有自己的纹理属性，且其 Reference 为 _MainTex、_NormalMap、_MaskTex、_EmissionTex 或 _GeometryTex，那么一旦 Sun Forge 节点添加了相同 Reference 的槽位，Shader Graph 就会显示错误。请删除该属性，改从 Sun Forge Sprite Textures 获取其采样结果。
  • 一次绘制许多小精灵的网格（例如一阵金币雨），使用 SunForgeBatchSprites 后，其中每个精灵会按各自的轴心和高度受光。节点为此读取 UV 通道 SunForgeBatchSprites.UvChannel，因此请勿在该通道中存放自己的数据。
  • 如果 Color 和 Base Color 之间有 Sample Texture 2D、DDX、DDY 或 DDXY 节点，在 OpenGL 和 Vulkan 上可能会沿精灵边缘绘制出错误的颜色。请用 Sample Texture 2D LOD 采样这类纹理，或将其接入 Sun Forge Lit Color 节点的某个端口。
  • 在 Sprite Skin 上，将位置加上 Tangent Vector 后再经过第二个 Sprite Skinning 节点，然后将该结果减去蒙皮后的位置，连接到 Tangent 块，这样表面起伏会随骨骼一起转动。
  • 在 WebGL 2 和 OpenGL ES 3.0 上，一个着色器最多可以采样 16 张纹理。光照自身要采样 10 张，而 Sun Forge Sprite Lit 和 Sun Forge Sprite Textures 会采样精灵的五张纹理，因此使用其中任一节点的 Shader Graph 在这些平台上还能再采样一张。
  • 在 Direct3D 上，一个着色器最多可以使用 16 个采样器状态。光照自身要使用 6 个，因此使用 Sun Forge Sprite Lit 或 Sun Forge Sprite Textures 的 Shader Graph 还能再使用五个。通过同一个 Sampler State 节点采样的纹理共用一个采样器状态。

手写着色器

每个 include 文件都位于 Packages/com.konradrzonca.sunforge.lighting/Runtime/Shaders/，其文件头说明了用法。

include 文件 用途
SunForgeLitColor.hlsl 与 Sun Forge Lit Color 节点一样为着色器照明。
SunForgeStyleKeywords.hlsl 为着色器的每种风格提供一个变体，并为风格 Quality（质量）部分的每个选项提供一个变体（参见 风格 › 风格质量）。请在 Pass 的 pragma 旁用 #include_with_pragmas 包含此文件。
SunForgeNormalDecode.hlsl 与自带材质一样读取法线贴图的采样结果，用它来照明，或自己显示或测量法线。
SunForgeHeightDecode.hlsl 与自带材质一样，声明几何信息纹理，并读取其采样结果的高度和前缘，或读取投影高度纹理采样结果的高度。
SunForgeHeightRamp.hlsl 与 Texture View（纹理视图）在 Geometry（几何信息）下一样，用颜色表示高度。
SunForgeHeightRampBar.hlsl 在名为 Height Ramp 的 Pass 中绘制上述高度色带的图例条，该 Pass 由 SunForgeHeightRamp.DrawBar 运行。
SunForgeMist.hlsl 绘制场景的薄雾（例如在全屏雾中）。
SunForgeHitFlash.hlsl 绘制受击闪白。
SunForgeBakedLight.hlsl 从自发光纹理的 Alpha 中，读取精灵从自身发光中受到的光。
SunForgeWalkBands.hlsl 对于 Sun Forge 围绕角色拆分的道具，只绘制其中属于自己着色器的那一块。
SunForgeRendererBakeValues.hlsl 读取精灵绘制时使用的角度和其他投影值，以及精灵离地面的高度。
SunForgeLightingGlobals.hlsl 读取 Lighting Setup 发布的内容。

要从脚本发布自己的光照，请使用 SunForgeLightingPublisher。

在 WebGPU 上，如果着色器按运行时计算的索引读取 static const 数组，或以同样方式选取向量的分量（例如 v[i]），Windows 上的 Chrome 加载该着色器会很慢。数组较大时，加载可能需要数分钟，之后 Player 可能丢失 GPU 设备并停止绘制。请改为直接计算该值、以常量索引读取数组，或用比较来选取分量，例如 dot(v, float4(i == uint4(0, 1, 2, 3)))。Custom Function 节点中的 HLSL 也是如此。

在 WebGL 2 上，Windows 上的 Chrome 会把只含一个数组且该数组有 50 个或更多元素的常量缓冲区计为一张纹理。如果着色器的纹理和这类缓冲区加起来超过 16 个，该着色器首次绘制时，页面会停止绘制。请在数组后面再添加一个值，该值无需读取。

缺少纹理的精灵

精灵没有法线贴图、遮罩、自发光或几何信息纹理时，着色器会采样材质在该槽位上的纹理；材质也没有时，则采样属性的默认值。Sun Forge Sprite Textures 添加的槽位已带有正确的默认值。在手写着色器中，使用 Unity 的默认值时，这样的精灵会绘制出错，因此请设置每个槽位：

纹理 属性 设置 否则精灵会
法线贴图 _NormalMap 以 SunForge_FlatNormal.png 为默认值 像倾斜了一样受光
遮罩 _MaskTex 以 SunForge_NeutralMask.png 为默认值 像抛光金属一样受光，或金属、平滑度、遮蔽出错
自发光 _EmissionTex "black" 发光呈白色
几何信息 _GeometryTex "black" 高度等于整个范围
  • 法线贴图和遮罩：这两张纹理都位于 Sun Forge 2D Lighting 包的 Runtime/Materials 文件夹中。选择着色器，然后在 Inspector 窗口的 Default Maps 下设置这两张纹理。
  • 自发光和几何信息：将属性声明为 "black"，例如 _GeometryTex ("Geometry Texture", 2D) = "black" {}。

如果材质的 _NormalMap 或 _MaskTex 上没有纹理，Check Setup（检查设置）会报告该材质，其修复操作会绑定对应的纹理。如果材质的 _GeometryTex 带有高度，Check Setup 也会报告该材质。

自己的着色器

请以 Sun Forge Sprite Lit 节点为基础搭建 Shader Graph，或以 Sun Forge Sprite Textures 和 Sun Forge Lit Color 为基础搭建（参见 自定义着色器 › Shader Graph）。然后按以下两种方式之一使用：

  • 用在烘焙出的精灵上。用 Add Component > Sun Forge > Lighting > Lighting Style Renderer（添加组件 > Sun Forge > Lighting > Lighting Style Renderer）在其 Baked Renderer Binding 旁添加 Lighting Style Renderer，并将其 Material（材质）设为自己的材质。精灵保留烘焙时的值。
  • 用作烘焙的材质。将该材质选为烘焙的 Prefab Material（预制件材质，Advanced（高级）视图）。烘焙会设置精灵的烘焙值，例如其 Bake Camera Elevation (Degrees)，预制件无需 Lighting Style Renderer。

无论 Alpha 如何，烘焙出的特效的粒子都会把自己的光叠加到其后方的内容上：

  • 如果 Shader Graph 的 Blending Mode 为 Premultiply，且 Premultiplied 连接到 Base Color，就会从特效的自发光纹理中绘制这部分光。使用其他 Blending Mode 时，这部分光会烘焙进特效的颜色。
  • 如果风格的 Sprite 材质无法绘制这部分光，烘焙出的特效的 Particles 子对象会保留烘焙时使用的材质。
  • 如果手写着色器声明了 _SFEmissionScale 和 _SFEmissionOutsideAlpha 并以 One OneMinusSrcAlpha 混合，就会绘制这部分光。具体做法见 SunForgeLitColor.hlsl 的文件头。
