道具中的角色

让角色站在灌木丛中，灌木丛位于角色脚底前方的部分绘制在角色之上。

本页内容
  • 修正单个预制件
  • 保持完整的道具
  • 用自己的着色器拆分

站在灌木丛中的角色可以绘制在灌木丛的各部分之间：位于角色脚底前方的部分绘制在角色之上，其余部分绘制在角色后面。要启用此功能：

  1. 在 Project Settings > Sun Forge（项目设置 > Sun Forge）中，为每个需要在构建中拆分道具的平台勾选 Per-Pixel Prop Sorting（逐像素道具排序）。道具在播放模式下和构建中都会拆分，播放模式采用当前活动平台的设置。
  2. 烘焙。类型模板的 Pixel Sort（像素排序，Archetypes（类型模板）选项卡 GAMEPLAY（玩法）部分，Advanced（高级）视图）决定哪些预制件是角色、哪些是道具。设为 Automatic（自动）时，预制件在播放动画或带有让其移动的行为时为角色，否则为道具。

角色会获得 Pixel Sort Character 组件，道具的主体精灵则会在其 Baked Renderer Binding 上勾选 Split Around Characters（围绕角色拆分）。脚本（例如选项菜单）可以用 SunForgePixelSort.Enabled 在本次运行的剩余时间内启用或禁用拆分。

修正单个预制件

目标 操作
让道具保持完整 在其主体精灵上取消勾选 Split Around Characters（围绕角色拆分）。重新烘焙会保留这一选择
让只在原地摆动的预制件（例如风中的蕨类）围绕角色拆分 取消勾选其 Pixel Sort Character。应取消勾选而不是移除：重新烘焙会让其保持未勾选，并会加回已移除的组件
让道具在高于或低于角色碰撞器前缘的位置拆分 在 Pixel Sort Character 上禁用 Automatic Depth（自动深度），然后输入 Depth（深度）
让道具围绕自己搭建的角色，或围绕由自己的脚本移动的烘焙道具拆分 为其添加 Pixel Sort Character：Add Component > Sun Forge > Pixel Sort Character（添加组件 > Sun Forge > Pixel Sort Character）
在通过 z 坐标或自身排序点绘制在道具前方的角色周围，让道具保持完整 取消勾选其 Pixel Sort Character

保持完整的道具

只要有透视摄像机绘制道具所在的图层，道具在所有摄像机中都完整绘制；道具与角色的排序图层、顺序或渲染队列不同时，道具也完整绘制。同一时间只有少数道具会拆分。因其他原因保持完整的道具，会在其 Baked Renderer Binding 上说明原因。

Lighting Setup 上的 Check Setup（检查设置）会报告透视摄像机，以及各部分无法沿其排序的排序轴：y 和 z 符号相反的 Custom Axis（自定义轴）。

用自己的着色器拆分

用自己的着色器绘制的道具，只有着色器绘制了自己负责的那部分时才会拆分：

  • Shader Graph：将 Sun Forge Sprite Lit 或 Sun Forge Lit Color 节点连接到 Shader Graph 的 Alpha，然后在道具的主体精灵上勾选 Split Around Characters（围绕角色拆分）。如果道具的材质是带有其中任一节点的 Shader Graph，烘焙不会勾选该选项，因为 Alpha 未经过该节点的 Shader Graph 会在角色站立处把道具绘制两次。
  • 手写着色器：按照 SunForgeWalkBands.hlsl 文件头的说明操作（参见 自定义着色器 › 手写着色器）。着色器不参与拆分的道具会完整绘制。
