Pixel art

Bake pixel art that the scene's lighting lights, and draw it with the Pixel Perfect Camera.

To bake pixel art that the scene's lighting lights:

  1. In the archetype's CAMERA section, set Pixels Per Unit to your art's density, such as 32. Use the same value on every archetype the scene uses, ground tiles included.
  2. In the Advanced view, in the archetype's QUALITY section, turn off Supersampling and set Animation Frame Rate to a low rate, such as 12.
  3. In the archetype's OUTPUT section (Advanced view), set Filter Mode to Point and turn off Generate Mip Maps.
  4. In the archetype's SHADOW section (Advanced view), set Softness to 0, and under Ground-Projected set Resolution Scale to 1, so each shadow pixel is a sprite pixel.
  5. For an outline, set the bake's Prefab Material (Advanced view) to Regular with Pixel Outline or Cinematic with Pixel Outline. To outline every sprite in a style, turn on Pixel Outline on the style's Sprite material instead (Tune a style).
  6. Bake, and add a Pixel Perfect Camera to the scene's camera (Pixel art › Pixel Perfect Camera).
  7. Clear Post Processing Enabled on the Lighting Setup, because bloom blurs the pixels. This turns off the style's whole post-processing.

Pixel Perfect Camera

URP's Pixel Perfect Camera draws each sprite pixel as a block of whole screen pixels. Set its Assets Pixels Per Unit to your sprites' Pixels Per Unit. A sprite at another Pixels Per Unit, or a scaled one, draws pixels of another size.

The camera works under the 2D Renderer and the Universal Renderer. Grid Snapping set to Upscale Render Texture works under the 2D Renderer only.

Grid Snapping Sprites move in steps of Lights, mist and cast shadows change
None Screen pixels From one screen pixel to the next, so they fall smoothly across a sprite pixel
Pixel Snapping Whole sprite pixels From one screen pixel to the next, so they fall smoothly across a sprite pixel
Upscale Render Texture Whole sprite pixels Once per sprite pixel, like the art, because the scene renders at the camera's Reference Resolution and is scaled up
