메뉴

Sun Forge에서 Unity에 추가하는 모든 메뉴 항목과 단축키, 그리고 각 항목이 하는 일.

메뉴 바의 도구 메뉴

Sun Forge

  • Bake Window

    Alt / OptionShiftB

    모델을 스프라이트 시트와 바로 쓸 수 있는 프리팹으로 만드는 Bake Window를 엽니다.

    첫 베이크

  • Set Up for Lighting

    목록에 표시되는 변경 사항을 확인하면, 무엇을 선택했든 열린 씬 또는 프리팹 모드에서 열린 프리팹을 비춥니다. 그 안의 스프라이트에 조명과 드리운 그림자를 적용하고, Lighting Setup 컴포넌트가 없는 씬에는 그 컴포넌트를 추가합니다.

  • Open Showcase

    Sun Forge로 베이크한 플레이 가능한 씬인 쇼케이스를 엽니다. 프로젝트에 없으면 먼저 다운로드하고 임포트합니다.

    쇼케이스 › 쇼케이스 열기 첫 베이크 › 쇼케이스

  • Guide

    이 가이드를 브라우저에서 엽니다.

계층 구조 창에서 마우스 오른쪽 버튼 클릭

메뉴 바의 게임 오브젝트 메뉴에도 있음

Sun Forge

  • Open in Bake Window

    선택한 베이크된 액터의 베이크, 또는 선택한 씬 오브젝트의 프리팹이나 모델을 Bake Window에서 엽니다.

  • Set Up for Lighting

    목록에 표시되는 변경 사항을 확인하면, 선택한 오브젝트의 스프라이트, 또는 열린 씬이나 프리팹 모드에서 열린 프리팹의 스프라이트에 조명과 드리운 그림자를 적용합니다. Lighting Setup 컴포넌트가 없는 씬에는 그 컴포넌트를 추가합니다.

    첫 베이크 씬 설정 광원 › 프로젝트의 Light 2D 광원 사용 사이드 뷰

  • Camera Follow

    선택한 오브젝트를 따라가도록 메인 카메라에 Camera Follow 컴포넌트를 추가합니다. 씬에 메인 카메라가 없으면 새로 만듭니다.

  • Cast Shadow Field

    스프라이트의 그림자를 지면과 다른 스프라이트에 드리우는 Cast Shadow Field 컴포넌트를 추가합니다.

  • Canopy Shade

    나무 윗부분 아래의 지면과 스프라이트에 그늘을 드리우는 Canopy Shade 컴포넌트를 추가합니다.

    그림자 › Canopy Shade

Sun Forge › Light Source

  • Light

    일정한 빛을 내는 원형 Light Source 컴포넌트를 씬에 추가합니다.

    씬 설정 광원 › 광원 추가

  • Spot Light

    화면 아래쪽을 향해 원뿔 모양으로 비추는 Light Source 컴포넌트를 추가합니다.

  • Line Light

    선을 따라 빛을 내는 Light Source 컴포넌트를 추가합니다.

  • Rectangle Light

    직사각형 영역에서 빛을 내는 Light Source 컴포넌트를 추가합니다.

Sun Forge › Light Source › Fire

  • Candle

    촛불의 불꽃처럼 빠르게 깜박이는 작은 Light Source 컴포넌트를 추가합니다.

  • Torch

    횃불의 불꽃처럼 깜박이는 Light Source 컴포넌트를 추가합니다.

    사이드 뷰

  • Campfire

    모닥불처럼 깜박이며 낮게 놓인 밝은 Light Source 컴포넌트를 추가합니다.

  • Fireplace

    벽난로처럼 깜박이며 화면 아래쪽을 향해 반원 모양으로 비추는 Light Source 컴포넌트를 추가합니다.

Sun Forge › Light Source › Lamps

  • Lantern

    랜턴처럼 손 높이에서 따뜻한 빛을 일정하게 내는 Light Source 컴포넌트를 추가합니다.

  • Street Lamp

    가로등처럼 높은 곳에서 빛이 닿는 영역을 고르게 밝히는 Light Source 컴포넌트를 추가합니다.

  • Neon Tube

    네온관처럼 선을 따라 분홍색 빛을 내는 Light Source 컴포넌트를 추가합니다.

Sun Forge › Light Source › Magic

  • Crystal

    빛나는 수정처럼 지면 가까이에서 차가운 색의 빛을 내는 작은 Light Source 컴포넌트를 추가합니다.

  • Magic Orb

    마법 구슬처럼 지면 위 높은 곳에서 보라색 빛을 내는 Light Source 컴포넌트를 추가합니다.

Sun Forge › Light Source › Windows and Doors

  • Window

    창문처럼 차가운 색의 빛을 직사각형으로 비추는 Light Source 컴포넌트를 추가합니다.

  • Moonlit Window

    창문으로 들어오는 달빛처럼 옅은 푸른빛을 직사각형으로 비추는 Light Source 컴포넌트를 추가합니다.

  • Doorway

    불 켜진 출입구처럼 따뜻한 색의 빛을 직사각형으로 비추는 Light Source 컴포넌트를 추가합니다.

Sun Forge › Showcase

  • Make Flyer

    Makes each selected baked actor fly like the Showcase scene's bats.

  • Make Butterfly

    Makes each selected baked actor flit, bask and roost like the Showcase scene's butterflies.

  • Make Animal

    Makes each selected baked actor roam like the Showcase scene's animals.

프로젝트 창에서 마우스 오른쪽 버튼 클릭

메뉴 바의 에셋 메뉴에도 있음

Sun Forge

  • Open in Bake Window

    선택한 모델, 프리팹, 베이크 프리셋, 아키타입 라이브러리, 베이크 출력 또는 출력 폴더를 Bake Window에서 엽니다. 선택한 항목을 열 수 없으면 마지막으로 사용한 상태 그대로 창을 엽니다.

  • Set Up for Lighting

    목록에 표시되는 변경 사항을 확인하면, 선택한 스프라이트와 프리팹, 그리고 선택한 폴더 안의 스프라이트와 프리팹에 조명과 드리운 그림자를 적용합니다.

프로젝트 창의 + 버튼

마우스 오른쪽 버튼 메뉴의 생성 메뉴에도 있음

Sun Forge

  • Physics World

    베이크된 액터가 함께 쓰는 2D 물리 월드를 담습니다. 이 에셋은 아키타입의 [물리] 섹션([고급] 보기)에서 선택합니다.

    플랫포머와 물리 › 물리 월드

  • Behavior Script

    Bake Window가 베이크된 프리팹에 추가할 비헤이비어 스크립트를 선택한 폴더에 생성합니다.

    비헤이비어 › 비헤이비어 작성 플랫포머와 물리 › 사이드 뷰 게임

  • Lighting Style

    선택한 폴더에 새 조명 스타일을 생성합니다. Regular 스타일의 사본이며, 자체 머티리얼과 포스트 프로세싱을 직접 조정할 수 있습니다.

인스펙터 창에서 컴포넌트의 ⋮ 버튼

컴포넌트 이름을 마우스 오른쪽 버튼으로 클릭해도 열림

Baked Prefab › Reset Anchor

  • Collider

    Baked Prefab 컴포넌트의 콜라이더를 베이크가 정한 크기와 위치로 되돌립니다.

  • Glow Point

    Baked Prefab 컴포넌트의 발광 지점과 발광 광원을 베이크가 배치한 위치로 되돌립니다.

  • Health Bar

    Baked Prefab 컴포넌트의 체력 바를 베이크가 배치한 위치로 되돌립니다.

  • Hitbox

    Baked Prefab 컴포넌트의 히트박스를 베이크가 정한 크기와 위치로 되돌립니다.

  • Overhead Anchor

    Baked Prefab 컴포넌트의 머리 위 앵커를 베이크가 배치한 위치로 되돌립니다.

  • VFX Box

    Baked Prefab 컴포넌트의 VFX 박스를 베이크가 정한 크기와 위치로 되돌립니다.

Sprite Renderer

  • Set Up for Lighting

    목록에 표시되는 변경 사항을 확인하면, 이 스프라이트의 오브젝트에 조명과 드리운 그림자를 적용합니다.

단축키

  • Sun Forge › Bake Window › Save

    Ctrl / CmdS

    Bake Window에서 열린 탭의 프리셋이나 아키타입 라이브러리를 저장합니다. 탭의 [저장] 버튼과 같습니다.

  • Sun Forge › Bake Window › Save As

    Ctrl / CmdShiftS

    Bake Window에서 열린 탭의 프리셋이나 아키타입 라이브러리를 새 에셋으로 저장합니다.

  • Tools › Sun Forge › Bake Window

    Alt / OptionShiftB

    모델을 스프라이트 시트와 바로 쓸 수 있는 프리팹으로 만드는 Bake Window를 엽니다.
