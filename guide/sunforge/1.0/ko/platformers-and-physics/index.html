플랫포머와 물리

직접 만든 스크립트로 사이드 뷰에서 베이크된 액터를 걷고 점프하게 하고, 베이크된 프리팹을 로우레벨 2D 물리 월드에서 실행합니다.

사이드 뷰 게임

Movement, Wander, Melee Attacker 비헤이비어는 날거나 헤엄치는 것처럼 중력 없이 액터를 화면의 좌우뿐 아니라 위아래로도 움직입니다. Movement 비헤이비어가 있는 액터를 좌우로만 걷게 하려면 ReadsInput 프로퍼티를 끄고, y 값이 0인 방향으로 매 프레임 SunForgeMovement.Walk(direction, Time.deltaTime) 메서드를 호출하세요.

플랫포머의 베이크 설정은 사이드 뷰 › 사이드 뷰 베이크을 참조하세요. 플랫포머의 액터와 바닥에 붙어 있어야 하는 액터는 직접 만든 스크립트로 움직이세요.

  1. Assets > Create > Sun Forge > Behavior Script(에셋 > 생성 > Sun Forge > Behavior Script) 메뉴로 스크립트를 만들고, [SunForgeBehavior] 특성에 movesActor: true 인수를 추가한 뒤, GAMEPLAY(게임플레이) 섹션(Advanced(고급) 보기)에 Movement, Wander, Melee Attacker 비헤이비어 대신 이 스크립트를 넣습니다. 그러면 베이크가 Rigidbody 2D 컴포넌트의 Linear Damping(선형 댐핑) 필드를 0으로 설정합니다. 프리팹에 직접 추가하는 스크립트라면 Linear Damping 필드를 0으로 설정해야 합니다.
  2. 액터에 중력을 줍니다. Rigidbody 2D의 Gravity Scale(중력 스케일) 필드 값을 올리면 되며, 이 값은 다시 베이크해도 유지됩니다. Physics World 에셋을 쓸 때는 그 월드 정의에서 중력을 설정합니다.
  3. 스크립트에서는 입력에 따라 Rigidbody 2D의 수평 속도를 설정하고, 수직 속도는 점프할 때만 설정합니다. Physics World 에셋을 쓸 때는 액터의 SunForgePhysicsBody 컴포넌트의 Velocity 프로퍼티에 값을 씁니다.
  4. 가만히 서 있을 때를 포함해 매 프레임, 액터가 걷는 방향과 Time.deltaTime 값을 넘겨 SunForgeFacing.FaceUnlessHeld 메서드를 호출합니다. SunForgeActorAnimation.Of(this).SetMoveSpeed 메서드도 걷는 동안에는 1, 멈춰 있을 때는 0을 넘겨 호출합니다. While Walking(걷는 동안) 필드를 Keep Walking(걷기 유지) 옵션으로 설정한 Shooter 비헤이비어에는 두 호출이 모두 필요합니다. SetMoveSpeed 호출이 없으면 쏠 때마다 Attack 애니메이션을 재생하고, FaceUnlessHeld 호출이 없으면 액터가 한쪽으로 쏘면서 반대쪽으로 걸을 때 걷기 애니메이션이 거꾸로 재생되지 않습니다.
  5. 점프 애니메이션을 재생하려면 같은 SunForgeActorAnimation 객체에서 SetBool(Animator.StringToHash("Jump"), true) 메서드를 호출합니다. 이 호출은 false로 설정할 때까지 이름이 Jump인 Loop While Bool(부울 참일 때 반복) 항목을 재생합니다.
  6. Shooter 비헤이비어는 Space 키로도 발사합니다. 스크립트가 Space 키로 점프한다면 Shooter의 Reads Input(입력 사용) 토글을 끄고, AimAt 메서드나 AimDirection 프로퍼티로 조준한 뒤, 스크립트에서 Fire 메서드를 호출합니다.

물리 월드

베이크된 프리팹을 Unity의 로우레벨 2D 물리 월드에서 실행하려면 Assets > Create > Sun Forge > Physics World(에셋 > 생성 > Sun Forge > Physics World) 메뉴로 Physics World 에셋을 만들고, 인스펙터에서 월드, 바디, 모양 정의를 설정한 뒤, 아키타입의 PHYSICS(물리) 섹션(Advanced(고급) 보기)에서 이 에셋을 지정하세요. 그러면 Collider Shape(콜라이더 모양) 필드가 설정된 각 프리팹에 SunForgePhysicsBody 컴포넌트가 생깁니다.

베이크 데이터로 물리 모양을 직접 만들려면 SunForgeBakedPrefab.Anchors 프로퍼티를 읽고, SunForgeBakedPrefab.AnchorsChanged 이벤트가 발생할 때마다 다시 읽으세요. 콜라이더의 Follows Facing(바라보는 방향 연동) 토글(Archetypes(아키타입) 탭, PHYSICS 섹션, Advanced 보기)이 켜진 액터는 다른 방향으로 돌 때 콜라이더가 바뀝니다.
