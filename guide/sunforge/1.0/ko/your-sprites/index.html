직접 그린 스프라이트

직접 그린 스프라이트에 노멀 맵, 발광, 금속을 지정하고, 똑바로 서 있지 않은 스프라이트에는 지오메트리 텍스처를 그립니다.

스프라이트 텍스처

직접 그린 스프라이트에 텍스처를 주는 방법은 두 가지입니다.

Sun Forge가 작성하게 하기

  1. Set Up for Lighting 메뉴로 스프라이트를 설정한 뒤, 스프라이트의 오브젝트를 선택하고 Lighting Style Renderer 컴포넌트에서 Glow, Surfaces and Edges(발광, 표면, 가장자리) 섹션을 엽니다.
  2. 발광할 색마다 Add Glow Color(발광 컬러 추가) 버튼을 클릭한 다음, 스프라이트에서 그 색을 클릭합니다.
  3. 금속처럼 빛날 색마다 Add Surface Color(표면 컬러 추가) 버튼을 클릭한 다음, 스프라이트에서 그 색을 클릭합니다.
  4. Glows(발광 부분) 그림과 Shines(광택 부분) 그림을 확인합니다. 두 그림은 고른 색과 일치하는 부분을 보여 주고 나머지는 회색으로 표시합니다. 더 넓은 부분이 일치하게 하려면 그 색의 Tolerance(허용치) 슬라이더 값을 높입니다.
  5. 가장자리를 둥글게 하려면 Round Edges(둥근 가장자리) 토글을 켭니다.
  6. Write Textures(텍스처 작성) 버튼을 클릭합니다.
  7. 발광 부분이 그 둘레의 스프라이트와 지면을 비추게 하려면 Glow Light(발광 광원) 행의 Add(추가) 버튼을 클릭합니다.

직접 만든 텍스처 가져오기

  1. 각 텍스처를 스프라이트의 텍스처 옆에 PNG로 저장하고, 이름은 아래 표와 같이 짓습니다. 여기서 <sheet> 부분은 그 텍스처의 확장자를 뺀 파일 이름입니다.
  2. Set Up for Lighting 메뉴를 실행하거나, 스프라이트의 Lighting Style Renderer 컴포넌트에서 Change Setup(설정 변경) 버튼을 클릭합니다.
  3. Sprites(스프라이트) 섹션에서 그 스프라이트의 행에 찾은 파일의 이름이 각각 나옵니다. Apply(적용) 버튼을 클릭해 그 파일을 스프라이트에 지정합니다. 그 종류의 텍스처가 이미 있는 스프라이트는 기존 텍스처를 유지합니다.

Unity의 Sprite Editor(스프라이트 에디터) 창에 있는 Secondary Textures(보조 텍스처) 모듈에서 직접 연결할 수도 있습니다.

각 텍스처의 내용

스타일 머티리얼은 스프라이트에 다음 텍스처가 있으면 읽습니다.

머티리얼 슬롯 파일 보조 텍스처 이름 채널
Normal Map <sheet>_Normal.png _NormalMap 위에서 본 모습으로 그린 씬의 Ground 역할에서는 탑다운으로 그린 노멀 맵. 그 밖에는 서 있는 스프라이트와 같은 각도에서 그린 노멀 맵. 스프라이트 바깥의 텍셀은 평평한 노멀인 128, 128, 255로 채우세요. 그렇지 않으면 스프라이트 가장자리가 어둡게 표시됩니다. SunForgeNormalDecode.hlsl 파일의 SFUnpackNormal 함수나 셰이더 그래프의 Sun Forge Sample Normal Map 노드로 읽으세요. 둘 다 128을 기울기 없는 값으로 읽습니다
Mask <sheet>_MaskTex.png _MaskTex R 메탈릭, G 평활도, B 앰비언트 오클루전. Sun Forge가 렌더링한 스프라이트에서는 A 태양 빛이 닿는 정도. 선형
Emission <sheet>_Emission.png _EmissionTex 강도 1에서의 발광 컬러, sRGB. Sun Forge가 렌더링하거나 작성한 텍스처의 A는 스프라이트가 자체 발광에서 받는 빛의 양
Geometry Texture <sheet>_Geometry.png _GeometryTex R 피벗 위의 높이. 피벗에서 검은색이고 밝을수록 높습니다. A는 선택 사항입니다(지오메트리 텍스처 포맷 참조). 선형이며 크런치 압축을 쓰지 않습니다

_MaskTex 텍스처에 채널 배치가 다른 마스크가 있는 스프라이트는 조명이 잘못 표시됩니다.

씬 뷰에서 텍스처 보기

씬 뷰의 Sun Forge Gizmos(Sun Forge 기즈모) 패널 맨 아래에 있는 Texture View(텍스처 보기) 행을 켜고 텍스처 하나를 고르세요.

  • 뷰에는 릿 또는 언릿 URP 머티리얼이 그리는 것만 표시되므로, Sprites/Default 셰이더를 쓰는 스프라이트, 드리운 그림자, 선, 텍스트는 보이지 않습니다.
  • Geometry(지오메트리) 옵션에서는 높이가 없는 텍셀이, Emission(이미션) 옵션에서는 이미션이 없는 스프라이트가 어두운 회색으로 표시됩니다.

지오메트리 텍스처 그리기

똑바로 서 있는 스프라이트에는 지오메트리 텍스처가 필요 없습니다. 탁자 상판, 수레, 누워 있는 인물처럼 똑바로 선 카드가 아닌 스프라이트에 그리세요.

  1. 스프라이트가 덮는 모든 픽셀을 회색으로 칠합니다. 지면에서는 검은색이고, 높이 서 있을수록 밝습니다. 시트에서 어떤 스프라이트를 똑바로 선 카드로 두려면 그 스프라이트를 투명하게 남겨 둡니다.
  2. 스프라이트의 피벗을 수레의 앞바퀴처럼 앞쪽 가장자리가 지면과 만나는 곳에 둡니다. 풀은 피벗보다 앞쪽에서만 스프라이트를 덮어 그립니다. 탁자 위의 램프처럼 다른 스프라이트 위에 서 있는 스프라이트는 피벗을 탁자와 만나는 곳에 두고, 그 스프라이트의 Lighting Style Renderer 컴포넌트에서 Height Above Ground(지면 위 높이) 필드를 탁자의 높이로 설정합니다.
  3. PNG를 시트 옆에 <sheet>_Geometry.png 이름으로 내보냅니다.
  4. Set Up for Lighting 메뉴를 실행합니다. 스프라이트의 행에 그 텍스처의 이름이 나오고, Apply(적용) 버튼이 텍스처를 임포트해 스프라이트에 지정합니다.
  • 픽셀 단위로 작업하려면 회색 값을 height in pixels * 255 / (Pixels Per Unit * range) 식으로 구하세요. 여기서 range 값은 머티리얼의 Height Range (World Units) 프로퍼티 값입니다. Pixels Per Unit 32와 기본 범위 8에서는 회색 한 단계가 약 1픽셀입니다.
  • 굴뚝처럼 수직으로 서 있는 부분이 그림에서 N픽셀 높이라면 실제 높이는 N / cos(elevation) 픽셀입니다. 여기서 elevation 값은 Lighting Setup 컴포넌트의 Art View(아트 시점) 행에 설정한 고도각입니다.
  • Point 필터링에서는 스프라이트 주변에 무엇이 있든 상관없습니다. 필터링하는 시트는 내보낸 파일의 배경이 투명해야 합니다. 투명하게 남겨 둔 부분이 있으면 알파가 있는 PNG가 필요합니다.
