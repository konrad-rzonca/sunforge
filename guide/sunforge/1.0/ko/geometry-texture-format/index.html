지오메트리 텍스처 포맷

지오메트리 텍스처를 읽거나 쓰는 셰이더나 도구를 직접 만들 때 알아야 할, 각 채널에 담긴 내용.

지오메트리 텍스처는 스프라이트 픽셀마다 피벗 위의 높이를 빨강에, 스프라이트가 지면과 만나는 위치를 알파에 담습니다. 지오메트리 텍스처를 그리는 방법은 직접 그린 스프라이트 › 지오메트리 텍스처 그리기을 참조하세요.

포맷

  • 피벗 위의 높이는 R * range * scale입니다. 검은색은 피벗의 높이, 흰색은 범위의 높이이며, 피벗보다 아래에 있는 것은 없습니다.
  • range 값은 렌더러에 있는 컴포넌트가 범위를 설정하면 그 범위이고, 그렇지 않으면 머티리얼의 Height Range (World Units) 프로퍼티 값입니다. 이 값은 SunForgeRendererBakeValues.hlsl 파일의 SFBakeHeightRange 함수가 읽습니다. scale 값은 오브젝트의 스케일입니다.
  • 알파가 8/255 이상인 텍셀에는 높이가 있습니다. 알파가 그보다 낮은 텍셀에는 높이가 없습니다. 그런 텍셀에서 서 있는 스프라이트는 똑바로 선 평평한 카드로, 지면 스프라이트는 높이 0으로 그립니다.
  • 초록과 파랑은 예약되어 있고 어떤 머티리얼도 읽지 않으므로, 빨강이 같으면 회색 맵, 빨강만 있는 맵, 단일 채널 맵을 똑같이 읽습니다. 직접 만든 셰이더에서 초록이나 파랑을 읽지 마세요.
  • 맵은 PNG 같은 무손실 포맷으로 저장하세요. 텍스처는 선형이고, 크런치 압축을 쓰지 않으며, 시트와 같은 방식으로 필터링합니다.
  • 빨강을 그대로 유지하고 알파가 4/255 이하로만 달라지는 텍스처 포맷은 모두 사용할 수 있습니다. 압축 포맷에서는 구분되는 높이의 수가 줄어들므로, Check Setup(설정 검사) 버튼은 칠한 맵을 압축하지 않고 임포트합니다.

Sun Forge의 그라운드 커버는 알파를 스프라이트가 지면에서 차지하는 영역의 앞쪽 가장자리로도 읽습니다. 앞쪽 가장자리는 스프라이트가 피벗에서 얼마나 앞쪽에서 지면과 만나는지를 나타냅니다. 풀은 그 가장자리보다 앞쪽에서만 스프라이트를 덮어 그립니다. 그라운드 커버를 쓰지 않는다면 이 표는 무시하세요.

알파 앞쪽 가장자리
243/255~255/255 피벗 위치
242/255~27/255 피벗에서 앞쪽으로 범위의 (n / 25)^2배. 여기서 n 값은 (247 - a) / 9 값을 가장 가까운 정수로 반올림한 값이고, a 값은 0~255의 알파입니다
8/255~26/255 피벗에서 앞쪽으로 범위 전체만큼 떨어진 위치
8/255 미만 높이 없음

가장자리를 저장하려면 a 값을 247 - 9 * n 값으로 설정하세요. 여기서 n 값은 25 * sqrt(edge / range) 값을 반올림한 값이며 최대 25입니다. n 값이 0이면 알파를 255로 설정하세요. 설정한 값보다 4/255까지 높거나 낮은 알파도 같은 가장자리로 읽습니다.

텍셀을 읽으려면 SunForgeHeightDecode.hlsl 파일의 SFHeightShare, SFHeightAbsent, SFHeightFrontEdgeShare 함수를 사용하거나, C#에서는 SunForgeHeightTexel.TryDecode 메서드를 사용하세요.
