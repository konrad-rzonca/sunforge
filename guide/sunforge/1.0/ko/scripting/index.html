KonradRzonca.SunForge.Lighting.Editor KonradRzonca.SunForge.Editor Sun Forge 2D Lighting 패키지의 기본 제공 조명 스타일 불러오기, 코드에서 씬의 조명 설정하기

사용하는 어셈블리는 직접 만든 어셈블리 정의에서 참조하세요.

컴포넌트의 클래스 이름은 인스펙터에 표시되는 이름 앞에 SunForge 접두사를 붙인 것입니다. Light Source 컴포넌트의 클래스는 SunForgeLightSource입니다.

IDE에 Sun Forge의 타입과 멤버 설명이 표시되게 하려면 Edit > Preferences > External Tools > Generate .csproj files for(편집 > 환경 설정 > 외부 툴 > Generate .csproj files for) 섹션에서 Registry packages 체크박스나 Local tarball 체크박스처럼 Sun Forge를 설치한 출처에 해당하는 체크박스를 켜세요. 그런 다음 Regenerate project files 버튼을 클릭하세요.

베이크 데이터 읽기

SunForgeBakedPrefab.Of(component) 메서드는 자식의 컴포넌트를 포함해 액터의 어느 컴포넌트에서든 베이크 데이터를 찾습니다.

using KonradRzonca.SunForge;
using UnityEngine;

public sealed class ShowBakeInfo : MonoBehaviour
{
    void Start()
    {
        SunForgeBakedPrefab baked = SunForgeBakedPrefab.Of(this);
        SunForgeBakedData data = baked.Data;
        Vector3 textPoint = baked.AnchorSpace.TransformPoint(baked.Anchors.OverheadAnchor);
        Rect hitbox = baked.WorldHitbox;
        Debug.Log($"{data.OutputName} bakes {data.Clips.Count} clips. Text goes at {textPoint}. Hits land in {hitbox}.");
    }
}
  • Anchors 프로퍼티의 모든 사각형과 점은 AnchorSpace 트랜스폼의 로컬 공간에 있습니다. 단, Anchors.Collider 프로퍼티는 루트의 로컬 공간에 있습니다. baked.Anchors.HealthBar.ToWorld(baked.AnchorSpace) 호출은 월드 공간의 사각형을 반환합니다.
  • Leaves The Ground(지면 이탈) 토글(Archetypes(아키타입) 탭, PHYSICS(물리) 섹션, Advanced(고급) 보기)을 켜고 베이크한 프리팹은 게임 실행 중에 높이를 바꿀 수 있습니다. Body 자식의 SunForgeBakedRendererBinding 컴포넌트에서 HeightAboveGround 프로퍼티를 설정한 뒤, 루트의 SunForgeBakedShadowSync 컴포넌트에서 PlaceAtHeight(Vector3.zero) 메서드를 호출하세요. 이 메서드는 본체와 그림자를 옮깁니다. 스케일을 바꾼 프리팹에서는 스크립트가 PlaceAtHeight 메서드를 호출하기 전까지 본체가 높이에 스케일을 곱한 위치에 있습니다.
