픽셀 아트

씬의 조명을 받는 픽셀 아트를 베이크하고, Pixel Perfect Camera 컴포넌트로 그립니다.

씬의 조명이 비추는 픽셀 아트를 베이크하려면 다음과 같이 합니다.

  1. 아키타입의 CAMERA(카메라) 섹션에서 Pixels Per Unit(단위당 픽셀) 필드를 32처럼 아트의 픽셀 밀도에 맞는 값으로 설정합니다. 지면 타일을 포함해 씬에서 쓰는 모든 아키타입에 같은 값을 사용합니다.
  2. Advanced(고급) 보기에서 아키타입의 QUALITY(품질) 섹션에 있는 Supersampling(슈퍼샘플링) 체크박스를 끄고 Animation Frame Rate(애니메이션 프레임 속도) 필드를 12처럼 낮은 값으로 설정합니다.
  3. 아키타입의 OUTPUT(출력) 섹션(Advanced 보기)에서 Filter Mode(필터 모드) 필드를 Point 옵션으로 설정하고 Generate Mip Maps(밉맵 생성) 체크박스를 끕니다.
  4. 아키타입의 SHADOW(그림자) 섹션(Advanced 보기)에서 Softness(부드러움) 필드를 0으로 설정하고, Ground-Projected(지면 투영) 토글 아래의 Resolution Scale(해상도 스케일) 필드를 1로 설정합니다. 그러면 그림자 픽셀 하나가 스프라이트 픽셀 하나에 해당합니다.
  5. 외곽선을 그리려면 베이크의 Prefab Material(프리팹 머티리얼) 필드(Advanced 보기)를 Regular with Pixel Outline 옵션이나 Cinematic with Pixel Outline 옵션으로 설정합니다. 스타일의 모든 스프라이트에 외곽선을 그리려면 대신 스타일의 Sprite 머티리얼에서 Pixel Outline 프로퍼티를 켭니다(스타일 조정 참조).
  6. 베이크하고, 씬의 카메라에 Pixel Perfect Camera 컴포넌트를 추가합니다(픽셀 아트 › Pixel Perfect Camera 참조).
  7. 블룸이 픽셀을 흐리게 하므로 Lighting Setup 컴포넌트의 Post Processing Enabled(포스트 프로세싱 활성화) 체크박스를 끕니다. 이렇게 하면 스타일의 포스트 프로세싱 전체가 꺼집니다.

Pixel Perfect Camera

URP의 Pixel Perfect Camera 컴포넌트는 스프라이트 픽셀 하나를 정수 개의 화면 픽셀로 된 블록으로 그립니다. 그 컴포넌트의 Assets Pixels Per Unit 필드를 스프라이트의 Pixels Per Unit 값으로 설정하세요. Pixels Per Unit 값이 다른 스프라이트나 스케일을 바꾼 스프라이트는 픽셀 크기가 다르게 표시됩니다.

이 카메라는 2D 렌더러와 유니버설 렌더러에서 모두 작동합니다. Grid Snapping(그리드 스내핑) 필드의 Upscale Render Texture 옵션은 2D 렌더러에서만 작동합니다.

Grid Snapping 스프라이트가 움직이는 단위 빛, 안개, 드리운 그림자의 변화
None(없음) 화면 픽셀 화면 픽셀 단위로 바뀌어 스프라이트 픽셀 하나 안에서도 매끄럽게 이어집니다
Pixel Snapping 스프라이트 픽셀 화면 픽셀 단위로 바뀌어 스프라이트 픽셀 하나 안에서도 매끄럽게 이어집니다
Upscale Render Texture 스프라이트 픽셀 씬을 카메라의 Reference Resolution(레퍼런스 해상도) 필드 값으로 렌더링한 뒤 확대하므로, 아트처럼 스프라이트 픽셀마다 한 번 바뀝니다
