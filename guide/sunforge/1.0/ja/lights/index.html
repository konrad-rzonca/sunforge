ライト

Light Source を追加し、その光の形を整え、既存の Light 2D のライトもそのまま使います。

このページの内容
  • ライトの追加
  • ライトの形の調整
  • Light 2D の利用
  • カメラがライティングに使うライトの数
  • スプライト自身の発光ライト

Light Source は、URP の 2D レンダラーとユニバーサルレンダラーのどちらでもスタイル用のマテリアルを照らします。光の照射範囲は、ライトの下の地面に広がります。

ライトの追加

  1. GameObject > Sun Forge > Light Source > Light を選択します。同じサブメニューの Spot Light、Line Light、Rectangle Light は、それぞれ円錐形、線状、矩形の範囲を照らします。Fire、Lamps、Magic、Windows and Doors には、たいまつ、街灯、窓など、見た目があらかじめ設定されたライトがあります。
  2. 作成したライトを、ランプの炎など、光を出したい位置に移動します。
  3. ライトを選択した状態で、シーンビューでライトの上にある点をドラッグして、Height Above Ground (地面からの高さ) を設定します。ライトが上下に動き、照射範囲はその場にとどまります。ほかのハンドルでは、Ground Radius (地面での半径)、Inner Radius (内側半径)、サイズ、各スポット角度を設定できます。ハンドルにポインターを合わせると、その名前と値が表示されます。

ランプのプレハブなど、既存のオブジェクトをライトにするには、Add Component > Sun Forge > Lighting > Light Source (コンポーネントを追加 > Sun Forge > Lighting > Light Source) を使ってください。

3D のポイントライトやスポットライトは、スタイルが適用されたスプライトを照らしません。こうしたライトに Light Source を付けるには、そのライトを選択し、Inspector の上部にある Add a Sun Forge Light Here (ここに Sun Forge のライトを追加) をクリックしてください。

ライトの形の調整

目的 操作
スポットライト Outer Spot Angle (外側スポット角度) を下げてから、Aim (照射方向) ハンドル (照射範囲の縁より外にある、弧の付いた点) をドラッグして向きを決めてください
より遠くまで届く照射範囲 Intensity (強さ) を上げてください。光が届かなくなる位置は Ground Radius (地面での半径) で決まります
管状のランプや発光するパネルのような、線状または矩形の光 Shape (形状) を設定してください
火のようにちらつくライト Kind (種類) を Flame (炎) に設定してください。再生モードでちらつきます。自作の炎のスプライトも一緒にちらつかせるには、そのスプライトのレンダラーを Glow Renderers (発光レンダラー) に追加してください

Light 2D の利用

2D ライトは、Unity Lights マテリアルを通常どおり照らします。スタイルが適用されたスプライトも 2D ライトで照らすには、次のようにしてください。

  1. GameObject > Sun Forge > Set Up for Lighting を選択し、Apply (適用する) をクリックします。すべてのソートレイヤーを対象にしている各 Light 2D に、その Light 2D が制御する Light Source が追加されます。スクリプトやアニメーションで Light 2D を変更すると、Light Source にも反映されます。ライトを 1 つだけ対象にする場合や、後からライトを追加した場合は、そのライトを選択し、Inspector の上部にある Use This Light with Sun Forge (このライトを Sun Forge で使用) をクリックします。
  2. 対象から外しているソートレイヤーがある Light 2D については、Lighting Setup を選択し、そのライトに関する指摘の横にある Fix (修正) をクリックします。
  3. 各 Light Source の Height Above Ground (地面からの高さ) を、対応する Light 2D の地面からの高さに合わせます。ライトは Light 2D の位置にとどまります。スタイルが適用されたスプライトでは、照射範囲がライトの下の地面に広がるため、アートに描かれた地面と同じように平たく見えます。サイドビューのアートでは、代わりに Height Above Ground を小さく設定します (サイドビューを参照)。

カメラがライティングに使うライトの数

ライティングに使うライトは、カメラごとに最大 512 個、WebGL 2 プレイヤーでは最大 128 個です。メインカメラから見えていても使われていないライトは、シーンビューに灰色の電球アイコンで表示されます。そのライトが常に使われるようにするには、ライトの Special Cases (特殊なケース) にある Is Prioritized (優先) をオンにしてください。

スプライト自身の発光ライト

発光ライトは、Sun Forge がスプライトの発光部分のために作成した Light Source です。Sun Forge がテクスチャを出力したスプライトでは、その Lighting Style Renderer の Glow, Surfaces and Edges (発光、表面、エッジ) にある Glow Light (発光ライト) の行で Add (追加) をクリックすると、発光ライトを追加できます。発光ライトが自身のスプライトをどう照らすかは、Lighting Setup の Values (値) の下にある Glow (発光) の 2 つの値で決まり、発光ライトの Special Cases (特殊なケース) にある Light On Its Object Shift (所属オブジェクトへの光のシフト) と Glow Parts Light Scale (発光部分の光の倍率) で、そのスプライトに限って変更できます。

Regular のシーンで Flat のマテリアルを使う場合のように、スプライトのマテリアルがシーンとは別のスタイルのものである場合、発光ライトがそのスプライトをどう照らすかはマテリアルのスタイルで決まり、Lighting Setup の Glow の 2 つの値を変更しても変わりません。この場合、Realistic は Regular として扱われ、自作のスタイルは、その元になったスタイルとして扱われます。発光ライトの Light On Its Object Shift と Glow Parts Light Scale は、こうしたスプライトにも効きます。
