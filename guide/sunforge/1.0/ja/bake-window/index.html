マスク › 金属と光沢金属と光沢の取得元です (マテリアル自身の値、または下に並んだ色)。HDRP と glTF のマスクマップは読み込まれません。
マスク › + 表面を追加金属と光沢を独自の値でベイクする色を追加します。

マスク › 強さAdvancedモデルの形状によるオクルージョンの暗さです。0 でなし、1 で最大になります。マテリアルのオクルージョンマップのほうが暗い部分では、マップの暗さが表示されます。
マスク › 半径Advancedスプライトオクルージョンが届く距離 (モデルの [描画の高さ] に対する割合)
マスク › 半径Advanced地面タイルオクルージョンが届く距離 (ワールド単位)

エミッション › 発光発光の取得元 (マテリアルのエミッションマップと色、または下に並んだ色)
エミッション › + 発光色を追加発光する色を追加します。

エミッション › レベルライトの明るさと届く範囲です。火やランプでは、約 1 まで上げてください。モデル自体に当たる光は、ライティングスタイルで決まります。
エミッション › 種類[炎] にすると、再生モードでライトとプレハブの発光がちらつきます。火には、[レベル] も約 1 に設定してください。
エミッション › 炎 › 振幅炎の光が暗くなる度合いの最大値です。ほとんどの場合はこれより小さくなります。0 で一定になります。
エミッション › 炎 › 周波数炎が揺らぐ速さです。目安は、ろうそくで約 10、たき火で約 3 です。ちらつきのうちこの速さで揺らぐ割合は、[Flutter] で設定します。この速さを 0 にすると一定になります。

ジオメトリテクスチャスプライト各ピクセルの地面からの高さをベイクします。この高さは、ライト、キャストシャドウ、木々の陰、霧で使われます。オフにすると、スプライトは平らな直立した板としてライティングされます。

アニメーション

レストポーズの方向数Advancedスプライトレストポーズとそのパーティクルをベイクする方向です。空欄のときはアーキタイプの値を使います。小道具のコライダーと発光はこの方向に従います。多いほどベイクに時間がかかり、[待機] のエントリーがない場合はテクスチャメモリも多く使います。
アニメーションプレイヤーAdvancedスプライトプレハブのアニメーションとパーティクルを再生するコンポーネントを選択します。シーン内のアクターやアニメーションする小道具が多いときは、Flipbook Player のほうが CPU の負荷が少なくなります。
クリップ › 複製スプライトこのエントリーを、重複しない出力名で複製します。

クリップ › 範囲スプライトドラッグして、元のクリップの一部だけをベイクします。ループするエントリーでは、開始と終了のポーズを合わせてください。合っていないと、繰り返すたびにスプライトの動きが飛びます。
クリップ › 逆再生スプライト[範囲] を終わりから始まりへ再生します。たとえば、倒れる動きから起き上がる動きを作れます。

クリップ › 方向Advancedスプライトこのアニメーションをベイクする方向 (独自の方向数とオン/オフの設定) です。空欄のときはアーキタイプの方向を使い、レストポーズのエントリーでは [レストポーズの方向数] を使います。
クリップ › + ポーズオーバーライドを追加スプライトこのエントリーの再生中、別のクリップのポーズ 1 つに固定するボーンを追加します。たとえば、歩行の間も腕を構えのポーズに固定できます。
クリップ › + エントリーを追加スプライトアニメーションエントリーを追加します。[モード] はクリップ名から推測されます。1 つのクリップを複数のエントリーでベイクできます。
クリップ › サイズの計測元Advancedスプライト[計測元] が [アニメーションのフレーム] の場合、コライダー、ヒットボックス、VFX ボックス、HP バーはこれらのアニメーションに合わせます。[計測元] の設定にかかわらず、これらのアニメーションで地面から 0.25 ワールド単位を超えて持ち上がる部分には、草が重なって描画されることがあります。

カメラ

単位毎のピクセル数1 ワールド単位あたりのスプライトのピクセル数です。高くするほど鮮明になり、テクスチャメモリの使用量が増えます。Flat ライティングスタイルでは、高くするほどくぼみの線が細く描画され、低い値ではアウトラインが太く描画されます。
俯角ゲームカメラが見下ろす角度です (度)。0 はサイドビューで、地面の影はベイクされません。90 では真下を見下ろします。サイドビューにするには、小さな角度ではなく 0 を使ってください。スプライトはこの角度から描画され、すべてのベイクのライティングにもこの角度が使われます。
方向スプライトモデルをベイクする方向数です (1 から 64)。1 では背面から見た方向だけを、8 では前後左右の 4 方向と斜めの 4 方向をベイクします。方向を増やすと、キャラクターの向きが、狙う方向や移動する方向により近くなります。画面の上と下に向かうときに最も効果があります。アニメーションとレストポーズは、それぞれ独自の方向を設定できます。
方向 › 最も広い隙間を埋めるスプライト

品質

スーパーサンプリングAdvanced1 ピクセルあたり最大 16 サンプルでレンダリングしてから縮小します。エッジが滑らかになり、細部がフレーム間で揺れなくなりますが、ベイクに時間がかかります。1 辺が 1024 ピクセルを超えるスプライトでは、サンプル数が少なくなります。オフにすると 1 サンプルでレンダリングします。ベイクが速くなりドット絵に適していますが、エッジがちらつくことがあります。オフにして [影] の [ぼかし] を 0 にすると、[地面投影] の影がピクセル単位でくっきりします。

影

影をベイク太陽の光でモデルが自身に影を落とす部分をマスク内で暗くし、下でオンにした種類の影をベイクします。
太陽の仰角太陽の高さ (度) です。太陽が低いほど影が長くなります。
太陽の方向太陽のある方角で、画面の上端から時計回りの角度 (度) です。180 にすると、太陽がカメラの後ろに来ます。
ぼかしAdvanced影の縁の柔らかさです。0 にすると縁がくっきりします。[スーパーサンプリング] がオフならピクセル単位でくっきりし、オンならわずかに滑らかになります。スプライトでは、[地面投影] の影の縁がぼける幅 (ワールド単位) です。スプライトが自身に落とす影も同じだけ柔らかくなりますが、[ぼかし] や [単位毎のピクセル数] が高いときは、地面に落ちる影よりくっきりしたままになります。地面タイルでは、影を落とすものから影が離れるほど、ぼける幅が広がります。
色味Advancedスプライト[地面投影] と [簡易丸影] の影の色です。アルファで、Regular スタイルの日中の光の下で影を描画する濃さが決まります。Sun Forge の影のマテリアルは、光と Lighting Setup の [Ground Shadow Strength] に応じて、影をより濃く、またはより薄く描画します。ベイクすると、プレハブの影の Sprite Renderer の [Color] にこの色が設定されます。そこで設定した [Color] は保持されます。
マテリアルAdvancedスプライト空欄のときは、光に合わせて変化し、霧の下で薄れる Sun Forge の影のマテリアルを使います。Cast Shadow Field は、このマテリアルから霧による薄れだけを取り込みます。霧のかからない地面の上では、Unity の Sprites-Default など、[色味] をそのまま描画するアンリットのマテリアルを選択してください。[ゲーム内] のプレビューには太陽と空の効果が反映されますが、雲、霧、Light Source は反映されません。
高さの範囲Advancedスプライトジオメトリテクスチャに保存する高さの範囲です (ワールド単位)。[自動] はモデルに合わせます。コードで固定値が必要な場合にのみ設定してください。
地面投影スプライト太陽が地面に落とす影をベイクします。
解像度スケールAdvancedスプライト影の精細さとテクスチャの負荷 ([単位毎のピクセル数] に対する割合) です。1 にすると、影の 1 ピクセルがスプライトの 1 ピクセルと一致します。ドット絵ではこの設定が必要です。
キャストハイトテクスチャをベイクAdvancedスプライト影の各ピクセルについて、影を落としている部分の高さをベイクし、Cast Shadow Field の中で木の枝葉がその下のスプライトに影を落とすようにします。オフにすると、影のシートごとにテクスチャが 1 枚減ります。その場合、太陽が横から当たると、影はかかったスプライトの下部にしか届きません。
Cast Shadow Caster を追加Advancedスプライトベイクしたプレハブに Cast Shadow Caster を追加し、シーンの Cast Shadow Field がその影を周囲のスプライトに落とすようにします。
簡易丸影スプライトモデルの下に簡易丸影をベイクします。
不透明度Advancedスプライト丸影を描画する濃さです。0 で見えなくなり、1 で [色味] そのままの濃さになります。
スケールAdvancedスプライトモデルを見下ろしたときの占有範囲を基準に、丸影の大きさを調整します。

物理

移動可能Advancedスプライトオン: [コライダーの形状] を設定すると動的な物理ボディになり、物理で動きます。オフ: 静的になり、物理で動くことはありません。Movement や Wander など、動かすビヘイビアがない場合は、Rigidbody 2D に [Linear Damping] が設定され、ぶつかった後に減速して止まります。

地面から離れるAdvancedスプライトオンのときは、プレハブは本体を子の Body に描画し、スクリプトでその Body を上下に動かせます。コライダー、影、移動は地面に残ります。空を飛んだりジャンプしたりする生き物向けです。
