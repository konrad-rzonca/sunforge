コードからのベイク

エディタースクリプトでベイクプリセットを作成し、実行します。

このページの内容
  • アニメーションエントリーの設定
  • プリセットやライブラリの変更

SunForgeBakeRequest は、ベイクプリセットと、それが使うアーキタイプライブラリの組です。プリセットを作成してから、リクエストを SunForgeBakeRunner に渡してください。

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEngine;

SunForgeBakeArchetypeLibrary library = SunForgeBakeArchetypeLibraryLocator.FindOrCreate();
SunForgeBakeArchetype character = library.FindArchetype("Character");
SunForgeBakePreset preset = SunForgeBakePreset.CreateWithDefaults(library, source, character);
var request = new SunForgeBakeRequest(library, preset);

// Every problem the bake has, without baking. A bake with a blocking one is refused.
List<SunForgeBakeDiagnostic> findings = SunForgeBakeRunner.Validate(request);
if (findings.Exists(finding => finding.Blocks))
{
    foreach (SunForgeBakeDiagnostic finding in findings)
        if (finding.Blocks)
            Debug.LogError(finding.Message);
    return;
}

SunForgeBakeResult result = SunForgeBakeRunner.Run(request);
if (result.Status == SunForgeBakeStatus.Failed)
    Debug.LogException(result.Exception);
foreach (string warning in result.Warnings)
    Debug.LogWarning(warning);
foreach (string error in result.Errors)
    Debug.LogError(error);
// A step beside the bake that failed, such as a check behind a warning. A completed bake can have them.
foreach (SunForgeBakeFault fault in result.Faults)
    Debug.LogError(fault.Message + "\n" + fault.Exception);
SunForgeBakedData baked = result.BakedData;
  • アーキタイプライブラリがないプロジェクトでは、FindOrCreate が新しいライブラリを保存します。このライブラリには、Bake Window の最初のベイクと同じスターターアーキタイプが入っています。
  • FindArchetype は、プロジェクトでそのアーキタイプの名前が変更されたか削除された場合は null を返し、そのとき CreateWithDefaults は Default アーキタイプを使います。
  • ScriptableObject.CreateInstance で作ったプリセットには、プレハブマテリアル、アーキタイプ、アニメーションエントリーがありません。プリセットは SunForgeBakePreset.CreateWithDefaults で作成してください。
  • preset.PrefabMaterial を設定すると、シーンのライティングスタイルにかかわらず、どのシーンでもそのマテリアルが使われます。preset.FollowLightingStyle() を呼ぶと、スプライトは再びスタイルのマテリアルで描画されます。

ベイクしたプレハブを置くシーンのライティングをスクリプトからセットアップするには、コードからのライティングを参照してください。

アニメーションエントリーの設定

CreateWithDefaults は、Bake Window がそのベイク元に追加するアニメーションエントリーをプリセットに設定します。エントリーがないプリセットでは、Source を設定したあとで preset.AddClipSettingsIfEmpty() を呼んでください。

エントリーは new SunForgeBakeClipSettings(clipName, outputName, mode) で作成してください。clipName はクリップの名前で、同じ名前のクリップが 2 つある場合は、そのどちらかを File|Name で指定します。レストポーズの場合は null を指定します。各 With メソッドは設定を 1 つ変更したエントリーを返すため、戻り値を代入し直してください。

preset.ClipSettings.Add(new SunForgeBakeClipSettings("Run", null, SunForgeBakeClipMode.LoopWhileBool).WithFrameRate(12));
preset.ClipSettings[0] = preset.ClipSettings[0].WithMode(SunForgeBakeClipMode.PlayOnce);

プリセットやライブラリの変更

保存したライブラリやプリセットをコードで変更する前には、もう一度読み込んでください。インポートが起こると、保持しているオブジェクトがアンロードされることがあり、そのオブジェクトへの変更は失われます。

  • 変更を残すには、ライブラリまたはプリセットに対して EditorUtility.SetDirty を呼んでください。この呼び出しがないと、次のインポートで Unity が変更を破棄することがあります。
  • 1 回のベイクだけプリセットを変えるには、Object.Instantiate(preset) でコピーを作り、コピーを変更してベイクしてください。

コードで作って保存しないライブラリやプリセットは、Unity が未使用のオブジェクトを解放するまでしか残りません。この解放は、ベイクで起こるものを含め、どのインポートでも起こりえます。ベイクのたびに作り直すか、破棄するまで静的フィールドに保持してください。
