カスタムシェーダー

Sun Forge のテンプレートから Shader Graph を作り始めるか、自作のグラフや HLSL のスプライトシェーダーを、シーンのスタイル、ライト、影、霧でライティングします。

Shader Graph

あらかじめ用意されたグラフから始めるには、Assets > Create > Shader Graph > From Template (アセット > 作成 > Shader Graph > From Template) を選択し、Sun Forge の下にある Sun Forge Sprite Lit または Sun Forge Dissolve を選んでから、下の手順 5 を実行してください。自分でグラフを作る場合の手順は次のとおりです。

  1. Sprite Unlit のグラフに Sun Forge > Sun Forge Sprite Lit を追加します。
  2. ノードの Color を Base Color に、Alpha を Alpha に接続します。
  3. Graph Settings で Disable Color Tint をオンにします。オフのままだと、Sprite Renderer の Color (色) が黒のスプライトでは、発光、リムライト、霧、ヒットフラッシュが失われます。
  4. 同じく Graph Settings で、Custom Editor GUI を KonradRzonca.SunForge.Editor.Inspector.SunForgeStyledMaterialEditor に設定します。これで、グラフのマテリアルの Inspector に、Sun Forge のマテリアルと同じプレビューとツールチップが表示されます。
  5. Project ウィンドウでグラフを右クリックし、Create > Material (作成 > マテリアル) を選択します。そのマテリアルを使う各レンダラーで Add Component > Sun Forge > Lighting > Lighting Style Renderer (コンポーネントを追加 > Sun Forge > Lighting > Lighting Style Renderer) を選択し、その Material (マテリアル) に自作のマテリアルを設定します。Mesh Renderer、Skinned Mesh Renderer、Line Renderer、Trail Renderer では、テクスチャは独自のプロパティブロックではなくマテリアルに設定します。プロパティブロックで設定すると、グラフで何も描画されないことがあります。

これで、マテリアルには Sun Forge のマテリアルと同じように、スプライトの 5 つのテクスチャスロットと、ライティングが読み取るマテリアルプロパティが備わります。マテリアルの Role を Sprite、Ground、Ground Clutter のいずれかに設定してください。スプライトはその役割に応じた見た目になり、Cast Shadow Field と、スプライトの Lighting Style Renderer は、役割をマテリアルから読み取ります。

ディゾルブやスクロールするテクスチャのように、ライティング前のスプライトに変更を加えるには、Sun Forge Sprite Lit の代わりに Sun Forge Sprite Textures と Sun Forge Lit Color を使ってください。Sun Forge Sprite Textures の各出力を、自作のエフェクトを間に挟んで、Sun Forge Lit Color の同じ名前のポートに接続し、Sun Forge Lit Color は手順 2 と同じように接続してください。UV に座標を接続すると、テクスチャはその座標でサンプリングされます。

Sun Forge Lit Color のポート 受け取るもの 未接続のとき
Albedo スプライトの色とアルファ 白
Normal Sun Forge Sample Normal Map などから得られるスプライトの法線 Bake Camera Elevation (Degrees) が 0 より大きい Ground では水平な地面、それ以外ではカメラの方を向いた表面
Mask 赤にメタリック、緑に滑らかさ、青にオクルージョン。アルファは Sun Forge Sprite Textures が出力した値のままにしてください 金属なし、滑らかさは半分、オクルージョンなし
Emission 発光色。アルファは、スプライト自身の発光がそのスプライトに届ける光です。Sun Forge Sprite Textures が出力した値のままにするか、自作の色を使う場合は 1 に設定してください 発光なし
Geometry ジオメトリテクスチャのサンプリング結果 (下の「ジオメトリテクスチャ」を参照) 立っているスプライトは平らな直立した板になります

グラウンドカバー、Flat のアウトライン、スプライトの輪郭の内側に収まるリムライト、Point フィルタリングのスプライトのくっきりしたハイライト、Regular と Cinematic で近くの Light Source から受ける滑らかな光は、各ピクセルの周囲でスプライト自身のテクスチャを読み取ります。グラフがスプライト自身の絵とは別の形を描画する場合は、Sun Forge Lit Color の Shape From を This Graph に設定してください。設定すると、上に挙げたものはいずれもスプライトのテクスチャを読み取らなくなります。

ノード 得られるもの
Sun Forge Sample Normal Map Sun Forge のマテリアルと同じように読み取った、Normal ポート用の自作の法線マップ
Sun Forge Mist Sun Forge のノードがライティングしないエフェクト用の、シーンの霧をかけた色
Sun Forge Scene Light 太陽または月の方向と色、Lighting Setup が公開する空と地面の色、Sun Forge のマテリアルがアニメーションに使う時間 (秒)
  • Reference が _MainTex、_NormalMap、_MaskTex、_EmissionTex、_GeometryTex のいずれかである独自のテクスチャプロパティを持つグラフでは、Sun Forge のノードがその Reference のスロットを追加すると、エラーが表示されます。そのプロパティを削除し、サンプリング結果は Sun Forge Sprite Textures から取ってください。
  • 降り注ぐコインのように、多数の小さなスプライトを一度に描画するメッシュでも、SunForgeBatchSprites を使うと、各スプライトはそれぞれのピボットと高さで照らされます。ノードはこの処理で UV チャンネル SunForgeBatchSprites.UvChannel を読み取るため、このチャンネルには独自のデータを入れないでください。
  • Color と Base Color の間に Sample Texture 2D、DDX、DDY、DDXY ノードがあると、OpenGL と Vulkan では、スプライトの縁に沿って誤った色が描画されることがあります。そのようなテクスチャは Sample Texture 2D LOD でサンプリングするか、Sun Forge Lit Color ノードのいずれかのポートに入力してください。
  • Sprite Skin コンポーネントを使う場合は、位置に Tangent Vector を加えた値を別の Sprite Skinning ノードに通し、その結果からスキニング後の位置を引いた値を Tangent ブロックに接続してください。これで、凹凸がボーンと一緒に回転します。
  • WebGL 2 と OpenGL ES 3.0 では、シェーダーがサンプリングできるテクスチャは 16 枚までです。ライティングが独自に 10 枚をサンプリングするため、スプライトの 5 枚のテクスチャをサンプリングする Sun Forge Sprite Lit または Sun Forge Sprite Textures を使うグラフは、これらのプラットフォームではあと 1 枚サンプリングできます。
  • Direct3D では、シェーダーが使えるサンプラーステートは 16 個までです。ライティングが独自に 6 個を使うため、Sun Forge Sprite Lit または Sun Forge Sprite Textures を使うグラフは、あと 5 個使えます。1 つの Sampler State ノードでサンプリングしたテクスチャは、1 個のサンプラーステートを共有します。

HLSL シェーダー

各インクルードファイルは Packages/com.konradrzonca.sunforge.lighting/Runtime/Shaders/ にあり、使い方はそのヘッダーに書かれています。

インクルードファイル 用途
SunForgeLitColor.hlsl Sun Forge Lit Color ノードと同じようにシェーダーをライティングします。
SunForgeStyleKeywords.hlsl シェーダーに、スタイルごとのバリアントと、スタイルの Quality (品質) セクションの各オプションのバリアントを持たせます (スタイル › スタイルの品質を参照)。パスのプラグマと並べて #include_with_pragmas でインクルードしてください。
SunForgeNormalDecode.hlsl パッケージ同梱のマテリアルと同じように、法線マップのサンプリング結果を読み取ります。その法線でライティングするときや、法線を独自に表示または測定するときに使います。
SunForgeHeightDecode.hlsl パッケージ同梱のマテリアルと同じように、ジオメトリテクスチャを宣言し、そのサンプリング結果の高さと前端を読み取ります。キャストハイトテクスチャのサンプリング結果の高さも読み取れます。
SunForgeHeightRamp.hlsl Texture View (テクスチャビュー) の Geometry (ジオメトリ) と同じように、高さに色を付けます。
SunForgeHeightRampBar.hlsl SunForgeHeightRamp.DrawBar が実行する Height Ramp という名前のパスで、その色分けの凡例のバーを描画します。
SunForgeMist.hlsl フルスクリーンのフォグなどでシーンの霧を描画します。
SunForgeHitFlash.hlsl ヒットフラッシュを描画します。
SunForgeBakedLight.hlsl エミッションテクスチャのアルファから、スプライト自身の発光がそのスプライトに届ける光を読み取ります。
SunForgeWalkBands.hlsl Sun Forge がキャラクターの周りで分割する小道具のうち、自作のシェーダーが受け持つ部分だけを描画します。
SunForgeRendererBakeValues.hlsl スプライトの描画に使われる角度などの投影の値と、スプライトが地面からどれだけ高い位置にあるかを読み取ります。
SunForgeLightingGlobals.hlsl Lighting Setup が公開するものを読み取ります。

スクリプトから独自のライティングを公開するには、SunForgeLightingPublisher を使ってください。

WebGPU では、Windows の Chrome は、実行時に計算したインデックスで static const 配列を読み取るシェーダーや、v[i] のように同じ方法でベクトルの成分を選ぶシェーダーの読み込みに時間がかかります。配列が大きいと読み込みに数分かかることがあり、その後プレイヤーが GPU デバイスを失って描画を停止することがあります。代わりに値を計算するか、定数のインデックスで配列を読み取るか、dot(v, float4(i == uint4(0, 1, 2, 3))) のように比較で成分を選んでください。Custom Function ノード内の HLSL にも同じことが当てはまります。

WebGL 2 では、Windows の Chrome で、要素数が 50 以上の配列を 1 つだけ保持する定数バッファが、テクスチャ 1 枚として数えられます。シェーダーのテクスチャとそのようなバッファの合計が 16 を超えると、そのシェーダーが最初に描画するときに、ページの描画が止まります。配列の後ろに 2 つ目の値を追加してください。その値を読み取る必要はありません。

テクスチャのないスプライト

スプライトに法線マップ、マスク、エミッション、ジオメトリテクスチャのいずれかがない場合、シェーダーはマテリアルのそのスロットのテクスチャをサンプリングし、マテリアルにもなければプロパティのデフォルトをサンプリングします。Sun Forge Sprite Textures が追加するスロットには、あらかじめ正しいデフォルトが設定されています。HLSL シェーダーの場合、Unity のデフォルトでは、そのようなスプライトが正しく描画されないため、各スロットを次のように設定してください。

テクスチャ プロパティ 設定 設定しない場合のスプライト
法線マップ _NormalMap デフォルトに SunForge_FlatNormal.png を設定 傾いているかのように照らされます
マスク _MaskTex デフォルトに SunForge_NeutralMask.png を設定 磨かれた金属のように照らされるか、金属、滑らかさ、オクルージョンが誤った値になります
エミッション _EmissionTex "black" 白く発光します
ジオメトリ _GeometryTex "black" 高さが範囲いっぱいになります
  • 法線マップとマスク: どちらのテクスチャも、Sun Forge 2D Lighting パッケージの Runtime/Materials フォルダーにあります。シェーダーを選択し、Inspector の Default Maps で設定してください。
  • エミッションとジオメトリ: _GeometryTex ("Geometry Texture", 2D) = "black" {} のように、プロパティを "black" として宣言してください。

Check Setup (セットアップを確認) は、_NormalMap または _MaskTex にテクスチャがないマテリアルを指摘し、その修正で対応するテクスチャがバインドされます。_GeometryTex が高さを持つマテリアルも指摘します。

自作のシェーダー

グラフは、Sun Forge Sprite Lit ノードか、Sun Forge Sprite Textures ノードと Sun Forge Lit Color ノードの組み合わせで作ります (カスタムシェーダー › Shader Graphを参照)。そのあと、次のどちらかの方法で使います。

  • ベイクしたスプライトで使う。Baked Renderer Binding の横に、Add Component > Sun Forge > Lighting > Lighting Style Renderer (コンポーネントを追加 > Sun Forge > Lighting > Lighting Style Renderer) で Lighting Style Renderer を追加し、その Material (マテリアル) に作成したマテリアルを設定してください。スプライトはベイク時の値を保持します。
  • ベイクのマテリアルとして使う。そのマテリアルをベイクの Prefab Material (プレハブマテリアル、Advanced (上級者向け) 表示) に選んでください。Bake Camera Elevation (Degrees) など、スプライトのベイク時の値はベイクで設定されるため、プレハブに Lighting Style Renderer は必要ありません。

ベイクしたエフェクトのパーティクルは、アルファにかかわらず、背後にあるものに光を加えます。

  • Blending Mode が Premultiply で、Premultiplied を Base Color に接続したグラフは、その光をエフェクトのエミッションテクスチャから描画します。Blending Mode がそれ以外の場合、光はエフェクトの色にベイクされます。
  • その光をスプライト用のマテリアルで描画できないスタイルでは、ベイクしたエフェクトの Particles 子オブジェクトが、ベイク時のマテリアルをそのまま使います。
  • HLSL シェーダーは、_SFEmissionScale と _SFEmissionOutsideAlpha を宣言し、One OneMinusSrcAlpha でブレンドする場合に、その光を描画します。その方法は SunForgeLitColor.hlsl のヘッダーに書かれています。
