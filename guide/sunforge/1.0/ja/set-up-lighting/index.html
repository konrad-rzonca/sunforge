シーンのセットアップ

3 つの手順で、シーンのスプライトをライティングし、最初のライトを追加します。

  1. シーンを開き、GameObject > Sun Forge > Set Up for Lighting を選択します。変更される内容がウィンドウに一覧表示されます。プラットフォーマーのアートのように、横から見て描かれたアートでは、ウィンドウの Art View (アートの視点) の行で From the Side (サイドビュー) を選択します。
  2. Apply (適用する) をクリックします。シーンに Regular スタイルの Lighting Setup が追加され、スプライトがライティングされます。上から見て描かれたアートでは、スプライトが影も落とします。
  3. ライトを追加するには、GameObject > Sun Forge > Light Source > Light を選択するか、同じサブメニューにある Fire > Torch などの、見た目があらかじめ設定されたライトを選択し、ランプや炎の位置に移動します。

ゲーム中に生成するプレハブは、Project ウィンドウで選択して右クリックし、Sun Forge > Set Up for Lighting を選択してください。

自作の法線マップを使う場合や、発光する色や金属のように光る色を使う場合は、自分で描いたスプライト › スプライトのテクスチャを参照してください。
