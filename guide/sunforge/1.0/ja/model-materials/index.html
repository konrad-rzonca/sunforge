モデルのマテリアル

ベイクがモデルのマテリアルから読み取るものと、それぞれがスプライトのテクスチャで何になるかを説明します。

このページの内容
  • スプライトと 2D リグ
  • 自作のシェーダーを使うモデル

モデルのマテリアルは、次のようにベイクされます。

  • モデルのカラーテクスチャはそのままの色としてベイクされ、シーンがスプライトをもう一度照らすため、テクスチャに描き込まれた光や陰は、すべてのスプライトに現れます。
  • マテリアルの Occlusion Map はマスクテクスチャにベイクされます。このマップは、樹皮の溝のような、メッシュより細かいディテールに使ってください。
  • アルファでフェードするマテリアルは不透明度の半分を境に切り抜かれてベイクされるため、ガラスなどの透ける表面は、不透明か空いた状態のどちらかでベイクされます。
  • ベイクは、マテリアルの Render Face (レンダー面) にかかわらず、モデルの表面の両面を描画します。そのため、片面の葉のカードやマントを裏側から見ても、スプライトには葉のカードやマントが表示されます。
  • メッシュ自身の頂点カラーは、URP の Lit と Standard が無視するため、ベイクされません。
  • 発光部分が自身のモデルを照らすのは、外に露出している箇所だけです。中身の詰まった立体の内側に押し込まれた部分は、何も照らしません。片面だけをレンダリングする表面は、中身の詰まった立体の外側の面として扱われます。そのため、1 層の面でモデリングしたランプシェードの下にある電球のように、そうした表面の裏側に発光がある場合は、シェードのマテリアルの Render Face を Both に設定してください。
  • メッシュ、スプライト、ラインのマテリアルを切り替えるクリップ、または 2D Animation の Sprite Swap でスプライトを切り替えるクリップは、各フレームを、そのフレームで表示される内容でベイクします。色、発光、テクスチャのオフセット、カットオフなど、クリップがマテリアル上でアニメーションさせる値は、クリップの再生どおりに各フレームでベイクされます。
  • ベイク中にスクリプトは実行されません。シーン内のオブジェクトでは、スクリプトが MaterialPropertyBlock でレンダラーに設定した値が、ベイクした時点の表示どおりにベイクされます。

スプライトと 2D リグ

  • 2D Animation でリグを組んだキャラクターは、各フレームを、ボーンと 2D IK が与えるポーズでベイクします。
  • Sun Forge のライティングマテリアルで描画されるスプライトでは、Set Up for Lighting (ライティング用にセットアップ) がスプライトに設定するものなど、描画に使う法線、マスク、エミッションテクスチャがベイクされます。
  • Sprite Renderer では、スプライトの各補助的テクスチャが、マテリアルの同じ名前のテクスチャの代わりにベイクされます。Shader Graph では、その名前のテクスチャプロパティの Show In Inspector をオンにしないと、ベイクがそのプロパティを見つけられません。
  • Sprite Renderer の Color (色) と Line Renderer の Color グラデーションは、シーンと同じようにそれぞれの部分に色味を加えます。

自作のシェーダーを使うモデル

自作のシェーダーは、次のプロパティからベイクされます。

ベイクされるもの 取得元
色 シェーダーがメインとして指定したテクスチャと色。指定がなければ _BaseMap または _MainTex と、_BaseColor または _Color
法線マップ _BumpMap または _NormalMap。URP の Lit と同じように _BumpScale でスケールされます
発光 マテリアルの Emission (放出) ボックス (_EMISSION キーワード) がオンのとき、またはシェーダーにそのキーワードがない場合は常に、_EmissionColor と _EmissionMap

Shader Graph では、プロパティを右クリックして Set as Main Texture または Set as Main Color を選んでください。

編集できないシェーダーの場合は、ベイク拡張で、ベイク用のモデルのコピーにこれらのプロパティ名を使うマテリアルを設定できます (ベイクの拡張 › 拡張を参照)。Bake (ベイク) タブは拡張が実行される前にモデルを確認するため、それでもそのマテリアルの名前を表示します。
