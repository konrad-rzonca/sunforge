再ベイク

再ベイクで保持されるもの、置き換えられるもの、参照が引き続き機能する仕組みを説明します。

このページの内容
  • 再ベイクで残るもの
  • 再ベイクで上書きされるもの
  • 出力フォルダーの移動と削除
  • Leaves The Ground のオンとオフの切り替え

すべてのファイルは、再ベイクしても GUID が変わらないため、プレハブやそのベイクデータを参照するシーンとスクリプトはそのまま動作します。

参照先 参照が有効な条件
スプライトまたはクリップ そのアニメーションエントリーの出力名と方向数が変わらず、そのスプライトやクリップの方向がオンになっていること
Animator のステート そのアニメーションエントリーの出力名が変わらないこと
レストポーズのスプライト Mode (モード) が Idle (待機) のアニメーションエントリーがなく、レストポーズの方向数が変わらず、スプライトの方向がオンになっていること

再ベイクで残るもの

  • プレハブに追加した子やコンポーネント、プレハブで変更した値、テクスチャやアトラスで変更したインポート設定、プラットフォームオーバーライド。ただし、「再ベイクで上書きされるもの」に挙げた値は除きます。プレハブの値を再びベイクに従わせるには、プレハブの Inspector でその行を右クリックし、Use the bake's value (ベイクの値を使用) を選んでください。
  • Shadow、Glow、Body など、ベイクが追加した子と、その子に付けた名前、プレハブ内で移動した位置。ベイクはその場所で子を更新し続けます。ベイクで使われなくなった子は、自分で追加したものを含んでいる間は残ります。
  • 出力フォルダー内の変更したファイルと、フォルダーに追加したそれ以外のもの。ベイクのファイルに戻すには、変更したファイルを削除してからベイクしてください。
  • Animator の編集。自作のコントローラー、または生成されたコントローラーをもとにしたアニメーターオーバーライドコントローラーを、プレハブの Animator に設定している場合に残ります。

再ベイクで上書きされるもの

  • 同じ出力の以前のベイクが書き出したファイルのうち、そのベイクが残したままの状態のもの。再ベイクで作られなくなったファイルは削除されます。
  • Texture Type、sRGB (Color Texture)、各スプライトの矩形とピボット、アトラスの Padding、Allow Rotation (回転を許可)、Tight Packing など、シェーダーとパッカーが読み取るもの。
  • プレハブのスプライトと、本体、影、発光の間のつながり。ただし、プレハブの発光ライトで変更した Glow Renderers (発光レンダラー) リストは上書きされません。
  • Filter Mode (フィルターモード)、Compression (圧縮)、Generate Mip Maps (ミップマップの生成) と、アトラス用の Atlas Max Size (アトラスの最大サイズ)。これらはアーキタイプの OUTPUT (出力) セクション (Advanced (上級者向け) 表示) で設定してください。追加テクスチャは常にそのシートの最大サイズになります。
  • ベイクのコントローラー。Animation Player (アニメーションプレイヤー、Advanced 表示) を Flipbook Player (フリップブックプレイヤー) に切り替えるか、Auto (自動) のときに最後のアニメーションエントリーを外すと、変更していない限り、ベイクのコントローラーは削除されます。元に戻すと、コントローラーがもう一度作られます。コントローラーへの参照は再び有効になります。ただし、最初のベイクのあとで出力フォルダーの名前を変更したか移動した場合は有効になりません。

出力フォルダーの移動と削除

  • 保存したプリセットをベイクしたあとは、そのプリセットのアーキタイプ、そのアーキタイプの Output Root (出力ルート)、または Output Root が空のときに Sun Forge フォルダーを変更すると、次のベイクで出力フォルダーが移動します。そのため、シーンからそのプレハブへの参照は切れません。代わりに別のコピーをベイクするには、先に Save As… (別名で保存...) を使ってください。保存したプリセットをベイクするまでは、同じ変更をするとベイクが新しいフォルダーを作り、古いフォルダーを残します。
  • Output Name (出力名) が異なる場合、または出力フォルダーを自分で移動した場合は、ベイクが新しいフォルダーを作り、古いフォルダーを残します。保存したプリセットをベイクしたあとであれば、フォルダーを移動するか新しく作るかは、ベイクする前に Bake (ベイク) タブに表示されます。
  • 出力フォルダーを削除してもう一度ベイクすると、新しいファイルが古いファイルの代わりになります。シーンには、配置した各プレハブが、そこで加えた変更とともに残ります。そのフォルダーへのベイクであればどれでもこうなるため、そこに別のモデルをベイクすると、古いモデルを配置していたすべての場所にそのモデルが現れます。これが当てはまるのは、このプロジェクトでその場所に最初にベイクしたフォルダーで、名前を変更したフォルダーや、そこに移動したフォルダーには当てはまりません。
  • 古いバージョンの出力など、ベイクのファイルと同じ名前のファイルがすでに出力フォルダーにあると、ベイクは止まります。それらのファイルをその場で上書きしてベイクするには、Bake タブの Replace them (置き換える) を押してください。
  • ベイク中に Unity が終了すると、名前が __SFS_ で始まるフォルダーが出力ルートに残ることがあります。そのアセットは使わないでください。そのルートへの次のベイクで削除されます。

Leaves The Ground のオンとオフの切り替え

Leaves The Ground (地面から離れる、Archetypes (アーキタイプ) タブの PHYSICS (物理)、Advanced (上級者向け) 表示) をオンまたはオフにすると、本体を描画し再生するコンポーネントが、設定した値とともに、Body 子オブジェクトへ、またはそこから移動します。設定し直す必要があるものは Console ウィンドウに一覧表示されます。自分で追加したほかの子オブジェクトは元の場所に残ります。本体に付いて動く子オブジェクトは、Body 子オブジェクトの下に移動してください。
