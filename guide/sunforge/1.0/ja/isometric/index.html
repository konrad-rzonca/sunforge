アイソメトリック

ベイクしたブロックから段差のある 2:1 のアイソメトリックシーンを組み立て、Tilemap 上の地面タイルをライティングします。

ベイクしたブロックで、段差のある 2:1 のアイソメトリックシーンを作る手順は次のとおりです。

  1. 各アーキタイプの Elevation Angle (俯角、CAMERA (カメラ) セクション) を 30 のままにし、すべてのアーキタイプの Pixels Per Unit (単位毎のピクセル数) を同じ値にします。30 では、正方形の地面が 2:1 のひし形として描画されます。
  2. Grid を追加し、Cell Layout を Isometric に、Cell Size をひし形の幅、その幅の半分、1 に設定します。
  3. 地形の各ブロックは、角をカメラに向けてモデリングします。Directions (方向) を 1、SHADOW (影) をオフにして小道具としてベイクし、その Cast Shadow Caster をオフにして、Grid.GetCellCenterWorld の位置に配置します。
  4. 高くなったブロックの上にプレハブを立たせるには、そのプレハブの各 Baked Renderer Binding コンポーネントで Height Above Ground (地面からの高さ) をブロックの高さに設定し、SunForgeBakedShadowSync.PlaceAtHeight を呼び出します。このメソッドは、プレハブとその影を上に移動します。パーティクルのベイクのように Baked Shadow Sync のないプレハブと、Leaves The Ground (地面から離れる) でベイクしたプレハブは、代わりに手動で上に移動します。ブロックの高さに Elevation Angle のコサイン (30 では 0.866) を掛けた値を、y 位置に加えます。Body 子オブジェクトの Height Above Ground は、ブロックからの高さのままです。
  5. 各ブロックの Order in Layer (レイヤーの順序) を、そのセルの (x + y) の -10 倍に設定します。こうすると、手前のセルが上に描画されます。そのセルの上にあるものには、そのブロックの値より大きく、次の行の値より小さい値を設定します。
  6. Light Source が立っている高さを、その Height Above Ground に加えます。照射範囲はブロックの上で Ground Radius (地面での半径) を保ち、シーンビューのアウトラインは地面の高さのままです。
  7. Cast Shadow Field の Mode (モード) を Ground Material And Sprites (地面マテリアルとスプライト) に設定します。こうすると、影がブロックと、その上に立っているものに落ちます。
  8. 最下段をブロックで組む代わりにペイントするには、地面タイルの Tilemap に描き (アイソメトリック › Tilemap 上の地面タイルを参照)、その Tilemap の Order in Layer をどのブロックの値よりも小さく設定します。そのタイルは、ブロックの上面と同じように照らされます。

Tilemap 上の地面タイル

  • Tilemap は、スタイルの Ground マテリアル SunForge_<Style>_Ground で描画してください。
  • Tilemap がタイルをそのプレハブと同じように照らすには、Baked Renderer Binding が必要です。Check Setup (セットアップを確認) で追加されます。Check Setup は、値の異なるベイクのタイルが混在する Tilemap も報告します。そうしたタイルは、それぞれ別の Tilemap に置いてください。
  • Tile View (タイルの視点、Archetypes (アーキタイプ) タブの OUTPUT (出力)) を Isometric (アイソメトリック) に設定したタイルは、ひし形のスプライトメッシュを持ちます。Tilemap のセルにタイルを合わせるには、このメッシュが必要です。このメッシュはすべてのベイクで書き込まれるため、Mesh Type をほかの値にしても保たれません。
