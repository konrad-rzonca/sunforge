スクリプティング

参照するアセンブリと、ベイクが書き出したものをスクリプトで読み取る方法を説明します。

アセンブリ 名前空間 内容
KonradRzonca.SunForge.Runtime KonradRzonca.SunForge ベイクデータ、アダプターのインターフェース、マーカー
KonradRzonca.SunForge.Lighting KonradRzonca.SunForge Sun Forge 2D Lighting パッケージのライティングコンポーネント
KonradRzonca.SunForge.Gameplay KonradRzonca.SunForge.Gameplay ゲームプレイのビヘイビアと物理
KonradRzonca.SunForge.Editor KonradRzonca.SunForge.Editor 拡張、プリセット、検証、コードからのベイク実行
KonradRzonca.SunForge.Lighting.Editor KonradRzonca.SunForge.Editor Sun Forge 2D Lighting パッケージの、同梱ライティングスタイルの読み込みと、コードからのシーンのライティングのセットアップ

使うアセンブリは、自作のアセンブリ定義から参照してください。

コンポーネントのクラス名は、Inspector での名前の前に SunForge を付けたものです。たとえば Light Source のクラスは SunForgeLightSource です。

IDE に Sun Forge の型とメンバーの説明を表示させるには、Edit > Preferences > External Tools > Generate .csproj files for (編集 > 環境設定 > 外部ツール > Generate .csproj files for) で、Registry packages や Local tarball など、Sun Forge のインストール元に当たる項目をオンにしてから、Regenerate project files をクリックしてください。

ベイクデータの読み取り

SunForgeBakedPrefab.Of(component) は、アクター上のどのコンポーネントからでも、子のコンポーネントを含めて、ベイクデータを見つけます。

using KonradRzonca.SunForge;
using UnityEngine;

public sealed class ShowBakeInfo : MonoBehaviour
{
    void Start()
    {
        SunForgeBakedPrefab baked = SunForgeBakedPrefab.Of(this);
        SunForgeBakedData data = baked.Data;
        Vector3 textPoint = baked.AnchorSpace.TransformPoint(baked.Anchors.OverheadAnchor);
        Rect hitbox = baked.WorldHitbox;
        Debug.Log($"{data.OutputName} bakes {data.Clips.Count} clips. Text goes at {textPoint}. Hits land in {hitbox}.");
    }
}
  • Anchors の矩形と点は、すべて AnchorSpace のローカル空間で表されます。ただし Anchors.Collider だけは、ルートのローカル空間で表されます。baked.Anchors.HealthBar.ToWorld(baked.AnchorSpace) はワールド空間の矩形を返します。
  • Leaves The Ground (地面から離れる、Archetypes (アーキタイプ) タブの PHYSICS (物理)、Advanced (上級者向け) 表示) をオンにしてベイクしたプレハブの高さをゲームの実行中に変えるには、Body 子オブジェクトの SunForgeBakedRendererBinding の HeightAboveGround を設定してから、ルートの SunForgeBakedShadowSync の PlaceAtHeight(Vector3.zero) を呼んでください。このメソッドは、本体とその影を移動します。スケールを変更したプレハブでは、スクリプトが PlaceAtHeight を呼ぶまで、本体は高さにスケールを掛けた位置にあります。
