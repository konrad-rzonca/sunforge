動作環境

ベイクやシーンのライティングを始める前に、プロジェクトに必要なものを説明します。

  • Unity 6.3 LTS (6000.3.29f1 以降) から Unity 6.6 までのバージョンが必要です。
  • ユニバーサルレンダーパイプライン (URP) の 2D レンダラーまたはユニバーサルレンダラーが必要です。ビルトインレンダーパイプラインと HDRP には対応していません。
  • リニア色空間が必要です。Project Settings > Player > Other Settings > Color Space (プロジェクト設定 > プレイヤー > その他の設定 > 色空間) で設定できます。
  • ベイクするには、アセットのシリアル化が Force Text である必要があります。Project Settings > Editor > Asset Serialization > Mode (プロジェクト設定 > エディター > アセットシリアル化 > モード) で設定できます。新規の Unity プロジェクトでは、これがデフォルトです。
  • Windows では、プロジェクトフォルダーのパスが 110 文字以内である必要があります。これより長いと、一部のファイルが Windows のパス長の上限を超え、インポートやベイクに失敗します。
  • 2D シーンと、スプライトを正面から映すカメラが必要です。カメラの Transform では、Rotation (回転) の X と Y を 0 にしてください。
    • 見下ろし、アイソメトリック、サイドビューのゲームのどれにも使えます。角度はベイクでスプライトに描き込まれるため、カメラ自体を地面に向けて傾けることはありません。
    • カメラは移動、ズーム、シェイクができ、ダッチアングルのように Rotation の Z を任意の角度にすることもできます。その場合も、光と影はワールド内の位置を保ちます。
    • パララックスレイヤー用などの Perspective (透視投影) カメラでも、シーンは同じように照らされます。このカメラでは、表示される影はスプライトとして描画される影だけで、茂みの中に立っているキャラクターは、全体が茂みの手前か奥に描画されます (小道具の中のキャラクターを参照)。
    • 3D シーンや、地面に向けて傾けたカメラでは、ベイクの Prefab Material (プレハブマテリアル、Bake (ベイク) タブ、Advanced (上級者向け) 表示) を Unity Lights に設定し、ユニバーサルレンダラーを使ってください。Unity Lights マテリアルは URP のライトで照らされます。このマテリアルでは、霧、キャストシャドウ、グラウンドカバーは描画されません (スタイル › マテリアルを参照)。
  • すべてのエフェクトは、WebGL 2 と OpenGL ES 3.0 のプレイヤーで動作します。16 ビットのレンダーテクスチャへのブレンドができないデバイスでは、Ground Overlay And Sprites (地面オーバーレイとスプライト)、Ground Material And Sprites (地面マテリアルとスプライト)、Ground Material Only (地面マテリアルのみ) のいずれかに設定した Cast Shadow Field はオフになります。スプライトとして描画される影は引き続き表示され、そのような影がないスプライトは影を落としません。
  • Sun Forge をインストールすると、Sun Forge 2D Lighting、URP、Render Pipelines Core、Burst、Input System、2D Sprite の各パッケージも一緒にインストールされ、Animation、JSONSerialize、Particle System、Physics 2D の各ビルトインパッケージが有効になります。
