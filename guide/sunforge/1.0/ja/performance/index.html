パフォーマンス

ライティングの各設定がシーンにかける負荷と、その設定を変更する場所を確認します。

このページの内容
  • 各設定の負荷
  • Web プレイヤーの最初のフレーム

フレーム時間に影響する設定には、名前の後ろにゲージが表示され、ツールチップに負荷の内容が表示されます。Lighting Setup の Performance (パフォーマンス) セクションには、開いているシーンで負荷がかかっている設定が、負荷の大きい順に一覧表示され、各行の横に Select (選択) があります。

負荷の高い設定をまとめて設定するには、Performance を開いて Fastest (最速)、Balanced (バランス)、Full (フル) のいずれかをクリックしてください。その後、そこから個別の設定を調整できます。各ボタンが変更する内容は、そのボタンのツールチップに表示されます。

各設定の負荷

次の表は、テストシーンで各設定を使った場合と使わなかった場合を比べて計測した負荷です。デスクトップは RTX 4060、スマートフォンは Pixel 8a です。範囲は、複数の計測値の幅を示します。デスクトップで約 0.8 ms 未満の計測値は、実行ごとのばらつきの範囲内です。

設定 設定する場所 負荷 計測値
Render Scale 各品質レベルの URP アセット 大 デスクトップ、1920 × 1080、2026-11: 0.5 にすると GPU で 1.3 から 1.5 ms 短縮
Mist Enabled (霧有効) Lighting Setup、またはスタイルの Default Lighting Values (デフォルトのライティング値) 大 スマートフォン、2026-10: 約 40 ms。デスクトップ、2560 × 1440、2026-11: 1.0 から 1.7 ms
Pixels Per Unit (単位毎のピクセル数) Cast Shadow Field 大 スマートフォン、2026-10: 128 に対して 64 では、GPU の 83 ms のうち約 30 ms 短縮。デスクトップ、2026-11: 64 に対して 16 でも、ばらつきの範囲内
Style (スタイル) Lighting Setup 中 スマートフォン、2026-10: Cinematic は Regular より大きく、Flat は小さい。デスクトップ、2026-11: Regular と比べて、Cinematic は 0.3 から 3 ms、Flat は 0.2 から 1.1 ms 大きい
Mode (モード) Cast Shadow Field 中 デスクトップ、アニメーションするキャラクター 1,000 体、2026-11: And Sprites (とスプライト) のモードは、対応する Only (のみ) のモードと比べて、GPU で 0.7 から 1 ms、メインスレッドで 0.5 から 1.3 ms 大きい
Cast Shadow Stretch Enabled (キャストシャドウの引き伸ばし有効) Lighting Setup、またはスタイルの Default Lighting Values と Hours (時間帯) 中 デスクトップ、2026-11: 4 回の計測のうち 3 回で約 1 ms。Regular の夜明けと夕暮れでは約 0.6 ms (この 2 つの時刻のキーがこの設定をオンにします)
Post Processing Enabled (ポストプロセス有効) Lighting Setup 中 スマートフォン、2026-10: 約 1 ms。デスクトップ、2026-11: 最大 1.6 ms
Light From Lit Ground (照らされた地面からの光) スタイルの Quality (品質) 中 デスクトップ、Cinematic、2026-10: 0.7 から 1.4 ms。2026-11: 0.2 から 1.1 ms
Exact Shadows On Sprites (スプライト上の正確な影) スタイルの Quality 中 デスクトップ、2026-11: 4 回の計測のうち 3 回で 0.5 から 2.2 ms
Mist Height (霧の高さ) Lighting Setup、またはスタイルの Default Lighting Values 小 高さに応じて増加。単独では未計測
Ground Radius (地面での半径) Light Source、および Scene Lights の Intensity (強さ) 小 デスクトップ、2026-11: テストシーンのライトでは、ばらつきの範囲内
Sorted Ground Cover 草のシートに付けたこのコンポーネント 小 デスクトップ、2560 × 1440、キャラクター 1,000 体、2026-11: 0.3 から 0.5 ms

デスクトップ (2026-11) では、Cloud Strength (雲の強さ)、Canopy Shade Strength (Canopy Shade の強さ)、Lighting Setup の Sprite Emission Enabled (スプライトのエミッション有効)、Ambient Occlusion Enabled (アンビエントオクルージョン有効)、Self Shadow Enabled (セルフシャドウ有効) の負荷は、計測できるほどではありませんでした。スマートフォン (2026-10) では、雲、樹冠の日陰、アンビエントオクルージョンの負荷は、それぞれ 1 ms 以下でした。

Web プレイヤーの最初のフレーム

Web プレイヤーでは、ライティングスタイル、またはスタイルで使うマテリアルを初めて描画するフレームに、ブラウザーがシェーダーを準備するため、数秒かかることがあります。Windows の Chrome では、WebGPU で約 2 から 3 秒、WebGL 2 で約 7 から 13 秒です。この時間をロード画面の裏で済ませるには、次のようにしてください。

  1. ゲームで使う各スタイルに切り替え、そのスタイルで使うすべてのマテリアルについて、そのマテリアルを使うスプライトを 1 つずつ描画します。非アクティブなオブジェクトのマテリアルと、後で生成するプレハブのマテリアルも含めます。
  2. Sprite Skin でアニメーションするキャラクターがいて、Project Settings > Player (プロジェクト設定 > プレイヤー) の GPU Skinning が CPU に設定されていない場合は、この手順を、そうしたキャラクターがどれもアクティブでない状態で 1 回、アクティブな状態でもう 1 回実行します。
  3. スタイルの Quality (品質) セクションで、あるオプションを一部の品質レベルでは描画し、ほかのレベルでは描画しないようにしていて、ゲームが実行中に品質レベルを切り替える場合は、そのスタイルを、オプションを描画するレベルと描画しないレベルのそれぞれでも描画します。
