サイドビュー

プラットフォーマーのアートのように、横から見て描かれたアートをライティングし、それに合うアクターをベイクします。

このページの内容
  • サイドビューのライト
  • サイドビューで表示されないもの
  • サイドビューのベイク

プラットフォーマーのアートのように、横から見て描かれたアートはサイドビューです。サイドビューのシーンを照らすには、次のようにしてください。

  1. GameObject > Sun Forge > Set Up for Lighting を選択します。
  2. ウィンドウの最初の行にある Art View (アートの視点) で From the Side (サイドビュー) を選び、Apply (適用する) をクリックします。これで、スプライト、床、壁が、どのスタイルとマテリアルでもサイドビューとして照らされます。
  3. Lighting Setup で、太陽の光が横から当たるように Sun Direction (太陽の方向) と Sun Elevation (太陽の仰角) を設定します。
  4. たいまつや火には、GameObject > Sun Forge > Light Source > Fire > Torch でライトを追加します。昼間に太陽の光で照射範囲が見えなくなる場合は、ライトの Intensity (強さ) を上げます。Flat スタイルでは、Lighting Setup の Light Sources In Sunlight (太陽光下の Light Source) も上げます。

Art View は Lighting Setup にもあり、後からそこで変更できます。Art View はシーンの Lighting Setup ごとに設定されるため、1 つのプロジェクトにサイドビューのステージと見下ろしのステージを混在させられます。

サイドビューのライト

  • Height Above Ground (地面からの高さ) は、ライトがアートからどれだけ手前に離れているかを表し、Ground Radius (地面での半径) は、光が画面上でどこまで届くかを表します。壁に掛けたランプや手に持ったランプでは、どれだけ高い位置にあっても、Height Above Ground を小さく設定してください。
  • ライトは、背景も含め、届く範囲にあるサイドビューのスプライトをすべて照らします。背景を照らさないようにするには、ライトの Excluded Objects (除外するオブジェクト) に追加してください。
  • 壁のたいまつの前を歩くキャラクターのように、Z がライトより小さいスプライトは、ライトの手前にあります。この場合、光はスプライトの縁にしか届かず、Flat ではスプライトにまったく届きません。スプライトの正面を照らすには、ライトの Z をスプライトの Z 以下にしてください。

サイドビューで表示されないもの

  • 雲の影、樹冠の日陰、霧、グラウンドカバー、キャストシャドウ、Cast Shadow Stretch (キャストシャドウの引き伸ばし)、Light From Lit Ground (照らされた地面からの光)、Exact Shadows On Sprites (スプライト上の正確な影) は表示されません。サイドビューには、これらがかかる地面が映らないためです。
  • Sun Forge が角度を付けてレンダリングしたスプライトは、雲の影、樹冠の日陰、霧を除いて、これらをすべて受けます。こうしたスプライトのシーンには From Above (見下ろし) を使ってください。

サイドビューのベイク

プラットフォーマーなど、サイドビューのゲーム用にアクターをベイクする手順は次のとおりです。

  1. アーキタイプの Elevation Angle (俯角、Archetypes (アーキタイプ) タブの CAMERA (カメラ)) を 0 に設定します。
  2. Directions (方向) を 4 に設定し、0° と 180° を向く方向をオフにします。こうすると、アクターは左または右を向き、最初は右を向きます。
  3. コライダーが足元ではなく本体全体を覆うようにするには、Elevation Angle の下にある Cover Whole Body (全体を覆う) を押します。または、PHYSICS (物理) セクション (Advanced (上級者向け) 表示) で、コライダーの Ignore Below Height (これより下を無視する高さ) を 0 に設定し、Ignore Above Height (これより上を無視する高さ) を空にして、Multiplier (乗数) を 1 に設定します。

プラットフォーマーでは、自作のスクリプトでアクターを動かしてください (プラットフォーマーと物理 › サイドビューのゲームを参照)。
