ドット絵

シーンのライティングで照らされるドット絵をベイクし、Pixel Perfect Camera で描画します。

シーンのライティングで照らされるドット絵をベイクする手順は次のとおりです。

  1. アーキタイプの CAMERA (カメラ) セクションで、Pixels Per Unit (単位毎のピクセル数) を 32 など、アートの密度に合わせて設定します。地面タイルも含め、シーンで使うすべてのアーキタイプで同じ値を使います。
  2. Advanced (上級者向け) 表示で、アーキタイプの QUALITY (品質) セクションの Supersampling (スーパーサンプリング) をオフにし、Animation Frame Rate (アニメーションのフレームレート) を 12 などの低いレートに設定します。
  3. アーキタイプの OUTPUT (出力) セクション (Advanced 表示) で、Filter Mode (フィルターモード) を Point (ポイント) に設定し、Generate Mip Maps (ミップマップの生成) をオフにします。
  4. アーキタイプの SHADOW (影) セクション (Advanced 表示) で、Softness (ぼかし) を 0 に設定し、Ground-Projected (地面投影) の下にある Resolution Scale (解像度スケール) を 1 にして、影の 1 ピクセルがスプライトの 1 ピクセルと一致するようにします。
  5. アウトラインを付けるには、ベイクの Prefab Material (プレハブマテリアル、Advanced 表示) を Regular with Pixel Outline (Regular (Pixel Outline 付き)) または Cinematic with Pixel Outline (Cinematic (Pixel Outline 付き)) に設定します。スタイルのすべてのスプライトにアウトラインを付けるには、代わりにスタイルの Sprite マテリアルで Pixel Outline をオンにします (スタイルの調整を参照)。
  6. ベイクし、シーンのカメラに Pixel Perfect Camera を追加します (ドット絵 › Pixel Perfect Cameraを参照)。
  7. ブルームでピクセルがぼやけるため、Lighting Setup の Post Processing Enabled (ポストプロセス有効) のチェックを外します。これにより、スタイルのポストプロセス全体がオフになります。

Pixel Perfect Camera

URP の Pixel Perfect Camera は、スプライトの各ピクセルを、画面の整数個のピクセルからなるブロックとして描画します。カメラの Assets Pixels Per Unit を、スプライトの Pixels Per Unit に設定してください。Pixels Per Unit が異なるスプライトや、スケールを変更したスプライトは、ピクセルのサイズが変わって描画されます。

このカメラは、2D レンダラーとユニバーサルレンダラーのどちらでも動作します。Grid Snapping を Upscale Render Texture に設定した場合は、2D レンダラーでのみ動作します。

Grid Snapping スプライトが動く単位 光、霧、キャストシャドウの変化
None (なし) 画面の 1 ピクセル 画面の 1 ピクセルごとに変わるため、スプライトの 1 ピクセルの中でもなめらかに変化
Pixel Snapping スプライトの 1 ピクセル 画面の 1 ピクセルごとに変わるため、スプライトの 1 ピクセルの中でもなめらかに変化
Upscale Render Texture スプライトの 1 ピクセル シーンがカメラの Reference Resolution (参照解像度) でレンダリングされてから拡大されるため、アートと同じように、スプライトの 1 ピクセルごとに 1 回変化
