平台跳跃游戏与物理

用自己的脚本让烘焙角色在侧视画面中行走和跳跃，并在底层 2D 物理世界中运行烘焙预制件。

本页内容
  • 侧视游戏
  • 物理世界

侧视游戏

Movement、Wander 和 Melee Attacker 除了让角色在屏幕上左右移动，还会让角色上下移动，而且不受重力影响，就像会飞或会游泳的角色。要让带有 Movement 的角色只左右行走，请禁用其 ReadsInput，并每帧用 y 为 0 的方向调用 SunForgeMovement.Walk(direction, Time.deltaTime)。

平台跳跃游戏的烘焙设置请参阅 侧视 › 侧视烘焙。请用自己的脚本移动这类游戏的角色，以及任何留在地面上的角色：

  1. 用 Assets > Create > Sun Forge > Behavior Script（资产 > 创建 > Sun Forge > Behavior Script）新建脚本，在其 [SunForgeBehavior] 中加上 movesActor: true，并把该脚本列在 GAMEPLAY（玩法）部分（Advanced（高级）视图）中，代替 Movement、Wander 或 Melee Attacker，这样烘焙会把 Rigidbody 2D 的 Linear Damping（线性阻尼）设为 0。如果自己把脚本添加到预制件上，需将 Linear Damping 设为 0。
  2. 为角色加上重力：调高其 Rigidbody 2D 的 Gravity Scale（重力大小），重新烘焙会保留该值。使用物理世界时，在其世界定义中设置重力。
  3. 在脚本中，根据输入设置 Rigidbody 2D 的水平速度，只在跳跃时设置垂直速度。使用物理世界时，写入角色的 SunForgePhysicsBody 的 Velocity。
  4. 每帧（包括站立不动时）用角色行走的方向和 Time.deltaTime 调用 SunForgeFacing.FaceUnlessHeld，并调用 SunForgeActorAnimation.Of(this).SetMoveSpeed，行走时传入 1，静止时传入 0。Shooter 的 While Walking（行走时）设为 Keep Walking（保持行走）时，这两个方法都需要调用：不调用 SetMoveSpeed，每次射击都会播放 Attack；不调用 FaceUnlessHeld，角色朝一个方向射击而朝另一个方向行走时，行走动画不会倒放。
  5. 要播放跳跃，在同一个 SunForgeActorAnimation 上调用 SetBool(Animator.StringToHash("Jump"), true)。这会播放名为 Jump 的 Loop While Bool（Bool 为真时循环）条目，直到将其设为 false。
  6. Shooter 也会在按下空格键时开火。如果脚本用空格键跳跃，禁用 Shooter 的 Reads Input（读取输入），用 AimAt 或 AimDirection 瞄准，并在脚本中调用其 Fire。

物理世界

要在 Unity 底层 2D 物理世界中运行烘焙出的预制件，请用 Assets > Create > Sun Forge > Physics World（资产 > 创建 > Sun Forge > Physics World）创建物理世界，在其 Inspector 窗口中设置世界、刚体和形状定义，并在类型模板的 PHYSICS（物理）部分（Advanced（高级）视图）中指定该物理世界。之后，每个带有 Collider Shape（碰撞器形状）的预制件都会获得 SunForgePhysicsBody。

要根据烘焙数据构建自己的物理形状，请读取 SunForgeBakedPrefab.Anchors，并在每次 SunForgeBakedPrefab.AnchorsChanged 触发时重新读取。如果角色的碰撞器启用了 Follows Facing（跟随朝向，Archetypes（类型模板）选项卡 PHYSICS 部分，Advanced 视图），角色转向时碰撞器会随之改变。
