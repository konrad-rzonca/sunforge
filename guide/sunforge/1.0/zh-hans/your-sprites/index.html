手绘的精灵

为手绘的精灵添加法线贴图、发光和金属，并为不直立的精灵绘制几何信息纹理。

本页内容
  • 精灵纹理
  • 绘制几何信息纹理

精灵纹理

自己绘制的精灵可以通过以下两种方式之一获得纹理。

让 Sun Forge 写入纹理

  1. Set Up for Lighting（设置光照）设置好精灵后，选择精灵所在的对象，在其 Lighting Style Renderer 上展开 Glow, Surfaces and Edges（发光、表面和边缘）。
  2. 为每种会发光的颜色单击一次 Add Glow Color（添加发光颜色），然后在精灵上单击该颜色。
  3. 为每种像金属一样反光的颜色单击一次 Add Surface Color（添加表面颜色），然后在精灵上单击该颜色。
  4. 查看 Glows（发光区域）和 Shines（反光区域）两张图片：图片显示所选颜色匹配到的部分，其余部分变灰。要匹配更多部分，调高该颜色的 Tolerance（容差）。
  5. 要使边缘圆滑，启用 Round Edges（圆滑边缘）。
  6. 单击 Write Textures（写入纹理）。
  7. 要让发光照亮地面和精灵上发光部位的周围，单击 Glow Light（发光光源）行中的 Add（添加）。

自备纹理

  1. 将每张纹理保存为 PNG，放在精灵所用纹理的旁边，并按下表的方式命名，其中 <sheet> 是该纹理不含扩展名的文件名。
  2. 运行 Set Up for Lighting（设置光照），或在精灵的 Lighting Style Renderer 上单击 Change Setup（更改设置）。
  3. 在 Sprites（精灵）下，精灵所在的行会列出找到的每个文件。单击 Apply（应用），将这些文件应用到精灵。已有同类纹理的精灵会保留原有纹理。

也可以在 Unity 的 Sprite Editor 窗口中的 Secondary Textures（辅助纹理）下绑定这些纹理。

各纹理包含的内容

只要精灵带有这些纹理，风格材质就会读取：

材质槽位 文件 辅助纹理名称 通道
Normal Map <sheet>_Normal.png _NormalMap 用途为 Ground 且场景的美术从上方绘制时，为按俯视角绘制的法线贴图。其他情况下为按与站立精灵相同的角度绘制的法线贴图。请用平坦法线（128, 128, 255）填充精灵以外的纹素，否则精灵边缘会绘制成暗色。请用 SunForgeNormalDecode.hlsl 中的 SFUnpackNormal 读取，或在 Shader Graph 中使用 Sun Forge Sample Normal Map 节点。两者都把 128 视为无倾斜
Mask <sheet>_MaskTex.png _MaskTex R 为金属度，G 为平滑度，B 为环境光遮蔽；在 Sun Forge 渲染的精灵上，A 表示照到精灵的太阳光多少。线性
Emission <sheet>_Emission.png _EmissionTex 强度为 1 时的发光颜色，sRGB；在 Sun Forge 渲染或写入的纹理上，A 表示精灵从自身发光中受到多少光
Geometry Texture <sheet>_Geometry.png _GeometryTex R 为轴心以上的高度：轴心处为黑色，越亮越高。A 可选（参见 几何信息纹理格式）。线性，且不使用 Crunch 压缩

如果精灵的 _MaskTex 中是其他布局的遮罩，精灵的受光会出错。

在 Scene 视图中查看纹理

在 Scene 视图中启用 Sun Forge Gizmos 面板底部的 Texture View（纹理视图），然后选择一种纹理。

  • 视图只显示有光照或无光照的 URP 材质所绘制的内容，因此使用 Sprites/Default 的精灵、投射阴影、线条和文字会隐藏。
  • 在 Geometry（几何信息）下，没有高度的纹素显示为暗灰色；在 Emission（自发光）下，没有自发光的精灵显示为暗灰色。

绘制几何信息纹理

直立的精灵不需要几何信息纹理。请为不是直立面片的精灵绘制几何信息纹理，例如桌面、手推车或躺着的人物。

  1. 在精灵覆盖的每个像素上涂灰色：地面处为黑色，越高越亮。在精灵表上，让某个精灵保持透明，即可使其保持为直立面片。
  2. 将精灵的轴心放在其前缘与地面相接处，例如手推车的前轮。只有在轴心前方，草才会绘制在精灵之上。精灵立在另一个精灵上时（例如桌上的灯），将轴心放在它与桌子相接处，并将其 Lighting Style Renderer 上的 Height Above Ground（离地高度）设为桌子的高度。
  3. 在精灵表旁边导出名为 <sheet>_Geometry.png 的 PNG。
  4. 运行 Set Up for Lighting（设置光照）。精灵所在的行会列出该纹理，Apply（应用）会导入该纹理并将其应用到精灵。
  • 要以像素为单位绘制，灰度值为 height in pixels * 255 / (Pixels Per Unit * range)，其中 range 是材质的 Height Range (World Units)。在每单位像素数为 32、范围为默认值 8 时，灰度每差一级约等于一个像素。
  • 竖直立起的部分（例如烟囱）在图中高 N 像素时，实际高度为 N / cos(elevation) 像素，其中 elevation 是 Lighting Setup 的 Art View（美术绘制视角）的角度。
  • 使用 Point 过滤时，精灵周围的内容无关紧要。精灵表使用过滤时，导出的背景必须透明。凡是要留为透明的地方，都需要导出带 Alpha 的 PNG。
