系统要求

烘焙或为场景打光之前，项目需要具备的条件。

  • Unity 6.3 LTS（6000.3.29f1 或更高版本）至 Unity 6.6。
  • 通用渲染管线（URP），搭配 2D Renderer 或 Universal Renderer。不支持内置渲染管线和 HDRP。
  • 线性颜色空间，在 Project Settings > Player > Other Settings > Color Space（项目设置 > 玩家 > 其他设置 > 颜色空间）中设置。
  • 烘焙需要 Force Text 资产序列化，在 Project Settings > Editor > Asset Serialization > Mode（项目设置 > 编辑器 > 资产序列化 > 模式）中设置。新建的 Unity 项目默认采用该模式。
  • 在 Windows 上，项目文件夹路径不超过 110 个字符。路径更长时，部分文件会超出 Windows 的路径长度限制，导致导入或烘焙失败。
  • 2D 场景，且摄像机正对精灵，其 Transform 中的 Rotation（旋转）X 和 Y 均为 0：
    • 俯视、等距和侧视游戏都适用：烘焙会把视角画进精灵中，因此摄像机本身从不朝地面倾斜。
    • 摄像机可以移动、缩放和抖动，也可以转到任意 Rotation Z（例如用于荷兰角镜头），光和阴影在世界中的位置保持不变。
    • 使用 Perspective（透视）摄像机（例如用于视差图层的摄像机）时，场景的光照效果相同。这种摄像机下只显示以精灵绘制的阴影，站在灌木丛中的角色会整体绘制在灌木丛前方或后方（参见 道具中的角色）。
    • 3D 场景或摄像机朝地面倾斜时，将烘焙的 Prefab Material（预制件材质，Bake（烘焙）选项卡，Advanced（高级）视图）设为 Unity Lights，并使用 Universal Renderer。Unity Lights 材质由 URP 的光源照亮，不绘制薄雾、投射阴影和地面覆盖物（参见 风格 › 材质）。
  • 所有特效都能在 WebGL 2 和 OpenGL ES 3.0 Player 上运行。在无法混合到 16 位渲染纹理的设备上，设为 Ground Overlay And Sprites（地面叠加层和精灵）、Ground Material And Sprites（地面材质和精灵）或 Ground Material Only（仅地面材质）的 Cast Shadow Field 会关闭。以精灵绘制的阴影仍会显示，没有这类阴影的精灵不投射阴影。
  • 安装 Sun Forge 时，还会安装 Sun Forge 2D Lighting、URP、Render Pipelines Core 包、Burst、Input System 和 2D Sprite 包，并启用 Animation、JSONSerialize、Particle System 和 Physics 2D 这几个内置包。
