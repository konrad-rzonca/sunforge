烘焙纹理

烘焙在精灵表之外添加的纹理，以及精灵表的打包和导入方式。

本页内容
  • 附加纹理
  • 纹理设置

附加纹理

每张附加纹理都以精灵辅助纹理的形式绑定到其精灵表上。法线、遮罩、自发光和几何信息纹理的名称和通道见光照包的页面（参见 手绘的精灵 › 精灵纹理）。烘焙会添加以下纹理：

纹理 辅助纹理名称 通道
遮罩 _MaskTex 烘焙时太阳照亮的纹素处 A 为 1，模型自身阴影中为 0
投影高度 _CastHeightTex 位于启用了 Bake Cast Height Texture（烘焙投影高度纹理，Advanced（高级）视图）的地面投影阴影精灵表上。对每个纹素，R × range 是其最高投射点相对于投下该处阴影的精灵轴心的高度。主体的轴心位于地面上。阴影未覆盖的纹素值为 0。覆盖范围为阴影精灵表的 Alpha。线性

精灵的法线贴图按烘焙摄像机的角度绘制，地面瓦片的法线贴图按俯视角绘制。range 是烘焙的高度范围。

以这些名称之一绑定到精灵表上的纹理，只要烘焙会写入该纹理，就会被替换。

URP 的 Shader Graph 模板

用 URP 的 2D Sprite Lit 或 2D Sprite Custom Lit 模板创建的 Shader Graph 将遮罩命名为 _MaskMap。要读取烘焙的遮罩，请将该属性的 Reference 设为 _MaskTex。Custom Lit 模板还将法线贴图命名为 _Normal_Map：请将其 Reference 设为 _NormalMap。

Unity 的 2D 光源

在 2D Renderer 下的 Unity Lights 材质上，读取遮罩中某个通道的 Light 2D 混合样式会按该通道的值照亮纹素。Unity 自带的 Multiply with Mask 和 Additive with Mask 混合样式读取红色通道，因此只照亮烘焙精灵上的金属部分。请将这两种混合样式改为读取蓝色通道或 Alpha，或改用无遮罩的混合样式。按 Alpha 遮罩的混合样式还会应用烘焙进遮罩的自阴影，否则 Unity Lights 材质不显示这部分自阴影。

烘焙精灵上的草

在烘焙写入的几何信息纹理中，Alpha 是该帧的前缘（参见 几何信息纹理格式）。只有草叶的根部位于该前缘前方时，Sorted Ground Cover 才会把草叶绘制在精灵之上。

前缘是距地面 0.25 世界单位以内各部分的前端，因此草会止于握得较低的武器前方。要让草绘制在动画抬得更高的部分之上，请在 Measure Sizes From（大小测量依据，Bake（烘焙）选项卡 ANIMATION（动画）部分，Advanced（高级）视图）下勾选该动画。

纹理设置

请在类型模板的 OUTPUT（输出）部分（Advanced（高级）视图）中设置 Filter Mode（过滤模式）、Compression（压缩）、Use Crunch Compression（使用 Crunch 压缩）、Generate Mip Maps（生成 Mip 贴图）和 Atlas Max Size（图集最大尺寸）。烘焙根据这些设置为每张纹理选择其在各个平台上的格式。

  • 当 Project Settings > Editor（项目设置 > 编辑器）中的 Sprite Packer Mode（Sprite 打包器模式）为 Sprite Atlas V2 - Enabled 或 Sprite Atlas V2 - Enabled for Builds 时，图集会打包。在其他任何模式下，每张精灵表都作为单独的纹理发布，Bake（烘焙）选项卡会提供 Use Sprite Atlas V2（使用 Sprite 图集 V2）。更改项目的 Sprite Packer Mode 后，重新烘焙之前烘焙过的内容。
  • 如果在烘焙出的图集上，自行在 Default 选项卡或某个平台的选项卡中设置了 Format（格式），或在 Compression（压缩）为 None（无）时启用了 Override（覆盖），该设置会在对应平台上替换烘焙的格式。将 Format 设回 Automatic（自动）后，下一次烘焙会重新写入烘焙的格式。在几何信息纹理或投影高度纹理上自行设置的 Format 会保留。
  • 在任何选项卡上（包括自行设置过格式的选项卡），烘焙都会替换导致几何信息纹理或投影高度纹理绘制出错的格式，并在 Console 窗口中说明。
  • 启用 Generate Mip Maps（Advanced 视图）时，以原尺寸四分之一或更小绘制的精灵，其最外圈像素受光更平，排序也更靠近地面。
  • 在图集上设置更小的 Max Texture Size（最大纹理尺寸）会把图集拆分成更多页，并不会节省空间。

面向手机的 Web 构建

在 Web 上，烘焙跟随 File > Build Profiles（文件 > 构建配置文件）中 Web 平台的 Texture Compression（纹理压缩）。为默认值 Use Player Settings（使用播放器设置）时，烘焙跟随 Player Settings > Web（播放器设置 > Web）中的 Texture compression format（纹理压缩格式）。使用 DXT 时，不支持 DXT 和 BC7 格式的浏览器（例如大多数手机浏览器）会把每张压缩的烘焙纹理解压，占用其 4 倍的内存。对于要在手机上运行的构建：

  1. 将 Texture Compression 设为 ASTC。ETC2 也可以，但使用 ETC2 时，靠近高大精灵的光源照在精灵上可能会出现条带。
  2. 再次烘焙。

在 Unity 6000.6 中，Use Player Settings 下的构建，或由未指定格式的构建脚本生成的构建，可能会以之前的格式发布各精灵图集的图集页。更改 Texture compression format 后，请在 Texture Compression 为 Use Player Settings 时选择这些精灵图集，右键单击并选择 Reimport（重新导入）。

仅对一个平台使用 Crunch 压缩

  1. 在输出文件夹中每个烘焙出的图集上打开该平台的选项卡，启用 Override（覆盖）和 Use Crunch Compression（使用 Crunch 压缩），并将 Format（格式）保持为 Automatic（自动）。图集不打包时，在烘焙出的精灵表上执行相同操作（不包括其法线贴图和几何信息纹理）。
  2. 再次烘焙。烘焙会让图集的法线贴图、几何信息纹理和投影高度纹理在该平台上保持不使用 Crunch 压缩。

重新烘焙会保留这一覆盖。
