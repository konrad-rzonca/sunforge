几何信息纹理格式

几何信息纹理每个通道存储的内容，供读写这种纹理的自制着色器或工具参考。

几何信息纹理用红色通道保存精灵每个像素在轴心以上的高度，用 Alpha 保存精灵与地面相接的位置。要绘制几何信息纹理，请参阅 手绘的精灵 › 绘制几何信息纹理。

格式

  • 轴心以上的高度为 R * range * scale。黑色表示轴心处，白色表示范围的高度，轴心以下没有任何内容。
  • range 是渲染器上的组件设置的范围；没有组件设置时，为材质的 Height Range (World Units)。SunForgeRendererBakeValues.hlsl 中的 SFBakeHeightRange 读取该值。scale 是对象的缩放。
  • Alpha 不低于 8/255 的纹素带有高度。Alpha 低于该值的纹素没有高度：站立的精灵在这些纹素处绘制为竖直的面片，地面精灵则按高度 0 绘制。
  • 绿色和蓝色通道为保留通道，任何材质都不读取，因此红色通道相同的灰度贴图、只有红色通道的贴图和单通道贴图读出的结果相同。请勿在自己的着色器中读取绿色或蓝色通道。
  • 以无损格式（例如 PNG）保存贴图。纹理为线性，不使用 Crunch 压缩，过滤方式与所在的精灵表相同。
  • 只要能保留红色通道，且 Alpha 的偏差不超过 4/255，任何纹理格式都可以使用。压缩格式能保留的高度级数较少，因此 Check Setup（检查设置）会以不压缩的方式导入手绘的贴图。

Sun Forge 的地面覆盖物还会把 Alpha 读作占地范围的前缘：精灵与地面相接的位置在轴心前方多远。只有在该前缘的前方，草才会绘制在精灵之上。如果不使用地面覆盖物，请忽略下表。

Alpha 前缘
243/255 到 255/255 位于轴心处
从 242/255 向下到 27/255 位于轴心前方，距离为范围的 (n / 25)^2 倍，其中 n 是 (247 - a) / 9 四舍五入后的整数，a 是从 0 到 255 的 Alpha 值
8/255 到 26/255 位于轴心前方，距离等于整个范围
低于 8/255 没有高度

要保存前缘，请将 a 设为 247 - 9 * n，其中 n 是 25 * sqrt(edge / range) 四舍五入后的值，最大为 25；n 为 0 时则设为 255。Alpha 与所设的值相差不超过 4/255 时，读出的前缘相同。

要读取纹素，请使用 SunForgeHeightDecode.hlsl 中的 SFHeightShare、SFHeightAbsent 和 SFHeightFrontEdgeShare，或 C# 中的 SunForgeHeightTexel.TryDecode。
