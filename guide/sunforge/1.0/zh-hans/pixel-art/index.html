像素画

烘焙能被场景光照照亮的像素画，并用 Pixel Perfect Camera 绘制。

要烘焙由场景光照照亮的像素画：

  1. 在类型模板的 CAMERA（摄像机）部分，将 Pixels Per Unit（每单位像素数）设为美术资源的像素密度，例如 32。为场景使用的每个类型模板设置相同的值，地面瓦片也不例外。
  2. 在 Advanced（高级）视图中，在类型模板的 QUALITY（质量）部分禁用 Supersampling（超采样），并将 Animation Frame Rate（动画帧速率）设为较低的帧速率，例如 12。
  3. 在类型模板的 OUTPUT（输出）部分（Advanced 视图）中，将 Filter Mode（过滤模式）设为 Point（点），并禁用 Generate Mip Maps（生成 Mip 贴图）。
  4. 在类型模板的 SHADOW（阴影）部分（Advanced 视图）中，将 Softness（柔和度）设为 0，并将 Ground-Projected（地面投影）下的 Resolution Scale（分辨率缩放）设为 1，使每个阴影像素对应一个精灵像素。
  5. 如需描边，将烘焙的 Prefab Material（预制件材质，Advanced 视图）设为 Regular with Pixel Outline 或 Cinematic with Pixel Outline。要为某个风格中的所有精灵描边，改为在该风格的精灵材质上启用 Pixel Outline（参见 调整风格）。
  6. 烘焙，然后为场景的摄像机添加 Pixel Perfect Camera（参见 像素画 › Pixel Perfect Camera）。
  7. 取消勾选 Lighting Setup 上的 Post Processing Enabled（启用后处理），因为泛光会让像素变模糊。这会关闭风格的全部后处理。

Pixel Perfect Camera

URP 的 Pixel Perfect Camera 把每个精灵像素绘制成由整数个屏幕像素组成的方块。请将其 Assets Pixels Per Unit 设为精灵的每单位像素数。每单位像素数与此不同的精灵，或经过缩放的精灵，绘制出的像素大小也不同。

该摄像机在 2D Renderer 和 Universal Renderer 下都可使用。Grid Snapping（网格吸附）的 Upscale Render Texture 仅在 2D Renderer 下有效。

Grid Snapping 精灵移动的步长 光、薄雾和投射阴影的变化
None（无） 屏幕像素 逐个屏幕像素变化，因此在一个精灵像素内平滑过渡
Pixel Snapping 整个精灵像素 逐个屏幕像素变化，因此在一个精灵像素内平滑过渡
Upscale Render Texture 整个精灵像素 与美术一样，每个精灵像素只变化一次，因为场景以摄像机的 Reference Resolution（参考分辨率）渲染后再放大
