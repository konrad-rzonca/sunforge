菜单

Sun Forge 为 Unity 添加的每个菜单项和快捷键，以及各自的作用。

菜单栏中的“工具”

Sun Forge

  • Bake Window

    Alt / OptionShiftB

    打开烘焙窗口，在其中将模型转换为精灵表和可直接使用的预制件。

    首次烘焙

  • Set Up for Lighting

    列出要做的更改，确认后照亮已打开的场景或在预制件模式中打开的预制件，不论当前选择了什么：为其中的精灵添加光照和投射阴影，并为没有 Lighting Setup 的场景添加 Lighting Setup。

  • Open Showcase

    打开 Showcase（用 Sun Forge 烘焙的可游玩场景）；项目中还没有 Showcase 时，会先下载并导入。

    Showcase › 打开 Showcase 首次烘焙 › Showcase

  • Guide

    在浏览器中打开本指南。

在“层级”窗口中右键单击

也可在菜单栏的“游戏对象”下找到

Sun Forge

  • Open in Bake Window

    在烘焙窗口中打开所选已烘焙角色的烘焙，或所选场景对象的预制件或模型。

  • Set Up for Lighting

    列出要做的更改，确认后为精灵添加光照和投射阴影，范围为所选对象、已打开的场景或在预制件模式中打开的预制件，并为没有 Lighting Setup 的场景添加 Lighting Setup。

    首次烘焙 设置场景 光源 › 使用现有的 Light 2D 光源 侧视

  • Camera Follow

    为主摄像机添加 Camera Follow，使其跟随所选对象；场景中没有主摄像机时会创建一个。

  • Cast Shadow Field

    添加 Cast Shadow Field，将精灵的阴影投射到地面和其他精灵上。

  • Canopy Shade

    添加 Canopy Shade，为树冠下的地面和精灵投下树荫。

    阴影 › Canopy Shade

Sun Forge › Light Source

  • Light

    在场景中添加圆形的 Light Source，发出稳定的光。

    设置场景 光源 › 添加光源

  • Spot Light

    添加 Light Source，朝屏幕下方照亮一片锥形区域。

  • Line Light

    添加沿一条线发光的 Light Source。

  • Rectangle Light

    添加在矩形区域内发光的 Light Source。

Sun Forge › Light Source › Fire

  • Candle

    添加小型 Light Source，像蜡烛的火焰一样快速闪烁。

  • Torch

    添加像火把火焰一样闪烁的 Light Source。

    侧视

  • Campfire

    添加明亮、位置较低的 Light Source，像篝火一样闪烁。

  • Fireplace

    添加闪烁的 Light Source，朝屏幕下方照亮一片半圆形区域，就像壁炉。

Sun Forge › Light Source › Lamps

  • Lantern

    添加位于手持高度、发出稳定暖光的 Light Source，就像提灯。

  • Street Lamp

    添加位置较高的 Light Source，光斑亮度均匀，就像路灯。

  • Neon Tube

    添加粉色的 Light Source，沿一条线发光，就像霓虹灯管。

Sun Forge › Light Source › Magic

  • Crystal

    添加靠近地面的冷色调小型 Light Source，就像发光的水晶。

  • Magic Orb

    添加高悬在地面上方的紫色 Light Source，就像魔法球。

Sun Forge › Light Source › Windows and Doors

  • Window

    添加 Light Source，投射一块冷色调的矩形光，就像窗户透进的光。

  • Moonlit Window

    添加 Light Source，投射一块淡蓝色的矩形光，就像透过窗户照进来的月光。

  • Doorway

    添加 Light Source，投射一块暖色调的矩形光，就像亮着灯的门口透出的光。

Sun Forge › Showcase

  • Make Flyer

    Makes each selected baked actor fly like the Showcase scene's bats.

  • Make Butterfly

    Makes each selected baked actor flit, bask and roost like the Showcase scene's butterflies.

  • Make Animal

    Makes each selected baked actor roam like the Showcase scene's animals.

在“项目”窗口中右键单击

也可在菜单栏的“资产”下找到

Sun Forge

  • Open in Bake Window

    在烘焙窗口中打开所选模型、预制件、烘焙预设、类型模板库、烘焙输出或输出文件夹；无法打开所选内容时，按上次离开时的状态打开该窗口。

  • Set Up for Lighting

    列出要做的更改，确认后为所选的精灵和预制件，以及所选文件夹中的精灵和预制件，添加光照和投射阴影。

“项目”窗口中的 + 按钮

也可在右键菜单的“创建”下找到

Sun Forge

  • Physics World

    存放烘焙出的角色共用的 2D 物理世界，可在类型模板的“物理”部分（“高级”视图）中选择。

    平台跳跃游戏与物理 › 物理世界

  • Behavior Script

    在所选文件夹中创建行为脚本，供烘焙窗口添加到烘焙出的预制件上。

    行为 › 编写行为 平台跳跃游戏与物理 › 侧视游戏

  • Lighting Style

    在所选文件夹中创建自己的光照风格：Regular 的副本，带有可单独调整的材质和后处理。

“检查器”窗口中组件上的 ⋮ 按钮

也可右键单击组件名称

Baked Prefab › Reset Anchor

  • Collider

    将 Baked Prefab 的“碰撞器”恢复为烘焙时设定的大小和位置。

  • Glow Point

    将 Baked Prefab 的“发光点”及其发光光源放回烘焙时放置的位置。

  • Health Bar

    将 Baked Prefab 的“血条”放回烘焙时放置的位置。

  • Hitbox

    将 Baked Prefab 的“受击框”恢复为烘焙时设定的大小和位置。

  • Overhead Anchor

    将 Baked Prefab 的“头顶锚点”放回烘焙时放置的位置。

  • VFX Box

    将 Baked Prefab 的“VFX 框”恢复为烘焙时设定的大小和位置。

Sprite Renderer

  • Set Up for Lighting

    列出要做的更改，确认后为此精灵所在的对象添加光照和投射阴影。

快捷键

  • Sun Forge › Bake Window › Save

    Ctrl / CmdS

    保存烘焙窗口当前选项卡中的预设或类型模板库，与该选项卡的“保存”按钮作用相同。

  • Sun Forge › Bake Window › Save As

    Ctrl / CmdShiftS

    将烘焙窗口当前选项卡中的预设或类型模板库另存为新资产。

  • Tools › Sun Forge › Bake Window

    Alt / OptionShiftB

    打开烘焙窗口，在其中将模型转换为精灵表和可直接使用的预制件。
