性能

查看各项光照设置在场景中的开销，以及在哪里更改。

本页内容
  • 各项设置的开销
  • Web Player 中的第一帧

占用帧时间的设置会在名称后显示一个仪表，其工具提示会说明其开销。Lighting Setup 的 Performance（性能）部分按开销从大到小列出已打开场景中有开销的项，每行旁边都有 Select（选择）。

要一次设置这些开销较大的设置，请打开 Performance，单击 Fastest（最快）、Balanced（均衡）或 Full（完整），然后在此基础上调整任意设置。每个按钮的工具提示会说明该按钮更改的内容。

各项设置的开销

下表是每项设置在测试场景中开启与关闭时的开销差异。台式机为 RTX 4060，手机为 Pixel 8a。范围涵盖各次读数。台式机上低于约 0.8 ms 的读数处于各次运行之间的噪声范围内。

设置 设置位置 开销 实测
Render Scale（渲染缩放） 每个质量级别的 URP 资产 大 台式机，1920 × 1080，2026-11：设为 0.5 时节省 1.3 到 1.5 ms GPU 时间
Mist Enabled（启用薄雾） Lighting Setup，或风格的 Default Lighting Values（默认光照值） 大 手机，2026-10：约 40 ms。台式机，2560 × 1440，2026-11：1.0 到 1.7 ms
Pixels Per Unit（每单位像素数） Cast Shadow Field 大 手机，2026-10：64 与 128 相比，在 83 ms GPU 时间中节省约 30 ms。台式机，2026-11：16 与 64 的差异在噪声范围内
Style（风格） Lighting Setup 中 手机，2026-10：Cinematic 比 Regular 多，Flat 比 Regular 少。台式机，2026-11：Cinematic 比 Regular 多 0.3 到 3 ms，Flat 比 Regular 多 0.2 到 1.1 ms
Mode（模式） Cast Shadow Field 中 台式机，1,000 个带动画的角色，2026-11：And Sprites 模式比对应的 Only 模式多 0.7 到 1 ms GPU 时间和 0.5 到 1.3 ms 主线程时间
Cast Shadow Stretch Enabled（启用投射阴影拉伸） Lighting Setup，或风格的 Default Lighting Values 和 Hours（时刻） 中 台式机，2026-11：四次读数中有三次约为 1 ms；在 Regular 的黎明和黄昏约为 0.6 ms，这两个时刻会启用该项
Post Processing Enabled（启用后处理） Lighting Setup 中 手机，2026-10：约 1 ms。台式机，2026-11：最多 1.6 ms
Light From Lit Ground（来自受光地面的光） 风格的 Quality（质量） 中 台式机，Cinematic 下，2026-10：0.7 到 1.4 ms；2026-11：0.2 到 1.1 ms
Exact Shadows On Sprites（精灵上的精确阴影） 风格的 Quality 中 台式机，2026-11：四次读数中有三次为 0.5 到 2.2 ms
Mist Height（薄雾高度） Lighting Setup，或风格的 Default Lighting Values 小 随高度增加。未单独计时
Ground Radius（地面半径） Light Source，以及 Scene Lights 上的 Intensity（强度） 小 台式机，2026-11：测试场景中光源的开销在噪声范围内
Sorted Ground Cover 草地覆盖物精灵上的该组件 小 台式机，2560 × 1440，1,000 个角色，2026-11：0.3 到 0.5 ms

在台式机上（2026-11），Cloud Strength（云强度）、Canopy Shade Strength（树冠阴影强度）以及 Lighting Setup 的 Sprite Emission Enabled（启用精灵自发光）、Ambient Occlusion Enabled（启用环境光遮蔽）和 Self Shadow Enabled（启用自阴影）没有可测出的开销。在手机上（2026-10），云、树冠阴影和环境光遮蔽的开销各为 1 ms 或更低。

Web Player 中的第一帧

在 Web Player 中，某个光照风格或某个风格下的材质第一次绘制时，这一帧可能耗时数秒，因为浏览器要准备其着色器：在 Windows 上的 Chrome 中，WebGPU 下约 2 到 3 秒，WebGL 2 下约 7 到 13 秒。要把这段时间安排在加载画面显示期间：

  1. 切换到游戏使用的每种风格，并为该风格下的每种材质绘制一个精灵，包括未激活对象的材质，以及稍后才生成的预制件的材质。
  2. 如果有角色由 Sprite Skin 驱动动画，且 Project Settings > Player（项目设置 > 玩家）中的 GPU Skinning（GPU 蒙皮）未设为 CPU，先在这些角色都未激活时执行一次上述操作，再在这些角色激活时执行一次。
  3. 如果某个风格的 Quality（质量）部分只在某些质量级别绘制某个选项，在其他级别不绘制，并且游戏在运行时会更改质量级别，还要在绘制和不绘制该选项的级别下各绘制一次这个风格。
