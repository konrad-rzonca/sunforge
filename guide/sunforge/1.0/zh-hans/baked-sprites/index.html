场景中的烘焙精灵

烘焙预制件使用哪种材质绘制、如何跟随场景的风格，以及其粒子在何处排序。

新烘焙的精灵用场景中 Lighting Setup 所用风格的材质绘制。要在每个场景中都用同一种材质绘制，请将该材质选为烘焙的 Prefab Material（预制件材质，Bake（烘焙）选项卡，Advanced（高级）视图），然后重新烘焙。该行菜单中的 Make a Material for This Bake（为此烘焙创建材质）会创建一个可自行调整的材质。

  • 启用了 Baked Renderer Binding 的精灵带有烘焙时的摄像机俯角和高度范围，风格材质中对应这些值的属性只改变没有启用该组件的精灵。精灵的发光是烘焙时的发光乘以材质的 Emission Scale。烘焙为 Glow Light（发光光源）添加的光源，亮度随风格材质的 Emission Scale 变化；使用自己的材质时，则在下一次烘焙时随之变化（参见 调整风格）。
  • 用自己的渲染器绘制烘焙出的精灵时，该渲染器需要 Baked Renderer Binding，否则会按材质中的范围读取精灵的高度。Check Setup（检查设置）会报告这一情况。
  • 使用 Unity 自带精灵材质的主体不显示受击闪白。
  • 配合 Unity 的 2D 光源使用时，为烘焙出的预制件的根添加 Shadow Caster 2D。其投射的阴影会落在 Unity Lights 材质上。
  • 薄雾不会覆盖标记点的发光和拖尾，也不会覆盖着色器不是 Sun Forge/Hand-Drawn Shadow 的阴影精灵（该着色器在 Advanced 视图中由 Archetypes（类型模板）选项卡 SHADOW（阴影）部分的 Material（材质）设置）。
  • 烘焙出的阴影的 Order in Layer（图层顺序）比其主体低 1。请为阴影下方的地面设置比两者都低的值。
  • 父对象的 Scale X 为 -1 时，烘焙出的阴影不会镜像，因此仍落在背离太阳的一侧。在 Cast Shadow Field 的范围之外，如果阴影的 Material（Archetypes 选项卡 SHADOW 部分，Advanced 视图）使用其他着色器，阴影会随父对象一起镜像。

场景中的烘焙粒子

预制件的粒子绘制在其整个主体之上，模型中位于粒子前方的部分也不例外，例如灯笼火焰四周的栅条。

  • 要让粒子绘制在主体后面，把预制件的 Particles 子对象向上移动。粒子按该子对象的位置排序。
  • 只用粒子烘焙出的预制件（例如篝火的火焰）和角色一样，按其站立的位置排序。要让火焰绘制在篝火之上，请把火焰放在篝火的位置或篝火稍前方。
  • 对于架高道具上的火（例如火把），将两者一起烘焙，这样火也会照亮道具，并按道具自身的形状产生明暗。也可以将 Origin Below Ground（原点入地深度，Advanced（高级）视图）设为道具高度的负值，并把火放在道具底部。
  • 单独烘焙的循环火焰自带 Glow 光源。要改用道具的光源，请禁用火焰的 Glow Light（发光光源），并在道具的 Glow 子对象上，将火焰的 Particles 子对象添加到 Light Source 的 Glow Renderers（发光渲染器）中。
  • 脚本在空中生成的特效（例如角色胸口处的受击火花）按其出现的点排序，因此会绘制在该角色后面。要让特效绘制在角色前方，请将其 Particles 子对象的 Order in Layer（图层顺序）设得比该角色的高。
