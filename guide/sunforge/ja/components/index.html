  • Health

    インスペクター

    発射された弾や攻撃でダメージを受け、HP が減っている間は HP バーをアクターの上に表示します。

    インスペクターの設定

    最大 HPアクターの開始時の HP
    Show BarHP が減っている間、HP バーをアクターの上に表示します。HP が 0 になると再び非表示になります。
    HP が 0 のとき[倒れずに残す] では、アクターをシーンに残し、自作のスクリプトで処理できるようにします。[死亡して非アクティブ化] では、ベイクに Die エントリーがあればそれを再生してから、アクターを非アクティブにします。
    Damaged命中するたびに、ダメージと命中した攻撃の進行方向を渡して呼び出されます。
    DepletedHP を 0 にした命中で 1 回だけ呼び出されます。

  • Melee Attacker

    Movement を持つ最も近いアクターまで歩いて行って攻撃し、Attack という名前の [1 回再生] エントリーを再生します。

    インスペクターの設定

    ターゲット追いかけるアクターです。空欄のときは、Movement を持つ最も近いアクターを追いかけます。そのアクターが非アクティブか HP が 0 の間、またはそのアクターの Health が無効の間は立ち止まります。
    速度単位は 1 秒あたりのワールド単位です。0 のときはベイクした歩行アニメーションの速度を使い、ベイクした歩行アニメーションがなければ 1.6 を使います。ベイクした速度では、左右に歩くときに足元が滑りません。
    Reach立ち止まって攻撃するときの、自身のコライダーとターゲットのコライダーの間隔 (ワールド単位) です。攻撃は、それより最大 0.25 遠くにいるターゲットにも当たります。
    ダメージ1 回の攻撃でターゲットの Health から減らす HP
    Cooldown Seconds攻撃の間隔 (秒)

  • Physics Body

    インスペクター

    再生モードの間、ベイクしたアクターを Physics World でシミュレーションします。

    インスペクターの設定

    Physics Worldこのアクターをシミュレーションする Physics World です。ベイクでアーキタイプから設定されます。
    Is Static物理演算で動かない背景のオブジェクトではオンにします。アーキタイプの [移動可能] ([上級者向け] 表示) がオフのとき、ベイクでオンになります。
    質量このオブジェクトに Rigidbody 2D がないときに使う質量 (kg) です。ベイクでは、モデルの体積にアーキタイプの [密度] ([上級者向け] 表示) を掛けた値が設定されます。

  • Shooter

    インスペクター

    クリック、タッチ、または Space キーでポインターに向けて発射し、Attack という名前の [1 回再生] エントリーを再生します。[While Walking] を [歩行を継続] にすると、代わりに歩行アニメーションを再生し続けます。発射した弾は Muzzle という名前のマーカーから (ない場合はヒットボックスの端から) 出て、照準を合わせた点を通って飛びます。

    インスペクターの設定

    Projectile Prefab発射ごとに生成するプレハブです。空欄のときは、組み込みの弾を発射します。
    Cooldown Seconds発射ボタンを押し続けている間の発射間隔 (秒) です。Attack の長さより短いと、発射のたびに Attack が最初から再生されます。それよりわずかに長いと、Attack は次の発射まで最後のフレームで止まります。
    歩行中アクターが歩いている間の発射で再生するアニメーションです。[Attack を再生] では、歩行アニメーションの代わりに Attack エントリーを再生します。[歩行を継続] では歩行アニメーションを続け、発射する方向と歩く方向が逆の間は逆再生し、Attack とそのアニメーションイベントはスキップします。武器を構えたまま歩く歩行アニメーションに適しています。
    Recoil Pixels[歩行を継続] のとき、歩行中に発射するとアクターの描画位置が後ろに押される距離 (スプライトのピクセル単位) です。すぐに元の位置に戻り、コライダーは動きません。0 にするとオフになります。
    Reads Inputポインターまたはタッチで照準を合わせ、クリック、タッチ、または Space キーで発射します。オフにすると、自作のスクリプトから照準を合わせて発射できます。
    Aim Cameraポインターで照準を合わせるときに使うカメラです。空欄のときは、MainCamera タグの付いたカメラを使います。

  • Canopy Shade

    インスペクター

    [マップを描画] で作成した、または手描きした樹冠マップをもとに、樹冠の下にある地面とスプライトを日陰にします。

    インスペクターの設定

    Map樹冠のマップです。白は開けた空、黒は樹冠に覆われた場所を表します。[マップを描画] は [Trees] からこのマップを描画します。赤チャンネルだけを読み取るため、[Single Channel] の [Red] としてインポートするとメモリを節約できます。
    矩形マップが覆う領域です (ワールド単位、このオブジェクトからの相対位置)。領域の外は空が開けています。
    Canopy Heightスプライトが日陰から外れる高さです (ワールド単位)。木の高さ程度に設定してください。[マップを描画] では、木の上端の高さの平均に設定されます。
    木[マップを描画] で使う、木だけをまとめたオブジェクトです。子の空のオブジェクトはグループ、それ以外の子オブジェクトは 1 本の木として扱われます。[マップを描画] は、木のピボットを幹が地面に接する位置として読み取ります。

    インスペクター

  • Cast Shadow Field

    インスペクター

    すべてのスプライトの影を地面と立っているスプライトに落とし、影が重なった部分は 1 回分だけ暗くします。

    インスペクターの設定

    Followed CameraCast Shadow Field が追従するカメラです。MainCamera タグが付いたカメラに追従させるには、未設定のままにしてください。
    単位毎のピクセル数影の解像度です (1 ワールド単位あたりのテクセル数)。0 にすると、影スプライトの中で最も細かい [Pixels Per Unit] に合わせます。値が低いほど、スマートフォンでの負荷が小さくなります。
    モード影が落ちる場所です。地面オーバーレイのモードは、どの地面のマテリアルでも機能します。地面マテリアルのモードには、Sun Forge のスタイルが適用された地面が必要で、Lighting Setup の [キャストシャドウの引き伸ばし] で影が長くなります。[地面オーバーレイとスプライト] と [地面マテリアルとスプライト] は、スタイルのマテリアルを使う立っているスプライトにも影を落とします。
    ソートモード[ソート最下位の影]: 最も下にソートされる影のソート位置を使います。[カスタム]: 下の欄で指定したレイヤーと順序を使います。影より上にソートされたデカールには影が表示されません。
    ソートレイヤー名影レイヤーを描画するソートレイヤーの名前です。未設定の場合は Default を使います。
    Sorting Order影レイヤーを描画するときのレイヤーの順序

  • Cast Shadow Pair

    地面の影太陽と反対側に落ちる、地面の影のレンダラーまたは手描きの影です。ない場合は未設定です。
    丸影丸影のレンダラーです。丸影がない場合は未設定です。

  • Light Source

    インスペクター

    点の周り、線に沿った範囲、または矩形の範囲でスプライトを照らします。明るさは一定にも、ちらつくようにもできます。

    ライト › ライトの追加

    インスペクターの設定

    Driving Light 2Dオンにすると、このゲームオブジェクトの Light 2D がこのライトの色、明るさ、[Ground Radius]、スポット角度を設定するため、Light 2D を制御するものがこのライトも制御します。
    Light 2D で制御オンにすると、このゲームオブジェクトの Light 2D がこのライトの色、明るさ、[Ground Radius]、スポット角度を設定するため、Light 2D を制御するものがこのライトも制御します。
    色ライトの色です。炎は暗くなると赤みを帯びます。Flat スタイルでは、明るいライトや彩度の高い色のライトの近くにあるアートが、ライトがオフのときより暗く描画されることがあります。夕暮れ、夜明け、室内、明るい夜に起こります。明るい夜には、金属はライトの色にかかわらず暗くなります。これを避けるには、ライトの [Intensity] を下げるか、ライトをアートから離してください。
    レベル
    強さライトの位置での明るさです。尺度は太陽の強さと同じです。距離とともに弱まり、[Ground Radius] で途切れます。0 にするとライトはオフになり、カメラが点灯できるライトの数には数えられません。
    地面からの高さ地面からのライトの高さです (ワールド単位)。照射範囲はゲームオブジェクトの真下の地面に広がり、ライトが高いほど、照射範囲は均一に、暗く照らされます。俯角 0 (サイドビュー) 向けに描かれたアートでは、ライトが高いほど、アートから離れた位置になります。
    地面での半径ライト直下の点、またはライトの線や矩形から、光が地面上と地面より高い位置にあるものに届く距離です (ワールド単位)。[Height Above Ground] を変えても変わりません。0 にすると、ライトは何も照らしません。俯角 0 (サイドビュー) 向けに描かれたアートでは、照射範囲は画面上でライトの周りに広がり、この半径で途切れます。
    Source Radius炎など、ライトの発光する部分の半径 (ワールド単位) です。半径を大きくすると、キャラクターやオブジェクトのシェーディングが柔らかくなり、ハイライトが広がります。炎の光はこの範囲の内側で動きます。
    形状地面上での光の形状です。光はその縁から [Ground Radius] の分だけ外まで届き、[Inner Radius] で形状の角が丸くなります。
    形状の長さゲームオブジェクトの上方向の軸に沿った、地面上での光の長さです (ワールド単位)。向きを変えるには、Scene ビューで照射方向のハンドルをドラッグするか、ゲームオブジェクトを回転させてください。
    幅ゲームオブジェクトの上方向の軸と直交する、地面上での光の幅 (ワールド単位)
    内側半径ライトの点、線、または矩形からこの距離 (ワールド単位) までは、地面が均一に照らされます。最大値は [Ground Radius] で、そのとき照射範囲の縁がくっきりします。
    内側スポット角度ゲームオブジェクトの上方向の軸を中心としたこの角度 (度単位) の内側では、光が弱まりません。向きを変えるには、Scene ビューで照射方向のハンドルをドラッグするか、ゲームオブジェクトを回転させてください。
    外側スポット角度ゲームオブジェクトの上方向の軸を中心とした、光が届かなくなる角度です (度単位)。360 で全周を照らします。
    種類一定の明るさのライト、または再生モードでちらつく炎

    特殊なケース › Glow Parts Light Scaleこのライトが所属するオブジェクトについて、ライティングスタイルの [Glow Parts Light On Its Object] に掛ける値です。1 でスタイルの値のまま、0 で光が加わりません。スタイルの値が 0 の場合は変わりません。

  • Lighting Setup

    インスペクター

    ライティングスタイルに沿った太陽または月、空、雲、霧でシーンを照らします。

    インスペクターの設定

    アートの視点[アートの視点] が設定されていないため、スプライト、Tilemap、Sprite Shape はそれぞれのマテリアルが指定する角度で描画されます。すべてを同じ角度で描画するには、[見下ろし] または [サイドビュー] を選んでください。
    スタイル › スタイルこの Lighting Setup が適用するライティングスタイルです。マテリアル、ポストプロセス、ライティングの値を適用します。
    スタイル › 時刻シーンのライティングの時刻です (0 から 24 の範囲)。この Lighting Setup で変更していない値は、それぞれこの時刻でのスタイルの値になり、12:00 ではスタイルのデフォルト値になります。時刻は、スクリプトで動かすまで、再生モードでも設定した値のままです。
    グローバルライト › 太陽と月の明るさ[Time Of Day] にかかわらず、昼は太陽の明るさに、夜は月の明るさに掛ける値です。[Values] の下にある行は、引き続きスタイルの時刻に従います。1 でスタイルの光のままです。Light Source の明るさは変わりません。Flat スタイルでは、1 より大きい値にしてもあまり明るくなりません。
    グローバルライト › 空の明るさ[Time Of Day] にかかわらず、日陰を照らす空の光の明るさに掛ける値です。[Values] の下にある行は、引き続きスタイルの時刻に従います。1 でスタイルの光のままです。Flat スタイルでは、1 より大きい値にしてもあまり明るくなりません。
    グローバルライト › ディレクショナルライトの太陽設定は任意です。未設定の場合は、この Lighting Setup 自身の太陽を使います。メッシュを照らしているライトなど、Unity のディレクショナルライトをここに設定すると、太陽の方向、仰角、色、強さがそのライトで決まります。Light 2D と Light Source はここには設定できません。スタイルが適用されたスプライトには、URP がメッシュを照らすときと同じようにこのライトの色が当たり、Lighting Setup 自身の太陽と同じく、[Sun Warmth] で色味が付きます。無効にするか、地平線より下から照らす向きにすると、太陽の光は当たりません。月で照らすには [Night] を上げてください。このライトを Lighting Setup だけで使う場合は、[Culling Mask] を [Nothing] に設定してください。
    グローバルライト › Sun Color太陽の色です。[Sun Warmth] で暖色寄りや寒色寄りに変わります。
    グローバルライト › Sun Intensity太陽の明るさです。0 で太陽の光がなくなります。
    グローバルライト › Ambient Sky Colorすべての表面に当たる空の光の色です。
    グローバルライト › Ambient Sky Intensity日陰を照らす空の光の明るさです。0 で空の光がなくなります。
    グローバルライト › Moon Color[Night] が大きくなるにつれてシーンを照らす、月の光の色です。明るさは [Moon Intensity] で設定します。
    グローバルライト › Moon Intensity月の明るさです。0 で月のない夜になります。
    値 › Follows Shadow Sun太陽と月を影ができたときの方位角に向け、照らされる面が影と合うようにします。[Sun From Directional Light] にライトが設定されている間は、月だけを向けます。影どうしの向きが一致しない場合は効果がありません。
    値 › 太陽 › 太陽の方向太陽の方位角です (度単位)。0 はカメラから離れる向き、90 は右、180 はカメラに向かう向き、270 は左です。影はこれに合わせて回転しません。
    値 › 太陽 › 太陽の仰角地平線からの太陽の高さです (度単位)。90 で真上、0 で地平線上です。太陽がどの面を照らすか、平らな地面にどれだけ光が当たるかが決まります。夜にするには [Night] を上げてください。影の長さは変わらないため、[キャストシャドウの引き伸ばし] で長く描画してください。
    値 › 太陽 › Sun Warmth太陽の色を変えます。0 で淡い銀色、0.5 で [Sun Color] のまま、1 で琥珀色になります。月には影響しません。
    値 › 太陽 › Ground Shadow Strength影スプライトと Cast Shadow Field の地面オーバーレイの濃さです。値が高いほど濃くなります。空の光に比べて太陽や月の光が強まるほど濃くなり、弱まるほど薄くなります。
    値 › 太陽 › Light Sources In Sunlight明るく照らされたシーンで Light Source の光が見える度合いです。0 では、ライトが太陽と空よりはるかに明るい場所でだけ光が見え、1 では夜と同じように見えます。明るい光の下では Light Source はアートに色味を付けるだけになり、淡い色のアートが暗くなることがあります。ライトでアートを明るくするには、Lighting Setup の [Sun And Moon Brightness] と [Sky Brightness] も下げてください。
    値 › 空 › 地面の照り返しの強さ地面がスプライトに照り返す光の量です。0 でオフになり、金属には地面が映り込まなくなるため暗く見えます。
    値 › 空 › 地面の照り返しの色
    値 › 空 › Canopy Shade Strength樹冠の下で、Canopy Shade が空の光を遮る割合です。0 で樹冠の日陰がなくなります。
    値 › 空 › 環境金属に映り込む、太陽を含まない画像です。太陽のハイライトは Lighting Setup が描画します。[None] にすると、空と地面の色から作られた空が映り込みます。
    値 › 空 › Environment Intensity金属に映る [Environment] の画像の明るさです。2 で 2 倍、0.5 で半分の明るさで映ります。
    値 › 空 › Environment Follows Sun And Skyオン: 太陽と空の変化に合わせて、映り込みが明るくなったり暗くなったりし、色味も変わります。屋外の画像向けです。オフ: 太陽と空がどう変わっても、金属には画像が元の色のまま映り込みます。室内の画像向けです。
    値 › 夜 › 夜夜の深まり具合です。0 では太陽が、1 では月がシーンを照らし、その間では太陽の光が徐々に月の光に変わります。マテリアルもこれに合わせて夜の見え方に変わります。夜間も空の明るさは [Ambient Sky Intensity] のままです。夜をもっと暗くするには、[Ambient Sky Intensity] を下げてください。
    値 › 夜 › Moon Direction月の方位角です (度単位)。0 はカメラから離れる向き、90 は右、180 はカメラに向かう向き、270 は左です。
    値 › 夜 › Moon Elevation地平線からの月の高さです (度単位)。90 で真上、0 で地平線上です。月がどの面を照らすか、平らな地面にどれだけ光が当たるかが決まります。
    値 › キャストシャドウの引き伸ばし › キャストシャドウの引き伸ばし有効Cast Shadow Field で、演出として地面の影を長く描画します。オフにすると、各影を本来の長さで表示します。
    値 › キャストシャドウの引き伸ばし › Cast Shadow Stretch Sun Angle Offset影ができたときの太陽より、この角度 (度単位) だけ太陽が低いかのように影を長くします。低くした太陽の高さは最低 10° です。長く引き伸ばした影ほど柔らかく描画されます。0 では影を引き伸ばしません。
    値 › キャストシャドウの引き伸ばし › Cast Shadow Stretch End Opacity引き伸ばされた影の先端の暗さです。1 で影と同じ暗さのまま、0 で先端に向かって消えます。
    値 › キャストシャドウの引き伸ばし › Cast Shadow Stretch End Sway引き伸ばされた影の先端が時間とともに揺れる大きさです (引き伸ばし量に対する割合)。0 で揺れません。
    値 › キャストシャドウの引き伸ばし › Cast Shadow Stretch Body Clearance引き伸ばされた影が立っているスプライトにかからなくなる高さを、キャスターの上端からどれだけ下にするかを設定します。0 では、同じ高さのスプライトの隣にあるスプライトが暗くなることがあり、1 では植物の上部に影がかからないことがあります。
    値 › 天候 › Cloud Strength最も暗い雲の影が遮る太陽光の割合です。時間とともに変化します。0 で雲がなくなります。俯角 0 (サイドビュー) 向けに描かれたアートには、雲の影がかかりません。
    値 › 天候 › Weather Scroll Direction雲と霧が流れていく方向です (度単位)。0 はカメラから離れる向き、90 は右、180 はカメラに向かう向き、270 は左です。

    値 › 天候 › Cloud Speed[Weather Scroll Direction] に沿って雲の影が地面を流れる速さ (1 秒あたりのワールド単位)
    値 › 天候 › Cloud Variation Over Time雲の強さ、流れ、形が時間とともに変化する度合いです。0 で一定になります。
    値 › 霧 › 霧有効地面の霧を表示します。霧の形は下の設定で決まります。俯角 0 (サイドビュー) 向けに描かれたアートには、霧がかかりません。
    値 › 霧 › Mist Strength霧で見えにくくなる度合いです。時間とともに変化します。0 で霧がなくなります。
    値 › 霧 › Mist Coverage同梱の [Cloud And Mist Texture] を使ったときに、霧が地面を覆うおおよその割合です。値を小さくすると、霧がまだらに途切れます。

    値 › 霧 › Mist Color白い光の下での霧の色です。太陽、空、Light Source の色味はさらに加わり、白以外の色にすると霧が暗くなります。
    値 › 霧 › Mist Repeat Length地面上で霧の模様が繰り返されるまでの大きさ (ワールド単位)
    値 › 霧 › Mist Speed[Weather Scroll Direction] に沿って霧が地面を流れる速さ (1 秒あたりのワールド単位)

    スタイル設定 › 名前スタイルの名前です。変更すると、スタイルの隣にある専用のマテリアルとポストプロセスの名前も変更されます。
    表示 › ポストプロセス有効この Lighting Setup が適用されている間、スタイルのポストプロセスを表示します。
    表示 › Sprite Emission Enabledスタイルが適用されたスプライトのエミッションを表示します。
    表示 › Ambient Occlusion Enabledスタイルが適用されたスプライトのアンビエントオクルージョンを表示します。
    表示 › Self Shadow Enabledスタイルが適用されたスプライトに描き込まれたセルフシャドウ (顔にかかる帽子のつばなど) を表示します。描かれたときの太陽と大きく異なる太陽では、オフにしてください。
