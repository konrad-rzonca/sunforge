ビヘイビア

Bake Window で追加できるビヘイビアを作成し、アニメーションイベントを受け取ります。

このページの内容
  • ビヘイビアの作成
  • アニメーションイベント

ビヘイビアの作成

ビヘイビアは Assets > Create > Sun Forge > Behavior Script (アセット > 作成 > Sun Forge > Behavior Script) で作成してください。Unity がコンパイルすると、+ Add Behavior (+ ビヘイビアを追加) のピッカー (GAMEPLAY (ゲームプレイ)、Advanced (上級者向け) 表示) の Your Project (プロジェクト) の下に、[AddComponentMenu] で指定した名前で表示されます。指定がなければクラス名で表示されます。

  • SunForgeBakedPrefab.Of(this) が返す SunForgeBakedPrefab を保持し、その Data は必要になったときに読んでください。そうすれば、あとから SetData で設定したデータもスクリプトに届きます。
  • 自作の弾では、SunForgeHitSweep.TryFirstHit が、その移動で最初に当たる SunForgeHealth または SunForgeProjectileBlocker を返します。

アクターの移動

  • アクターを動かすスクリプトでは、その [SunForgeBehavior] に movesActor: true を追加してください。追加しないと、ベイクが移動可能なプレハブに線形減衰を設定するため、アクターが減速します。
  • 自作の移動ビヘイビアでは、SunForgeLocomotion がアクターを歩かせ、歩く方向にアクターの向きを変え、歩行アニメーションを再生します。OnEnable からその ClearCachedAnimator を呼ぶと、見た目を差し替えたアクターが新しい見た目のアニメーションを再生します。
  • Movement はキーボード入力だけを読み取ります。タッチ操作でアクターを歩かせるときや、アクターをある地点まで歩かせるときは、その ReadsInput をオフにし、SunForgeMovement.Walk または SunForgeMovement.WalkTowards を毎フレーム呼んでください。
  • Movement、Wander、Melee Attacker または Shooter を持つアクターの見た目を差し替えたら、アクターを無効にしてから有効にしてください。これらのビヘイビアが新しい見た目のアニメーションを再生するようになります。

アニメーションの再生

  • アニメーションは SunForgeActorAnimation.Of(this) を通して再生してください。そのトリガー、bool、Speed、リスタートは、ベイクの Animation Player (アニメーションプレイヤー、Advanced (上級者向け) 表示) がどちらのプレイヤーを選んでも動作します。
  • SunForgeActorAnimation.BakedParticlesOf(this) は、アクターのパーティクルを再生するものを返します。その Play(SunForgeAnimatorParameters.BakedParticlesState, t) に 0 から 1 の t を渡すと、パーティクルを開始するか、再生し直します。プールしたエフェクトは、再生する前にアクティブにしてください。
  • アニメーションの終了を知るには、PlayTracked または SetTriggerTracked で開始してください。どちらも SunForgeAnimationWait を返すので、その IsDone を読むか、コルーチンで yield return してください。
  • アニメーションの特定の時点でメソッドを実行するには、そのクリップにアニメーションイベントを追加してください (ビヘイビア › アニメーションイベントを参照)。

アニメーションイベント

ベイク元のクリップにあるアニメーションイベントは、Animation Player (アニメーションプレイヤー、Advanced (上級者向け) 表示) がどちらのプレイヤーを選んでも、イベントの時点のポーズを写したフレームが表示されたときに、ベイクしたアニメーションで発火します。イベントは、プレハブのルートにある各スクリプトの、イベントと同じ名前のメソッドを呼び出します。そのメソッドを持つスクリプトをプレハブのルートに追加するか、GAMEPLAY (ゲームプレイ) セクション (Advanced 表示) に登録してください。

  • エントリーの Range (範囲) の外にあるイベントは含まれません。
  • 2 つのフレームの間にあるイベントは近いほうのフレームで発火するため、Frame Rate (フレームレート) が低いと、ベイク元で 1 フレーム離れた 2 つのイベントが同時に発火することがあります。
  • ループするアニメーションでは、最後の半フレームにあるイベントは最初のフレームで発火するため、最初のループを含め、各ループの開始時に発火します。
  • アニメーションにイベントがある場合、コントローラー内のそのステートの Speed (速度) は 2 になり、コントローラーには値が 1 の SunForge:Events パラメーターがあります。どちらもそのままにしてください。この 2 つの設定によって、アニメーションがベイクしたレートでイベントとともに再生されます。
  • Flipbook Player (フリップブックプレイヤー) のときと、Leaves The Ground (地面から離れる、Archetypes (アーキタイプ) タブの PHYSICS (物理)、Advanced 表示) でベイクしたプレハブでは、AnimationEvent を受け取るメソッドに、関数名、パラメーター、時間が渡されます。受け取ったイベントから Animator のクリップ情報やステート情報を読むとエラーがログに出力されるため、先に isFiredByAnimator を確認してください。どちらの場合も、AnimationEventInfo を受け取るメソッドは呼び出されません。Leaves The Ground でベイクしたプレハブを Animator で再生する場合、自作のクリップのイベントは Body 子オブジェクトで発火します。
