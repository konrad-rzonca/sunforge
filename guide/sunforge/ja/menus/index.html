メニュー

Sun Forge が Unity に追加するすべてのメニュー項目とショートカットを、それぞれの働きとともに紹介します。

このページの内容
  • メニューバーの [ツール]

  • プロジェクトウィンドウで右クリック

  • インスペクターでコンポーネントにある ⋮ ボタン

メニューバーの [ツール]

Sun Forge

  • Bake Window

    Alt / OptionShiftB

    Bake Window を開きます。このウィンドウでは、モデルをスプライトシートとすぐに使えるプレハブに変換できます。

    最初のベイク

  • Set Up for Lighting

    一覧表示される変更を確認した後で、何を選択しているかにかかわらず、開いているシーン、またはプレハブモードで開いているプレハブを照らします。そのスプライトにライティングとキャストシャドウを適用し、Lighting Setup がないシーンには Lighting Setup を追加します。

  • Open Showcase

    ショーケース (Sun Forge でベイクしたプレイ可能なシーン) を開きます。プロジェクトにない場合は、先にダウンロードしてインポートします。

    ショーケース › ショーケースの開き方 最初のベイク › ショーケース

  • Guide

    このガイドをブラウザーで開きます。

ヒエラルキーで右クリック

メニューバーの [ゲームオブジェクト] にもあります

Sun Forge

  • Open in Bake Window

    ベイクしたアクターを選択しているときはそのベイクを、シーン内のオブジェクトを選択しているときはそのプレハブかモデルを、Bake Window で開きます。

  • Set Up for Lighting

    一覧表示される変更を確認した後で、選択したオブジェクトのスプライト、または開いているシーンかプレハブモードで開いているプレハブのスプライトにライティングとキャストシャドウを適用し、Lighting Setup がないシーンには Lighting Setup を追加します。

    最初のベイク シーンのセットアップ ライト › Light 2D の利用 サイドビュー

  • Camera Follow

    選択したオブジェクトに追従する Camera Follow をメインカメラに追加します。シーンにメインカメラがない場合は作成します。

  • Cast Shadow Field

    スプライトの影を地面やほかのスプライトに落とす Cast Shadow Field を追加します。

  • Canopy Shade

    樹冠の下にある地面とスプライトに日陰を落とす Canopy Shade を追加します。

    影 › Canopy Shade

Sun Forge › Light Source

  • Light

    一定の明るさで発光する円形の Light Source をシーンに追加します。

    シーンのセットアップ ライト › ライトの追加

  • Spot Light

    画面の下方向へ円錐形に照らす Light Source を追加します。

  • Line Light

    線に沿って発光する Light Source を追加します。

  • Rectangle Light

    矩形の範囲で発光する Light Source を追加します。

Sun Forge › Light Source › Fire

  • Candle

    ろうそくの炎のように速くちらつく、小さな Light Source を追加します。

  • Torch

    たいまつの炎のようにちらつく Light Source を追加します。

    サイドビュー

  • Campfire

    焚き火のようにちらつく、明るく低い位置の Light Source を追加します。

  • Fireplace

    暖炉のように、画面の下方向へ半円形に照らす、ちらつく Light Source を追加します。

Sun Forge › Light Source › Lamps

  • Lantern

    ランタンのような、手に持つ高さにある、暖色で一定の明るさの Light Source を追加します。

  • Street Lamp

    街灯のような、照射範囲を均一に照らす高い位置の Light Source を追加します。

  • Neon Tube

    ネオン管のように、線に沿ってピンク色に発光する Light Source を追加します。

Sun Forge › Light Source › Magic

  • Crystal

    発光するクリスタルのような、地面近くにある寒色の小さな Light Source を追加します。

  • Magic Orb

    魔法のオーブのような、地面から高い位置にある紫色の Light Source を追加します。

Sun Forge › Light Source › Windows and Doors

  • Window

    窓明かりのような、寒色の矩形の光を放つ Light Source を追加します。

  • Moonlit Window

    窓から差し込む月明かりのような、淡い青色の矩形の光を放つ Light Source を追加します。

  • Doorway

    明かりが漏れる戸口のような、暖色の矩形の光を放つ Light Source を追加します。

Sun Forge › Showcase

  • Make Flyer

    Makes each selected baked actor fly like the Showcase scene's bats.

  • Make Butterfly

    Makes each selected baked actor flit, bask and roost like the Showcase scene's butterflies.

  • Make Animal

    Makes each selected baked actor roam like the Showcase scene's animals.

プロジェクトウィンドウで右クリック

メニューバーの [アセット] にもあります

Sun Forge

  • Open in Bake Window

    選択したモデル、プレハブ、ベイクプリセット、アーキタイプライブラリ、ベイクした出力、または出力フォルダーを Bake Window で開きます。選択したものを開けないときは、ウィンドウを前回の状態のまま開きます。

  • Set Up for Lighting

    一覧表示される変更を確認した後で、選択したスプライトとプレハブ、および選択したフォルダー内のスプライトとプレハブにライティングとキャストシャドウを適用します。

プロジェクトウィンドウの + ボタン

右クリックメニューの [作成] にもあります

Sun Forge

  • Physics World

    ベイクしたアクターが共有する 2D 物理ワールドを保持します。このワールドは、アーキタイプの [物理] セクション ([上級者向け] 表示) で選択します。

    プラットフォーマーと物理 › 物理ワールド

  • Behavior Script

    選択したフォルダーにビヘイビアのスクリプトを作成します。Bake Window は、ベイクしたプレハブにこのスクリプトを追加します。

    ビヘイビア › ビヘイビアの作成 プラットフォーマーと物理 › サイドビューのゲーム

  • Lighting Style

    選択したフォルダーに、自作のライティングスタイルを作成します。Regular をコピーしたもので、専用のマテリアルとポストプロセスを調整できます。

インスペクターでコンポーネントにある ⋮ ボタン

コンポーネント名を右クリックしても開けます

Baked Prefab › Reset Anchor

  • Collider

    Baked Prefab のコライダーを、ベイクで設定されたサイズと位置に戻します。

  • Glow Point

    Baked Prefab の発光ポイントとその発光ライトを、ベイクで配置された位置に戻します。

  • Health Bar

    Baked Prefab の HP バーを、ベイクで配置された位置に戻します。

  • Hitbox

    Baked Prefab のヒットボックスを、ベイクで設定されたサイズと位置に戻します。

  • Overhead Anchor

    Baked Prefab の頭上アンカーを、ベイクで配置された位置に戻します。

  • VFX Box

    Baked Prefab の VFX ボックスを、ベイクで設定されたサイズと位置に戻します。

Sprite Renderer

  • Set Up for Lighting

    一覧表示される変更を確認した後で、このスプライトのオブジェクトにライティングとキャストシャドウを適用します。

ショートカット

  • Sun Forge › Bake Window › Save

    Ctrl / CmdS

    Bake Window で開いているタブのプリセットまたはアーキタイプライブラリを、タブの [保存] ボタンと同じように保存します。

  • Sun Forge › Bake Window › Save As

    Ctrl / CmdShiftS

    Bake Window で開いているタブのプリセットまたはアーキタイプライブラリを、新しいアセットとして保存します。

  • Tools › Sun Forge › Bake Window

    Alt / OptionShiftB

    Bake Window を開きます。このウィンドウでは、モデルをスプライトシートとすぐに使えるプレハブに変換できます。
