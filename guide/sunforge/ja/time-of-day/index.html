時刻

シーンの時刻の設定と、夜明けから夜まで、その時刻に従って変わるものを説明します。

このページの内容
  • 変更した値
  • スタイルの時刻の変更
  • スクリプトによる一日の進行

Lighting Setup の Style (スタイル) の下にある Time Of Day (時刻) は、時刻を 0 から 24 の範囲で設定します。各値は、その時刻におけるスタイルの値になります。同梱のスタイルにはすべて、夜明け、朝、午後、夕暮れと、20:00 から 04:00 までの夜があります。Indoor のスタイルでは、窓から差し込む光が夜明けと夕暮れに暖かみを帯びて弱まり、夜は月と Light Source が部屋を照らします。

同梱のスタイルが時刻に応じて変える値は次のとおりです。

値 変わるもの
Sun Elevation (太陽の仰角) 太陽がどの面を照らすか、水平な地面がどれだけ明るいか
Sun Color (太陽光の色)、Sun Intensity (太陽光の強さ)、Sun Warmth (太陽光の暖かみ) 太陽光の色と明るさ
Ambient Sky Color (空の環境光の色)、Ambient Sky Intensity (空の環境光の強さ) 日陰やあらゆる向きの面に届く、空からの光
Night (夜) 太陽から月への移り変わりと、マテリアルの夜の見え方
Cast Shadow Stretch Enabled (キャストシャドウの引き伸ばし有効)、Cast Shadow Stretch Sun Angle Offset (キャストシャドウの引き伸ばしの太陽角度オフセット) Regular での、夜明けと夕暮れ時の地面の長い影
Ground Shadow Strength (地面の影の強さ) 影スプライトと、Cast Shadow Field の地面オーバーレイの濃さ

変更した値

Lighting Setup で変更した値は、どの時刻でも変更した値のままです。時刻に従っている値は、その時刻にスタイルがすでに与えている値と同じ値に設定しても、時刻に従い続けます。値の行にある元に戻すボタンか、Global Light (グローバルライト) または Values (値) のヘッダーにある Revert All (すべてを元に戻す) を使うと、その値はスタイルの時刻ごとの値に戻ります。値を時刻に従わせたままシーンを明るく、または暗くするには、代わりに Global Light の下にある Sun And Moon Brightness (太陽と月の明るさ) と Sky Brightness (空の明るさ) を設定してください。

時刻に従っている値をアニメーションさせるには、その値のカーブを Animation ウィンドウで追加するか、エディタースクリプトで AnimationUtility.SetEditorCurve を使って追加してください。AnimationClip.SetCurve で作成したクリップが値を動かすのは、その値を Lighting Setup で変更するか、その値に対して SunForgeLightingSetup.KeepValue を呼び出した後だけです。

スタイルの時刻の変更

  1. Lighting Setup を選択し、Values (値) の下にある、スタイルの名前が付いたセクションを開きます。Sun Forge のスタイルを使っている場合は、セクションのヘッダーにある Edit A Copy (コピーして編集) をクリックします。
  2. そのセクションで Hours (時間帯) を開きます。ここには、スタイルの Default Lighting Values (デフォルトのライティング値) を開く 12:00 の行と、スタイルが値を設定するほかの時刻ごとのキーが並んでいます。各キーで、その時刻に設定する値のチェックボックスをオンにします。
  3. 新しいキーを追加するには、Add Hour (時刻を追加) をクリックします。値を一定の時間帯にわたって保つキーでは、Held (保持) をオンにします。

スクリプトによる一日の進行

スクリプトで一日の時間を進めるには、Update で SunForgeLightingSetup.TimeOfDay を設定してください。

スクリプトで、その時刻にスタイルがすでに与えている値と同じ値を設定し、その値をどの時刻でも保つには、setup.KeepValue(nameof(SunForgeLightingValues.MistEnabled)) のように SunForgeLightingSetup.KeepValue を呼び出してください。
