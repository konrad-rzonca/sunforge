ジオメトリテクスチャの形式

ジオメトリテクスチャを読み書きする自作のシェーダーやツール向けに、各チャンネルが保持するものを説明します。

ジオメトリテクスチャは、スプライトの各ピクセルのピボットからの高さを赤に、スプライトが地面に接する位置をアルファに保持します。描き方は、自分で描いたスプライト › ジオメトリテクスチャの描き方を参照してください。

形式

  • ピボットからの高さは R * range * scale です。黒がピボット、白が範囲で、ピボットより下の高さはありません。
  • range は、レンダラーに付いているコンポーネントが範囲を設定している場合はその範囲で、設定していない場合はマテリアルの Height Range (World Units) です。この値は、SunForgeRendererBakeValues.hlsl の SFBakeHeightRange で読み取れます。scale はオブジェクトのスケールです。
  • アルファが 8/255 以上のテクセルには高さがあります。それ未満のテクセルには高さがなく、その位置では、立っているスプライトは平らな直立した板として、地面のスプライトは高さ 0 で描画されます。
  • 緑と青は予約されていて、どのマテリアルも読み取らないため、赤が同じであれば、グレーのマップ、赤だけのマップ、単一チャンネルのマップは同じように読み取られます。自作のシェーダーでは、緑と青を読み取らないでください。
  • マップは PNG などの可逆形式で保存してください。テクスチャはリニアで、クランチ圧縮は使わず、フィルターはシートと同じです。
  • 赤を保持し、アルファのずれが 4/255 以内に収まるテクスチャ形式であれば、どれでも使えます。圧縮形式では保持できる高さの段階が減るため、Check Setup (セットアップを確認) はペイントしたマップを非圧縮でインポートします。

Sun Forge のグラウンドカバーは、アルファを占有範囲の前端としても読み取ります。前端は、スプライトがピボットからどれだけ手前で地面に接するかを表します。草は、その前端より手前でだけスプライトの上に描画されます。グラウンドカバーを使わない場合、この表は無視してください。

アルファ 前端
243/255 から 255/255 ピボットの位置
242/255 から 27/255 ピボットから範囲の (n / 25)^2 倍だけ手前。n は (247 - a) / 9 を最も近い整数に丸めた値、a は 0 から 255 のアルファ
8/255 から 26/255 ピボットから範囲いっぱいの距離だけ手前
8/255 未満 高さなし

前端を保存するには、a を 247 - 9 * n に、n が 0 のときは 255 に設定してください。n は 25 * sqrt(edge / range) を丸めた値で、最大 25 です。設定した値との差が 4/255 以内のアルファは、同じ前端として読み取られます。

テクセルを読み取るには、SunForgeHeightDecode.hlsl の SFHeightShare、SFHeightAbsent、SFHeightFrontEdgeShare を使うか、C# で SunForgeHeightTexel.TryDecode を使ってください。
