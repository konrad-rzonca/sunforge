ショーケース

ショーケースのシーンの開き方、シーンに必要なもの、削除の方法を説明します。

このページの内容
  • 動作環境
  • ショーケースの開き方
  • ショーケースの削除

プレイできる森のシーンです。アクターと小道具はすべて Sun Forge のベイク出力で、草と、夜に現れるウィスプを除けば、エフェクトもすべてベイク出力です。コントロールパネルで各機能を切り替えられます。サンプルには、アートのベイク元の 3D モデルと、そのアートをベイクしたプリセットも入っているため、プリセットを変更して再ベイクできます。

動作環境

  • Sun Forge と Sun Forge 2D Lighting が必要です。どちらもショーケースと一緒にインストールされます。Sun Forge の README の「動作環境」に記載されているものも、すべて必要です。
  • ショーケースをインストールすると、UIElements と Vector Graphics のビルトインパッケージも有効になります。
  • Android または iOS 向けのビルドでは、そのプラットフォームが使う品質レベルに URP アセットの専用のコピーを割り当て、そのコピーで Render Scale を 0.5 に設定してください。Android または iOS のプレイヤーでは、シーンのキャストシャドウは 1 ワールド単位あたり 16 テクセルで描画されます。この値は、Features の下にある Cast Shadow Field Controller オブジェクトの Phone Pixels Per Unit で決まります。
  • Windows では、プロジェクトフォルダーのパスを 110 文字以内にしてください。これより長いと、サンプルの一部のファイルが Windows のパス長の上限を超え、それらのファイルのインポートに失敗します。

ショーケースの開き方

Tools > Sun Forge > Open Showcase を選択してください。初回は、サンプルを Assets/Samples/Sun Forge Showcase/<version>/Showcase/ にインポートして、そのシーンを開きます。プロジェクトに Sun Forge Showcase がなければ、先にダウンロードします。シーンの遊び方とアートの再ベイクの方法は、そのフォルダーにある README.md に書かれています。

ショーケースの削除

インポートされた Assets/Samples/Sun Forge Showcase フォルダーを削除してから、Package Manager ウィンドウで Sun Forge Showcase を削除してください。サンプルのシーンとプレハブはこのパッケージのスクリプトを使っているため、パッケージを先に削除すると、シーンとプレハブに欠落しているスクリプトが残ります。
