ベイクしたテクスチャ

ベイクがスプライトシートのほかに追加するテクスチャと、シートがどのようにパックされ、インポートされるかを説明します。

このページの内容
  • 追加テクスチャ
  • テクスチャ設定

追加テクスチャ

各追加テクスチャは、スプライトの補助的テクスチャとしてシートに割り当てられます。法線、マスク、エミッション、ジオメトリテクスチャの名前とチャンネルは、ライティングのページにあります (自分で描いたスプライト › スプライトのテクスチャを参照)。ベイクでは次のテクスチャが加わります。

テクスチャ 補助的テクスチャの名前 チャンネル
マスク _MaskTex ベイクの太陽が照らしたテクセルでは A が 1、モデル自身の影の中では 0
キャストハイト _CastHeightTex Bake Cast Height Texture (キャストハイトテクスチャをベイク、Advanced (上級者向け) 表示) がオンのとき、地面に投影した影のシートにあります。R × range は、各テクセルに影を落とす最も高い点が、その影を落とすスプライトのピボットからどれだけ上にあるかを表します。本体のピボットは地面にあります。影が覆わないテクセルは 0 です。カバレッジは影のシートのアルファです。リニア

スプライトの法線マップはベイクカメラの角度で、地面タイルの法線マップは見下ろし視点で描かれます。range はベイクの高さの範囲です。

これらの名前でシートに割り当てたテクスチャは、ベイクがそのテクスチャを書き出している限り置き換えられます。

URP の Shader Graph テンプレート

URP の 2D Sprite Lit または 2D Sprite Custom Lit テンプレートから作った Shader Graph では、マスクの名前が _MaskMap です。ベイクしたマスクを読むには、そのプロパティの Reference を _MaskTex にしてください。Custom Lit テンプレートでは法線マップの名前も _Normal_Map なので、その Reference を _NormalMap にしてください。

Unity の 2D ライト

2D レンダラーの Unity Lights マテリアルでは、チャンネルでマスクされた Light 2D のブレンドスタイルが、マスクのそのチャンネルに応じてテクセルを照らします。Unity 標準の Multiply with Mask と Additive with Mask のブレンドスタイルは赤チャンネルを読むため、ベイクしたスプライトの金属の部分だけを照らします。これらが青またはアルファのチャンネルを読むように設定するか、マスクなしのブレンドスタイルを使ってください。アルファでマスクされたブレンドスタイルは、マスクにベイクされたセルフシャドウも適用します。Unity Lights マテリアルは、通常これを省きます。

ベイクしたスプライトに重なる草

ベイクが書き出すジオメトリテクスチャでは、アルファがフレームの前端を表します (ジオメトリテクスチャの形式を参照)。Sorted Ground Cover は、草の葉の根元がこの前端より手前にある場合にだけ、その葉をスプライトの上に描画します。

前端は、地面から 0.25 ワールド単位以内にある部分の前面です。そのため、武器を低く構えていれば、草はその手前で止まります。アニメーションがそれより高く持ち上げる部分の上に草を描画させるには、Measure Sizes From (サイズの計測元、Bake (ベイク) タブの ANIMATION (アニメーション)、Advanced (上級者向け) 表示) でそのアニメーションにチェックを入れてください。

テクスチャ設定

Filter Mode (フィルターモード)、Compression (圧縮)、Use Crunch Compression (クランチ圧縮を使用)、Generate Mip Maps (ミップマップの生成)、Atlas Max Size (アトラスの最大サイズ) は、アーキタイプの OUTPUT (出力) セクション (Advanced (上級者向け) 表示) で設定してください。ベイクは、これらの設定から、各プラットフォームでの各テクスチャの形式を選びます。

  • Project Settings > Editor (プロジェクト設定 > エディター) の Sprite Packer Mode が Sprite Atlas V2 - Enabled または Sprite Atlas V2 - Enabled for Builds のとき、アトラスがパックされます。それ以外のモードでは、各シートは個別のテクスチャとしてビルドに含まれ、Bake (ベイク) タブに Use Sprite Atlas V2 (スプライトアトラス V2 を使用) が表示されます。プロジェクトの Sprite Packer Mode を変更したら、以前にベイクしたものを再ベイクしてください。
  • ベイクしたアトラスの Default タブまたはプラットフォームのタブで自分で設定した Format (形式) と、Compression (圧縮) を None にした Override は、そのプラットフォームではベイクの形式より優先されます。Format を Automatic (自動) に戻すと、次のベイクでベイクの形式がもう一度書き込まれます。ジオメトリテクスチャやキャストハイトテクスチャに設定した Format は保たれます。
  • ベイクは、ジオメトリテクスチャやキャストハイトテクスチャを正しく描画できない形式を、自分で設定したタブも含めてどのタブでも置き換え、そのことを Console ウィンドウに表示します。
  • Generate Mip Maps (Advanced 表示) がオンのとき、元のサイズの 4 分の 1 以下で描画されるスプライトは、最も外側のピクセルがより平坦に照らされ、より地面に近い位置にソートされます。
  • アトラスの Max Texture Size (最大テクスチャサイズ) を小さくすると、アトラスがより多くのページに分かれるだけで、何も節約できません。

スマートフォン向けの Web ビルド

Web では、ベイクは Web プラットフォーム (File > Build Profiles) の Texture Compression (テクスチャ圧縮) に従います。デフォルトの Use Player Settings (プレイヤー設定を使用) では、Player Settings > Web (プレイヤー設定 > Web) の Texture compression format (テクスチャ圧縮形式) に従います。DXT の場合、ほとんどのスマートフォンのブラウザーのように、DXT と BC7 の形式に対応していないブラウザーは、ベイクした圧縮テクスチャをそれぞれ 4 倍のメモリ量に展開します。スマートフォンで動かすビルドの手順は次のとおりです。

  1. Texture Compression を ASTC に設定します。ETC2 も使えますが、ETC2 では、背の高いスプライトの近くにライトがあると、そのスプライトが帯状に照らされることがあります。
  2. もう一度ベイクします。

Unity 6000.6 では、Use Player Settings でのビルドと、形式を指定しないビルドスクリプトからのビルドで、スプライトアトラスのページが以前の形式のままビルドに含まれることがあります。Texture compression format を変更したら、Texture Compression が Use Player Settings の間に、スプライトアトラスを選択し、右クリックして Reimport (再インポート) を選んでください。

1 つのプラットフォームだけのクランチ圧縮

  1. 出力フォルダー内のベイクした各アトラスでそのプラットフォームのタブを開き、Override と Use Crunch Compression (クランチ圧縮を使用) をオンにして、Format (形式) は Automatic (自動) のままにします。アトラスがパックされないときは、ベイクしたスプライトシートにも同じ設定をします。その法線マップやジオメトリテクスチャには設定しません。
  2. もう一度ベイクします。ベイクは、そのプラットフォームで、アトラスの法線マップ、ジオメトリテクスチャ、キャストハイトテクスチャをクランチ圧縮しないままにします。

再ベイクしてもオーバーライドは保たれます。
