自分で描いたスプライト

自分で描いたスプライトに法線マップ、発光、金属の質感を付け、直立していないスプライトにはジオメトリテクスチャを描きます。

このページの内容
  • スプライトのテクスチャ
  • ジオメトリテクスチャの描き方

スプライトのテクスチャ

描いたスプライトにテクスチャを与える方法は、次の 2 つです。

Sun Forge による出力

  1. Set Up for Lighting (ライティング用にセットアップ) でスプライトをセットアップしたら、そのオブジェクトを選択し、Lighting Style Renderer の Glow, Surfaces and Edges (発光、表面、エッジ) を開きます。
  2. 発光する色ごとに、Add Glow Color (発光色を追加) をクリックしてから、スプライト上でその色をクリックします。
  3. 金属のように光る色ごとに、Add Surface Color (表面色を追加) をクリックしてから、スプライト上でその色をクリックします。
  4. Glows (発光部分) と Shines (光沢部分) の画像を確認します。これらの画像では、指定した色に一致する部分が表示され、それ以外の部分はグレーで表示されます。一致する範囲を広げるには、その色の Tolerance (許容範囲) を上げます。
  5. エッジを丸くする場合は、Round Edges (エッジの丸め) をオンにします。
  6. Write Textures (テクスチャを出力) をクリックします。
  7. 発光が地面と、発光の周りのスプライト自身を照らすようにするには、Glow Light (発光ライト) の行にある Add (追加) をクリックします。

自作のテクスチャの利用

  1. 各テクスチャを、スプライトのテクスチャと同じ場所に、下の表にある名前の PNG として保存します。<sheet> は、スプライトのテクスチャの、拡張子を除いたファイル名です。
  2. Set Up for Lighting (ライティング用にセットアップ) を実行するか、スプライトの Lighting Style Renderer で Change Setup (セットアップを変更) をクリックします。
  3. Sprites (スプライト) の下にあるスプライトの行に、見つかった各ファイルの名前が表示されます。Apply (適用する) をクリックして、スプライトに割り当てます。その種類のテクスチャをすでに持っているスプライトでは、元のテクスチャがそのまま残ります。

Unity の Sprite Editor ウィンドウの Secondary Textures (補助的テクスチャ) で割り当てることもできます。

各テクスチャの内容

スタイルのマテリアルは、スプライトにこれらのテクスチャがあれば、それらを読み込みます。

マテリアルのスロット ファイル 補助的テクスチャの名前 チャンネル
Normal Map <sheet>_Normal.png _NormalMap 上から見て描かれたシーンの Ground では、見下ろし視点で描かれた法線マップ。それ以外では、立っているスプライトと同じ角度から描かれた法線マップ。スプライトの外側のテクセルは、平らな法線 128、128、255 で埋めてください。埋めないと、スプライトの縁が暗く描画されます。SunForgeNormalDecode.hlsl の SFUnpackNormal か、Shader Graph の Sun Forge Sample Normal Map ノードで読み込んでください。どちらも 128 を傾きなしとして読み取ります
Mask <sheet>_MaskTex.png _MaskTex R がメタリック、G が滑らかさ、B がアンビエントオクルージョン。Sun Forge がレンダリングしたスプライトでは、A が太陽の光の届く量。リニア
Emission <sheet>_Emission.png _EmissionTex 強度 1 での発光の色。sRGB。Sun Forge がレンダリングまたは出力したテクスチャでは、A が、スプライトが自身の発光から受ける光の量
Geometry Texture <sheet>_Geometry.png _GeometryTex R がピボットからの高さ。ピボットの位置が黒で、明るいほど高くなります。A は省略できます (ジオメトリテクスチャの形式を参照)。リニアで、クランチ圧縮は使いません

_MaskTex に別のレイアウトのマスクを持つスプライトは、正しく照らされません。

シーンビューでのテクスチャの確認

シーンビューの Sun Forge Gizmos (Sun Forge ギズモ) パネルの下端にある Texture View (テクスチャビュー) をオンにして、テクスチャを 1 つ選んでください。

  • ビューには、URP のマテリアル (ライティングの影響を受けるもの、またはアンリットのもの) が描画するものだけが表示されるため、Sprites/Default を使うスプライト、キャストシャドウ、線、テキストは表示されません。
  • Geometry (ジオメトリ) では高さのないテクセルが、Emission (エミッション) ではエミッションのないスプライトが、暗い灰色で表示されます。

ジオメトリテクスチャの描き方

直立したスプライトには、ジオメトリテクスチャは必要ありません。テーブルの天板、荷車、横たわった人物のように、直立した板ではないスプライトには、ジオメトリテクスチャを描いてください。

  1. スプライトが覆うすべてのピクセルをグレーで塗ります。地面の位置を黒にし、高い位置ほど明るくします。シートでは、直立した板のままにするスプライトは透明のままにします。
  2. スプライトのピボットを、荷車の前輪のように、スプライトの前端が地面に接する位置に置きます。草がスプライトの上に描画されるのは、ピボットより手前だけです。テーブルの上のランプのように、ほかのスプライトの上に立つスプライトでは、テーブルに接する位置にピボットを置き、Lighting Style Renderer の Height Above Ground (地面からの高さ) をテーブルの高さに設定します。
  3. <sheet>_Geometry.png という名前の PNG を、シートと同じ場所に書き出します。
  4. Set Up for Lighting (ライティング用にセットアップ) を実行します。スプライトの行にテクスチャの名前が表示され、Apply (適用する) をクリックすると、テクスチャがインポートされてスプライトに割り当てられます。
  • ピクセル単位で作業する場合、グレーの値は height in pixels * 255 / (Pixels Per Unit * range) です。range は、マテリアルの Height Range (World Units) です。Pixels Per Unit が 32 で、範囲がデフォルトの 8 のとき、グレーの 1 段階は約 1 ピクセルに相当します。
  • 煙突のようにまっすぐ立っている部分は、描いた絵の中で N ピクセルの高さなら、実際の高さは N / cos(elevation) ピクセルです。elevation は、Lighting Setup の Art View (アートの視点) の角度です。
  • Point フィルタリングでは、スプライトの周囲に何があっても影響しません。フィルタリングするシートでは、書き出す画像の背景を透明にする必要があります。透明のまま残す部分がある場合は、アルファ付きの PNG が必要です。
