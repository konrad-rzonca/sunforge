コードからのライティング

エディタースクリプトから、シーンをライティングし、そのスプライトをセットアップします。

このページの内容
  • セットアップのプレビュー
  • スプライトへの役割の指定
  • Performance のボタンの適用
  • スタイルの保存と調整

エディタースクリプトから、スタイルを指定してシーンをライティングし、Set Up for Lighting (ライティング用にセットアップ) と同じようにスプライトをセットアップし、Fix All (すべて修正する) と同じ処理を実行できます。

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.Rendering;

SunForgeSceneLighting.SetUp(SunForgeShippedLightingStyle.Regular);

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.SetUpSprites(art))
    Debug.Log(line);

SunForgeSceneLighting.FixAll();

// On the Universal Renderer, the sort that Fix All skips. A Custom Axis is a choice of yours, so keep it.
if (GraphicsSettings.transparencySortMode != TransparencySortMode.CustomAxis)
{
    GraphicsSettings.transparencySortMode = TransparencySortMode.CustomAxis;
    GraphicsSettings.transparencySortAxis = new Vector3(0f, 1f, 0f);
}

IReadOnlyList<string> left = SunForgeSceneLighting.Check();
foreach (string message in left)
    Debug.LogWarning(message);

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • SetUp(SunForgeShippedLightingStyle.Regular, SunForgeLightingStyleVariant.Indoor) は、Regular の Indoor バリアントでシーンをセットアップします。
  • プラットフォーマーのアートのように、横から見て描かれたアートの場合は、スプライトをセットアップする前に、SetUp が返す Lighting Setup の ViewElevationDegrees を 0 に設定してください。
  • SetUpSprites は、Set Up for Lighting で Apply (適用する) をクリックしたときと同じ処理を実行し、表示またはログ出力するための行を返します。行には、変更して保存するもの、各スプライトが何としてセットアップされるか、変更されないスプライト、移動するピボットが示されます。フォルダーを渡すとその中のすべてのスプライトテクスチャとプレハブが、ゲームオブジェクトを渡すとその下のすべてのスプライトが、スプライトを渡すとそれを表示するすべてのレンダラーが対象になります。ピボットが移動するスプライト、プレハブ、開いていないシーン、ピボットの移動に合わせて配置済みのアートが補正される開いているシーンは、その場で保存されます。この保存は Undo では元に戻せません。Lighting Setup は追加せず、Art View (アートの視点) も設定しないため、SetUp を呼び出して視点を設定した後に呼び出してください。各スプライトのセットアップ方法は視点で決まり、サイドビューではピボットは移動しません。
  • FixAll は、Fix All が適用する修正をすべて適用します。ウィンドウは開きません。Set Up for Lighting を開く修正は適用しないため、その対象のスプライトは SetUpSprites でセットアップしてください。戻り値は残っている問題です。残るのは、自分で修正するしかない問題、Fix All がスキップした修正、SetUpSprites で修正する指摘です。Fix All は、自分で選んだ設定を変更する修正をスキップします。シーンにスプライトを置いてから呼び出し、スプライトを追加したらもう一度呼び出してください。影を落とすスプライトのための Cast Shadow Field のように、スプライトに必要なものが追加されます。Check は残っている問題を返し、何も変更しません。
  • 読み込み済みのカメラのソートは、そのシーンが再び読み込まれるまで変わりません。シーンビューのソートも、開き直すまで変わりません。すぐにソートを反映するには、読み込み済みの各カメラと、SceneView.GetAllSceneCameras() が返す各カメラにも transparencySortMode と transparencySortAxis を設定してください。
  • そのほかの変更は、開いているシーンとプロジェクトのアセットのメモリ上の内容に加えられます。最後の 2 行のように、スクリプトが終わる前に両方を保存してください。

セットアップのプレビュー

セットアップが何かを保存する前に、その変更内容を表示するには、適用するときと同じ引数でプレビューしてください。PreviewSpriteSetup は、SetUpSprites が返すのと同じ行を返し、何も変更しません。

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.PreviewSpriteSetup(art))
    Debug.Log(line);

if (EditorUtility.DisplayDialog("Set Up for Lighting", "Set up the sprites the Console lists?", "Set Up", "Cancel"))
{
    SunForgeSceneLighting.SetUpSprites(art);
    EditorSceneManager.SaveOpenScenes();
}
  • Keep these pivots (これらのピボットを維持) と同じようにピボットを現在の位置のままにするには、両方の呼び出しに keepPivots: true を渡してください。この選択は、以降の実行でも維持されます。

スプライトへの役割の指定

各スプライトの横にあるドロップダウンと同じようにスプライトに役割を与えるには、役割を引数で渡してください。ほかのスプライトが床に合わせてセットアップされるように、先に床をセットアップしてください。

var floor = AssetDatabase.LoadAssetAtPath<Sprite>("Assets/Art/Floor.png");
SunForgeSceneLighting.SetUpSprites(new Object[] { floor }, SunForgeSpriteRole.Ground);
SunForgeSceneLighting.SetUpSprites(new Object[] { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") });
EditorSceneManager.SaveOpenScenes();
  • 役割は、指定した各 Sprite Renderer、指定した各ゲームオブジェクトの Sprite Renderer、指定したスプライトまたはスプライトテクスチャを表示するすべてのレンダラーに設定されます。フォルダーを指定した場合は、その中の各スプライトテクスチャと、その中の各プレハブのルートにある Sprite Renderer に設定されます。シーンに配置したプレハブのインスタンスでは、役割はそのプレハブに設定されます。地面かもしれないスプライトのように、ウィンドウであれば確認を求めるスプライトは、ウィンドウがそのスプライトに最初に示す役割でセットアップされ、返される行に確認の内容が入ります。何かが保存される前に答えるには、先にプレビューしてから、上のコードの床と同じように、選んだ役割を指定してそのスプライトをセットアップしてください。
  • プレハブモードで開いているプレハブやファイルのないシーンについて、ウィンドウであれば保存を求める場合、再生モード中など Set Up for Lighting (ライティング用にセットアップ) を実行できない場合、またはバージョン管理や読み取り専用のファイルが原因でセットアップが止まる場合は、呼び出しが InvalidOperationException をスローし、何も変更されません。セットアップの開始後にファイルを保存できなかった場合や、Unity が例外をスローした場合は、IOException をスローします。そのメッセージに、セットアップされていないものが示されます。

Performance のボタンの適用

スクリプトから Performance (パフォーマンス) のボタンを押すには、ApplyPerformance を使ってください。戻り値は、変更された各設定です。

var lit = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeSceneLighting.ApplyPerformance(lit, SunForgeLightingPerformanceButton.Balanced);
EditorSceneManager.SaveOpenScenes();

スタイルの保存と調整

スクリプトでも、自作のスタイルを保存し、Look (見た目) と同じように調整できます (スタイルの調整を参照)。次のスクリプトは、シーンの見た目を保存し、Pixel Outline をオンにします。

var setup = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeLightingStyle style = SunForgeSceneLighting.SaveAsNewStyle(setup, "Assets/Lighting/My Style.asset");
IReadOnlyList<Material> materials = SunForgeLightingStyleEditing.EnsureOwnMaterials(style);

SunForgeLightingStyleSetting row = SunForgeLightingStyleSettings.Find("_SFPixelOutline");
foreach (Material material in materials)
{
    if (!material.HasProperty(row.Name))
        continue;

    Undo.RecordObject(material, "Set Pixel Outline");
    material.SetFloat(row.Name, 1f);
    if (row.Keyword != null)
        material.EnableKeyword(row.Keyword);
}

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • SaveAsNewStyle は、パスにファイルがすでにある場合は例外をスローします。ただし、overwrite: true を渡し、そのファイルがライティングスタイルであれば、スローしません。以前に保存したスタイルを調整するには、代わりに AssetDatabase.LoadAssetAtPath<SunForgeLightingStyle> で読み込んでください。
  • ポストプロセスについては、EnsureOwnProfile が、スタイルにプロファイルの専用のコピーを与えて、そのコピーを返します。
  • SunForgeLightingStyleSettings.MaterialProperties は、すべての行を、プロパティの Name、Tooltip、Group とともに一覧にします。Look に表示される行のラベルは、マテリアルのシェーダーにあるプロパティの説明で、shader.GetPropertyDescription(shader.FindPropertyIndex(row.Name)) で取得できます。
  • スライダーの上限と下限はシェーダーのもので、shader.GetPropertyRangeLimits で取得できます。SetFloat は、値をその範囲内に収めません。
  • Keyword がある行では、プロパティの設定と、EnableKeyword でキーワードをオンに、または DisableKeyword でオフにする操作の両方が必要です。Switch がある行は、その名前が示す行がオンの間だけ表示されます。Pixel Outline の下の Pixel Outline Color がその例です。
  • 変更のたびにその前で Undo.RecordObject を呼び出すと、シーンに変更がすぐ描画されます。呼び出さない場合は、Lighting Setup の Publish を呼び出してください。
  • BakedArt の行は Look にはありません。対象のマテリアルで設定してください。Orientation の行は変更しないでください。
