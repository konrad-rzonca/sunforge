影

スプライトがキャストシャドウを落とす仕組みと、樹冠がその下にあるものを日陰にする仕組みを説明します。

このページの内容
  • キャストシャドウ
  • Canopy Shade

キャストシャドウ

アートが上から見て描かれている場合、Set Up for Lighting (ライティング用にセットアップ) は、立っているスプライトがキャストシャドウを落とすようにセットアップし、その影を描画する Cast Shadow Field を追加します。影が落ちる場所は、Cast Shadow Field の Mode (モード) で決まります。

影の濃さ

雲のかかっていない Regular スタイルの日中の光の下では、影スプライトは描いたとおりの濃さになります。Realistic スタイルのように、空の光に比べて太陽の光が強いときは濃くなります。空の光に比べて太陽や月の光が弱まったとき、雲がかかっているとき、太陽が低いときには薄くなります。Light Source の光の中でも薄くなりますが、Flat の見た目とサイドビューでは薄くなりません。すべての影を濃くするには、Lighting Setup の Ground Shadow Strength (地面の影の強さ) を上げてください。

カメラとスクリプト

  • Cast Shadow Field は 1 台のカメラに追従するため、画面分割では、両方のビューが、追従しているカメラの影を共有します。
  • Cast Shadow Field は、1 フレームに 1 回、最初のカメラより前に描画されます。キャプチャのように、スクリプトが 1 フレーム内の 2 回のレンダリングの間でカメラやスプライトを動かす場合は、後のレンダリングの前に Cast Shadow Field の Redraw を呼び出してください。
  • 影がカメラの視界から遠く離れているキャスターの処理負荷は、ほとんどありません。Sprite Renderer がオフになっているキャスターでは、それぞれの Sprite Renderer を毎フレーム確認する処理負荷がかかります。

反転したスプライトとほかのシェーダー

  • キャラクターを左に向けるために親の Scale X を -1 にしても、ペアになった影は反転しないため、太陽と反対の方向に落ちたままです。
  • Cast Shadow Field の外では、シェーダーが Sun Forge/Hand-Drawn Shadow ではない影スプライトは親と一緒に反転し、描いたとおりの濃さのままです。
  • 霧は、パーティクル、シェーダーが Sun Forge/Hand-Drawn Shadow ではない影スプライト、霧を描画しない自作のシェーダーを覆いません (カスタムシェーダー › Shader Graphを参照)。

Canopy Shade

Canopy Shade は、樹冠の下にある地面とスプライトから空の光を取り除きます。セットアップするには、次のようにしてください。

  1. GameObject > Sun Forge > Canopy Shade を選択します。
  2. 木だけを 1 つのオブジェクトの下に置き、Canopy Shade の Trees (木) にそのオブジェクトを設定します。オブジェクトの中でグループに分けてもかまいません。
  3. Rect (矩形) を、木が立っている地面の範囲に設定します。
  4. Draw Map (マップを描画) をクリックします。マップがシーンと同じ場所に保存され、Map (マップ) と Canopy Height (樹冠の高さ) が設定されます。

木を移動、追加、削除したら、もう一度 Draw Map をクリックしてください。日陰をどの程度表示するかは、Lighting Setup の Canopy Shade Strength (Canopy Shade の強さ) で設定してください。

マップの自作

マップが Rect (矩形) 全体を覆うようにしてください。白は開けた空、黒は閉じた樹冠の下を表します。各樹冠の日陰は、奥行きの 1 / sin e 倍の幅で描いてください。e は Lighting Setup の Art View (アートの視点) の角度で、その角度が 3° より小さい場合は 3° です。樹冠の日陰が表示される場所では、Art View は常に From Above (見下ろし) です。
