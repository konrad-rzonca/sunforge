プラットフォーマーと物理

自作のスクリプトで、ベイクしたアクターをサイドビューで歩かせてジャンプさせ、ベイクしたプレハブを低レベル 2D 物理ワールドで動かします。

  • サイドビューのゲーム
  • 物理ワールド

サイドビューのゲーム

Movement、Wander、Melee Attacker は、空を飛ぶものや泳ぐもののように、重力なしで、アクターを画面の左右だけでなく上下にも動かします。Movement を持つアクターを左右だけに歩かせるには、その ReadsInput をオフにし、y が 0 の方向を渡して SunForgeMovement.Walk(direction, Time.deltaTime) を毎フレーム呼んでください。

プラットフォーマーのベイク設定は、サイドビュー › サイドビューのベイクを参照してください。プラットフォーマーのアクターと、床の上にとどまるアクターは、次のように自作のスクリプトで動かしてください。

  1. スクリプトは Assets > Create > Sun Forge > Behavior Script (アセット > 作成 > Sun Forge > Behavior Script) で作成し、その [SunForgeBehavior] に movesActor: true を追加して、Movement、Wander、Melee Attacker の代わりに GAMEPLAY (ゲームプレイ、Advanced (上級者向け) 表示) に登録します。こうすると、ベイクが Rigidbody 2D の Linear Damping (線形減衰) を 0 に設定します。自分でプレハブに追加するスクリプトの場合は、Linear Damping を 0 にしておく必要があります。
  2. アクターに重力を与えるために、Rigidbody 2D の Gravity Scale (重力スケール) を上げます。この値は再ベイクしても保持されます。Physics World を使う場合は、そのワールドの定義で重力を設定します。
  3. スクリプトでは、Rigidbody 2D の水平方向の速度を入力から設定し、垂直方向の速度はジャンプするときにだけ設定します。Physics World を使う場合は、アクターの SunForgePhysicsBody の Velocity に書き込みます。
  4. 立ち止まっている間も含めて毎フレーム、アクターが歩く方向と Time.deltaTime を渡して SunForgeFacing.FaceUnlessHeld を呼びます。また、SunForgeActorAnimation.Of(this).SetMoveSpeed を、歩いている間は 1、止まっている間は 0 を渡して呼びます。While Walking (歩行中) が Keep Walking (歩行を継続) の Shooter には、この両方が必要です。SetMoveSpeed がないと発射のたびに Attack を再生し、FaceUnlessHeld がないと、アクターがある方向に撃ちながら反対の方向に歩いても、歩行アニメーションが逆再生されません。
  5. ジャンプを再生するには、同じ SunForgeActorAnimation の SetBool(Animator.StringToHash("Jump"), true) を呼びます。false に設定するまで、Jump という名前の Loop While Bool (Bool が true の間ループ) エントリーが再生されます。
  6. Shooter は Space キーでも発射します。スクリプトが Space キーでジャンプする場合は、Shooter の Reads Input (入力で操作) をオフにし、AimAt または AimDirection で狙いを付けて、スクリプトから Fire を呼びます。

物理ワールド

ベイクしたプレハブを Unity の低レベル 2D 物理ワールドで動かすには、Assets > Create > Sun Forge > Physics World (アセット > 作成 > Sun Forge > Physics World) でアセットを作成し、その Inspector でワールド、物理ボディ、シェイプの定義を設定して、アーキタイプの PHYSICS (物理) セクション (Advanced (上級者向け) 表示) で指定してください。すると、Collider Shape (コライダーの形状) を持つ各プレハブに SunForgePhysicsBody が付きます。

ベイクデータから独自の物理シェイプを組む場合は、SunForgeBakedPrefab.Anchors を読み、SunForgeBakedPrefab.AnchorsChanged が発生するたびにもう一度読んでください。コライダーの Follows Facing (向きに追従、Archetypes (アーキタイプ) タブの PHYSICS、Advanced 表示) がオンのアクターは、向きを変えるとコライダーが変わります。
