シーン内のベイクしたスプライト

ベイクしたプレハブが描画に使うマテリアル、シーンのスタイルに従う仕組み、パーティクルがソートされる位置を説明します。

新しくベイクしたスプライトは、シーンの Lighting Setup が使うスタイルのマテリアルで描画されます。どのシーンでも同じマテリアルで描画するには、ベイクの Prefab Material (プレハブマテリアル、Bake (ベイク) タブ、Advanced (上級者向け) 表示) でそのマテリアルを選択して、もう一度ベイクしてください。その行のメニューの Make a Material for This Bake (このベイク用にマテリアルを作成) は、調整できる自作のマテリアルを作成します。

  • Baked Renderer Binding を有効にしたスプライトは、ベイク時の俯角と高さの範囲を保持します。スタイルのマテリアルにあるこれらの行が効くのは、Baked Renderer Binding を有効にしていないスプライトだけです。スプライトの発光は、ベイク時の発光にマテリアルの Emission Scale を掛けた強さになります。ベイクが Glow Light (発光ライト) 用に追加するライトは、スタイルのマテリアルでは Emission Scale に合わせて明るくなり、自作のマテリアルでは次のベイクで明るくなります (スタイルの調整を参照)。
  • ベイクしたスプライトを描画する自作のレンダラーには Baked Renderer Binding が必要です。これがない場合、そのレンダラーはスプライトの高さをマテリアルの範囲で読み取ります。この状態は Check Setup (セットアップを確認) で報告されます。
  • Unity 標準のスプライトマテリアルを使う本体には、ヒットフラッシュが表示されません。
  • Unity の 2D ライトを使う場合は、ベイクしたプレハブのルートに Shadow Caster 2D を追加してください。その影は Unity Lights マテリアルの上に落ちます。
  • マーカーの発光やトレイル、および Material (マテリアル、Archetypes (アーキタイプ) タブの SHADOW (影)、Advanced 表示) で Sun Forge/Hand-Drawn Shadow 以外のシェーダーを使う影スプライトは、霧に覆われません。
  • ベイクした影は、本体より 1 小さい Order in Layer (レイヤーの順序) で描画されます。その下の地面には、どちらよりも小さい値を設定してください。
  • 親の Scale X を -1 にしても、ベイクした影は反転しないため、太陽と反対の方向に落ちたままです。Cast Shadow Field の外では、Material (Archetypes タブの SHADOW、Advanced 表示) で別のシェーダーを使う影は親と一緒に反転します。

シーン内のベイクしたパーティクル

プレハブのパーティクルは、モデルのうちパーティクルより手前にある部分 (ランタンの炎を囲む格子など) も含めて、本体全体の上に描画されます。

  • パーティクルを本体の後ろに描画するには、プレハブの Particles 子オブジェクトを上に動かしてください。パーティクルは、この子オブジェクトの位置でソートされます。
  • 焚き火の炎など、パーティクルだけからベイクしたプレハブは、キャラクターと同じく、立っている位置でソートされます。炎を焚き火の上に描画するには、炎を焚き火と同じ位置か、そのすぐ手前に置いてください。
  • たいまつのような背の高い小道具の上の火は、小道具と一緒にベイクしてください。こうすると、火が小道具も照らし、その光には小道具自身の形による陰影が付きます。または、Origin Below Ground (原点の地面からの深さ、Advanced (上級者向け) 表示) を小道具の高さにマイナスを付けた値に設定し、火を小道具の根元に置いてください。
  • 単独でベイクした、ループする炎には専用の発光ライトが付きます。代わりに小道具のライトを使うには、炎の Glow Light (発光ライト) をオフにし、炎の Particles 子オブジェクトを、小道具の Glow 子オブジェクトの Light Source にある Glow Renderers (発光レンダラー) に追加してください。
  • キャラクターの胸に出るヒット時の火花など、スクリプトが空中に生成するエフェクトは、出現した位置でソートされるため、そのキャラクターの後ろに描画されます。手前に描画するには、エフェクトの Particles 子オブジェクトの Order in Layer (レイヤーの順序) をキャラクターの値より大きくしてください。
