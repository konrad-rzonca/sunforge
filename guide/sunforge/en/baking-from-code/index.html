Baking from code

Create a bake preset in an editor script and run it.

On this page
  • Setting Animation Entries
  • Changing A Preset Or Library

A SunForgeBakeRequest is a bake preset together with the archetype library it uses. Create the preset, then hand the request to SunForgeBakeRunner:

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEngine;

SunForgeBakeArchetypeLibrary library = SunForgeBakeArchetypeLibraryLocator.FindOrCreate();
SunForgeBakeArchetype character = library.FindArchetype("Character");
SunForgeBakePreset preset = SunForgeBakePreset.CreateWithDefaults(library, source, character);
var request = new SunForgeBakeRequest(library, preset);

// Every problem the bake has, without baking. A bake with a blocking one is refused.
List<SunForgeBakeDiagnostic> findings = SunForgeBakeRunner.Validate(request);
if (findings.Exists(finding => finding.Blocks))
{
    foreach (SunForgeBakeDiagnostic finding in findings)
        if (finding.Blocks)
            Debug.LogError(finding.Message);
    return;
}

SunForgeBakeResult result = SunForgeBakeRunner.Run(request);
if (result.Status == SunForgeBakeStatus.Failed)
    Debug.LogException(result.Exception);
foreach (string warning in result.Warnings)
    Debug.LogWarning(warning);
foreach (string error in result.Errors)
    Debug.LogError(error);
// A step beside the bake that failed, such as a check behind a warning. A completed bake can have them.
foreach (SunForgeBakeFault fault in result.Faults)
    Debug.LogError(fault.Message + "\n" + fault.Exception);
SunForgeBakedData baked = result.BakedData;
  • In a project with no archetype library, FindOrCreate saves one, with the starter archetypes of the Bake Window's first bake.
  • FindArchetype returns null when the project has renamed or removed that archetype, and CreateWithDefaults then uses the Default archetype.
  • A preset from ScriptableObject.CreateInstance has no Prefab Material, archetype or animation entries. Make it with SunForgeBakePreset.CreateWithDefaults.
  • Setting preset.PrefabMaterial picks that material for every scene, whatever the scene's lighting style. preset.FollowLightingStyle() has the sprites draw the style's material again.

To set up the lighting of the scene the baked prefabs go in from a script, see Lighting from code.

Setting Animation Entries

CreateWithDefaults gives the preset the animation entries the Bake Window adds for its source. For a preset that has none, set its Source and then call preset.AddClipSettingsIfEmpty().

Build an entry with new SunForgeBakeClipSettings(clipName, outputName, mode), where clipName is the clip's name, File|Name for one of two clips that share a name, or null for the rest pose. Each With method returns the entry with one setting changed, so assign it back:

preset.ClipSettings.Add(new SunForgeBakeClipSettings("Run", null, SunForgeBakeClipMode.LoopWhileBool).WithFrameRate(12));
preset.ClipSettings[0] = preset.ClipSettings[0].WithMode(SunForgeBakeClipMode.PlayOnce);

Changing A Preset Or Library

Before you change a saved library or preset in code, load it again: an import can unload the one you hold, and a change to that one is lost.

  • To keep the change, call EditorUtility.SetDirty on the library or preset. Without that call Unity can drop the change at the next import.
  • To change a preset for one bake only, make a copy with Object.Instantiate(preset), change the copy and bake it.

A library or preset that you make in code and do not save lasts only until Unity frees unused objects, which any import can do, a bake's included. Make it again before each bake, or keep it in a static field until you destroy it.
