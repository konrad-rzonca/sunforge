코드로 베이크

에디터 스크립트에서 베이크 프리셋을 만들고 실행합니다.

이 페이지의 내용
  • 애니메이션 항목 설정
  • 프리셋이나 라이브러리 변경

SunForgeBakeRequest 타입은 베이크 프리셋과 그 프리셋이 사용하는 아키타입 라이브러리를 묶은 것입니다. 프리셋을 만든 뒤 요청을 SunForgeBakeRunner 클래스에 넘기세요.

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEngine;

SunForgeBakeArchetypeLibrary library = SunForgeBakeArchetypeLibraryLocator.FindOrCreate();
SunForgeBakeArchetype character = library.FindArchetype("Character");
SunForgeBakePreset preset = SunForgeBakePreset.CreateWithDefaults(library, source, character);
var request = new SunForgeBakeRequest(library, preset);

// Every problem the bake has, without baking. A bake with a blocking one is refused.
List<SunForgeBakeDiagnostic> findings = SunForgeBakeRunner.Validate(request);
if (findings.Exists(finding => finding.Blocks))
{
    foreach (SunForgeBakeDiagnostic finding in findings)
        if (finding.Blocks)
            Debug.LogError(finding.Message);
    return;
}

SunForgeBakeResult result = SunForgeBakeRunner.Run(request);
if (result.Status == SunForgeBakeStatus.Failed)
    Debug.LogException(result.Exception);
foreach (string warning in result.Warnings)
    Debug.LogWarning(warning);
foreach (string error in result.Errors)
    Debug.LogError(error);
// A step beside the bake that failed, such as a check behind a warning. A completed bake can have them.
foreach (SunForgeBakeFault fault in result.Faults)
    Debug.LogError(fault.Message + "\n" + fault.Exception);
SunForgeBakedData baked = result.BakedData;
  • 아키타입 라이브러리가 없는 프로젝트에서는 FindOrCreate 메서드가 Bake Window의 첫 베이크 때와 같은 기본 제공 아키타입이 든 라이브러리를 저장합니다.
  • FindArchetype 메서드는 프로젝트에서 그 아키타입의 이름을 바꿨거나 아키타입을 제거했으면 null을 반환합니다. 이때 CreateWithDefaults 메서드는 Default 아키타입을 사용합니다.
  • ScriptableObject.CreateInstance 메서드로 만든 프리셋에는 프리팹 머티리얼, 아키타입, 애니메이션 항목이 없습니다. 프리셋은 SunForgeBakePreset.CreateWithDefaults 메서드로 만드세요.
  • preset.PrefabMaterial 프로퍼티를 설정하면 씬의 조명 스타일과 관계없이 모든 씬에서 스프라이트가 그 머티리얼을 사용합니다. preset.FollowLightingStyle() 메서드를 호출하면 스프라이트가 다시 스타일의 머티리얼을 사용합니다.

베이크된 프리팹을 배치할 씬의 조명을 스크립트에서 설정하려면 코드로 조명 설정을 참조하세요.

애니메이션 항목 설정

CreateWithDefaults 메서드는 Bake Window가 소스에 맞춰 추가하는 애니메이션 항목을 프리셋에 넣습니다. 애니메이션 항목이 없는 프리셋에는 Source 프로퍼티를 설정한 뒤 preset.AddClipSettingsIfEmpty() 메서드를 호출하세요.

항목은 new SunForgeBakeClipSettings(clipName, outputName, mode) 생성자로 만드세요. clipName 인수는 클립의 이름이며, 이름이 같은 두 클립 중 하나라면 File|Name 형식으로 쓰고, 기본 자세라면 null입니다. 각 With 메서드는 설정 하나를 바꾼 항목을 반환하므로, 반환값을 다시 대입하세요:

preset.ClipSettings.Add(new SunForgeBakeClipSettings("Run", null, SunForgeBakeClipMode.LoopWhileBool).WithFrameRate(12));
preset.ClipSettings[0] = preset.ClipSettings[0].WithMode(SunForgeBakeClipMode.PlayOnce);

프리셋이나 라이브러리 변경

저장된 라이브러리나 프리셋을 코드에서 바꾸기 전에는 다시 로드하세요. 임포트 때문에 참조 중인 객체가 언로드될 수 있으며, 그 객체에 한 변경은 사라집니다.

  • 변경을 유지하려면 라이브러리나 프리셋을 넘겨 EditorUtility.SetDirty 메서드를 호출하세요. 이 호출이 없으면 다음 임포트 때 Unity가 변경을 버릴 수 있습니다.
  • 한 번의 베이크에만 프리셋을 바꾸려면 Object.Instantiate(preset) 메서드로 사본을 만들고, 사본을 바꿔 베이크하세요.

코드에서 만들고 저장하지 않은 라이브러리나 프리셋은 Unity가 사용하지 않는 객체를 해제할 때까지만 남습니다. 이 해제는 베이크 중의 임포트를 포함해 어떤 임포트에서든 일어날 수 있습니다. 베이크할 때마다 다시 만들거나, 직접 삭제할 때까지 static 필드에 보관하세요.
