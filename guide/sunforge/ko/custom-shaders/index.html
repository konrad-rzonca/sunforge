직접 만든 셰이더

Sun Forge 템플릿으로 셰이더 그래프를 시작하거나, 직접 만든 그래프나 직접 작성한 스프라이트 셰이더에 씬의 스타일, 광원, 그림자, 안개를 적용합니다.

이 페이지의 내용
  • 셰이더 그래프
  • 직접 작성한 셰이더
  • 텍스처가 없는 스프라이트
  • 직접 만든 셰이더

셰이더 그래프

완성된 그래프에서 시작하려면 Assets > Create > Shader Graph > From Template(에셋 > 생성 > 셰이더 그래프 > From Template) 메뉴를 선택하고, Sun Forge 아래에서 Sun Forge Sprite Lit 템플릿이나 Sun Forge Dissolve 템플릿을 고른 다음 아래 단계 중 5단계를 진행하세요. 그래프를 직접 만들려면 다음과 같이 하세요.

  1. Sprite Unlit 그래프에 Sun Forge > Sun Forge Sprite Lit 노드를 추가합니다.
  2. 노드의 Color 포트를 Base Color 블록에, Alpha 포트를 Alpha 블록에 연결합니다.
  3. Graph Settings 탭에서 Disable Color Tint 체크박스를 켭니다. 이 체크박스가 꺼져 있으면 Sprite Renderer 컴포넌트의 Color(컬러) 필드가 검은색인 스프라이트에서 발광, 림, 안개, 피격 플래시가 사라집니다.
  4. 같은 Graph Settings 탭에서 Custom Editor GUI 필드를 KonradRzonca.SunForge.Editor.Inspector.SunForgeStyledMaterialEditor 값으로 설정합니다. 그러면 이 그래프로 만든 머티리얼의 인스펙터에도 Sun Forge 머티리얼의 인스펙터와 같은 미리보기와 툴팁이 나타납니다.
  5. 프로젝트 창에서 그래프를 마우스 오른쪽 버튼으로 클릭하고 Create > Material(생성 > 머티리얼) 메뉴를 선택합니다. 이 머티리얼을 쓰는 각 렌더러에서 Add Component > Sun Forge > Lighting > Lighting Style Renderer(컴포넌트 추가 > Sun Forge > Lighting > Lighting Style Renderer) 메뉴를 선택하고, Lighting Style Renderer 컴포넌트의 Material(머티리얼) 필드를 만든 머티리얼로 설정합니다. Mesh Renderer, Skinned Mesh Renderer, Line Renderer, Trail Renderer 컴포넌트에서는 텍스처를 직접 만든 프로퍼티 블록이 아니라 머티리얼에 설정합니다. 직접 만든 프로퍼티 블록으로 설정하면 그래프가 아무것도 그리지 않을 수 있습니다.

그러면 머티리얼에 Sun Forge 머티리얼과 같은 스프라이트 텍스처 슬롯 5개와 조명이 읽는 머티리얼 프로퍼티가 생깁니다. 머티리얼의 Role 프로퍼티를 Sprite, Ground, Ground Clutter 옵션 중 하나로 설정하세요. 스프라이트는 그 역할의 모습을 따르고, Cast Shadow Field 컴포넌트와 스프라이트의 Lighting Style Renderer 컴포넌트는 머티리얼에서 역할을 가져옵니다.

디졸브나 스크롤하는 텍스처처럼 빛을 받기 전의 스프라이트를 바꾸려면 Sun Forge Sprite Lit 노드 대신 Sun Forge Sprite Textures 노드와 Sun Forge Lit Color 노드를 사용하세요. Sun Forge Sprite Textures 노드의 각 출력을 Sun Forge Lit Color 노드에서 이름이 같은 포트에 연결하되 그 사이에 직접 만든 이펙트를 넣고, Sun Forge Lit Color 노드는 2단계와 같이 연결하세요. 텍스처를 특정 좌표에서 샘플링하려면 UV 포트에 그 좌표를 연결하세요.

Sun Forge Lit Color 노드의 포트 받는 값 연결하지 않으면
Albedo 스프라이트의 색과 알파 흰색
Normal 스프라이트의 노멀(예: Sun Forge Sample Normal Map 노드의 출력) Bake Camera Elevation (Degrees) 값이 0보다 큰 Ground 역할에서는 수평인 지면, 그 밖에는 카메라를 향한 표면
Mask 빨강, 초록, 파랑에 각각 담은 메탈릭, 평활도, 오클루전. 알파는 Sun Forge Sprite Textures 노드가 주는 값을 그대로 유지하세요 금속 없음, 평활도 절반, 오클루전 없음
Emission 발광 컬러. 알파에는 스프라이트 자체의 발광이 그 스프라이트에 보내는 빛을 담습니다. 알파는 Sun Forge Sprite Textures 노드가 주는 값을 그대로 유지하거나, 직접 정한 발광 컬러를 쓸 때는 1로 설정하세요 발광 없음
Geometry 지오메트리 텍스처를 샘플링한 값(아래의 '지오메트리 텍스처' 섹션 참조) 서 있는 스프라이트가 똑바로 선 평평한 카드처럼 보입니다

그라운드 커버, Flat 스타일의 외곽선, 스프라이트의 윤곽 안에 머무는 림, Point 필터링을 쓰는 스프라이트의 또렷한 하이라이트, Regular 스타일과 Cinematic 스타일에서 가까운 Light Source 광원이 비추는 매끄러운 빛, 이 효과는 모두 각 픽셀 주변에서 스프라이트 자체의 텍스처를 읽습니다. 그래프가 스프라이트 자체의 그림이 아닌 다른 모양을 그리는 경우에는 Sun Forge Lit Color 노드의 Shape From 필드를 This Graph 옵션으로 설정하세요. 그러면 위의 효과가 스프라이트의 텍스처를 읽지 않습니다.

노드 주는 값
Sun Forge Sample Normal Map 직접 만든 노멀 맵을 Sun Forge 머티리얼이 자기 노멀 맵을 읽는 방식으로 읽은 값. Normal 포트에 연결합니다
Sun Forge Mist 씬의 안개를 입힌 색. Sun Forge 노드가 비추지 않는 이펙트에 사용합니다
Sun Forge Scene Light 태양이나 달의 방향과 색, Lighting Setup 컴포넌트가 출력하는 하늘과 지면의 색, Sun Forge 머티리얼이 애니메이션에 쓰는 초 단위 시간
  • 그래프에 Reference 필드가 _MainTex, _NormalMap, _MaskTex, _EmissionTex, _GeometryTex 중 하나인 자체 텍스처 프로퍼티가 있으면, Sun Forge 노드가 같은 Reference 값의 슬롯을 추가할 때 그래프에 오류가 표시됩니다. 그 프로퍼티를 삭제하고, 그 텍스처를 샘플링한 값은 Sun Forge Sprite Textures 노드에서 가져오세요.
  • 쏟아지는 동전처럼 작은 스프라이트 여러 개를 한 번에 그리는 메시에서는 SunForgeBatchSprites 클래스를 사용하면 각 스프라이트가 자기 피벗과 높이에서 빛을 받습니다. 노드가 이를 위해 SunForgeBatchSprites.UvChannel UV 채널을 읽으므로, 이 채널에는 직접 만든 데이터를 넣지 마세요.
  • Color 포트와 Base Color 블록 사이에 Sample Texture 2D, DDX, DDY, DDXY 노드가 있으면 OpenGL과 Vulkan에서 스프라이트 가장자리를 따라 색이 잘못 나올 수 있습니다. 이런 텍스처는 Sample Texture 2D LOD 노드로 샘플링하거나, Sun Forge Lit Color 노드의 포트 중 하나에 연결하세요.
  • Sprite Skin 컴포넌트를 쓰는 스프라이트에서는 위치에 Tangent Vector 노드 값을 더해 두 번째 Sprite Skinning 노드에 통과시키고, 그 결과에서 스키닝된 위치를 뺀 값을 Tangent 블록에 연결하세요. 그러면 표면의 요철이 뼈대와 함께 회전합니다.
  • WebGL 2와 OpenGL ES 3.0에서는 셰이더 하나가 텍스처를 16장까지 샘플링할 수 있습니다. 조명이 자체 텍스처 10장을 샘플링하므로, 스프라이트의 텍스처 5장을 샘플링하는 Sun Forge Sprite Lit 노드나 Sun Forge Sprite Textures 노드를 쓰는 그래프는 이 플랫폼에서 텍스처를 한 장 더 샘플링할 수 있습니다.
  • Direct3D에서는 셰이더 하나가 샘플러 상태를 16개까지 사용할 수 있습니다. 조명이 자체 샘플러 상태 6개를 사용하므로, Sun Forge Sprite Lit 노드나 Sun Forge Sprite Textures 노드를 쓰는 그래프는 샘플러 상태를 5개 더 사용할 수 있습니다. Sampler State 노드 하나로 샘플링하는 텍스처는 몇 장이든 샘플러 상태 하나를 함께 사용합니다.

직접 작성한 셰이더

각 인클루드 파일은 Packages/com.konradrzonca.sunforge.lighting/Runtime/Shaders/ 폴더에 있으며, 사용 방법은 파일 헤더에 나와 있습니다.

인클루드 파일 용도
SunForgeLitColor.hlsl Sun Forge Lit Color 노드와 같은 방식으로 셰이더에 조명을 적용합니다.
SunForgeStyleKeywords.hlsl 셰이더에 스타일마다 배리언트를 하나씩, 스타일의 Quality(품질) 섹션에 있는 옵션마다 배리언트를 하나씩 만듭니다(스타일 › 스타일 품질 참조). 패스의 프라그마 옆에 #include_with_pragmas 지시문으로 인클루드합니다.
SunForgeNormalDecode.hlsl 기본 제공 머티리얼과 같은 방식으로 노멀 맵을 샘플링한 값을 읽습니다. 읽은 노멀로 조명을 적용하거나, 노멀을 직접 표시하거나 측정할 때 사용합니다.
SunForgeHeightDecode.hlsl 지오메트리 텍스처를 선언하고, 기본 제공 머티리얼과 같은 방식으로 지오메트리 텍스처를 샘플링한 값에서 높이와 앞쪽 가장자리를 읽거나 그림자 하이트 맵을 샘플링한 값에서 높이를 읽습니다.
SunForgeHeightRamp.hlsl Texture View(텍스처 보기) 행의 Geometry(지오메트리) 옵션과 같은 방식으로 높이를 색으로 표시합니다.
SunForgeHeightRampBar.hlsl SunForgeHeightRamp.DrawBar 메서드가 실행하는 Height Ramp 이름의 패스에서 그 색상 램프의 범례 막대를 그립니다.
SunForgeMist.hlsl 전체 화면 안개 같은 셰이더에서 씬의 안개를 그립니다.
SunForgeHitFlash.hlsl 피격 플래시를 그립니다.
SunForgeBakedLight.hlsl 스프라이트 자체의 발광이 그 스프라이트에 보내는 빛을 이미션 텍스처의 알파에서 읽습니다.
SunForgeWalkBands.hlsl Sun Forge가 캐릭터 주변에서 분할하는 프롭에서 직접 만든 셰이더가 맡은 조각만 그립니다.
SunForgeRendererBakeValues.hlsl 스프라이트를 그릴 때 쓰는 각도와 그 밖의 투영 값, 그리고 스프라이트가 지면 위로 얼마나 높이 서 있는지를 읽습니다.
SunForgeLightingGlobals.hlsl Lighting Setup 컴포넌트가 출력하는 값을 읽습니다.

스크립트에서 직접 조명 값을 출력하려면 SunForgeLightingPublisher 클래스를 사용하세요.

WebGPU에서 Windows용 Chrome은 런타임에 계산한 인덱스로 셰이더가 static const 배열을 읽거나, v[i]처럼 그런 인덱스로 벡터의 성분을 고르면 그 셰이더를 느리게 로드합니다. 배열이 크면 로드에 몇 분이 걸릴 수 있고, 그 뒤 플레이어가 GPU 디바이스를 잃어 아무것도 그리지 못할 수 있습니다. 대신 값을 계산하거나, 상수 인덱스로 배열을 읽거나, dot(v, float4(i == uint4(0, 1, 2, 3)))처럼 비교로 성분을 고르세요. Custom Function 노드에 작성한 HLSL도 마찬가지입니다.

WebGL 2에서 Windows용 Chrome은 요소가 50개 이상인 배열 하나만 들어 있는 상수 버퍼를 텍스처로 셉니다. 셰이더의 텍스처와 이런 버퍼를 합쳐 16개를 넘으면, 그 셰이더가 처음 그릴 때 페이지가 그리기를 멈춥니다. 배열 뒤에 두 번째 값을 추가하세요. 그 값은 아무 데서도 읽지 않아도 됩니다.

텍스처가 없는 스프라이트

스프라이트에 노멀 맵, 마스크, 이미션 텍스처, 지오메트리 텍스처 중 없는 것이 있으면, 직접 만든 셰이더는 그 슬롯에 있는 머티리얼의 텍스처를 샘플링하고, 머티리얼에도 텍스처가 없으면 프로퍼티의 기본값을 샘플링합니다. Sun Forge Sprite Textures 노드가 추가하는 슬롯에는 알맞은 기본값이 이미 들어 있습니다. 직접 작성한 셰이더에서는 Unity의 기본값이 이런 스프라이트를 잘못 그리므로 슬롯마다 다음과 같이 설정하세요.

텍스처 프로퍼티 설정 설정하지 않으면 스프라이트는
노멀 맵 _NormalMap 기본값으로 SunForge_FlatNormal.png 텍스처 기울어진 것처럼 빛을 받습니다
마스크 _MaskTex 기본값으로 SunForge_NeutralMask.png 텍스처 광택 나는 금속처럼 빛을 받거나, 금속, 평활도, 오클루전이 잘못된 채로 빛을 받습니다
이미션 _EmissionTex "black" 흰색으로 발광합니다
지오메트리 _GeometryTex "black" 높이가 범위 전체 값이 됩니다
  • 노멀 맵과 마스크: 두 텍스처는 Sun Forge 2D Lighting 패키지의 Runtime/Materials 폴더에 있습니다. 셰이더를 선택하고 인스펙터의 Default Maps 섹션에서 설정하세요.
  • 이미션과 지오메트리: _GeometryTex ("Geometry Texture", 2D) = "black" {}처럼 프로퍼티를 "black" 값으로 선언하세요.

Check Setup(설정 검사) 버튼은 _NormalMap 프로퍼티나 _MaskTex 프로퍼티에 텍스처가 없는 머티리얼을 알리며, 이 문제 항목의 수정을 적용하면 알맞은 텍스처가 지정됩니다. _GeometryTex 프로퍼티에 높이가 들어 있는 머티리얼도 알립니다.

직접 만든 셰이더

그래프는 Sun Forge Sprite Lit 노드로 만들거나, Sun Forge Sprite Textures 노드와 Sun Forge Lit Color 노드로 만듭니다(직접 만든 셰이더 › 셰이더 그래프 참조). 그런 뒤 아래 두 방법 중 하나로 사용합니다.

  • 베이크된 스프라이트에 사용. Add Component > Sun Forge > Lighting > Lighting Style Renderer(컴포넌트 추가 > Sun Forge > Lighting > Lighting Style Renderer) 메뉴로 Baked Renderer Binding 컴포넌트 옆에 Lighting Style Renderer 컴포넌트를 추가하고, Material(머티리얼) 필드를 만든 머티리얼로 설정하세요. 스프라이트는 베이크의 값을 그대로 유지합니다.
  • 베이크의 머티리얼로 사용. 만든 머티리얼을 베이크의 Prefab Material(프리팹 머티리얼) 필드(Advanced(고급) 보기)에서 선택하세요. 베이크가 Bake Camera Elevation (Degrees) 프로퍼티 같은 스프라이트의 베이크 값을 설정하므로 프리팹에 Lighting Style Renderer가 필요 없습니다.

베이크된 이펙트의 파티클은 알파와 관계없이 뒤에 있는 것에 빛을 더합니다.

  • Blending Mode 필드가 Premultiply 옵션이고 Premultiplied 포트를 Base Color 블록에 연결한 그래프는 이펙트의 이미션 텍스처에서 그 빛을 그립니다. Blending Mode 필드가 다른 옵션이면 빛은 이펙트의 색에 베이크됩니다.
  • Sprite 머티리얼이 그 빛을 그릴 수 없는 스타일에서는 베이크된 이펙트의 Particles 자식이 베이크할 때의 머티리얼을 유지합니다.
  • 직접 작성한 셰이더는 _SFEmissionScale 프로퍼티와 _SFEmissionOutsideAlpha 프로퍼티를 선언하고 One OneMinusSrcAlpha 블렌드를 사용하면 그 빛을 그립니다. 방법은 SunForgeLitColor.hlsl 파일의 헤더에 나와 있습니다.
