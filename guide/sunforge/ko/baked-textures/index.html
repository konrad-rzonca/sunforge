베이크된 텍스처

베이크가 스프라이트 시트 옆에 추가하는 텍스처, 그리고 시트가 패킹되고 임포트되는 방식.

이 페이지의 내용
  • 추가 텍스처
  • 텍스처 설정

추가 텍스처

각 추가 텍스처는 스프라이트 보조 텍스처로 시트에 연결됩니다. 노멀, 마스크, 이미션, 지오메트리 텍스처의 이름과 채널은 조명 패키지의 페이지에 있습니다(직접 그린 스프라이트 › 스프라이트 텍스처 참조). 베이크는 다음 텍스처를 추가합니다.

텍스처 보조 텍스처 이름 채널
마스크 _MaskTex 베이크의 태양이 텍셀을 비춘 곳은 A가 1, 모델 자체의 그림자 안은 0
그림자 하이트 맵 _CastHeightTex Bake Cast Height Texture(그림자 하이트 맵 베이크) 체크박스(Advanced(고급) 보기)가 켜져 있을 때 지면 투영 그림자 시트에 생깁니다. 각 텍셀의 R × range 값은 그 텍셀에 그림자를 드리우는 점 중 가장 높은 점의 높이이며, 그 점이 속한 스프라이트의 피벗에서 잰 값입니다. 본체의 피벗은 지면에 있습니다. 그림자가 덮지 않는 텍셀의 값은 0입니다. 커버리지는 그림자 시트의 알파입니다. 선형

스프라이트의 노멀 맵은 베이크 카메라 각도에서 그린 것이고, 지면 타일의 노멀 맵은 탑다운으로 그린 것입니다. range 값은 베이크의 높이 범위입니다.

이 이름 중 하나로 시트에 직접 연결한 텍스처는 베이크가 그 텍스처를 쓰는 경우 베이크의 텍스처로 바뀝니다.

URP의 셰이더 그래프 템플릿

URP의 2D Sprite Lit 템플릿이나 2D Sprite Custom Lit 템플릿으로 만든 셰이더 그래프는 마스크의 이름이 _MaskMap입니다. 베이크된 마스크를 읽으려면 그 프로퍼티의 Reference 필드를 _MaskTex 값으로 설정하세요. Custom Lit 템플릿은 노멀 맵의 이름도 _Normal_Map입니다. 그 Reference 필드를 _NormalMap 값으로 설정하세요.

Unity의 2D 광원

2D 렌더러에서 Unity Lights 머티리얼을 쓰면 채널로 마스킹한 Light 2D 블렌드 스타일은 마스크의 그 채널 값에 따라 텍셀을 비춥니다. Unity 기본 블렌드 스타일인 Multiply with Mask와 Additive with Mask는 빨간색 채널을 읽으므로, 베이크된 스프라이트에서 금속인 부분만 비춥니다. 이 블렌드 스타일이 파란색이나 알파 채널을 읽게 하거나, 마스크를 쓰지 않는 블렌드 스타일을 사용하세요. 알파 채널로 마스킹한 블렌드 스타일은 마스크에 베이크된 자체 그림자도 적용합니다. 그 밖의 경우에는 Unity Lights 머티리얼이 이 그림자를 적용하지 않습니다.

베이크된 스프라이트 위의 풀

베이크가 쓰는 지오메트리 텍스처에서 알파는 프레임의 앞쪽 가장자리입니다(지오메트리 텍스처 포맷 참조). Sorted Ground Cover 컴포넌트는 풀잎의 뿌리가 그 가장자리보다 앞에 있는 곳에서만 풀잎을 스프라이트 위에 그립니다.

이 가장자리는 지면에서 0.25 월드 단위 안에 있는 부분의 앞쪽입니다. 그래서 무기를 낮게 들고 있으면 풀이 무기 앞에서 멈춥니다. 애니메이션이 더 높이 들어 올리는 부분 위에 풀이 그려지게 하려면 Measure Sizes From(크기 측정 기준) 필드(Bake(베이크) 탭, ANIMATION(애니메이션) 섹션, Advanced(고급) 보기)에서 그 애니메이션을 체크하세요.

텍스처 설정

Filter Mode(필터 모드), Compression(압축), Use Crunch Compression(크런치 압축 사용), Generate Mip Maps(밉맵 생성), Atlas Max Size(아틀라스 최대 크기) 필드는 아키타입의 OUTPUT(출력) 섹션(Advanced(고급) 보기)에서 설정하세요. 베이크는 이 값에 따라 플랫폼마다 각 텍스처의 포맷을 고릅니다.

  • Project Settings > Editor(프로젝트 설정 > 에디터) 창의 Sprite Packer Mode(스프라이트 패커 모드) 필드가 Sprite Atlas V2 - Enabled 옵션이나 Sprite Atlas V2 - Enabled for Builds 옵션이면 아틀라스가 패킹됩니다. 그 밖의 모드에서는 각 시트가 별도의 텍스처로 빌드에 포함되며, Bake(베이크) 탭에 Use Sprite Atlas V2(Sprite Atlas V2 사용) 버튼이 나타납니다. 프로젝트의 Sprite Packer Mode 필드를 바꾼 뒤에는 이전에 베이크한 것을 다시 베이크하세요.
  • 베이크된 아틀라스의 Default(기본) 탭이나 플랫폼 탭에서 Format(포맷) 필드에 직접 지정한 값, 또는 Compression(압축) 필드가 None인 상태에서 켠 Override(오버라이드) 체크박스는 그 플랫폼에서 베이크의 포맷을 대신합니다. Format 필드를 Automatic(자동) 옵션으로 되돌리면 다음 베이크가 자체 포맷을 다시 씁니다. 지오메트리 텍스처나 그림자 하이트 맵에 직접 설정한 Format 필드는 유지됩니다.
  • 베이크는 지오메트리 텍스처나 그림자 하이트 맵을 잘못 그리게 되는 포맷을, 직접 설정한 탭을 포함해 어느 탭에서든 다른 포맷으로 바꾸고 콘솔에 알립니다.
  • Generate Mip Maps 체크박스(Advanced 보기)가 켜져 있으면, 원래 크기의 4분의 1 이하로 그려지는 스프라이트는 가장 바깥 픽셀이 빛을 더 평평하게 받고 지면에 더 가깝게 정렬됩니다.
  • 아틀라스의 Max Texture Size(최대 텍스처 크기) 필드를 더 작게 설정하면 아틀라스가 더 많은 페이지로 나뉠 뿐 용량은 줄지 않습니다.

휴대폰용 Web 빌드

Web에서 베이크는 File > Build Profiles(파일 > 빌드 프로파일) 창에 있는 Web 플랫폼의 Texture Compression(텍스처 압축) 필드를 따릅니다. 기본값인 Use Player Settings(플레이어 설정 사용) 옵션에서는 Player Settings > Web(플레이어 설정 > Web) 창의 Texture compression format(텍스처 압축 포맷) 필드를 따릅니다. DXT에서는 DXT와 BC7 포맷을 지원하지 않는 브라우저가 압축된 베이크 텍스처를 각각 원래 메모리의 4배 크기로 풉니다. 대부분의 휴대폰 브라우저가 여기에 해당합니다. 휴대폰에서 실행할 빌드는 다음과 같이 합니다.

  1. Texture Compression 필드를 ASTC로 설정합니다. ETC2도 쓸 수 있지만, ETC2에서는 키가 큰 스프라이트 가까이에 있는 광원의 빛이 스프라이트에 띠 모양으로 나타날 수 있습니다.
  2. 다시 베이크합니다.

Unity 6000.6에서는 Use Player Settings 옵션으로 빌드하거나, 포맷을 지정하지 않는 빌드 스크립트로 빌드하면 스프라이트 아틀라스의 페이지가 이전 포맷으로 들어갈 수 있습니다. Texture compression format 필드를 바꾼 뒤에는 Texture Compression 필드가 Use Player Settings 옵션인 상태에서 스프라이트 아틀라스를 선택하고 우클릭한 다음 Reimport(다시 임포트) 메뉴를 선택하세요.

한 플랫폼만 크런치 압축하기

  1. 출력 폴더의 베이크된 아틀라스마다 그 플랫폼의 탭을 열고, Override(오버라이드) 체크박스와 Use Crunch Compression(크런치 압축 사용) 체크박스를 켠 뒤 Format(포맷) 필드는 Automatic(자동) 옵션으로 둡니다. 아틀라스가 패킹되지 않는 동안에는 베이크된 스프라이트 시트에서도 같은 방법으로 설정합니다. 시트의 노멀 맵과 지오메트리 텍스처는 제외합니다.
  2. 다시 베이크합니다. 베이크는 그 플랫폼에서 아틀라스의 노멀 맵, 지오메트리 텍스처, 그림자 하이트 맵을 크런치 압축하지 않은 상태로 유지합니다.

다시 베이크해도 직접 설정한 오버라이드는 유지됩니다.
