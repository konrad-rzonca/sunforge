코드로 조명 설정

에디터 스크립트에서 씬에 조명을 설정하고, 그 씬의 스프라이트를 설정합니다.

이 페이지의 내용
  • 설정 미리보기
  • 스프라이트에 역할 지정
  • Performance 버튼 누르기
  • 스타일 저장과 조정

에디터 스크립트로 씬을 원하는 스타일로 비추고, Set Up for Lighting(조명용으로 설정) 창처럼 스프라이트를 설정하고, Fix All(모두 수정) 버튼이 하는 일을 할 수 있습니다.

using System.Collections.Generic;
using KonradRzonca.SunForge;
using KonradRzonca.SunForge.Editor;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.Rendering;

SunForgeSceneLighting.SetUp(SunForgeShippedLightingStyle.Regular);

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.SetUpSprites(art))
    Debug.Log(line);

SunForgeSceneLighting.FixAll();

// On the Universal Renderer, the sort that Fix All skips. A Custom Axis is a choice of yours, so keep it.
if (GraphicsSettings.transparencySortMode != TransparencySortMode.CustomAxis)
{
    GraphicsSettings.transparencySortMode = TransparencySortMode.CustomAxis;
    GraphicsSettings.transparencySortAxis = new Vector3(0f, 1f, 0f);
}

IReadOnlyList<string> left = SunForgeSceneLighting.Check();
foreach (string message in left)
    Debug.LogWarning(message);

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • SetUp(SunForgeShippedLightingStyle.Regular, SunForgeLightingStyleVariant.Indoor) 호출은 씬을 Regular 스타일의 Indoor 배리언트로 설정합니다.
  • 플랫포머처럼 옆에서 본 모습으로 그린 아트에서는 스프라이트를 설정하기 전에 SetUp 메서드가 반환하는 Lighting Setup 컴포넌트의 ViewElevationDegrees 프로퍼티를 0으로 설정하세요.
  • SetUpSprites 메서드는 Set Up for Lighting 창에서 Apply(적용) 버튼을 클릭할 때와 같은 일을 하고, 화면에 표시하거나 로그로 남길 줄을 반환합니다. 이 줄에는 메서드가 바꾸고 저장하는 것, 각 스프라이트가 무엇으로 설정되는지, 그대로 두는 스프라이트, 옮기는 피벗이 나옵니다. 폴더를 넘기면 그 아래의 모든 스프라이트 텍스처와 프리팹이, 게임 오브젝트를 넘기면 그 아래의 모든 스프라이트가, 스프라이트를 넘기면 그 스프라이트를 표시하는 모든 렌더러가 대상이 됩니다. 이 메서드는 피벗이 움직이는 스프라이트, 프리팹, 열려 있지 않은 씬, 그리고 피벗 이동에 맞춰 배치된 아트를 보정한 열린 씬을 즉시 저장하며, 이 저장은 Undo(실행 취소)로 되돌릴 수 없습니다. Lighting Setup은 추가하지 않고 Art View(아트 시점) 행도 설정하지 않으므로, SetUp 메서드를 호출하고 시점을 정한 뒤에 이 메서드를 호출하세요. 스프라이트마다 설정하는 방식은 시점이 정하며, 사이드 뷰에서는 피벗이 움직이지 않습니다.
  • FixAll 메서드는 Fix All 버튼이 적용하는 수정을 모두 적용하며, 창은 열지 않습니다. Set Up for Lighting 창을 여는 수정은 남겨 두므로, 그런 스프라이트는 SetUpSprites 메서드로 설정하세요. 남은 문제를 반환하며, 직접 고쳐야 하는 문제, 직접 정한 설정을 바꾸게 되어 Fix All 버튼이 건너뛰는 수정, SetUpSprites 메서드로 고칠 문제 항목이 여기에 해당합니다. 씬에 스프라이트를 넣은 뒤에 호출하고, 스프라이트를 더 추가한 뒤에 다시 호출하세요. 그림자를 드리우는 스프라이트의 Cast Shadow Field 컴포넌트처럼 스프라이트에 필요한 것을 추가합니다. Check 메서드는 남은 문제를 반환하며 아무것도 바꾸지 않습니다.
  • 이미 로드된 카메라는 그 카메라의 씬이 다시 로드될 때까지, 씬 뷰는 그 창을 다시 열 때까지 기존 정렬 방식을 유지합니다. 지금 바로 정렬하려면 로드된 각 카메라와 SceneView.GetAllSceneCameras() 메서드가 반환하는 각 카메라에도 transparencySortMode 프로퍼티와 transparencySortAxis 프로퍼티를 설정하세요.
  • 나머지 변경 사항은 열린 씬과 프로젝트 에셋에 반영되지만, 둘 다 아직 메모리에만 있습니다. 마지막 두 줄처럼 스크립트가 끝나기 전에 둘 다 저장하세요.

설정 미리보기

설정이 무엇을 바꾸는지 저장 전에 보여 주려면, 적용할 때 쓸 인수와 같은 인수로 미리보기를 실행하세요. PreviewSpriteSetup 메서드는 SetUpSprites 메서드가 반환하는 줄을 반환하며 아무것도 바꾸지 않습니다.

Object[] art = { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") };
foreach (string line in SunForgeSceneLighting.PreviewSpriteSetup(art))
    Debug.Log(line);

if (EditorUtility.DisplayDialog("Set Up for Lighting", "Set up the sprites the Console lists?", "Set Up", "Cancel"))
{
    SunForgeSceneLighting.SetUpSprites(art);
    EditorSceneManager.SaveOpenScenes();
}
  • Keep these pivots(이 피벗 유지) 토글처럼 피벗을 제자리에 두려면 두 호출 모두에 keepPivots: true 인수를 넘기세요. 이후의 실행에서도 이 선택이 유지됩니다.

스프라이트에 역할 지정

각 스프라이트 옆의 드롭다운처럼 스프라이트에 역할을 지정하려면 역할을 인수로 넘기세요. 나머지 스프라이트가 바닥을 기준으로 설정되도록 바닥을 먼저 설정하세요.

var floor = AssetDatabase.LoadAssetAtPath<Sprite>("Assets/Art/Floor.png");
SunForgeSceneLighting.SetUpSprites(new Object[] { floor }, SunForgeSpriteRole.Ground);
SunForgeSceneLighting.SetUpSprites(new Object[] { AssetDatabase.LoadAssetAtPath<DefaultAsset>("Assets/Art") });
EditorSceneManager.SaveOpenScenes();
  • 역할은 지정한 각 Sprite Renderer 컴포넌트, 지정한 각 게임 오브젝트의 Sprite Renderer, 지정한 스프라이트나 스프라이트 텍스처를 표시하는 모든 렌더러에 적용됩니다. 폴더를 지정하면 그 아래의 각 스프라이트 텍스처와 그 아래 각 프리팹의 루트에 있는 Sprite Renderer에 적용됩니다. 씬에 배치한 프리팹 인스턴스는 그 프리팹에서 역할을 받습니다. 지면일 수 있는 스프라이트처럼 창에서 설정했다면 질문이 나왔을 스프라이트는 이 메서드가 창에서 처음 표시되는 역할로 설정하며, 그 질문은 메서드가 반환하는 줄에 나옵니다. 저장하기 전에 답하려면 먼저 미리보기를 실행한 다음, 위 코드가 바닥에 하듯이 그 스프라이트를 원하는 역할로 설정하세요.
  • 창에서 설정했다면 프리팹 모드에서 열린 프리팹이나 파일이 없는 씬을 저장하라는 요청이 나왔을 경우, 플레이 모드에서처럼 Set Up for Lighting 메뉴를 실행할 수 없는 경우, 버전 관리나 읽기 전용 파일 때문에 진행할 수 없는 경우에는 이 메서드가 InvalidOperationException 예외를 던지고 아무것도 바뀌지 않습니다. 설정이 시작된 뒤에 파일이 저장되지 않거나 Unity가 예외를 던지면 IOException 예외를 던지며, 예외 메시지에 설정되지 않은 항목이 나옵니다.

Performance 버튼 누르기

스크립트는 ApplyPerformance 메서드로 Performance(성능) 섹션의 버튼을 누르며, 이 메서드는 바꾼 설정을 각각 반환합니다.

var lit = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeSceneLighting.ApplyPerformance(lit, SunForgeLightingPerformanceButton.Balanced);
EditorSceneManager.SaveOpenScenes();

스타일 저장과 조정

스크립트로 직접 만든 스타일을 저장하고, Look(모습) 섹션처럼 그 스타일을 조정할 수 있습니다(스타일 조정 참조). 다음 스크립트는 씬의 모습을 스타일로 저장하고 Pixel Outline 프로퍼티를 켭니다.

var setup = Object.FindAnyObjectByType<SunForgeLightingSetup>();
SunForgeLightingStyle style = SunForgeSceneLighting.SaveAsNewStyle(setup, "Assets/Lighting/My Style.asset");
IReadOnlyList<Material> materials = SunForgeLightingStyleEditing.EnsureOwnMaterials(style);

SunForgeLightingStyleSetting row = SunForgeLightingStyleSettings.Find("_SFPixelOutline");
foreach (Material material in materials)
{
    if (!material.HasProperty(row.Name))
        continue;

    Undo.RecordObject(material, "Set Pixel Outline");
    material.SetFloat(row.Name, 1f);
    if (row.Keyword != null)
        material.EnableKeyword(row.Keyword);
}

EditorSceneManager.SaveOpenScenes();
AssetDatabase.SaveAssets();
  • SaveAsNewStyle 메서드는 그 경로에 파일이 있으면 예외를 던집니다. 단, overwrite: true 인수를 넘기고 그 파일이 조명 스타일이면 예외를 던지지 않습니다. 이전에 저장한 스타일을 조정하려면 대신 AssetDatabase.LoadAssetAtPath<SunForgeLightingStyle> 메서드로 불러오세요.
  • 포스트 프로세싱의 경우 EnsureOwnProfile 메서드가 스타일에 프로파일의 전용 사본을 주고 그 사본을 반환합니다.
  • SunForgeLightingStyleSettings.MaterialProperties 프로퍼티는 모든 행을 나열하며, 행마다 프로퍼티의 Name 값, Tooltip 값, Group 값이 있습니다. Look 섹션에 나오는 행의 레이블은 머티리얼의 셰이더에 있는 프로퍼티 설명인 shader.GetPropertyDescription(shader.FindPropertyIndex(row.Name)) 값입니다.
  • 슬라이더의 한계는 셰이더의 한계이며, shader.GetPropertyRangeLimits 메서드로 얻습니다. SetFloat 메서드는 값을 그 한계 안에 가두지 않습니다.
  • Keyword 값이 있는 행은 두 가지가 모두 필요합니다. 프로퍼티를 설정하고, 키워드를 EnableKeyword 메서드로 켜거나 DisableKeyword 메서드로 끄세요. Switch 값이 있는 행은 그 이름의 행이 켜져 있는 동안에만 표시됩니다. Pixel Outline 행 아래의 Pixel Outline Color 행이 그 예입니다.
  • 변경하기 전에 매번 Undo.RecordObject 메서드를 호출하면 씬이 변경 사항을 바로 그립니다. 호출하지 않는다면 Lighting Setup 컴포넌트의 Publish 메서드를 호출하세요.
  • BakedArt 행은 Look 섹션에 없습니다. 해당 머티리얼에서 직접 설정하세요. Orientation 행은 그대로 두세요.
