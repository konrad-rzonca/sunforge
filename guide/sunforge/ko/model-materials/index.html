모델의 머티리얼

베이크가 모델의 머티리얼에서 읽는 것, 그리고 그 각각이 스프라이트의 텍스처에 담기는 방식.

이 페이지의 내용
  • 스프라이트와 2D 리그
  • 직접 만든 셰이더를 쓰는 모델

모델의 머티리얼은 다음과 같이 베이크됩니다.

  • 모델의 컬러 텍스처는 모델의 색으로 베이크되고, 씬이 스프라이트를 다시 비춥니다. 그래서 텍스처에 그려 넣은 빛이나 음영은 모든 스프라이트에 나타납니다.
  • 머티리얼의 Occlusion Map(오클루전 맵) 필드에 있는 맵은 마스크 텍스처에 베이크됩니다. 이 맵은 나무껍질의 골처럼 메시보다 세밀한 디테일에 사용하세요.
  • 알파로 페이드되는 머티리얼은 불투명도 절반을 기준으로 잘라 베이크되므로, 유리 같은 투명한 표면은 완전히 불투명하거나 완전히 뚫린 상태로 베이크됩니다.
  • 베이크는 머티리얼의 Render Face(렌더 페이스) 필드와 관계없이 모델 표면의 양면을 모두 그립니다. 그래서 단면 나뭇잎 카드나 망토는 뒤에서 볼 때도 스프라이트에 나타납니다.
  • 메시 자체의 버텍스 컬러는 URP의 Lit 셰이더와 Standard 셰이더가 무시하므로 베이크되지 않습니다.
  • 발광하는 부분은 트인 곳에 있을 때만 자기 모델을 비춥니다. 속이 찬 물체 안으로 밀어 넣은 부분은 아무것도 비추지 않습니다. 한 면만 렌더링하는 표면은 속이 찬 물체의 겉면입니다. 그러므로 면 한 겹으로 모델링한 전등갓 아래의 전구처럼 그런 표면 뒤에 발광이 있다면 전등갓 머티리얼의 Render Face 필드를 Both 옵션으로 설정하세요.
  • 메시, 스프라이트, 라인의 머티리얼을 바꾸거나 2D Animation 패키지의 Sprite Swap으로 스프라이트를 바꾸는 클립은 각 프레임을 그 프레임에 보이는 대로 베이크합니다. 색, 발광, 텍스처 오프셋, 컷오프처럼 클립이 머티리얼에서 애니메이션하는 값은 클립이 재생하는 대로 모든 프레임에 베이크됩니다.
  • 스크립트는 베이크 중에 실행되지 않습니다. 씬 오브젝트에서 스크립트가 MaterialPropertyBlock 객체로 렌더러에 설정한 값은 베이크할 때 오브젝트에 보이는 대로 베이크됩니다.

스프라이트와 2D 리그

  • 2D Animation 패키지로 리깅한 캐릭터는 각 프레임을 뼈대와 2D IK가 주는 자세로 베이크합니다.
  • Sun Forge 조명 머티리얼로 그리는 스프라이트에서는 Set Up for Lighting 메뉴가 스프라이트에 주는 텍스처처럼, 그릴 때 쓰는 노멀, 마스크, 이미션 텍스처를 베이크합니다.
  • Sprite Renderer에서는 스프라이트의 각 보조 텍스처가 머티리얼의 같은 이름 텍스처 대신 베이크됩니다. 셰이더 그래프에서는 그 이름의 텍스처 프로퍼티에서 Show In Inspector 체크박스가 켜져 있어야 베이크가 텍스처를 찾을 수 있습니다.
  • Sprite Renderer의 Color(컬러) 필드와 Line Renderer의 Color 그레디언트는 씬에서처럼 해당 부분에 색을 입힙니다.

직접 만든 셰이더를 쓰는 모델

직접 만든 셰이더는 다음 프로퍼티에서 베이크됩니다.

베이크가 가져오는 것 가져오는 곳
색 셰이더가 메인으로 지정한 텍스처와 색. 지정한 것이 없으면 _BaseMap 또는 _MainTex 프로퍼티와 _BaseColor 또는 _Color 프로퍼티
노멀 맵 _BumpMap 또는 _NormalMap 프로퍼티. URP의 Lit 셰이더처럼 _BumpScale 값으로 스케일됩니다
발광 머티리얼의 Emission(이미션) 체크박스, 즉 _EMISSION 키워드가 켜져 있으면 _EmissionColor 프로퍼티와 _EmissionMap 프로퍼티. 셰이더에 그런 키워드가 없으면 항상 이 두 프로퍼티

셰이더 그래프에서는 프로퍼티를 우클릭하고 Set as Main Texture 또는 Set as Main Color 메뉴를 선택하세요.

수정할 수 없는 셰이더라면 베이크 확장이 베이크용 모델 인스턴스에 이 프로퍼티 이름을 쓰는 머티리얼을 줄 수 있습니다(베이크 확장 › 확장 참조). Bake(베이크) 탭은 확장이 실행되기 전에 모델을 검사하므로 그래도 원래 머티리얼의 이름을 표시합니다.
