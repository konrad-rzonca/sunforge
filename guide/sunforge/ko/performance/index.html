성능

씬에서 각 조명 설정에 드는 비용과 그 설정을 바꾸는 곳을 확인합니다.

이 페이지의 내용
  • 설정별 비용
  • 웹 플레이어의 첫 프레임

프레임 시간이 드는 설정은 이름 뒤에 게이지가 표시되며, 어떤 비용이 드는지는 툴팁에 나옵니다. Lighting Setup 컴포넌트의 Performance(성능) 섹션에는 열린 씬에서 비용이 드는 항목이 비용이 큰 순서로 나오고, 각 줄 옆에 Select(선택) 버튼이 있습니다.

비용이 큰 설정을 한꺼번에 바꾸려면 Performance 섹션을 열고 Fastest(가장 빠름), Balanced(균형), Full(최고 품질) 버튼 중 하나를 클릭한 다음, 그 상태에서 원하는 설정을 조정하세요. 각 버튼이 바꾸는 내용은 그 버튼의 툴팁에 나옵니다.

설정별 비용

다음은 테스트 씬에서 각 설정을 켰을 때와 껐을 때를 비교해 잰 비용입니다. 데스크톱은 RTX 4060, 휴대폰은 Pixel 8a입니다. 범위는 측정값의 최솟값에서 최댓값까지를 나타냅니다. 데스크톱에서 약 0.8ms 미만인 측정값은 실행할 때마다 생기는 오차 범위 안입니다.

설정 설정하는 곳 비용 측정값
Render Scale(렌더 스케일) 각 품질 레벨의 URP 에셋 큼 데스크톱, 1920×1080, 2026-11: 0.5로 낮추면 GPU 시간 1.3~1.5ms 절약
Mist Enabled(안개 활성화) Lighting Setup 컴포넌트 또는 스타일의 Default Lighting Values(기본 조명 값) 섹션 큼 휴대폰, 2026-10: 약 40ms. 데스크톱, 2560×1440, 2026-11: 1.0~1.7ms
Pixels Per Unit(단위당 픽셀) Cast Shadow Field 컴포넌트 큼 휴대폰, 2026-10: 128 대신 64로 하면 GPU 시간 83ms 중 약 30ms 절약. 데스크톱, 2026-11: 64 대신 16으로 해도 오차 범위 안
Style(스타일) Lighting Setup 컴포넌트 중간 휴대폰, 2026-10: Cinematic 스타일은 Regular 스타일보다 크고 Flat 스타일은 작음. 데스크톱, 2026-11: Regular 스타일 대비 Cinematic 스타일 0.3~3ms, Flat 스타일 0.2~1.1ms 추가
Mode(모드) Cast Shadow Field 컴포넌트 중간 데스크톱, 애니메이션되는 캐릭터 1,000개, 2026-11: And Sprites 모드는 짝이 되는 Only 모드보다 GPU 시간 0.7~1ms, 메인 스레드 시간 0.5~1.3ms 추가
Cast Shadow Stretch Enabled(드리운 그림자 늘이기 활성화) Lighting Setup 컴포넌트 또는 스타일의 Default Lighting Values 섹션과 Hours(시간대) 섹션 중간 데스크톱, 2026-11: 측정 네 번 중 세 번에서 약 1ms, 이 설정을 켜는 키가 있는 Regular 스타일의 새벽과 해 질 녘에서 약 0.6ms
Post Processing Enabled(포스트 프로세싱 활성화) Lighting Setup 컴포넌트 중간 휴대폰, 2026-10: 약 1ms. 데스크톱, 2026-11: 최대 1.6ms
Light From Lit Ground(빛 받은 지면에서 오는 빛) 스타일의 Quality(품질) 섹션 중간 데스크톱, Cinematic 스타일, 2026-10: 0.7~1.4ms, 2026-11: 0.2~1.1ms
Exact Shadows On Sprites(스프라이트 위 정확한 그림자) 스타일의 Quality 섹션 중간 데스크톱, 2026-11: 측정 네 번 중 세 번에서 0.5~2.2ms
Mist Height(안개 높이) Lighting Setup 컴포넌트 또는 스타일의 Default Lighting Values 섹션 작음 높이가 클수록 커짐. 단독으로는 측정하지 않음
Ground Radius(지면 반지름) Light Source 컴포넌트, 그리고 Scene Lights 컴포넌트의 Intensity(강도) 필드 작음 데스크톱, 2026-11: 테스트 씬의 광원은 오차 범위 안
Sorted Ground Cover 풀 시트에 있는 해당 컴포넌트 작음 데스크톱, 2560×1440, 캐릭터 1,000개, 2026-11: 0.3~0.5ms

데스크톱(2026-11)에서 Cloud Strength(구름 강도) 필드, Canopy Shade Strength(Canopy Shade 강도) 필드와 Lighting Setup 컴포넌트의 Sprite Emission Enabled(스프라이트 이미션 활성화), Ambient Occlusion Enabled(앰비언트 오클루전 활성화), Self Shadow Enabled(자체 그림자 활성화) 체크박스는 측정할 만한 비용이 들지 않았습니다. 휴대폰(2026-10)에서 구름, 캐노피 그늘, 앰비언트 오클루전의 비용은 각각 1ms 이하였습니다.

웹 플레이어의 첫 프레임

웹 플레이어에서는 조명 스타일이나 스타일의 머티리얼을 처음 그리는 프레임이 브라우저가 셰이더를 준비하는 동안 몇 초씩 걸릴 수 있습니다. Windows의 Chrome에서는 WebGPU에서 약 2~3초, WebGL 2에서 약 7~13초입니다. 로딩 화면이 표시되는 동안 이 준비를 미리 끝내려면 다음과 같이 합니다.

  1. 게임에서 쓰는 스타일로 하나씩 전환하고, 스타일마다 그 스타일의 모든 머티리얼로 스프라이트를 하나씩 그립니다. 비활성 오브젝트의 머티리얼과 나중에 스폰할 프리팹의 머티리얼도 포함합니다.
  2. Sprite Skin 컴포넌트로 애니메이션되는 캐릭터가 하나라도 있고 Project Settings > Player(프로젝트 설정 > Player) 창의 GPU Skinning(GPU 스키닝) 필드가 CPU 옵션으로 설정되어 있지 않으면, 그 캐릭터가 하나도 활성화되지 않은 상태에서 한 번, 활성화된 상태에서 한 번 이 작업을 합니다.
  3. 스타일의 Quality(품질) 섹션 설정에 따라 어떤 옵션이 일부 품질 레벨에서만 그려지고 게임이 실행 중에 품질 레벨을 바꾼다면, 그 옵션을 그리는 레벨과 그리지 않는 레벨에서도 각각 그 스타일을 그립니다.
