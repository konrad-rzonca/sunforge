Unity 2D day and night cycle and cloud shadows

In a 2D URP scene, a day and night cycle is a Global Light 2D whose color follows a Gradient over the time of day. A Volume grades the picture at night, lamps fade in after dusk, and a scrolling cloud texture shades the ground. The steps below are for Unity 6.3.

Unity 2D day night cycle with a Global Light 2D

A Light 2D with Light Type set to Global lights all 2D GameObjects equally. Change its color and every lit sprite changes with it.

  1. Keep your sprites on the Sprite-Lit-Default material, which new sprites get by default. 2D lights do not affect Sprite-Unlit-Default.
  2. Right-click in the Hierarchy, select Light and pick the global 2D light, or pick any 2D light and set its Light Type to Global. Unity allows one global light per blend style and sorting layer.
  3. Add the script below to any GameObject and assign the light. In its Light Color gradient, put midnight at both ends and noon in the middle.
  4. Enable Post Processing on the camera. Choose GameObject > Volume > Global Volume, click New for a profile, then Add Override and pick Color Adjustments. Set it to your night look, such as a lower Saturation. Assign the Volume to the script, which sets its Weight.
  5. Add a Spot Light 2D for each lamp or fire, and list them in the script. Tutorials for older versions call this light a Point light.
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class DayCycle : MonoBehaviour
{
    public Light2D globalLight;
    public Gradient lightColor;   // the same color at both ends
    public AnimationCurve night;  // 1 at time 0 and at 1, 0 by day
    public Volume nightVolume;
    public Light2D[] lamps;
    public float lampIntensity = 1f;
    public float dayLengthSeconds = 600f;
    public float time;            // 0 and 1 are midnight, 0.5 is noon

    void Update()
    {
        time = Mathf.Repeat(time + Time.deltaTime / dayLengthSeconds, 1f);
        float n = night.Evaluate(time);

        globalLight.color = lightColor.Evaluate(time);
        nightVolume.weight = n;
        foreach (Light2D lamp in lamps)
            lamp.intensity = lampIntensity * n;
    }
}

Traps in a 2D day and night cycle

  • The loop at midnight. Gradient.Evaluate takes a time from 0 to 1, and the script wraps the time back to 0 at midnight. If the gradient's first and last colors differ, the scene jumps there. Give both ends the same color, and the night curve the same value. A Gradient takes at most 8 color keys, so choose which hours get one.
  • Lights that pop on. A lamp enabled at a fixed hour appears in one frame. The script sets each lamp's intensity from the night curve instead, so the lamps come up as the curve rises.
  • Glowing things that dim. The global light darkens every lit sprite, a window or a flame included. Draw the glowing parts as separate sprites with the Sprite-Unlit-Default material. In the Volume, Color Filter and Post Exposure change the whole picture, glowing parts included. Put the night's darkness and tint in the light's color, and use the Volume for saturation and contrast.
  • Bloom thresholds. Bloom is off until its Intensity is above 0. It then applies only to pixels brighter than its Threshold, 0.9 by default. A glow on a lit sprite falls under the threshold at night, another reason to draw it unlit. A Light 2D Intensity above 1 brightens sprites beyond their own color, so at noon a pale wall can pass the threshold and bloom.

Unity 2D sunlight: what a Global Light 2D cannot show

A global light has no direction. It lights everything equally, and its Inspector has no Normal Maps and no Shadows sections. Noon and dusk then differ only in color: no side of a sprite is brighter than another, and nothing casts a shadow.

To show where the sun is, you need both of these:

  1. A normal map on each sprite. In the Sprite Editor, open Secondary Textures and add it under the name _NormalMap (the steps).
  2. A light with a position. Add a large Spot Light 2D, under Normal Maps set its Quality to Fast or Accurate, and move or turn it from the script over the day.

Unity's Happy Harvest sample lights its day this way, with a large Spot light that a script turns. Unity names two costs: normal maps add a full-size render pass per layer batch, and one large light can cost more than several small ones.

Shadow Caster 2D shadows come from lights like that one, never from the global light. For the sun's shadows, Happy Harvest uses stretched blob sprites, which a script turns and lengthens over the day. Shadows for 2D and top-down sprites compares the ways.

Unity 2D cloud shadows

Two ways use only Unity's own tools:

  • A scrolling overlay. Put a dark, soft cloud texture on a Sprite Renderer that sorts above the ground. Set its Draw Mode to Tiled so the texture repeats over the view, and give it the Sprite-Unlit-Default material. Move it each frame and wrap its position by one tile. It darkens everything drawn under it, lamp light and glowing sprites included.
  • A light that subtracts. In the 2D Renderer asset, under Light Blend Styles, set one style's Blend Mode to Subtractive. Add a Light 2D with Light Type set to Sprite, give it the cloud texture as its sprite, pick that blend style, and move it the same way. It takes light only from lit sprites on its Target Sorting Layers, so unlit glows keep their brightness.

With either one, fade the clouds by the night curve too, through the overlay's color or the light's intensity. Otherwise the shadows are as dark at midnight as at noon.

How Sun Forge 2D Lighting does it

Sun Forge 2D Lighting is a lighting package for URP, under the 2D Renderer or the Universal Renderer. It has a sun, a moon, a sky and weather from day to night. To light sprites you drew, select them, right-click and choose Sun Forge > Set Up for Lighting. A normal map of your own gives them form. Without one, a sprite is lit as a flat surface.

Time Of Day on the Lighting Setup sets the hour, from 0 to 24, and the lighting style sets the light at each hour. To run a day from a script, set SunForgeLightingSetup.TimeOfDay in Update. The lighting draws live in Edit mode, Play mode and a player, so the sprites relight as the hour changes.

  • At night, moonlit surfaces turn blue while firelight and glows keep their color.
  • A light can be a point, a spot, a line or a rectangle, and can flicker like fire. A Unity Light 2D can drive a Sun Forge Light Source, and it keeps lighting Sun Forge's Unity Lights material.
  • The sky adds drifting cloud shadows and ground mist. In a side view neither shows, because a side view shows no ground for them to lie on.

Shadows fall in the sun direction they were baked or drawn for and do not turn as the sun moves. They fade as the sun sets.

It needs Unity 6.3 LTS (6000.3.29f1 or newer) through Unity 6.6, and URP.
