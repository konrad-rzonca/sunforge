Unity 2D lights not working: what to check

Unity's 2D lights belong to the Universal Render Pipeline (URP) and work only under its 2D Renderer. When a light does nothing, check the settings below in this order. Menu names are Unity 6.3's.

Unity 2D lights grayed out in the menu

What you see: the 2D lights under GameObject > Light cannot be clicked, or a Light 2D's Inspector shows only "2D renderer data must be assigned to your universal render pipeline asset or camera."

Why: the project has no URP Asset and runs the Built-In Render Pipeline, or the default renderer of its URP Asset is the Universal Renderer.

  1. In the Project window, choose Create > Rendering > URP Asset (with 2D Renderer). Unity creates a URP Asset and a 2D Renderer asset.
  2. Open Edit > Project Settings > Graphics and set Default Render Pipeline to the new URP Asset.

To keep a URP Asset you have, create a renderer with Create > Rendering > URP 2D Renderer, add it to the asset's Renderer List and choose Set Default for it.

A quality level names another URP Asset

What you see: Graphics settings are right, and the lights are still disabled or do nothing.

Why: each quality level has a Render Pipeline Asset field. When it is set, Unity uses that asset at that level instead of the one in Graphics settings.

  1. Open Edit > Project Settings > Quality.
  2. Select each level in turn and read Render Pipeline Asset.
  3. Clear the field, or set it to a URP Asset that uses the 2D Renderer.

Unity 2D light not affecting a sprite

What you see: some sprites keep their full brightness whatever the lights do, often those made before the project moved to URP.

Why: a 2D light changes only materials made for it. Sprite-Lit-Default is one. Materials from the Built-In Render Pipeline, such as Sprites-Default, and Sprite-Unlit-Default do not react.

  1. Select the sprite.
  2. In its Sprite Renderer, set Material to Sprite-Lit-Default.

To convert a whole project, back it up, open Window > Rendering > Render Pipeline Converter, pick 2D Converters > Built-in to 2D URP Material Upgrader and run Material and Material Reference Upgrade. Start a shader of your own from Create > Shader Graph > URP > Sprite Lit Shader Graph.

The light's Target Sorting Layers leave the sprite out

What you see: a light reaches some of the sprites it covers and not others.

Why: a Light 2D lights only the sorting layers in its Target Sorting Layers. A new light targets all of them. A light in a scene or prefab that was not open when you added a sorting layer does not have the new layer.

  1. Select the sprite and read Sorting Layer on its Sprite Renderer.
  2. Select the light and add that layer to Target Sorting Layers.

The light's Z position does not matter: a 2D light lights a sprite at any distance in front of or behind it.

Everything outside the light is black

What you see: the scene looked normal until you added a light. Now only that light's area shows.

Why: while a scene has no Light 2D, Unity draws its sprites in their own colors. From the first light on, a sprite shows only the light that reaches it. A Global Light 2D lights every sprite on its target layers equally.

  1. Choose GameObject > Light > Global Light 2D.
  2. Set its Color and Intensity to how the scene should look away from every other light.

Unity allows one global light per blend style and sorting layer. With two, the Console shows "More than one global light on layer". Delete one, or give each its own Target Sorting Layers.

Unity Light 2D not showing: blend style and intensity

What you see: everything above is right, and the light still changes nothing.

Why: lights that overlap add up. Under the Multiply blend style a total of 1 shows a sprite in its own colors, and more than 1 pushes it past them. A white global light at 1 leaves the other lights little to show.

  1. Lower the global light's Intensity, for example to 0.3.
  2. Check the other light's Blend Style. Multiply with Mask (R) and Additive with Mask (R) light a sprite only where the red channel of its mask map is above 0.

Unity 2D normal map not working

What you see: the sprite is lit, and its normal map makes no difference. Check these in order, and see Sprite normal maps in Unity for the full steps:

  1. The light. Under Normal Maps, set Quality to Fast or Accurate. A new light has it at Disabled. A Global Light 2D has no such setting, so add a spot, freeform or sprite light.
  2. The name. Select the sprite's texture, click Open Sprite Editor, switch to Secondary Textures and check that the normal map is listed as _NormalMap.
  3. The import. Select the normal map and set Texture Type to Normal map.
  4. The layout. Unity reads the normal map with the sprite texture's UV coordinates, so each frame must sit at the same place in both textures.
  5. The material. Sprite-Lit-Default reads the normal map. In a Shader Graph of your own, connect it to Normal (Tangent Space).
  6. The distance. Lower Distance under Normal Maps. The light then acts as if it were closer and lights the detail from a lower, more grazing angle.
  7. The atlas. Select the Sprite Atlas and use the dropdown at the top right of its preview to display the packed secondary textures. Sprites packed together should have the same number of them.

Lights show in the Game view but not in the Scene view

The Scene view has its own lighting switch, the lightbulb button in its toolbar. While it is off, the Scene view draws sprites without your 2D lights. Turn it on. The Game view and builds do not use it.

Unity Light 2D not showing in a build

What you see: the lights work in the editor and not in the player.

Why: the editor uses the quality level highlighted in Project Settings > Quality. A build starts at its platform's default level, the green checkbox in that platform's column, which may name another URP Asset. A build also includes only the URP Asset of Graphics settings and those of the levels enabled for its platform. If none of them has a 2D Renderer, Unity strips the 2D lighting pass from the build's shaders.

  1. In Project Settings > Quality, check Render Pipeline Asset on every level whose checkbox is on for your platform.
  2. If you use build profiles, check the profile: it can override the Graphics settings for its platform.
  3. Turn on Strict shader variant matching under Project Settings > Player > Other Settings and build again. A missing shader variant then draws with the error shader and is named in the log.

2D lighting under the Universal Renderer

Sun Forge 2D Lighting is a separate lighting package that works under both the 2D Renderer and the Universal Renderer. A scene's lighting sets up from one menu item and Fix All, and a Unity Light 2D can drive a Sun Forge Light Source.
